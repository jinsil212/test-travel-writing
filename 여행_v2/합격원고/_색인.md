## 장 구성 공식 (뼈대 전문을 읽기 전 미리보기용, 지역명 없음)

- **F01 절차형 교통:** 도입 → 돈 아끼는 법(요금·상한·결제수단 고정·일행) → 방향 → 급행·완행 같은 헷갈리는 구분 → 갈아타기·실수 복구 → 조심할 것·인터넷 → 들어갈 때·나갈 때 → "꼭 기억하실 건 세 가지" → CTA
- **F02 티켓 구매형:** 도입(알고 계셨나요→방법 N 예고→가장 추천은 마지막) → 현지 방법 시간순 N(방법→단점) → "실제 일정에 넣어 보면 얘기가 달라져요" → 상품(이유 셋) → 정가 직접 구매 비추천 → 정리 → 고정 댓글
- **F03 추천형:** 도입(큰돈 날리는거죠→N개+기준 N개) → 대상이 특별한 이유 → 기준 설명 → 카드 N(한마디→사실→장점→기준 대조→아쉬운 점→"~라면 ○○ 추천합니다"→금액→옵션) → "왜 ○○은 빠졌지?" → 상황별 한 문장 정리 → 예고 → CTA
- **F04 목록형:** 도입(막막→경험 나열→위치·매력·스타일별·비행시간 예고) → 권역 개요 → 권역별 도시 카드(위치→볼거리 1~2→경험 한 줄→"~분께 잘 맞아요"→"반대로") → 스타일별 추천 → 비행시간 순 정리 → CTA
- **F05 코스형:** 도입(고민되시죠→당연해요→경험→"오히려 좋아 마인드"→코스 N) → 코스 N(아침→점심→오후 선택→저녁, 요일 체크) → 상품 → 활용법(예보·취소 말고 변경) → 정리 → CTA
- **F06 비교형:** 도입(막막하시죠→왜 여기만 고민→"알고계신가요?" 손실 예→기준 N 예고+바로 시작 한 문장) → 대상 소개 → 대상별 장(경험)·단·체크, 말로 전환 → 기준 N → "처음이라면 ○○" → 꿀팁(섞기·나눠 잡기) → 상품(고정 댓글·할인) → CTA
- **F07 선택형:** 도입(고민되시죠→다 가 봤다→기준까지 알려드릴거에요) → 순서 안내 → 위치·교통·비용 → 도시 카드 N(한 줄→경험→일정→아쉬운 점→추천 대상) → "어느 쪽이 더 끌리세요?" → 기준 2 → 못 정하면 → "꼭 가야 할까?" → 출발 전 확인 3 → 상품 → 정리 → CTA
- **F08 매장형:** 도입(사오는 편이신가요→여기는 한 번 오기 쉽지 않다→N곳→공항 뺏김 손실→사 올 것·두고 올 것 예고) → 매장 카드 N(왜→대표 품목→먹을 것→시즌/멤버십) → 두고 올 것 → 정리(한 곳만이면·틈틈이·숫자 두 개) → CTA
- **F09 절차 단독:** 도입(상황→난감하시죠→생각해보세요→말이 안 되잖아요→곳·요금·예약 예고→직접 이용한 곳도) → 첫 확인(숙소) → 속마음 질문(락커?) → 선택지 N(경험→위치→예약→요금→시간→환불) → 맡기기 전 할 일 → 고르는 기준(위치→금액→시간) → 꿀팁 → 정리 → 마무리
- **F10 쇼핑+교통:** 도입(후기 득템→가는 법에서 막히시죠→총정리 예고) → 브랜드 → 위치·가는 법 → 셔틀 비교→상품 이티켓 → 예약~탑승 순서 → 할인 → 세금·면세 → 꿀팁 N → 정리 → 감사

## 비고

- F10은 손수정 전이라 `[각색]`·"안내돼 있어요"·조사 과정 문장이 남아 있다. 문체 견본으로 쓰지 않는다.
- 손수정본 오타(F05 "예버서·당아요", F06 "여햄·은금히", F04 "열 간·올께요")를 따라 쓰지 않는다. F01 "옴니 카드 금액은 3달러"는 사용자 삽입 문장이며 공식과 달라 사실 견본이 아니다.
