# 문체카드 — 사용자 최종본 10편(합격원고 F01~F10)에서 뽑은 쓰는 법 한 장 (슬림화 전 판, 2026-10-21 보관 — 비교용, 사용하지 않음)

근거: 2026-10-20 분석 보고서 2~5장·9-5. 인용은 전부 합격원고의 실제 구절(괄호 안 번호). **이 카드가 말투의 유일한 기준**이다. **규칙 문장에는 지역명이 없다.** 뉴욕·미국은 예시일 뿐이고, 다른 나라·다른 도시 주제도 같은 틀(공감 질문 → 왜 고민인지 → 오늘 알려 줄 것 → 본론 → 정리 → CTA)로 쓴다. 인용 속 "뉴욕"은 그 주제의 지역명으로 바꿔 읽는다. 벤치마크(타이거투어) 말투 장치(5단계 훅·역설적 비추천·손실 회피·브릿지 상투구·"저희→저" 근거 붙이기)는 가져오지 않는다.

## 1. 도입 틀 (3~5문단, 350~600자)

순서는 고정, 각 단계 1~2문장. 프레임(기준 N개의 내용)은 도입에서 **선언하지 않는다**. 결과만 약속한다.

| 단계 | 하는 일 | 실제 구절 |
|---|---|---|
| ① 상황 공감 질문 | 시청자가 지금 겪는 막막함을 질문으로 | "지하철 타는거 왠지 막막하고 걱정되지않나요?"(F01) · "짐을 어디에 맡겨둬야하나 난감하시죠?"(F09) · "뭘로 예약하는게 좋을까 막막한 분들 많으시죠?"(F06) · "보는 사람마다 낸 표값이 제각각이라는 거 알고 계셨나요?"(F02) |
| ② 공감 확장 | 왜 그게 고민인지 한 문장. 시청자 입장 서술 | "큰맘 먹고 멀리 가는 여행인데, 비 때문에 하루를 날릴까 봐 걱정되는게 당연해요."(F05) · "그시간동안 캐리어를 끌고 다닌다고 생각해보세요. … 반나절만 끌고 다녀도 진이 다 빠질거예요."(F09) · "그렇다고 가격만 보고 제일 싼 곳을 덜컥 잡았다간 여행 내내 숙소 때문에 고생할 수 있다는 사실 알고계신가요?"(F06) |
| ③ 내 경험 한 줄 | **주제와 직접 관련된 것만.** `내경험.md`에 그 지역·그 주제 경험이 없으면 이 칸을 빼고, 필요하면 "다녀온 분들 후기를 보면 ~" 같은 **조사 기반 한 문장**으로 대체한다(다른 지역 경험을 끌어오거나 각색하지 않는다. 조사 과정 서술은 여전히 금지). 체류 기간·숙소 위치 같은 신뢰 근거용 경험 금지 | "저도 뉴욕에서 지하철 정말 많이 타봤는데요, 처음에는 복잡하고 정신이 없어서 긴장하고 다녔는데 확실한 정보만 딱 익히고나니 그다음부터는 정말 수월하더라고요."(F01) · "저도 처음 뉴욕에 도착한 날 비가 왔는데요"(F05) · "저는 세곳을 다 가 봤는데요"(F07) |
| ④ 오늘 내용 예고 | "오늘 영상에서는 A, B, C까지 한번에 정리해 드릴게요" — **3덩어리 이내** | "가장 먼저 교통비 절약 방법, 그 다음으로 지하철 타는 방법과 열차 안에서 조심할 것, 마지막으로 여러 꿀팁까지 듬뿍 다 담았어요."(F01) · "뉴욕에서 체크아웃한 뒤 짐을 맡길 수 있는 곳과, 요금과 예약 방법까지 한번에 정리해 드릴게요."(F09) |
| ⑤ (선택) 시작 멘트 | 앞 문장에 **붙여서**. 매 편 고정 멘트 아님(F05·F04 마무리형·F01 등 생략 가능) | "제가 직접 이용했던 곳도 알려드릴테니 바로 시작해볼게요!"(F09) · "…영상 다 보시면 어떤 숙소가 나한테 가장 잘 맞는지 선명해질거에요, 그럼 바로 시작해 볼게요!"(F06) |
| (선택) 기준일 확인 | 영상당 **한 번만**, 도입 또는 해당 장에 | "요금이랑 규정은 2026년 10월 기준으로 교통기관 공식 안내에서 하나씩 다시 확인했고요."(F01) · "2026년 시월 기준으로 공식 홈페이지에서 체크한 사항이지만 이후 휴관일 등은 변경이 있을 수있으니 가기 전에 공식 사이트에서 한번 더 확인해 주세요."(F05) |
| (선택) 고정 댓글 예고 | 상품·링크가 있으면 도입 끝에 | "오늘 소개하는 앱과 사이트, … 티켓 예약 링크는 고정 댓글에 한 번에 정리해 둘게요."(F02) |

**도입에서 지워진 문장 유형:** "영상 끝까지 보시면 ~하실 수 있을 거예요"(보상 약속), "결론부터 말씀드리면 ~", 순서 안내가 5덩어리 넘는 것, "어디를 갈지는 딱 두 가지만 정하면 쉽게 답이 나와요. 하나는…"(프레임 선언), 조사 과정("공식 안내를 하나하나 비교해 봤고", "후기 마흔 편").

## 2. 본론 뼈대 (합격원고 공통 큰 틀)

1. (비교형이면) 대상 짧은 소개 한 문단 — "본격적으로 비교하기 전에 오늘 비교할 이 세곳에 대해 간략하게 짚어볼게요."(F06)
2. **본론 N개 — 가장 중요한 것부터.** "순서는 실제로 도움이 되는 내용부터 알려드릴건데요"(F01). 각 본론은 아래 공식 중 하나:
   - **장단점형**(숙소·도시·작품): 한 줄 요약 → 장점(경험 한 줄 포함) → 단점/주의 → 체크 포인트 → **"~분들에게 추천해요"**(F06·F07·F03)
   - **도시 카드형**(F04): 위치 → 대표 볼거리(요금 1~2개) → 경험 한 줄 → "그래서 ○○은 ~분께 잘 맞아요" → "반대로 ~분께는 조금 심심하게 느껴질 수 있어요"
   - **절차형**(F09·F01·F10): 첫 번째 할 일 → 물어볼/확인할 것 N개(짧게) → 안 될 때 → 다음 선택지 → 요금·시간·예약 방법 → "꼭 보셔야 할 게"
   - **하루 코스형**(F05): 아침 → 점심 → 오후(취향 둘 중 하나) → 저녁 → 요일·우산 같은 체크 포인트
3. 중간에 **상황 한번 돌아보기**: "여기까지 들으셨을 때 어느 쪽이 더 끌리세요? … 마음속으로 한 곳만 정해 두시고 마지막 도시를 들어 보세요."(F07) · "여기까지가 현지에서 싸게 사는 세 가지예요. … 그런데 이걸 실제 여행 일정에 넣어 보면 얘기가 달라져요."(F02)
4. **기준 N개 / 애매할 때 추천 / 꿀팁**: "첫번째 기준은 혼자만의 공간이에요. … 하시는 분들은 호텔로 가시면 돼요."(F06) · "아직도 잘 모르겠다, 뉴욕이 처음이라면 호텔 혹은 한인민박 소규모의 이삼인실 정도 추천해요."(F06) · "일정이 빠듯해서 한 곳만 갈 수 있다면 트레이더조를 추천해요."(F08)
5. **상품 자리**(있을 때만, `상품목록.md`): 현지 방법 다 설명 → "그래서 제가 가장 추천하는 게 네번째 방법이에요."(F02) → 이유 2~3 → "링크는 고정 댓글에 넣어 둘게요." 또는 마무리 직전 한 문단 "제가 마이리얼트립에서 오늘 말씀드린 조건에 맞는 ○○을 직접 한번 추려 봤어요. 고정 댓글에 정리해 뒀으니까 꼭 확인해 보세요."(F06)
6. **정리** (짧게, 없는 편도 있음): "꼭 기억하실 건 세 가지예요. 결제수단은 하나로 정해서 끝까지 쓰기, 열차는 종착역 이름을 보고 타기, 급행인지 완행인지 한 번 더 보기."(F01) · "다시 한번 정리하면, 맡길 곳은 먼저 위치를 보고, 그다음 금액을 보고 고르면 돼요."(F09)
7. 마무리 → 4번 틀.

**항목 공식(축약 금지):** 본론 항목마다 ① 사실 → ② 왜 그런지 한 문장 → ③ 예시 하나 → ④ 할 행동. 최종본은 항목을 이렇게 푼다: "같은 번호 열차라도 중간에서 끝나기도 하고, 가다가 길이 갈라져서 다른 곳으로 가는 열차도 있어요.(사실) / 그래서 저는 종착역 이름을 꼭 보고 타시는 걸 추천해요.(행동) / 예를 들어 1선은 위쪽 끝이 밴코틀랜드 파크예요. 그러니까 타임스스퀘어에서 센트럴파크로 갈때 밴코틀랜드 파크라고 적힌 열차가 들어오면 안심하고 타셔도 되는 거죠.(예시)"(F01) · "이걸 모르고 이것저것 찍다 보면 상한 혜택은 못 받고, 탈 때마다 정가 3달러씩 계속 내게 되거든요.(이유) 그래서 타기 전에 가장 먼저 어떤 결제수단을 쓸지부터 정하셔야 해요.(행동)"(F01). 사실만 던지고 넘어가면 짧고 얕아진다(hold-out 초안이 그랬다).

섹션마다 **개인 입장 1문장**이 들어간다("저는 ~추천해요", "개인적으로 ~", "저는 종착역 이름을 꼭 보고 타시는 걸 추천해요"(F01), "저는 개인적으로 메트를 더 좋아하는데요"(F05)). 편당 "추천" 2~10회, "저는/저도/제가" 3~9회.

**한 편 = 한 질문.** 곁가지·예외·플랜B·다른 영상 내용 요약은 넣지 않는다. 다른 편은 한 문장으로만 가리킨다: "표를 싸게 사는 방법이나 원하는 자리에서 보는 방법은 따로 영상으로 소개할 거예요."(F03)

## 3. 장 전환 문장 (말로 넘긴다 — 꼬리표·소제목 낭독 금지)

| 상황 | 실제 구절 |
|---|---|
| 다음 항목으로 | "두번째는 워싱턴 디씨에요. 박물관이 잘 되어 있고, 미국 수도니까 의미가 크죠."(F07) · "자, 그럼 가장 먼저 보스턴부터 소개할게요."(F07) · "이제 갈아타는 방법이에요."(F01) · "네번째 작품은 시카고예요."(F03) · "두 번째는 타겟이에요. 트레이더조가 ~사는 곳이라면, 타겟은 ~"(F08) |
| 앞 장 닫고 질문으로 | "여기까지가 한인민박이구요. 그럼 방을 나눠 쓰는 건 똑같은데, 한국어 대신 영어 기반인 호스텔은 어떨까요?"(F06) · "그럼 반대로 돈을 더 내고 나만의 공간을 쓰는 호텔은 어떨까요?"(F06) · "그럼 요금은 얼마일까요?"(F09) |
| 다 봤으니 | "자, 이렇게 세 곳의 장단점을 다 봤는데요."(F06) · "동부를 봤으니까, 이제 따뜻한 남쪽으로 내려가 볼게요."(F04) · "본토는 다 봤으니까 마지막으로 바다를 건너가 볼게요."(F04) · "여기까지가 열세곳이에요."(F04) |
| 더 중요한 것으로 | "가장 중요한 교통비 아끼는 법을 알려드렸으니, 이제 타는 방법을 중요한 것부터 볼게요."(F01) · "표 준비가 끝났으면, 이제 아울렛 안에서 더 싸게 사는 방법을 볼게요."(F10) |
| 시청자 속마음 받기 | "근데 아마 유명한 작품 중의 하나인 해밀턴은 왜 빠졌지? 라고 생각하실 수 있는데요."(F03) · "그럼 기차나 지하철역에 있는 코인 락커에 넣으면 되지 않을까 싶으실 텐데요. 뉴욕은 한국과 달라요."(F09) · "그럼 이런 생각이 드실거에요, 아무곳이나 나가서 밖에서 다시 그 출구쪽 찾아가면 안되나?"(F01) · "그런데 코스트코는 회원카드가 있어야 들어갈 수 있지 않나 싶으시죠? 맞아요."(F08) |
| 마무리 들어가기 | "마지막으로 상황별로 한 번만 더 정리해 드릴게요."(F03) · "정리해 드릴게요."(F07) · "마지막으로 가시기 전에 알아 두면 좋은 꿀팁을 한 번에 모아 드릴게요."(F10) |

쓰지 않는 전환: "해주고 싶은 얘기가 너무 많아서 영상이 길어졌는데", "결론부터 말씀드리면", "그럼 ~는 어떨까요?"만 반복하기, `[기차]`·`[이런 분께]` 꼬리표, `▷ 화면용 표`.

## 4. 마무리 틀 (3~5문장)

정리 1~2문장 → (다음 영상 예고 1문장, 있을 때) → 좋아요·구독·댓글 후기/공유 요청 → "감사합니다 / 즐거운 {지역} 여행 되세요". **요약 반복 금지**(본문에서 한 말을 다시 풀지 않는다).

- "영상이 도움이 되었다면 좋아요와 구독 부탁드릴게요. 그럼 즐거운 뉴욕 여행 되세요. 시청해 주셔서 감사합니다."(F01)
- "도움이 되셨다면 뉴욕 여행을 앞둔 친구에게 영상 공유해주시고 좋아요와 구독은 큰 힘이 됩니다 감사합니다."(F05)
- "제 경험을 바탕으로 한 추천이라 사람마다 느낌이 다를 수 있으니, 참고하시고 다녀와서 댓글로 후기알려주세요. 도움이 되셨다면 구독과 좋아요 부탁드려요. 그럼 즐거운 여행 되세요."(F07)
- "구독과 좋아요, 하이프로 다음에도 더 좋은 영상 가지고 올께요. 감사합니다."(F04 — '하이프로'는 채널 호칭)
- "다음 영상에서는 ~알려 드릴 테니, 꼭 확인해 보세요. … 도움이 되셨다면 좋아요와 구독 한 번씩만 눌러 주세요. 그럼 즐거운 여행 되세요."(F03)

교체된 Claude 마무리: "뉴욕 마지막 날까지 가볍게 즐기시고, 안전하게 돌아오세요!", "그럼 즐거운 뉴욕 여행 되세요!"만 있고 CTA 없는 것, "정리하면, 도시의 활기가 좋다면 동부의 뉴욕, 바다 보며 느긋하게…"(요약 반복).

## 5. 어미

**넣는 어미(구어):** "~답니다"("교통비가 엄청나게 많이 나왔답니다" F04), "~구요"("필라델피아는 자동차로 다녀왔구요" F07), "~거든요", "~죠?"("뉴욕에서는 거의 지하철을 메인으로 타고 다니게 되실 텐데요" F01), "~잖아요"("한국에서도 그렇게 많이 하시잖아요" F01), "~않나요?"("극장 안에서 보내는 건 오히려 분위기 있지않나요?" F05), "~는 사실 알고계신가요?"(F06), "~더라구요"("둘러보니 맨하튼 내에서 위치가 정말 많더라구요" F09), "~더라고요", "~는데요,"로 문장 이어 붙이기.
**추천은 바로:** "~추천해요", "~추천합니다", "~추천드려요"(F03 "아이와 함께 가는 첫 브로드웨이라면 라이온 킹 추천합니다").
**줄이는 어미:** "~라고 생각해요"(초안 41편에 49회 → 사용자 글에는 편당 1~3회), "~추천드리고 싶어요"(22회 → "~추천해요"로), "~인 것 같더라고요" 남발.
**단정해도 된다:** 확인된 사실은 헤지 없이. "메트는 수요일에 문을 닫아요", "매일 열어요".

## 6. 지우는 문장 유형 (초안에 쓰지 않는다)

**지우는 범위는 이 표의 유형뿐이다.** "왜 그런지 한 문장", "예시 하나", "실수하면 어떻게 되는지 장면"은 설명이 아니라 내용이라 깎지 않는다. 최종본이 지운 건 **출처 표현·조사 과정·제도 블록·되풀이**이지 **이유와 예시**가 아니다. 애매하면 남기고 점검표에 "유지 이유"를 적는다.

| 유형 | 지워진 예 → 남은 형태 |
|---|---|
| 출처 헤지 | "수요일에 문을 닫는 걸로 안내돼 있어요" → "수요일에 문을 닫아요" · "~고 해요", "~고 하니까" → "~있어서" · "제가 확인한 시점에" (기준일 문장 1회로 대신) |
| 조사 과정·면책·겸손 | "공식 안내를 하나하나 비교해 봤고", "후기 마흔 편 넘게 참고", "제가 이용해 본 건 아니지만 찾아보니까", "코스트코는 안 가봤는데", "제가 찾아본 선에서 열심히 답변해 드릴게요", "참고만 하시고 내 취향에 맞게" → "참고하시고 다녀와서 댓글로 후기알려주세요" |

## 8. 문장 호흡

- **도입·전환·감상 대목은 길게:** 짧은 문장 2~3개를 "~는데요, ~는데 ~니까 ~더라고요"로 한 문장에 묶는다.
  - Claude 3문장 "저도 뉴욕에서 걸어 다니고 지하철 타고 다닌 적이 정말 많은데요. / 솔직히 처음에는 저도 복잡하고 정신이 하나도 없었어요. / 그런데 한 번 그 틀만 이해하고 나니까…" → 사용자 1문장 "저도 뉴욕에서 지하철 정말 많이 타봤는데요, 처음에는 복잡하고 정신이 없어서 긴장하고 다녔는데 확실한 정보만 딱 익히고나니 그다음부터는 정말 수월하더라고요."(F01)
  - 도입 5문장 → 1문장: "그래서 제가 처음 뉴욕 여행 앞두고 있는 친구에게 제 경험 기반 꿀팁을 모두 알려 준다는 마음으로, 숙소 고르는 기준 세가지 정리했으니, 영상 다 보시면 어떤 숙소가 나한테 가장 잘 맞는지 선명해질거에요, 그럼 바로 시작해 볼게요!"(F06)
- **정보 나열 대목은 짧아도 된다:** "첫째는 지금 쓰고 계신 신용카드나 체크카드예요. / 둘째는 폰이에요. / 셋째는 역자판기에서 파는 실물 교통카드인데요."(F01)
- 문단 길이는 편마다 다르다(한 문장 한 문단 ↔ 150~230자 문단). 문체 기준으로 삼지 않는다. **낭독문 문단은 도구가 2~5문장으로 맞춘다**(`script_txt.py 최종`).
- 숫자: **판단을 가르는 숫자는 다 쓴다**(최종본 교통비 장에는 3달러·두세 번·만 원·7일·열두 번·35달러·4만 7천 원이 한 장에 들어 있다). 안 쓰는 건 요금표·세목·인상 이력·배차 간격처럼 **나열용 숫자**다. 원화 환산은 판단을 가르는 금액에만 한 번("3달러, 우리 돈으로 4천 원이 넘어요" F01). 시청자가 화면에서 보는 금액은 "결제 직전 총액으로 확인"으로.
