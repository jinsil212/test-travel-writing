# 「최종」·「탈고」 절차 (사용자가 "최종" 또는 "탈고"라고 하면 이 파일을 읽고 묻지 않고 끝까지 한다)

## 최종 — "최종"이라고 하면 (묻지 않고 끝까지, 다시 해도 같은 순서)

0. **트렐로 판이 기준이다(사용자 지시 2026-10-22).** `& 'C:\영상편집\참고영상\_도구\cc-trello.ps1' -Action export -Board '여행' -List '초안'`으로 「초안」 카드들을 받아(`C:\영상편집\참고영상\_작업\<카드이름>\script.txt`) 이 편의 카드를 찾는다(카드 링크는 `원고/{주제}/트렐로_등록결과.json`). 설명에서 `---` 사이의 낭독문 부분을 떼어 `원고/{주제}/대본_트렐로최종_읽기용.txt`로 저장하고, 직전 Claude 판 읽기용과 문장 단위로 비교해 사용자가 고친 문장을 `선택.md`에 기록한다(아래 「탈고」 1의 재검증도 이때 같이). 로컬 `대본_vN.md` 본문을 트렐로 판으로 맞춘 새 판(`대본_v{N+1}.md`, 상단에 "트렐로 탈고 반영")을 저장한다. 카드를 못 받으면 보고하고 로컬 최신 판으로 진행한다.
1. `… script_txt.py 최종 원고/{주제}/대본_트렐로최종_읽기용.txt 원고/{주제}/대본_v{N+1}.md` → 영문 약어·날짜·달러 한글 소리, 문단 2~5문장. "[알림] 다름"이면 md 반영, "[경고]"면 고친 뒤 다시.
2. 편집 폴더 `C:\여행영상소스\{주제}\`(있으면 그대로, `[완성] ` 폴더 우선): 루트에 `{주제}_대본_TTS용.txt` 하나만, `썸네일\썸네일_문구.txt`("대본 단계 1안 — 편집 단계 재생성 가능" 표시), `_자료\작업안내.txt`.
3. 스킬 `midform-source`를 이 폴더·이 대본으로 백그라운드 실행(묻지 않음). `_소스영상_목록.md` 있으면 새 장면만. 소스 완료로 트렐로 카드를 옮기지 않는다.
4. 낭독문을 파일 창에, 글자 수·편집 폴더·소스 진행 보고. 제작 관리표 `script=in_progress`, `folder`=편집 폴더.

## 탈고 — "탈고"라고 하면

1. **사용자 수정분 재검증:** 직전 Claude 판과 최신 읽기용 txt를 문장 단위로 비교해 사용자가 추가·수정한 문장만 ⓐ 팩트 재확인(자료.md·공식 출처; 틀리면 고치지 않고 "정정 제안") ⓑ 오타 교정(표현 불변, 철자·띄어쓰기만) ⓒ 결과 보고.
2. 「최종」 1~2 다시. 건너뛰었으면 3도.
3. 트렐로 여행 보드 **「탈고」**에 upsert(같은 제목의 「초안」 카드가 있으면 설명을 바꾸고 「탈고」로 옮긴다 — 새 카드를 만들지 않는다) — 카드 제목 = 확정 제목, 설명(UTF-8 txt, 16,000자 이하):
   ```
   📌 핵심 문장: … / 🎬 확정 제목: … / 🖼️ 썸네일 문구: 윗줄 … / 아랫줄 … / 메인 오브젝트 … / 배경 … (대본 단계 1안 — 편집 단계 재생성 가능)
   🛒 상품: … / 📁 원고 폴더: 원고/{주제}/ · 편집 폴더: C:\여행영상소스\{주제}\
   --- {낭독문 전문} --- 💬 고정 댓글 초안 {…}
   ```
   `& 'C:\영상편집\참고영상\_도구\cc-trello.ps1' -Action upsert -Board '여행' -List '탈고' -Name '{확정 제목}' -File <설명.txt>`. 댓글은 공용 `_대본지침서.md` 0장 "전달 카드의 댓글 구성"(① 원고 정보 ② 참고영상 검색 키워드 ③ 유튜브 챕터(TTS 뒤) ④ 원본영상 폴더 ⑤ 원본영상 링크). 실패해도 계속, 보고에 "트렐로는 못 올렸어요".
4. 편집 폴더를 탐색기로 연다. 관리표 `script=complete`.
5. 보고: 재검증 결과 · 카드 링크 · 편집 폴더 · 소스 상태 · 다음 할 일 "TTS mp3 넣고 「{주제} 편집해줘」".

트렐로 리스트: 초안 → 탈고 → 썸네일 제작완료 → TTS 완료 → GPT 이미지 생성 → 캡컷 프로젝트 → 업로드 완료. Claude는 「탈고」까지만 옮긴다.
