## 2. 썸네일 문구 — 대본 단계 1안 확정 규칙

- 카피 **2~6글자 덩어리 1~2개**(윗줄/아랫줄). 제목의 긴 문장을 압축한다.
- **결과형·도움형 카피 기본**, 부정형(손해·후회) 대신: 통과한 예 — 우드버리 `하루 쓸 가치?` / `가는 법·세금 총정리`, 지하철 `복잡해 보이죠?` / `순서대로 정리했어요`. 폐기된 예 — `싸게 사도 손해?`, `하루 값 8만 원`.
- 고대비 박스(검정/빨강/노랑 단색) + 두꺼운 흰/노란 글씨, 중앙 또는 좌상단 크게. 메인 오브젝트 1개(얼굴 없음: 지도·실물 아이템·입구 간판 등).
- 확정 형식: `윗줄 {…}(박스 색) / 아랫줄 {…}(박스 색) / 메인 오브젝트 {…} / 배경 {…}`.

## 3. ⚠️ 썸네일 규칙 상태 — 사용자 결정 전

**대본 단계 1안 확정(위 2번), 편집 단계 pd-guide와 충돌 중.**

| | 대본 단계(이 파일) | 편집 단계 (`C:\여행영상소스\_채널규칙\pd-guide.md` 9-3·9-4, `thumbnail-strategy.json`) |
|---|---|---|
| 줄 구성 | 2~6자 카피 1~2개, 박스 자유 | 2줄 하단 좌측. **윗줄 감정/조건(흰색 작게) / 아랫줄 목적지+숫자(하늘색 #00E0FF 크게)** |
| 국기 이모지 | 없음 | 있음 |
| 제목 금지어 | 없음("완벽 정리" 허용) | `완벽`·`가성비`·`끝판왕` 금지, `추천` 경고 |
| 후보 수 | 1안 확정 | 후보 5개 이상 → 추천 1 |
| 실제 운영 | 트렐로 카드 설명에 1안 기록 | 「TTS 완료」 카드 첨부 `유튜브_업로드정보_*.txt`에서 제목 3·썸네일 10개를 **다시 만든다** (예: 지하철 `아무 카드나 찍으면 손해` / `🇺🇸 뉴욕 지하철 주 35달러 끝`) |

- 「썸네일 제작완료」 리스트에 사용자가 실제로 고른 문구 데이터가 없다 → 어느 쪽이 맞는지 이번 분석으로 수렴시킬 수 없다.
- **사용자가 결정할 것:** ⓐ 대본 단계 1안을 그대로 쓰고 편집 단계는 재생성하지 않는다 / ⓑ 편집 단계가 pd-guide로 재생성하고 대본 단계는 후보만 낸다. 결정되면 이 파일 2번과 pd-guide 중 한 벌만 남긴다.
- 결정 전까지: 트렐로 카드 설명의 썸네일 줄에 `(대본 단계 1안 — 편집 단계 재생성 가능)`을 붙인다.
