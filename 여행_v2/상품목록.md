# 마이리얼트립 상품 목록 — 기획 단계 대조용

기획 1단계에서 **이 주제에 연결할 상품이 있는지** 이 표를 지역·주제로 먼저 본다(CLAUDE.md 1단계). **표에 없는 지역이면** 마이리얼트립에서 그 지역의 티켓·투어·버스·숙소 상품을 검색해 지역 칸을 채워 한 줄씩 추가한다(상품 번호·링크·제휴 문구는 사용자가 채움). 지역이 달라도 상품 자리의 형태(아래 "상품 자리 쓰는 법")는 같다. 있으면 본문 결론부에 "현지 방법 안내 → 그래도 편한 건 이 상품" 자리를 잡고, 고정 댓글 초안에 링크 자리를 둔다. 없으면 상품 연결 없이 쓴다(억지로 끼우지 않음).
상품을 깎아내리는 각도("싸게", "굳이 안 가도", "본전")는 쓰지 않는다.

## 상품 자리 쓰는 법 (합격원고에서 확인된 형태)

- **결론 자리**: 현지 방법을 다 설명한 뒤 "그래서 제가 가장 추천하는 게 ○○이에요" → 추천 이유 2~3개(좋은 자리·일정 먼저 확정·받는 법 간단 등) → "링크는 고정 댓글에 정리해 둘게요". (F02 네번째 방법, F07 데이 투어, F05 도슨트 투어)
- **덧붙임 자리**: 숙소·버스처럼 상품이 주제의 일부일 때는 마무리 직전 한 문단 — "제가 마이리얼트립에서 오늘 말씀드린 조건에 맞는 ○○을 직접 한번 추려 봤어요. 고정 댓글에 정리해 뒀으니까 꼭 확인해 보세요." (F06, F10)
- **할인 한 줄**(선택): "마이리얼트립은 단독 프로모션이 많고, 웬만한 곳은 카드사 혜택이 적용되는 경우가 많아서… 생각보다 상시할인이 많아서 저는 자주 사용해요." (F06, 사용자 실제 경험)
- 가격은 "작품과 날짜, 좌석에 따라 다르니까 상품 페이지에서 확인" — 낭독문에 상품 가격을 못 박지 않는다(F02).

## 추가 요령

- **새 지역 추가 절차:** ① 기획 단계에서 마이리얼트립 검색(지역명 + 티켓/투어/버스/숙소) → ② 이 주제와 직접 연결되는 상품만 `지역`·`상품명`·`관련 주제` 칸을 채워 추가 → ③ 번호·링크·제휴 문구는 빈 칸으로 두고 보고에 "사용자 확인 필요" → ④ 낭독문에는 "링크는 고정 댓글에"까지만.

- 새 상품을 알게 되면 이 표에 한 줄 추가하고 `관련 주제`에 검색 키워드를 넉넉히 적는다(기획 때 grep으로 찾기 때문).
- 사용자가 상품 페이지·요금표·예약 화면을 붙여 주면 그 정보는 본문에 거의 그대로 들어간다(보고서 6장). 상품이 있는데 페이지 자료가 없으면 초안 상단 질문에 "상품 페이지 주시면 반영"을 남긴다.
