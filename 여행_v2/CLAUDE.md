# 여행 원고 v2 — 손 안 대고 쓰는 완성본

목표는 **사용자가 손대지 않고 바로 TTS로 넘기는 완성본**. 기준은 사용자 최종본 10편(`합격원고/`)과 `문체카드.md`만. 다른 폴더의 규칙·말투 장치를 가져오지 않는다. 지역 무관 — 다른 나라 주제도 같은 틀로 쓰고, 뼈대는 `합격원고/_색인.md` 구조 유형이 가장 가까운 1편. 답변은 한국어.

## 실행

- 평소 말로 요청("○○ 원고 쓰자"). 0단계 → **구성안 확인(사용자 OK 한 번)** → 1단계 → 2단계 → 완성 산출물까지, 구성안 OK 뒤로는 **중간 선택 없이 한 번에**. 3안 제시 없음. 사용자가 "구성안 건너뛰고 바로"라고 하면 구성안을 생략한다. 수정은 사용자가 말하면 `선택.md`에 적고 v2.
- `.claude/hooks/gate.py`가 `원고/{주제}/기획.md`·`대본*.md` 저장을 검사한다(뼈대 F##·금지 구절·핵심 문장 1회·꼬리표·🇺🇸·분량 하한). 거부되면 채운다. 우회 금지.
- 결과물: `원고/{주제}/자료.md` → `기획.md` → `선택.md` → `대본_v1.md`(상단 메타 + `<!-- 본문 시작 -->`~`<!-- 본문 끝 -->` 낭독문 + 고정 댓글 초안 + 점검표) → `대본_v1_읽기용.txt`(기본 보기) → ("최종") `대본_최종_낭독문.txt`.
- **읽는 파일은 단계마다 필요한 것만, 전문으로.** 자동 로드는 이 파일·문체카드·색인만. `내경험.md`·`상품목록.md`·`참고/01_제목썸네일.md`는 해당 단계에서 읽는다. 합격원고는 뼈대 1편만 읽는다.

## 0단계 — 중복 확인

**`원고목록.md` 한 파일만 본다**(폴더를 뒤지지 않는다). 같은 도시 + 같은 시청자 질문이면 중복 → 각도를 바꾸고 이유를 적는다. 상태가 "자료·기획만(미작성)"·"초안 있음(미완)"인 주제는 중복이 아니라 이어 쓸 후보 — 그 폴더의 `자료.md`만 가져다 쓰고(기획.md는 읽지 않음) 여기 규칙으로 새로 쓴다. 결과를 `기획.md` 맨 위에. **편이 완성되면 `원고목록.md`에 한 줄 추가한다.**

## 구성안 확인 — 조사 전에 사용자에게 보여 주고 OK를 받는다 (사용자 지시 2026-10-21)

0단계 중복 확인과 뼈대 선택(1단계 4번)까지만 하고 **조사·대본 전에** 아래 구성안을 대화창에 보여 준다. 사용자가 OK하면 1단계 자료 조사부터 간다. 장소·항목만 나열한 구성안은 안 된다 — 사용자가 구성안만 보고 영상이 어떻게 흘러가는지 알 수 있어야 한다.

1. **맨 위에 "핵심 주제 가안" 한 줄.**
2. **도입부터 마무리까지 순서(흐름)대로**, 단계마다 ① 그 단계의 역할 ② 들어갈 내용(사실·이유·예시·행동의 대략, 쓸 경험담, 다음 단계로 넘기는 연결 한 줄) ③ 뼈대 편의 어느 블록과 짝인지.
3. **뼈대는 도입부만 보지 않는다.** 뼈대 전문의 **본문 전개 방식**까지 읽어 이번 주제에 적용해서 보여 준다: 한 항목 안의 전개 순서(예: 이 타깃에게 맞는 이유 → 설명 → 단점과 해결 팁 → 같이 할 것 → 경험담), 항목 사이를 넘기는 방식, 규칙을 선언하는 자리와 실패담을 놓는 자리, 마무리 방식. 구성안에 "뼈대의 이 전개 방식을 이 항목에 이렇게 적용한다"가 보여야 한다.
4. **억지 짝은 구조·흐름이 어색할 때만 표시**한다(내용 측면에서는 억지가 아님). 표시한 칸은 빼거나 합치거나 맞는 칸으로 옮기자고 제안한다.
5. 조사 전이라 확인 안 된 사실은 단정하지 않고 "조사 후 확인"이라고 적는다.
6. 사용자가 항목을 넣고 빼면 그대로 반영해 `기획.md`에 남기고, 빠진 항목은 대본에 쓰지 않는다.

## 1단계 — 기획

1. **자료:** 키워드만 주면 웹 검색, 소스를 주면 소스 먼저. 출처·확인 수준을 `자료.md`에. 공식 출처나 여러 출처 일치만. 확인 안 되면 빼거나 행동 안내("예약 화면에서 확인")로.
2. **각도:** 시청자가 검색창에 칠 질문을 그대로 순서대로 다 알려 주는 **총정리형**. 계산형(본전·며칠)·분류 체계형(N가지 기준·네 갈래)·역발상형(가격 말고)·부정 프레임(손해·굳이 안 가도) 금지. `기획.md`에 핵심 질문 한 줄 + 각도 판정.
3. **상품:** `상품목록.md`를 지역·주제로 대조. 그 지역이 표에 없으면 마이리얼트립에서 티켓·투어·버스·숙소를 검색해 상품명·관련 주제를 추가(번호·링크·제휴 문구는 사용자, 낭독문에 링크 안 말함). 있으면 결론부 "현지 방법 → 그래도 편한 건 이 상품" 자리 + 고정 댓글 안내. 상품 가치를 깎는 각도 금지. 페이지 자료가 없으면 상단 질문에 "상품 페이지 주시면 반영".
4. **뼈대:** `_색인.md` 구조 유형 표에서 질문 형태가 가장 가까운 1편(지역 무관: 오사카 숙소 비교→F06, 도쿄 지하철→F01, 방콕 비 오는 날→F05). 한 편만. 각도가 먼저, 뼈대는 그 다음.
5. **제목·썸네일:** `참고/01_제목썸네일.md`를 읽고 4블록 제목 1안(+후보 2, 국기 이모지 없음, 블록 3은 알려 줄 내용 2~4개 나열+총정리/이 영상 하나로 끝) + 결과형 썸네일 문구 1안. `선택.md`에 "Claude 확정안". 바로 2단계.

## 2단계 — 대본

1. 읽기: `문체카드.md`, 뼈대 F## **전문**, `내경험.md`, `상품목록.md`(상품 있을 때), `선택.md`. **문체카드는 초안을 처음 쓸 때 적용하는 지침이다. 첫 문장부터 카드대로 쓴다. 쓰고 나서 고치는 데 쓰는 표가 아니다**(사용자 지시 2026-10-22).
2. 상단 메타(본문 표식 밖): `핵심 문장:` / `뼈대: F##` + 장 대응표(억지 칸 처리) / `제목:` / `썸네일 문구:` / `이 편에 넣을 경험 질문:` 2~3개 / `상품 자리:`.
3. **도입**(문체카드 1): 공감 질문 → 확장 → 관련 경험(있을 때만) → 예고 3덩어리 → (붙인) 시작 멘트. 그 지역·주제 경험이 `내경험.md`에 없으면 경험 없이 같은 틀로 완성, 다른 지역 경험·각색 금지, "다녀온 분들 후기를 보면" 한 문장 허용. 체류 기간·숙소 위치는 신뢰 근거 금지.
4. **본론**(문체카드 "틀·원칙 셋·본론"): **장마다 쓰기 전에 친구의 질문 한 줄을 `기획.md`에 적고 그 답만 쓴다.** 뼈대 장 구성을 따르되 **순서는 시청자 이익 순**(돈 → 길 → 시간 → 안전 → 실수 복구). 절차형이라도 돈 아끼는 장을 맨 앞에. 없는 조각은 지어내지 않고 비운다(예시는 경험·자료·지명만), 같은 지시는 편에서 1회, 기관 이름은 편당 6회 이하. 기기 조작 설명 금지. 섹션마다 개인 입장 1문장. 한 편 = 한 질문.
5. 핵심 문장은 상단 메타용 한 줄이고, 본문에는 0~1회·표어식 과장 금지. **마무리**(문체카드): 정리 → (예고) → 좋아요·구독·댓글 후기 → 감사.
6. **뼈대 편의 길이·글자 수에 맞추지 않는다 (사용자 지시 2026-10-21: "원고 길이에 집착하지 마, 구조와 흐름을 참고하는 거야").** 분량은 이번 항목들이 사실·이유·예시·행동을 다 채우는 데 필요한 만큼이고, `_색인.md` 분량은 참고용이다. 짧아 보이면 늘려 쓰지 말고 항목 공식이 빠진 자리를 채운다. gate는 절대 하한 4,500자(지역 가이드형은 8,000~11,000 권장)만 본다. 글자 수는 스크립트로 세어 보고한다.
7. 본문 아래 **고정 댓글 초안**(`[링크]`·타임스탬프·정정 사항·질문 1개), 끝에 **점검표** 한 묶음: 읽기용 txt를 처음부터 끝까지 **"친구에게 이 문장 그대로 말할까?"**로 읽고 걸린 문장 전부(고친 전/후) + `check_script.py` 출력. 통과 증거 인용·칸 채우기용 문장 없음(사용자 지시 2026-10-22).
8. 읽기용 txt를 만들어 파일 창에 띄운다(대화창에 전문 안 붙임): `C:/Users/진실/AppData/Local/Python/pythoncore-3.14-64/python.exe -X utf8 .claude/tools/script_txt.py 읽기용 원고/{주제}/대본_vN.md`. 수치는 같은 경로의 `check_script.py 원고/{주제}/대본_vN.md`. 세션 폴더가 아니면 먼저 `request_directory`.

**완성 산출물:** 낭독문 · 제목 1안(+후보 2) · 썸네일 문구 1안 · 고정 댓글 초안 · 상품 자리. 보고: 제목·썸네일, 읽기용 txt 위치, 중복 확인, 경험 질문, 글자 수.

## 3단계 — 트렐로 「초안」 카드 (사용자 지시 2026-10-22: 대본이 끝나면 바로, 묻지 않고)

사용자가 대본을 보고 더 고칠 게 없다고 하면(또는 "트렐로로") 그 판을 **트렐로 여행 보드 「초안」 리스트**에 올린다. 사용자는 거기서 직접 탈고한다. 카드 제목 = 확정 제목(SEO 대괄호 제외). 설명(UTF-8 txt, 16,000자 이하)은 위에서부터: `📌 핵심 주제`(핵심 질문 한 줄) / `🎬 제목` 1안(추천 표시)+후보 2 + SEO 대괄호 / `🖼️ 썸네일 문구` / `📝 핵심 내용`(장별 한 줄) / `🛒 상품 자리` / `📁 원고 폴더` / `❓ 확인 필요`(재확인 권장 사실·경험 질문) / `---` / 낭독문 전문(읽기용 그대로, 장 제목 【】 포함) / `---` / `💬 고정 댓글 초안`.
`& 'C:\영상편집\참고영상\_도구\cc-trello.ps1' -Action upsert -Board '여행' -List '초안' -Name '{제목}' -File <설명.txt>` → 출력 `CARD <id> <url>`을 `원고/{주제}/트렐로_등록결과.json`과 `선택.md`에 남기고, 관리표 `note`에 카드 링크. 실패하면 보고에 "트렐로는 못 올렸어요"라고 적고 설명 txt 위치를 알려 준다. 이 단계에서는 댓글을 달지 않는다(댓글은 탈고 절차에서).
**이후 "최종"은 트렐로 카드의 설명(사용자가 고친 원고)을 기준으로 한다**(`절차_최종탈고.md`). 로컬 md는 그 뒤에 트렐로 판으로 맞춘다.

## 수정

원본은 대본 md. 고친 뒤 읽기용 txt 재생성. 지시는 `선택.md`에. 삭제는 "빼/삭제/지워" 명시 때만, 애매하면 유지하고 보고. 사용자가 읽기용 txt를 직접 고쳤으면 md에 반영.

## 최종 · 탈고

사용자가 **"최종"** 또는 **"탈고"**라고 하면 `절차_최종탈고.md`를 읽고 그대로 한다(**트렐로 「초안」 카드의 설명을 받아와 사용자 최종 원고로 삼음** → 로컬 md 반영 → 낭독문 변환 → 편집 폴더 → 소스 찾기 / 사용자 수정분 재검증 → 트렐로 「탈고」로 이동 → 관리표). 대본 쓰는 동안은 읽지 않는다.

## 지킬 것

- 경험은 `내경험.md`에 있는 것만, **그리고 있는 것은 깎지 않고 다 쓴다**(지어내기와 깎기 둘 다 금지). 사용자가 경험을 답하면 `내경험.md`에 옮기고 `경험_질문지.md`에 ✅와 날짜를 남긴다. 새 지역 편을 쓸 때 `경험_질문지.md`의 그 지역 질문을 상단 경험 질문에 함께 넣는다.
- 자료는 `자료.md`에 출처와 등급으로 남기고, **낭독문은 단정으로 말한다.** 출처가 있다는 이유로 기관 이름을 문장 주어로 세우지 않는다(상식 조언에는 기관 이름 0).
- 확인 안 된 수치·규정·시행일·배차는 뺀다. 기준일 문장은 영상당 1회. 보상(체크리스트 등)은 사용자가 실제로 준비한 것만.
- 썸네일 규칙은 사용자 결정 전(`참고/01` 3번) — 카드에 표시. 사용자가 준 상품 페이지·요금표는 본문에 거의 그대로.
