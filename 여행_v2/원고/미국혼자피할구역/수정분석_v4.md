# 수정 분석 — 대본 v4 사용자 지적의 공통 원인 (2026-10-22, 1차: 도입~공통 행동 장)

사용자 지적(도입 4곳 + 공통 행동 장 7곳)을 모아 공통 원인을 뽑고, 같은 원인이 본문 뒤쪽(뉴욕·엘에이·샌프란시스코·마무리)에서도 나오는 자리를 전부 찍었다. **사용자가 추가 지적을 보내는 중이라 v5 수정은 전부 받은 뒤에 한다.** 수치는 `대본_v4_읽기용.txt` 178문장 기준.

## 1. 공통 원인 6가지

### 원인 A. 점검표 칸을 채우려고 문장을 만들었다 (문체카드 6-2-9 위반)
"항목마다 사실·이유·예시·행동"을 **기계적으로 채우느라** 없는 장면을 지어내고, 이미 한 말을 "행동" 자리에 다시 썼다.
- 지어낸 장면: "숙소 예약 화면은 열어 놨는데 밤에 혼자 돌아다녀도 되는 건지"(사용자: 말도 안 되는 예시) / "공연이 끝나고 나왔는데 밤 열한 시" / "밤 열 시에 한 칸에 나 혼자" / "횡단보도에서 신호를 기다리며 폰" / "일요일 밤 승강장에서 열차가 안 와서" / "밤 열한 시에 승강장 끝에서 혼자" — **6개가 전부 내가 만든 가상 장면**이고, 시청자가 실제로 겪는 걱정에서 나온 게 아니다. 사용자가 원한 건 "혼자 가도 괜찮을까? 숙소는 어디? 뭘 조심해야 하지?" 같은 **진짜 머릿속 질문**.
- 되풀이: "사람 있는 칸에 타세요"를 공통 장에서 두 번(사실 → 행동), 뉴욕 카드에서 두 번(지시 → "~쪽이 낫겠죠?" 반문), 샌프란시스코에서 한 번. "번호판 맞춰 보세요" 4회. "거리뷰로 걸어 보세요" 4회(뉴욕 2, 엘에이 1, 마무리 1). "막차" 7회. "짐이 보이면 표적" 3회.
- 점검표에는 "네 조각 인용"으로 통과 증거를 적어 놓아서, **채운 것처럼 보이지만 내용은 비어 있는 상태**를 스스로 못 잡았다.

### 원인 B. 근거에 맞춰 문장을 썼다 — 기관 이름이 주어가 됨 (문체카드 6-2-5 위반)
"[확인]된 것만 쓴다"를 지키려다 **문장의 출발점이 시청자의 궁금증이 아니라 내가 가진 출처**가 됐다. 그래서 외교부 3회, 관광청 6회, 우버·엠티에이·산타모니카 시까지 기관 언급 12회.
- 전체 도시를 말하는 공통 장에서 "샌프란시스코 관광청도 ~"를 근거로 든 것(사용자 지적)이 전형이다. 그 문장은 '이상하면 자리를 뜨라'는 상식인데, 출처가 샌프란시스코 것밖에 없어서 그걸 붙였다.
- 같은 사실을 두 번 말하는 원인도 이것: "뉴욕은 지하철이 밤새 다녀요. 뉴욕 관광청도 밤새 운행한다고 알려 주거든요." — 앞 문장이 사실, 뒤 문장은 출처 보증. 시청자에게는 같은 말.
- 외교부 "시비 걸면 피하라"처럼 **상식 수준의 말에 기관을 붙이면** 권위가 아니라 공허함이 된다(사용자: 당연한 소리). 문체카드는 기관 이름을 벌금·규정·금액처럼 신뢰가 꼭 필요한 곳에 **항목당 한 번**만 쓰라고 했다.

### 원인 C. 소제목을 입으로 읽는 라벨형 전환 (문체카드 3 위반)
"다음은 우버예요." / "소지품과 폰도 있어요." / "여섯 가지예요." / "마지막은 ~" / "하나는 ~, 다른 하나는 ~" / "거리에서는 한 가지만 기억하세요." — **앞 항목의 생각이 다음 항목으로 이어지는 연결이 없고, 번호표만 붙였다.** 사용자 지적 "첫 번째 밤 이동 정해라 해 놓고 두 번째 우버 말하는 게 말이 됨?"이 정확히 이것. 사실 1번(밤 이동수단 미리 정하기)과 2번(우버)은 "그 이동수단이 대개 우버니까 우버 탈 때 ~"로 한 호흡인데, 라벨로 끊어 놔서 따로 노는 항목이 됐다.
- 기획 용어가 낭독문에 새어 나왔다: "카드마다 말씀드릴게요"(카드=내 구성 용어), "도시가 어디든 똑같이 쓰는 행동"(행동을 '쓴다'). 문체카드 6번 "낭독문 속 표식" 금지의 변형.

### 원인 D. 짧게만 끊은 빈 문장 + 추상 카피 (문체카드 8 위반, 6-2-1 위반)
번역투를 피하려고 문장을 잘게 끊었는데, **정보 없이 짧기만 한 문장**이 됐다. 20자 미만 문장 24개. 사용자: "길 땐 길고 짧을 땐 짧아야 하는데 그냥 짧게만 한 느낌".
- 경험 문장이 대표: "저는 혼자 여행을 정말 많이 다녀 봤는데요, 미국에서도 혼자 오래 지내 봤어요." — `내경험.md`에 **유럽·미국 각각 3달 넘게 혼자**가 있는데 과장이 두려워 깎았다. 사용자가 원한 건 "유럽도 혼자 갔고 미국도 혼자 갔고, 특히 미국은 오래 지냈다"처럼 **있는 사실을 다 말하는 길이**.
- 추상 카피: "겁부터 낼 일이 있고 준비만 하면 되는 일이 있다" — 뜻이 없는 명사구 요약(6-2-1 "영어식 카피를 명사구로 압축하지 않는다"). "돌아가는 건 창피한 게 아니라 가장 빠른 대처예요"도 같은 류.
- 반대로 꼬인 문장도 있다: "첫 번째는 밤에 어떻게 이동할지 도착하기 전에 정해 두는 거예요"(사용자: 말을 어렵게 함). 짧아야 할 곳은 길고, 길어야 할 곳은 짧다.

### 원인 E. 핵심 문장·훅을 끼워 넣느라 과장했다
gate가 "핵심 문장 1회"를 요구해서 "혼자일 때는 밤에 어떻게 이동하고 어디서 묵는지만 정해 두면, 도시가 달라도 마음이 훨씬 편해져요"를 도입 끝에 박았다. 이건 **표어**지 말이 아니고, "~만 하면 편해진다"는 과장이다. 사용자가 원한 마무리는 "이것만 알면 100% 안전하다고 할 수는 없지만, 유념하면 즐겁고 안전한 여행을 만들 수 있다"는 **솔직한 수위**. 숙소 카드 끝의 "~분께 잘 맞아요"(F04 틀)도 치안 주제에서는 억지 결론이 됐다: "밤 이동은 우버로 정해 두실 분께 산타모니카가 잘 맞아요".

### 원인 F. "이유" 자리에 전제를 되풀이한 당연한 소리
"일행이 없으면 혼자 해결해야 하니까 걱정되는 게 당연해요" / "혼자일 때는 말을 섞는 순간 끼어들어 줄 일행이 없거든요" / "텅 빈 칸에서는 도와줄 사람이 없으니까요" / "뒤쪽은 누가 손을 대도 모르니까요" — **'왜'를 묻는 자리에 '혼자니까'를 네 번 넣었다.** 사용자가 원한 이유는 시청자 심리 쪽: "누가 괜찮았다고 해서 나한테도 괜찮은 건 아니다".

## 3. 왜 점검표가 이걸 못 걸렀나
점검표는 **"있는지"**(핵심 문장 1회? 네 조각 있나? 전환 말로 했나?)만 묻고 **"말이 되는지"**는 묻지 않는다. 그래서 가상 장면도 "예시 있음", 기관 보증도 "사실 있음", 라벨도 "전환 있음"으로 통과했다. 소리 내어 읽기(6-2) 칸도 "의심 문장 2개 고침"으로 형식만 채웠다. **다음 편부터는 점검 방식 자체를 바꿔야 한다**(아래 4).

## 4. 지침에 반영할 후보 (사용자 결정 후)
1. **예시는 지어내지 않는다.** 예시 자리에는 ① 내 경험 ② 자료의 실제 사례 ③ 시청자가 검색창에 치는 질문, 셋 중 하나만. "밤 열한 시에 ~라고 해 보세요" 같은 가상 장면 금지.
2. **기관 이름은 편당 상한을 둔다**(예: 공통 장 1회, 도시 카드당 1회). 상식·행동 조언에는 붙이지 않는다. 출처는 `자료.md`에 남기고 낭독문에서는 단정으로.
3. **전환은 앞 항목의 결과로 다음 항목이 필요해지는 문장**으로만. "다음은 ~예요 / ~도 있어요 / N가지예요 / 카드" 금지 목록 추가.
4. **같은 지시는 편에서 1회.** 다른 도시에서 다시 필요하면 "앞에서 말한 그대로"로 가리키기만.
5. **경험 문장은 `내경험.md`에 있는 사실을 전부 쓴다**(깎지 않는다). 지어내는 것과 깎는 것 둘 다 금지.
6. **핵심 문장은 표어가 아니라 솔직한 한 문장**: "100%는 아니지만 ~" 수위. "~만 하면 편해진다" 류 금지.
7. **점검표에 '소리 내어 읽은 어색 문장 전부'를 적는다**(2개 고정이 아니라 발견한 만큼). 명령형 비율도 세어 적는다.
8. **이유 자리에 전제 되풀이 금지**: "혼자니까 / 일행이 없으니까"는 이유가 아니다.

## 6. v5 지적 (2026-10-22) — 공통 원인 셋과 비포/애프터 전체

사용자가 v5에서 16곳을 짚음. 공통 원인은 셋이고, 문체카드 원칙 2·3에 넣었다(목록이 아니라 "이렇게 말한다"로).

- **A. 글로 쓴 문장** — 주어가 개념("정해 둘 건", "기준은", "~는 더 중요해져요", "'~한다'가")이거나 서술어가 명사("~지예요", "~곳이에요", "~원칙이에요", "~뜻이기도 해요")이거나, 대구 카피("X가 걷는 도시라면 Y는 ~도시"), 표제어식 명령("막차부터 보세요"). 친구에게 말할 때는 **주어가 사람, 서술어가 동사**다.

- **C. 조언을 내 습관처럼 꾸밈** — "저는 ~하는 편이에요"가 `내경험.md`에 없음. "저는 ~해요"는 경험에 있는 것만, 조언은 "~추천해요/~게 좋아요".
