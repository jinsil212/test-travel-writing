# 레전드열전 작성 실험 폴더

이 폴더는 `midform-writing/레전드열전`의 복사본으로 **원고 작성 방식 실험용**이다. 원본 폴더는 건드리지 않는다.

## 원고를 쓸 때 (강제)

1. 쓰는 동안 여는 문서는 **둘뿐**이다. `레전드열전/분석지/_쓰기전에_읽는_것.md`와 견본 전문. 견본은 `레전드열전/_합격원고/`가 1순위(있으면 전부), `레전드열전/분석지/원문/`의 벤치마크 전문이 2순위(최소 3편: 원화·황비홍·최영의 + 같은 형태 1편).
2. 견본은 **Read 도구로 전문**을 연다. 요약·발췌·기억으로 대신하지 않는다. 안 열면 `.claude/hooks/require_sample_read.py`가 대본 파일 Write/Edit를 차단한다.
2-1. 대본을 쓰기 전에 편 폴더에 **`쓰기전_설계.md`**(핵심 질문·문단표·용어표·훅 약속표)를 만든다. 없으면 대본 Write/Edit가 차단된다.
2-2. 초안 뒤 사장님께 보여주기 전에 `/대본검수`(차가운 독자) 1차 → 문제 행 전부 고침 → 2차 독자 → `판정:`. 대본을 쓴 세션은 판정 없이는 턴을 못 끝낸다(Stop 훅).
3. 공용 `_대본지침서.md`(이 폴더 사본)와 원칙서 3부, 검수 기준서는 쓰는 동안 열지 않는다. 사실 확인·수익화·비하 표현·회수 누락 검수 때만 연다.
4. 초안이 나오면 사용자에게 보여주기 전에 **자체 루프**를 돈다. `python 레전드열전/분석지/_계측_원고.py <대본.txt>` → 벤치마크 범위를 벗어난 항목만 고침 → 다시 계측. 2~3회. 결과표를 집필기록에 붙인다.
5. 사용자가 고친 문장은 규칙으로 만들지 않는다. `_쓰기전에_읽는_것.md` 2장 표에 전→후 한 줄로 넣되 **표는 15줄 상한**이고, 합격본이 `_합격원고/`에 들어오면 표보다 합격본이 우선이다.
6. 한 편이 합격하면 그 최종본을 `레전드열전/_합격원고/<편>.txt`로 넣는다. 다음 편부터 자동으로 1순위 견본이 된다.

## 기획·제목·썸네일·출력 형식

채널설정 원칙 1~8과 원칙서 1·2부, 9장 출력 형식을 그대로 따른다. 바뀐 건 "쓰는 동안 무엇을 보느냐"뿐이다.
