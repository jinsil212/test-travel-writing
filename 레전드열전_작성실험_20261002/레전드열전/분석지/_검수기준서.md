# 레전드 열전 원고 검수 기준서

**초고를 벤치마크형 원고로 고치는 검수자(AI)용**

- 벤치마크 채널: 퇴근후헛소리 (@heotsorry)
- 벤치마크 자료: 롱폼 19편
  - 대본 전문 7편: 원화, 황비홍, 황정리, 지한재, 양사, 견자단, 역도산
  - 도입부 19편 전부 (영상 시작부터 1분 15초까지)
  - 썸네일 19장, 제목·조회수 19편
- 작성 원칙서: `_채널분석_원칙서.md` (같은 폴더) (이하 "원칙서"). 이 기준서의 기준 번호 옆에 원칙서의 해당 장을 적어 두었다.
- 작성일: 2026-09-19

## 이 문서를 읽는 검수자에게

당신의 일은 **이미 있는 초고를 벤치마크 원고처럼 들리게 고치는 것**이다. 처음부터 다시 쓰는 것이 아니다.

- 할 수 있는 것: 문장 다듬기, 흐름과 연결 고치기, 문단 순서 옮기기, 역할이 겹치는 문단 합치기, 한국어로 어색한 표현 고치기
- 할 수 없는 것: 새 사실이나 일화 추가, 확정된 항목 변경, 원고 전체를 새로 쓰기

이 문서는 다음 순서로 되어 있다. 1장과 2장을 먼저 읽고, 3장 순서대로 작업하고, 판단이 필요할 때 5장 기준을 찾아본다.

1. 먼저 알 것
2. 수정 범위와 등급
3. 작업 순서 (5단계)
4. 진단 도구 3가지 (빈 양식)
5. 기준 목록 (가장 중요)
6. 벤치마크 원형 4편 주석본
7. 고친 예 모음 (전 → 후)
8. 요청서 양식 / 제출물 양식

# 1. 먼저 알 것

## 1-1. 채널과 원고

| 항목 | 내용 |
|---|---|
| 채널 | 레전드 열전 |
| 장르 | 과거 무술영화 스타, 실전 무술가, 격투가와 그 주변 인물의 인생을 전설과 실제를 비교하며 들려주는 나레이션 |
| 시청자 | 40~60대 남성. 홍콩영화, 오락실 세대. 화면보다 **귀로 듣는** 비중이 큼 |
| 화자 | 자료를 다 찾아보고 온 동네 형. 전문가 행세를 하지 않음. 전설을 좋아하지만 믿지는 않음 |
| 말투 | 서술(~했다, ~했다고 한다)과 논평(~죠, ~네요, ~습니다)을 섞는 **두 목소리** |
| 분량 | 10~13분. 공백 제외 3,800~5,000자 (벤치마크 19편 실측 3,165~6,004자, 평균 4,450자) |
| 출력 | TTS에 그대로 들어감. 괄호, 따옴표, 편집 지시가 없어야 함 |
| 캐치프레이즈 | **"전설과 실제를 나란히 놓고"** (2026-09-24 확정). 주제에 맞는 편에만 쓴다. 요청서에 "캐치프레이즈 없음"이라고 적혀 있으면 넣지 않는다. 벤치마크 채널의 문구는 쓰지 않는다 |

## 1-2. 절대 고치면 안 되는 것 (고정 항목)

1. **요청서에 "확정"으로 적힌 것:** 제목, 썸네일 문구, 기획 방향(핵심 약속), 도입부의 약속과 예고 항목
2. **사실:** 날짜, 숫자, 인명, 지명, 금액, 인용 발언의 내용
3. **"설"과 "기록"의 구분:** "~라는 설이 있다", "확인은 안 되지만" 같은 표현을 확정 표현으로 바꾸지 않는다
4. **핵심 일화의 존재:** 초고에 있는 일화를 통째로 지우려면 변경표에 이유를 적어야 한다. 5장의 S5, V5에 해당할 때만 가능하다

> 사실이 틀린 것 같으면 **고치지 말고** 변경표에 "사실 확인 필요"로 표시한다.

## 1-3. 하면 안 되는 수정

| 금지 | 이유 |
|---|---|
| 초고에 없는 사실, 일화, 숫자, 인용을 추가 | 검수자는 조사를 하지 않는다. 그럴듯한 가짜가 들어간다 |
| 원고 전체를 새로 쓰기 | 초고의 사실 배치와 기획이 사라진다 |
| 서술을 전부 존댓말로 바꾸기 | 벤치마크 말투(두 목소리)가 사라진다 |
| 논평을 전부 지우고 건조한 해설문으로 바꾸기 | 〃 |
| "벤치마크처럼"을 이유로 "참고로", 비유, 대사를 새로 끼워 넣기 | 할당량처럼 넣으면 AI 티가 난다. 5장 V4는 **최대치**다 |
| 벤치마크 채널의 캐치프레이즈나 고유 문장을 가져오기 | 표절이 되고 채널이 구분되지 않는다 |
| 과장 형용사 추가 (충격적인, 소름 돋는 등) | 벤치마크는 사실과 숫자로 놀라게 한다 |
| 편집 지시, 음악 표시, 괄호 설명 추가 | TTS로 그대로 읽힌다 |

> **가장 흔한 실수:** "벤치마크처럼"을 너무 넓게 해석해서 과하게 고치는 것.
> 초고가 이미 기준을 통과하는 부분은 **그대로 둔다.** 고친 문장마다 5장의 기준 번호를 댈 수 있어야 한다. 댈 수 없는 수정은 하지 않는다.

# 2. 수정 범위와 등급

## 2-1. 수정 범위 3단계

요청서의 "고칠 범위"를 따른다. 적혀 있지 않으면 **흐름까지**가 기본이다.

| 범위 | 할 수 있는 것 |
|---|---|
| 문장 | 단어, 어미, 어순, 문장 나누기와 합치기, 한국어 교정 |
| 흐름 (기본값) | 문장 범위 + 문단 연결 문장 추가·수정, 문단 안에서 문장 순서 바꾸기, 인접 문단 순서 바꾸기, 역할이 겹치는 문단 합치기 |
| 구조 | 흐름 범위 + 문단을 멀리 옮기기(예: 70% → 40%), 초고 안의 사실로 연결 문단 새로 쓰기, 문단 삭제 |

어느 범위에서든 **초고 전체 문장의 절반 이상을 바꾸게 되면** 수정을 멈추고, 제출물 맨 위에 "초고 재작성 필요"와 그 이유를 적는다.

## 2-2. 기준 등급

| 등급 | 의미 | 검수자의 행동 |
|---|---|---|
| **반드시** | 어기면 벤치마크형이 아니다 | 수정 범위 안에서 반드시 고친다. 범위 밖이면 변경표에 "범위 밖 필수 수정"으로 보고한다 |
| **권장** | 벤치마크 대부분이 이렇다 | 고치면 좋아지지만 문장을 크게 흔들어야 하면 보고만 한다 |
| **선택** | 있으면 더 좋다 | 쉽게 되면 하고, 아니면 둔다 |
| **진단만** | 확정 항목이라 고칠 수 없다 | 기준을 어겼으면 보고만 한다 (주로 도입부) |

## 2-3. 근거 표시

5장의 기준마다 합격선이 어디서 나왔는지 표시했다.

| 표시 | 뜻 |
|---|---|
| [실측] | 벤치마크 원고에서 직접 세거나 위치를 잰 값 |
| [관찰] | 벤치마크 원고를 읽고 확인한 패턴. 정확한 수치는 세지 않음 |
| [제안] | 벤치마크에 직접 근거는 없지만 TTS 품질이나 한국어 규범상 필요한 기준 |

# 3. 작업 순서 (5단계)

순서를 바꾸지 않는다. 1~3단계는 **읽기만** 하고 고치지 않는다.

| 단계 | 할 일 | 산출물 |
|---|---|---|
| ① 약속 사슬 표 | 제목, 썸네일, 도입 끝, 핵심 회수, 결말의 실제 문장을 찾아 적는다 | 4-1 표 |
| ② 구간 지도 | 문단마다 누적 위치(%)와 역할 코드를 적는다 | 4-2 표 |
| ③ 계측 | 4-3 계측표의 항목을 센다 | 4-3 표 (수정 전 열) |
| ④ 판정 | 5장 기준마다 합격 / 불합격 / 해당 없음을 적는다. 불합격이면 등급과 수정 범위를 보고 고칠지 보고만 할지 정한다 | 판정 목록 |
| ⑤ 수정 | 반드시 → 권장 → 선택 순서로 고친다. 고친 뒤 ③을 다시 재서 수정 후 열을 채운다 | 수정본 + 변경표 + 계측표 |

**위치(%) 계산법:** 해당 문장이 시작되기 전까지의 글자 수(공백 포함) ÷ 원고 전체 글자 수(공백 포함) × 100. 소수점은 버린다.
**시간 환산:** 공백 제외 380자 = 1분. [실측: 벤치마크 19편, 355~403자/분]

# 4. 진단 도구 3가지 (빈 양식)

## 4-1. 약속 사슬 표

핵심 약속(요청서에 적힌 기획 방향)이 다섯 곳에서 같은 말로 이어지는지 본다.

| 위치 | 실제 문장 (그대로 옮겨 적기) | 핵심어 포함 | 같은 약속인가 |
|---|---|---|---|
| 제목 | | O / X | O / X |
| 썸네일 1줄 + 2줄 | | O / X | O / X |
| 도입 마지막 두 문장 | | O / X | O / X |
| 핵심 회수 문단의 첫 문장 (위치 %) | | O / X | O / X |
| 결말 요약 문장 | | O / X | O / X |

- **핵심어:** 핵심 약속을 대표하는 단어 1~2개. 예: 기획 방향이 "원표는 왜 스타가 못 됐나"면 핵심어는 "스타", "원표"
- 한 칸이라도 X면 5장 P1을 본다.

## 4-2. 구간 지도

| 문단 | 시작 위치 % | 역할 코드 | 한 줄 요약 | 메모 |
|---|---|---|---|---|
| 1 | 0 | HOOK | | |
| 2 | | BIRTH | | |
| … | | | | |

**역할 코드**

| 코드 | 뜻 | 벤치마크 기준 위치 |
|---|---|---|
| HOOK | 도입 (예고와 캐치프레이즈) | 0~6% |
| BIRTH | 출생, 가족, 어린 시절 | 도입 직후 |
| REWARD | 1분 안의 작은 보상 일화 | 도입 끝부터 공백 제외 약 380자 안 |
| SEED | 뒤에서 회수할 떡밥 심기 | 10~20% |
| RISE | 수련, 입문, 기회, 귀인 | 15~35% |
| PAYOFF | 제목·썸네일 약속의 핵심 회수 | **30~50%** (C형은 70% 안팎) |
| VERDICT | 설 vs 기록 판정 | 어디든 |
| SHADOW | 사고, 논란, 연애, 불화, 몰락 | 55~80% |
| BONUS | 예고하지 않은 트리비아 | **70~80%** |
| NOW | 말년, 근황, 죽음 | 85~95% |
| END | 인생 요약 → 이상 ~의 일대기였습니다 → 인사 | 95~100% |
| ASIDE | "참고로" 곁가지 | 어디든 (최대 3회) |

# 5. 기준 목록

형식: `번호 · 이름 [등급]` → 원칙서 대응 / 벤치마크 근거 / 측정법 / 합격선 / 고치는 방법 / 고친 예

> 벤치마크 근거는 영상 이름, 시점, 내용 요약으로 적었다. 원문 인용은 넣지 않았다. 예문은 전부 이 문서를 위해 새로 쓴 문장이다.

## 5-P. 약속 사슬

### P1 · 약속 일치 [반드시]
- **원칙서:** 7장, 8장
- **근거:** 썸네일이 제목과 같은 약속을 한 원화, 황비홍, 견자단, 지한재, 왕호는 평균 약 33만이었다. 다른 이야기를 약속한 이연걸, 김일, 담도량, 임청하는 평균 약 7만이었다. [실측]
- **측정:** 4-1 약속 사슬 표
- **합격선:** 다섯 칸 모두 같은 약속이고, 핵심어가 네 칸 이상에 있다
- **고치는 방법**
  - 제목, 썸네일, 도입은 확정이라 못 고친다. 고칠 수 있는 곳은 **핵심 회수 문단**과 **결말 요약 문장**이다.
  - 회수 문단의 첫 문장에 약속을 다시 꺼내고, 결말 요약에 핵심어를 넣는다.
- **예 (전 → 후)**
  - 전: 1978년 그는 새 영화에 출연한다.
  - 후: 그리고 1978년, 그가 정말 스타보다 뛰어났는지 확인할 수 있는 영화가 나온다.

### P2 · 예고 전부 회수 [반드시]
- **원칙서:** 0장 5단계, 4-1
- **근거:** 상위 6편은 도입에서 예고한 일화를 본문에서 전부 다뤘다. [실측]
- **측정:** 도입의 예고 항목을 목록으로 적고, 본문에서 해당 문단을 찾는다
- **합격선:** 예고 항목 전부 본문에 회수 문단이 있다
- **고치는 방법**
  - 본문에 해당 사실이 있지만 약하게 지나가면 → 문장을 늘려 장면으로 만든다 (초고 안의 사실만 쓴다).
  - 본문에 해당 사실이 아예 없으면 → 고치지 말고 변경표에 "도입 예고 미회수: 도입 수정 또는 사실 추가 필요"로 보고한다.

### P3 · 가장 센 장면의 예고 [진단만]
- **원칙서:** 0장 5단계
- **근거:** 황정리 편의 썸네일 대사 장면, 원화 편의 서머솔트킥처럼 상위작은 본문 최강 장면을 도입이나 썸네일에서 예고했다. [관찰]
- **측정:** 본문에서 가장 긴 일화나 반전이 큰 일화가 도입에 예고됐는지 본다
- **합격선:** 예고됨
- **고치는 방법:** 보고만 한다. "도입 수정 제안: ○○ 장면을 예고에 넣을 것"

## 5-H. 도입부

> 도입부는 사용자가 기획 방향에 맞춰 확정한다. 검수자는 **약속과 예고 항목을 바꾸지 않고** 문장만 다듬을 수 있다. H1~H6은 주로 진단 후 보고한다.

### H1 · 도입 길이 [진단만]
- **원칙서:** 4장
- **근거:** 19편 도입부는 21~48초였다. 48초였던 이소룡 1편은 이소룡인데도 12.3만에 그쳤다. [실측]
- **측정:** M2
- **합격선:** 공백 제외 125~220자
- **고치는 방법:** 문장 범위 안에서 군더더기 수식어만 줄인다. 예고 항목을 빼야 할 정도로 길면 보고한다.

### H2 · 첫 문장의 새 정보 [진단만]
- **근거:** 상위권 첫 문장은 몰랐던 사실, 도발 대사, 숫자, 판정 질문이었다. 하위권 성룡, 역도산, 김일은 이미 아는 명성을 소개하며 시작했다. [실측]
- **측정:** 첫 문장에서 시청자가 이미 알 만한 정보(월드스타, 전설적인, 유명한)를 빼고 남는 게 있는지 본다
- **합격선:** 새 정보가 하나 이상 있다
- **고치는 방법:** 첫 문장 안에서 새 정보를 앞으로 당기는 어순 수정만 한다.
- **예**
  - 전: 홍콩 액션 영화의 전설적인 배우 원표는 사실 성룡보다 공중제비를 잘했다.
  - 후: 성룡보다 공중제비를 잘했다는 배우가 있었다. 원표다.

### H3 · 판정형 질문 [진단만]
- **근거:** 상위권 질문은 전부 "얼마나 / 누가 / 어디까지"였다. "왜 ~했는지"를 2~3개 던진 김일, 성룡, 역도산은 전부 하위권이었다. [실측]
- **측정:** M3, M4
- **합격선:** 질문 1개 이하, "왜" 0개
- **고치는 방법:** "왜 ~했는지" 문장을 명사형 예고로 바꾸는 건 허용한다. 약속이 바뀌지 않기 때문이다.
- **예**
  - 전: 왜 그는 정상에서 은퇴했을까?
  - 후: 정상에서 갑자기 사라진 사연.

### H4 · 예고의 성격 [진단만]
- **근거:** 연애, 결혼, 열애설이 예고의 중심이었던 성룡 1.9만, 임청하 4.1만. [실측]
- **합격선:** 예고의 절반 이상이 실력, 대결, 숨은 역할, 권력자와의 인연
- **고치는 방법:** 예고 순서만 바꿔서 연애 항목을 뒤로 보낸다. 삭제는 보고한다.

### H5 · 캐치프레이즈 마무리 [반드시 — 쓰는 편에 한해]
- **근거:** 19편 중 18편이 캐치프레이즈 문장으로 도입을 닫았다. [실측]
- **합격선:** 캐치프레이즈를 쓰는 편이면 도입 마지막 문장이 "전설과 실제를 나란히 놓고, [수식어] [인물]의 [○○ 같은] 인생을 파헤쳐 본다" 틀이다. 안 쓰는 편이면 이 검사는 해당 없음으로 적고, 도입 마지막 문장이 본문으로 이어지는지만 본다
- **고치는 방법:** 요청서의 캐치프레이즈로 교체한다. 끝 단어는 주제에 맞춘다.
  - 드라마 같은 인생: 일반
  - 영화 같은 인생: 명장면이 있는 인물
  - 무협지 같은 인생: 일화가 많은 인물
  - 거짓말 같은 인생: 비극

### H6 · 도입 직후 흐름 [반드시]
- **원칙서:** 4장 훅 직후 규칙
- **근거:** 하위권 이준구 편은 출생 직후 태권도 역사 강의로, 왕호 편은 출생 전에 4대퇴왕 설명으로 샜다. 이소룡 2편은 1편을 먼저 보고 오라고 안내했다. 상위권은 전부 도입 → 바로 출생이나 영상 자료였다. [실측]
- **측정:** 도입 다음 두 문단의 역할 코드
- **합격선:** 도입 다음 문단이 BIRTH, 또는 영상 자료 소개("실력부터 잠깐 보고 가겠습니다"), 또는 출처 선언 한 문장
- **고치는 방법:** 설명이나 역사 문단을 그 개념이 처음 필요한 장면 바로 앞으로 옮기고, 두세 문장으로 줄인다. (흐름 범위)
- **예**
  - 전: [도입] → 합기도의 역사는 일본의 대동류에서 시작되는데… (6문장) → 그는 1936년에 태어났다.
  - 후: [도입] → 그는 1936년에 태어났다. … (몇 문단 뒤, 도장에 들어가는 장면에서) 이 무술은 일본에서 건너온 기술에 발차기를 더한 것이었다고 한다.

## 5-S. 구조와 흐름

### S1 · 1분 안의 작은 보상 [권장]
- **원칙서:** 2장 회수 규칙
- **근거:** 상위 6편 모두 도입 뒤 1분 안에 가벼운 일화가 있었다. 원화 편의 물구나무 선 채 잠든 일화, 황비홍 편의 약장수 농담, 지한재 편의 기술마다 돈 받는 스승 같은 것이다. [실측]
- **측정:** M5
- **합격선:** 도입 끝부터 공백 제외 약 380자 안에 REWARD가 있다
- **고치는 방법:** 초고의 어린 시절이나 입문 구간에서 가장 가볍고 구체적인 일화를 앞으로 당긴다. 없으면 보고한다.

### S2 · 핵심 회수 위치 [반드시]
- **원칙서:** 2장 회수 규칙
- **근거:** 원화 47%, 황정리 32~50%, 지한재 38~50%, 양사 45%, 황비홍 17~29%(1차) → 94%(최종). 예외는 견자단 72%인데, 떡밥 장치(C형)로 버텼다. [실측]
- **측정:** M6
- **합격선:** 30~50%. 원고 형태가 C형이면 60~75%
- **고치는 방법**
  - 너무 늦으면 → 그 앞의 RISE 구간을 압축한다. 연도별 작품 나열을 한두 문장으로 줄이는 식이다.
  - 너무 이르면 → 회수 뒤에 약속과 관련된 2차 증거를 배치해 긴장을 유지한다. 초고 안의 사실로만 한다.

### S3 · 보너스 트리비아 [권장]
- **근거:** 상위 6편 모두 70~80% 지점에 예고하지 않은 일화가 있었다. 황정리의 드래곤볼 모티브, 원화의 설악산 촬영지, 양사의 괴력 수치 같은 것이다. [실측]
- **측정:** M7
- **합격선:** 70~80% 지점에 BONUS 1개
- **고치는 방법:** 초고에서 앞쪽에 소비된 트리비아 중 약속과 직접 관련 없는 것을 70~80%로 옮긴다.

### S4 · 시간 흐름 [반드시]
- **근거:** 7편 모두 출생부터 시간순이었다. [실측]
- **합격선:** 원고 형태가 H1(콜드 오픈)이나 H2(대결 교차)가 아니면 시간순. 시간을 거슬러 갈 때는 신호 문장이 있다 (예: 이야기를 조금 앞으로 돌려 보면)
- **고치는 방법:** 문단 순서를 바로잡거나 신호 문장을 넣는다.

### S5 · 문단 전환 [반드시]
- **근거:** 벤치마크는 문단 첫 문장에 시점이나 연결어를 둔다. 예: 당시, 이때, 그러던 중, 그렇게, 이후, 그런데. [관찰]
- **측정:** 각 문단 첫 문장에 시점 표지, 연결어, 앞 문단을 받는 말 중 하나가 있는지 본다
- **합격선:** 전환 표지 없이 시점이나 장소가 바뀌는 문단 0개
- **고치는 방법:** 문단 첫머리에 짧은 연결을 넣는다. "그래서", "따라서", "결론적으로" 같은 논문투는 쓰지 않는다.
- **예**
  - 전: 그는 쇼브라더스와 계약했다. / 1973년 그는 은퇴를 선언했다.
  - 후: 그는 쇼브라더스와 계약했다. / 그렇게 잘나가던 그가, 1973년 갑자기 은퇴를 선언한다.

### S6 · 핵심어 공백 [권장]
- **근거:** 황비홍 편은 55% 지점에서 "그럼 실제로는 얼마나 강했을까"라고 질문을 다시 던지고, 견자단 편은 15%에 떡밥을 심었다. 약속을 중간에 다시 상기시킨다. [관찰]
- **측정:** M8
- **합격선:** 핵심어가 없는 연속 구간이 35% 미만 [제안]
- **고치는 방법:** 공백 구간 한가운데 문단 끝에 **씨앗 문장** 하나를 넣는다. 씨앗 문장은 새 사실 없이 약속만 다시 꺼내는 문장이다.
- **예:** 그런데 이때까지만 해도, 그가 성룡보다 뛰어났다는 말은 누구도 하지 않았다.

### S7 · 핵심 일화의 5단계 [권장]
- **원칙서:** 2부 2-2 (분석 문서)
- **근거:** 상위작의 큰 일화는 설정 → 사건 → 대사 → 출처 → 뒷말 순서였다. 황정리 도장깨기, 지한재의 건달 일화와 시라소니 대결이 그렇다. [관찰]
- **합격선:** PAYOFF 일화가 최소 설정, 사건, 출처, 뒷말 네 단계를 갖춘다
- **고치는 방법:** 빠진 단계만 보충한다.
  - 대사: 초고에 대사가 있을 때만 쓴다. 지어내지 않는다.
  - 출처: "~했다고 한다" 한 문장
  - 뒷말: 짧은 논평 한 줄

### S8 · 결말 공식 [반드시]
- **근거:** 7편 모두 "A였지만 B" 대비 한 문장 → "이상 ~의 일대기였습니다" → 구독 인사 순서였다. 교훈이나 감동 문장은 없었다. [실측]
- **합격선:** 세 요소가 순서대로 있고, 교훈·설교·자기계발 문장이 0개
- **고치는 방법:** 교훈 문장을 지우고 대비 문장 하나로 요약한다.
- **예**
  - 전: 그의 삶은 우리에게 포기하지 않는 것이 얼마나 중요한지 가르쳐 줍니다. 여러분도 꿈을 포기하지 마세요.
  - 후: 누군가의 대역으로 시작해서 결국 자기 이름으로 기억된 배우, 원표의 일대기였습니다.

### S9 · 반복 문단 정리 [권장]
- **측정:** 같은 사실이나 평가를 두 번 이상 말하는 문단
- **합격선:** 0개
- **고치는 방법:** 뒤쪽 문단에서 겹치는 문장을 지우고, 남는 내용을 앞 문단에 합친다. (흐름 범위)

## 5-V. 말투

### V1 · 두 목소리 [반드시]
- **원칙서:** 5-1
- **근거:** 7편 모두 서술(~했다)로 사실을 전하고 논평(~죠, ~네요)으로 끼어들었다. 어느 한쪽만 있는 원고는 없었다. [관찰]
- **측정:** M14
- **합격선:** 논평 어미 15~25% (19편 실측 평균 20%). 논평만 3문장 이상 연속되는 구간 3곳 이하
- **고치는 방법**
  - 서술이 너무 길게 이어지면 → 일화가 끝나는 지점의 문장 하나를 논평 어미로 바꾸거나, 짧은 뒷말 한 줄을 붙인다. 새 사실은 넣지 않는다.
  - 논평이 너무 많으면 → 사실을 전하는 문장을 서술 어미로 바꾼다.
- **예**
  - 전: 그는 하루에 공중제비를 40번씩 돌았습니다. 사람들은 그를 인간 와이어라고 불렀습니다. 그는 누구보다 몸이 가벼웠습니다.
  - 후: 그는 하루에 공중제비를 40번씩 돌았다고 한다. 사람들은 그를 인간 와이어라고 불렀다. 별명이 괜히 붙은 게 아니죠.

### V2 · 전해 들은 말투 [권장]
- **근거:** 벤치마크의 일화는 대부분 "~했다고 한다 / ~했다고 합니다"로 닫힌다. [관찰]
- **합격선:** 확인이 어려운 일화(인터뷰, 증언, 소문)가 단정 어미로 끝나지 않는다
- **고치는 방법:** 일화의 마지막 문장만 "~했다고 한다"로 바꾼다. 연속 3문장에 쓰지 않는다 (K6).

### V3 · 서술 문장의 길이와 연결 [권장]
- **근거:** 벤치마크 서술은 "~는데", "~고", "~자"로 두세 절을 이어 붙인 긴 문장이 많고, 논평은 짧다. [관찰]
- **합격선**
  - 서술이 15자 안팎 단문으로만 5개 이상 이어지는 구간 0개

### K2 · AI투 표현 [반드시]
- **근거:** 벤치마크에 한 번도 나오지 않는 표현이다. [관찰]

- **목록과 처리**

  - ~의 여정, ~의 서막, 새로운 장을 열다, 한 획을 긋다 → 구체적인 동사로
  - 한 편의 영화 같은, 전설적인 순간, 역사적인 순간 → 삭제 (캐치프레이즈 문장 제외)

# 7. 고친 예 모음 (전 → 후)

## 7-1. 두 목소리 (V1)
- 전: 그는 1950년에 태어났습니다. 그는 가난한 집에서 자랐습니다. 그는 경극학교에 들어갔습니다. 그곳의 훈련은 매우 혹독했습니다.
- 후: 그는 1950년 홍콩의 가난한 집에서 태어났다. 결국 경극학교로 보내지는데, 이곳 훈련이 그야말로 생지옥이었다고 한다. 새벽부터 밤까지 물구나무를 서고, 틀리면 맞는 게 일상이었죠.

## 7-2. 할당량처럼 끼운 장치 (V4, V5)

- 후: 이 영화는 흥행에 성공했고, 감독은 이 작품으로 상까지 받았다. 참고로 그때 입었던 의상은 지금도 박물관에 남아 있다고 합니다.

## 7-3. 과장 형용사 (M16)
- 금지 목록: 충격적인, 경악스러운, 소름 돋는, 믿을 수 없는, 엄청난 비밀, 놀라운 반전, 전율, 경이로운, 압도적인 (수치 없이 쓸 때)

- 후: 그가 공중에서 발을 세 번 바꿔 차는 장면에서 관객석이 조용해졌다고 한다.
