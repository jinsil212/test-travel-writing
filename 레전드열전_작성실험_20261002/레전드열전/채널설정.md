# 레전드 열전 — 채널 설정과 자료 위치

2026-09-19 사용자가 새 채널로 시작했다. 같은 주(2026-09-17~19) 폴더 없는 작업 공간에서 벤치마크(퇴근후헛소리) 분석, 원칙서, 검수 기준서, 첫 편 기획을 먼저 진행했고, 사용자 "커밋" 요청으로 이 미드폼 폴더에 등록했다. 공용 작성 기준은 상위의 [_대본지침서.md](../_대본지침서.md)다. 공용 규칙을 이 파일에 복제하지 않는다.

## 원고 작성 시 반드시 지킬 것 (사용자 확정)

1. **기획 방향이 먼저, 도입부는 그다음 (2026-09-18).** 도입부는 확정된 기획 방향(핵심 약속)을 가장 잘 드러내면서 궁금증을 더 키우는 쪽으로 고른다. 기획 방향을 사용자가 주지 않았으면 후보를 내고 멈춘다. 도입부 후보 3개와 검증표를 보여주고 사용자가 고른 뒤 본문을 쓴다. 본문 뒤에 회수 지도와 역검증을 붙인다. → [원칙서](분석지/_채널분석_원칙서.md) 0장, 4-1
2. **모르는 인물·작품은 입구부터 바꾼다 (2026-09-19).** 기획 전에 한국어 유튜브 검색으로 인지도를 점검한다. 인지도가 낮으면 한국 시청자가 아는 이름(이소룡, 성룡, 반 담, UFC 등)이나 누구나 궁금한 질문(거짓말 검증, 실력 판정)을 제목·도입 입구로 세운다. 작품은 도입에서 한 줄로 설명한다. → 원칙서 0장 2-1
3. **"A vs B"로 쓰지 않고 "아는 인물의 숨은 ○○"으로 끄집어낸다 (2026-09-19).** 예: 이소룡 vs 웡잭맨 (X) → 이소룡의 숨은 대결 상대 (O). 모르는 인물 이름은 궁금증의 답으로 나중에 공개한다. → 원칙서 0장 2-1
4. **기획 결과는 확정된 표 형식으로 낸다 (2026-09-19).** 기획 방향 표·원고 뼈대 → 제목 10+근거표 → 썸네일 5+근거표 → 도입부 후보 3 → 검증표 → 추천. → 원칙서 9장 9-0~9-C
5. **검수 기준서는 쓸 때 보지 않는다 (2026-09-19).** [검수 기준서](분석지/_검수기준서.md)는 다른 AI 검수자가 초고를 벤치마크형으로 다듬을 때 쓰는 문서다. 원고를 쓸 때는 원칙서만 본다.
6. **폭력적이거나 가이드라인에 걸릴 소재는 피한다 (2026-09-17).** 실제 싸움·폭행 영상, 잔인한 장면 중심 소재는 쓰지 않는다. 경기 장면보다 인물의 인생 이야기 중심으로 간다.
7. **최종 원고는 고정 형식으로 보여준다 (2026-09-19).** 순서: ① 제목 ② 썸네일 문구 ③ 기획 의도 ④ 핵심 주제 → ⑤ 원고 전문. 원고 전문은 복사 버튼이 생기도록 코드 블록 하나에 넣는다. 제목·썸네일은 복사하기 쉽게 각각 코드 블록에 넣고, 사용자가 아직 고르지 않았으면 "작업자 추천(미확정)"이라고 표시한다. → 원칙서 9장 9-4
8. **캐치프레이즈는 주제에 맞을 때만 넣는다 (2026-09-24).** 기본 문구는 "전설과 실제를 나란히 놓고"이고, 도입 마지막 문장에 넣는다. 전설·소문·과장된 이야기의 진위를 따지는 편에는 넣고, 그런 대조가 없는 편(예: 기록이 분명한 인물의 일대기)에는 빼고 자연스럽게 닫는다. 넣었는지 뺐는지와 그 이유를 편 문서에 적는다. 끝 단어는 주제에 맞춰 바꿔도 된다 (인생을 파헤쳐 본다, 그날의 진실을 파헤쳐 본다 등).
9. **쓸 때 보는 문서와 검수할 때 보는 문서를 나눈다 (2026-10-02 사용자 요청: "분석한 벤치마크 원고와 흐름·말투·기승전결이 유사하게 나오게").** 원고를 쓰는 동안 여는 것은 [분석지/_쓰기전에_읽는_것.md](분석지/_쓰기전에_읽는_것.md)와 `분석지/원문/`의 벤치마크 원문 전문 3편(원화·황비홍·최영의, 필요하면 같은 형태 1편 추가)뿐이다. 공용 `_대본지침서.md`, 원칙서 3부, 검수 기준서는 초안이 끝난 뒤 검수 패스에서만 연다. 초안이 끝나면 `python 분석지/_계측_원고.py <대본.txt>`로 벤치마크 19편 평균·범위와 대조하고 벗어난 항목만 고친다. 사용자가 문장을 고치면 규칙을 추가하지 않고 `_쓰기전에_읽는_것.md` 2장 표에 전→후 한 줄을 추가한다. 근거: 2026-10-01 오토 4편은 공용 지침 전문과 원칙서를 읽고 썼는데도 한 줄 한 사실의 짧은 문장, 설명형 논평("~ㄴ 셈이죠"), 구어 0개로 벤치마크와 딴판이었다. 엽문 v1→v2 계측 비교는 `원고/엽문_실제실력/집필기록.md`.
