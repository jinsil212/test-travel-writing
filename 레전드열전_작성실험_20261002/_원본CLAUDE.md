공용 _대본지침서.md의 0-5·0-6과 G5-2를 적용한다. **최종 원고 제출 직전 마지막 수정본을 다시 열어 검사하고, 결과 뒤에 실제 구절·삭제 또는 유지 이유·수정 결과를 붙인다. 근거 없이 검사 완료라고 보고하지 않는다.** 상세 검사 절차는 공용 원문 한 곳을 따른다. 이후 추가되는 사용자 요청도 같은 검증 대상이며, 제출 직전 최신 요청과 실제 결과를 대조한다. 기준 저장과 결과 반영·검증 완료를 구별한다. 지침 전문과 실제 사용할 원문을 읽고, 단계별 조항의 반영 근거를 이번 편 문서에 남긴다. 검수표 존재만으로 통과시키지 않는다. 현재 단계 필수 항목이 미완료면 완성으로 제출하지 말고 먼저 보완한다. 일반/오토 모두 동일하며 오토에 사용자 승인 관문을 추가하지 않는다.
