# 내 실제 여행 경험

원고의 1인칭 경험담에 쓰는 실제 경험. 생각날 때 한 줄씩 추가하면 된다. 여기 없는 경험은 `[각색]` 표시로만 쓴다. 적힌 사실 이상(가격·사건·감정 디테일)을 지어내지 않는다.

| 지역 | 언제 | 무슨 일 (실패·당황·만족) | 쓸 만한 주제 |
|---|---|---|---|
| 뉴욕 — 뉴저지 | 첫 뉴욕 여행 | 조금 길게(장기) 머물러서 뉴저지에서 지냄. 원고에서는 "뉴저지에서 살아 봤다"로 표현 | 뉴욕 숙소, 뉴저지 숙소, 장기 체류 |
| 뉴욕 — 맨해튼 펜 스테이션 근처 | 두 번째 뉴욕 여행 | 맨해튼 펜 스테이션 근처에서 지냄. 원고에서는 "맨해튼에서도 살아 봤다"로 표현 | 뉴욕 숙소, 맨해튼 숙소 |
| 필라델피아·보스턴·워싱턴 | 뉴욕 여행 때 근교로 | 세 도시 모두 다녀옴 (2026-10-09 사용자 말). 이동: 보스턴 버스, 워싱턴 버스, 필라델피아 자동차. 몇 박인지는 기록 없음. 뉴욕에 오래 있어서 시간 여유가 있었음. 의견: 짧은 일정으로 왔다면 투어 상품으로 하루 만에 다녀오는 게 가장 효율적일 것이고 자신도 반드시 이용했을 것 같다. 투어를 직접 이용한 적은 없음(가정형으로만 말할 것) | 뉴욕 근교 도시 선택, 투어 이야기 |
| 필라델피아 | 근교 여행 | 하루 정도 구경하기 좋았음. 뉴욕·다른 미국 도시들과 비교했을 때 가장 특색이 덜했던 것 같음. 그래도 하루 시내를 돌아다니기에는 괜찮았고, 걸어서 다니기에 부담이 없어 혼자 다녀도 괜찮을 것 같다 | 필라델피아 카드 |
| 보스턴 아쉬운 점 | 근교 여행 | 아쉬운 점은 거리뿐 | 보스턴 카드 |
| 워싱턴 인상 정정 | 근교 여행 | 첫인상을 "썰렁"이 아니라 "너무 넓어서 사람이 생각보다 많이 안 보이고 널널하고 여유로운 인상"이라고 긍정적으로 표현하길 원함(2026-10-09). "썰렁" 표현은 쓰지 않음 | 워싱턴 카드 |
| 필라델피아 미술관 계단 | 근교 여행 | 사람이 너무 많거나 복잡하지 않아 느긋하게 혼자 둘러보기 좋았음(2026-10-09 사용자 지시 표현) | 필라델피아 카드 |
| 보스턴 | 근교 여행 | 하버드·MIT 캠퍼스 구경이 너무 좋았음. 하버드 기념품 샵에서 모자·후드티를 샀고 실용적이라 한국에서도 계속 쓰는 중이라 추억으로 남음. 도시 분위기가 좋음(보스턴 마라톤으로 유명, 꽤 큰 도시). 추천 대상: 학교 보는 걸 좋아하는 사람, 살아 있는 도시 느낌을 원하는 사람 | 보스턴 선택 이유 |
| 워싱턴 D.C. | 근교 여행 | 갔을 때 생각보다 썰렁했음(워낙 넓고 복작복작한 뉴욕에 비해 광활한 느낌, 관광지·유명한 곳에는 사람이 몰림). 박물관이 굉장히 잘 되어 있어 좋았음. 백악관을 봤으나 철창 사이로 꽤 멀리서 본 것이라 신기했음(국회의사당은 본 게 아니라고 정정). 오바마 전 대통령이 자주 갔다고 하는 식당 등 대통령이 실제로 있는 곳에 가 본 경험이 특별했음. 의견: 가족·아이와 가기 좋을 것 같음 | 워싱턴 선택 이유, 솔직 단점 |
| 뉴욕 예약 | 뉴욕 체류 전반 | 오래 머물러서 미리 예약하고 간 경우가 많지 않았음. 예약하려 해도 갑자기 자리가 생기는 경우가 있어 크게 상관없었음(2026-10-09 사용자 말). 의견: 짧게 여행 오는 사람은 하루하루를 허투루 쓰고 싶지 않으니 예약을 잘 활용하면 기간을 알차게 보낼 수 있다. 진짜 놓치고 싶지 않은 것만 예약하고 나머지는 즉흥적으로 새로운 곳도 가 보는 게 좋다 | 뉴욕 예약 순서, 일정 짜기 |
| 뉴욕 — 퀸즈보로 쪽 | 두 번째 뉴욕 여행 | 퀸즈보로 쪽에서도 머물러 봄 (숙소 원고에서는 뉴저지·맨해튼 두 가지만 쓰기로 함, 2026-10-08) | 퀸즈 숙소 |
