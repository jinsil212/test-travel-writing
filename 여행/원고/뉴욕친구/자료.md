## 1. 숙소 — 인원이 3~4명일 때
- 뉴욕시 Local Law 18: 30일 미만 단기임대는 집주인 동거 + 손님 최대 2명, 집 전체 임대는 불법 [검색요약, 뉴스12·브라운스톤 등]. 개정안 논의, 통과 미확인.
- 호텔: 두 침대 방은 킹보다 비싼 경우가 많음, 추가 인원·추가 침대 요금이 호텔마다 다름(예: 1박 10달러대~90달러), 객실 최대 인원 확인 필요 [검색요약]
- 의무 수수료(데스티네이션 피 등) 가격 표시 포함 의무: 2026-02-21부터 [검색요약, 테스트 `뉴욕7일경비/자료.md` §4]
- 정산: 예약자·결제 카드 정하기, 총액(방값+세금+수수료+추가 요금)을 인원 또는 숙박 일수로 나누기, 중도 귀국 시 부담 미리 정하기 [일반 조언 — 출처 아님]

## 2. 술 · ID
- 음주 연령 21세. 유효한 여권은 인정 ID, 외국 운전면허는 목록에 없음. 일부 업장은 사진이 아닌 원본 ID 요구 [검색요약, 퀸즈 크로니클(뉴욕주 주류법 인용)·tao group]
- 영업 마감: 법정 한도는 4시 부근이지만 구역·면허에 따라 더 일찍 닫는 곳 많음 [검색요약, 오래된 기사 — 원고는 "업장마다 다름" 정도]

## 3. 식당 · 팁 · 단체
- 단체 자동 팁: 6명 이상(관광청 안내) vs 8명 이상(소송 보도) 출처 상충 → 원고는 숫자 대신 "인원이 많으면 계산서에 이미 팁이 붙었는지 확인"만 [검색요약]
- 팁 18~22%, 세금 8.875% [검색요약, 테스트 `뉴욕7일경비/자료.md` §5]
- 별도 계산서(separate checks): 식당마다 정책 다름, 자동 팁이 있으면 어떻게 나뉘는지 확인 필요 [검색요약]

## 4. 공연 · 예약 · 이동
- TKTS 당일 할인, 인기작은 안 나옴 [검색요약] — 친구 편에서는 "인원이 많을수록 같은 줄에서 같은 자리 구하기 어렵다"로 연결 (일반 상식)
- 우버·택시 요금 분담: 차 1대에 4명이면 인원당 부담이 줄어듦 [일반 상식]
- 인기 식당 예약은 30일 전쯤 오픈 [검색요약, 커플 편 자료 §3]
