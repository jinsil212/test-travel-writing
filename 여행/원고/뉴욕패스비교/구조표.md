# 구조표 — 뉴욕 시티패스 vs 고시티 (대본_v2 기준, 2026-10-09)

핵심 주제: **시티패스는 "짜여 있는 패스", 고시티는 "내가 짜는 패스". 그 차이가 구성·포함 범위·기간·쓰는 방법·가격으로 이어지고, 그래서 내 여행이 짧고 대표 명소 위주인지, 길고 취향대로인지에 따라 맞는 쪽이 갈린다.**

영상의 큰 흐름(사용자 요청): **차이 → 그 차이가 어떤 여행에 맞는지(장단점) → 꿀팁**. 가격은 도입에서 빼지 않고 차이의 마지막(뒷부분)에서 다룬다.

## 표 1. 구조 비교 — 뼈대 S12(도쿄 핵심요약) ↔ 이번 주제

큰 틀만 맞추고 억지로 끼우지 않았다. 맞지 않는 S12 장(숙소 위치·공항 이동)은 쓰지 않았다.

| 순서 | S12의 구조·장치 | 이번 주제 대입 | 유사도 |
|---|---|---|---|
| 도입 ① | 대상이 크고 다양해서 준비 방법을 정하기 어렵다 | 시티패스·고시티가 비슷해 보여 고르기 어렵다 + 한 줄 결론 | ○ |
| 도입 ② | 준비 안 하면 이런 결과(사람에 치이고 지침) | 모르고 고르면 목록에 없거나 앱 등록에 시간을 쓰다 아쉬움 | ○ |
| 도입 ③ | 많이 준비했다·친한 친구에게 알려준다 + "바로 시작" | 상세페이지·공식 안내·후기를 읽었다 + 오늘 다룰 순서(차이→맞는 여행→꿀팁) + "바로 시작" | ○ |
| A 차이 비교 | 지하철 패스 vs 교통카드를 항목별로 직접 비교 → 한계 → "반대로 ~" | 구성 방식 → 포함 범위 → 기간·시작 → 쓰는 방법 → 가격(5가지 차이, 가격은 마지막) | ○ |
| B 어떤 여행에 맞나 | 지역마다 [특징 → 잘 맞는 사람 → 반면 맞지 않는 사람] | 시티패스·고시티 각각 [장점 → 잘 맞는 여행 → 반면 아쉬운 점] | ○ 가장 유사 |
| B 결론 | "정해 줬으면 하시는 분께 간단히 추천", "무조건 좋다기보다 성향에 맞게" | 유형 추천(시티패스형·고시티형·패스 없이) + 세 가지 질문 | ○ |
| C 꿀팁 | 뒷부분에 현금·카카오페이 등 알아 두면 좋은 꿀팁 정리 | 구매 후 세팅, 이중 차감, 왕관·특별 체험, 예약 시기, 일정 여유, 결제 혜택 | ○ |
| 마무리 | "얘기가 많아서 영상이 길어졌는데" | 한 줄 정리 + 본전 뽑으려 무리하지 말기 | ○ |
| 보조(S01) | "~하신 분들은 X / 반면 ~는 Y", "사용 가능한 곳이 다르니 미리 확인" | 6장 유형 추천 문장 틀, 2·7장 포함 목록 확인 | ○ 문장 틀만 |
| (쓰지 않음) | 숙소 위치·공항 이동 | 주제와 무관 | × 억지로 넣지 않음 |

## 표 2. 마이리얼트립 기준 두 패스 차이 전체 정리 (영상의 1~5장 근거)

| 차이 | 시티패스 (5820889) | 고시티 (5821337) |
|---|---|---|
| ① 구성 방식 | 5곳 세트. 엠파이어 스테이트·자연사 박물관 고정 + 6곳 중 3곳 선택 | 100개 이상 중 2~10곳을 곳도 개수도 직접 선택. 구매 전 곳을 정할 필요 없음, 구매 후 앱에서 결정 |
| ② 포함 범위 | 엠파이어 86층+2층 박물관+당일 밤 재입장, 자연사 40개 이상 전시관+유료 전시 1개, 여신상 페리·오디오 투어·박물관·엘리스섬, 구겐하임 무료 건축 투어. 여신상 왕관·받침대 불포함 | 전망대(엠파이어·에지·탑 오브 더 락·원 월드), 9/11, 여신상 페리, 자연사, MoMA, 구겐하임, 인트레피드, 빅버스·자전거 대여·워킹 투어·야간 크루즈·재즈·코니 아일랜드·레고랜드, 일부 기프트숍 할인. 써밋 미포함 후기 |
| ③ 기간·시작 | 첫 사용일 포함 연속 9일, 각 명소 1회 | 구매일로부터 1년 안에 사용 시작, 첫 명소 방문 시 활성화 후 30일, 각 명소 1회 |
| ④ 쓰는 방법 | 이메일 바우처 → My CityPASS 앱·웹에서 확인·예약 → 모바일 티켓 스캔. 여권 지참. 입장권 앱과 예약 앱이 따로라 헷갈린다는 후기 | 이메일 → 두 번째 확인 메일(스팸함 확인) → 앱 동기화 → 앱에서 선택·예약 → 첫 명소에서 활성화. 충전된 스마트폰 필수. 등록 복잡·이중 차감 후기 |
| ⑤ 가격 (10월 초, 성인 1명) | 약 18.7만 원, 한 곳당 약 3.7만 원 (곳 수 고정) | 3곳 약 15.5만, 5곳 약 23.4만, 7곳 약 30만, 10곳 약 39만. 한 곳당 약 5.2만(3곳)→3.9만(10곳). 4곳 이상은 빅버스 포함 |
| 환불 | 옵션마다 다름 | 옵션마다 다름 |

## 표 3. 궁금증 연쇄 설계 (한 구간이 남기는 궁금증을 다음 구간이 푼다)

| 순서 | 내용 | 이 앞에서 품는 궁금증 | 이 구간이 남기는 다음 궁금증 |
|---|---|---|---|
| 도입 | 비슷해 보이지만 다르다 → 한 줄: 짜여 있는 패스 vs 내가 짜는 패스 → 오늘 순서 안내 | 둘이 뭐가 달라? | 구체적으로 뭐가 짜여 있다는 거야? |
| 1. 구성 방식 | 5곳 세트(3곳 선택) vs 100곳 중 2~10곳 | 뭐가 짜여 있다는 거야? | 그래서 내가 갈 곳은 어디에 있어? |
| 2. 포함 범위 | 겹치는 대표 명소, 시티패스의 알찬 구성, 고시티의 넓은 선택 | 내가 갈 곳이 있나? | 며칠 쓸 수 있어? |
| 3. 기간·시작 | 9일 vs 30일(첫 방문 때 시작) | 며칠 쓸 수 있어? | 쓰는 건 얼마나 번거로워? |
| 4. 쓰는 방법 | 바우처→앱 예약→스캔 vs 메일 두 번→앱 동기화→예약→활성화 | 쓰는 건 번거로워? | 그래서 값은 얼마나 차이 나? |
| 5. 가격 | 18만 원대 후반 vs 곳 수별(15만 중반~39만), 한 곳당 값 | 값은 얼마나 달라? | 그래서 난 어떤 여행에 맞아? |
| 6. 장단점·여행 유형 | 각각 [장점→잘 맞는 여행→아쉬운 점] + 유형 3가지 + 세 가지 질문 | 난 어느 쪽? | 사기 전에 더 알아 둘 건? |
| 7. 꿀팁 | 출발 전 세팅, 이중 차감, 왕관·특별 체험, 예약 시기, 일정 여유, 결제 혜택·환불 | 알아 둘 게 뭐야? | — |
| 마무리 | 한 줄 정리, 본전 뽑으려 무리하지 말기 | — | — |

## 표 4. 기존 원고와 겹침 대조

| 항목 | `뉴욕패스계산` v3 | 이번 영상 (v2) |
|---|---|---|
| 시청자 질문 | 패스가 이득이야? | 둘이 뭐가 달라? 난 어느 쪽? |
| 핵심 한 줄 | 한 곳당 값보다 비싼 곳을 갈 때만 이득 | 시티패스는 짜여 있는 패스, 고시티는 내가 짜는 패스 |
| 뼈대 | S01 오사카 핵심요약 | S12 도쿄 핵심요약 |
| 비교 대상 | 시티패스·고시티·빅애플패스 + 개별권 | 시티패스·고시티 2종 |
| 가격 | 핵심 장 2개(느슨·빽빽 일정별 견적, 개별권 합계, 한 곳당 값 판정) | 한 장(5장): 두 패스 총액 구조와 한 곳당 값 요약만. 일정별 견적·개별권·빅애플 없음 |
| 장 구성 | 패스 3종 설명 → 일정 정의 → 느슨 → 빽빽 → 이럴 때만·확인 → 대입법 | 구성 → 포함 범위 → 기간 → 쓰는 방법 → 가격 → 장단점·유형 → 꿀팁 |
| 결론 | 일정별 개별권 vs 시티패스 | 여행 스타일별 시티패스 vs 고시티 vs 패스 없이 |
| 겹치는 사실 | 시티패스 5곳 구성·9일, 고시티 2~10곳·30일, 왕관 별도, 앱 둘/등록 복잡, 가격 | 같은 사실을 다른 틀로 사용 |
| 새로 들어간 것 | — | 포함 범위 상세 대조(에지·원월드·MoMA·써밋, 시티패스 구성 혜택), 처음 쓰는 흐름 비교, 장단점·유형 추천, 꿀팁 6가지 |

판정: 가격 장이 생겨 겹침이 늘었지만 질문·결론·뼈대·장 구성이 다르고 핵심 정보 겹침은 절반 미만이다. 중복 아님. 다만 가격 숫자는 `뉴욕패스계산`과 같은 마이리얼트립 화면 값을 쓰므로, 두 원고를 모두 올릴 경우 숫자가 같아야 한다.
