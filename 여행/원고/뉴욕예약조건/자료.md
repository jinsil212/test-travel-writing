# 자료 — 뉴욕 호텔 예약 조건: 무료 취소 vs 환불 불가

조사일 2026-10-08. 관리표 제작 ID ca08ec269289. **공식 근거와 2차 자료를 구분해 적는다.** 뉴욕 호텔만의 최신 가격 차이 통계는 찾지 못했다. 그래서 원고는 "소폭 차이"라고만 말하고 금액·%는 약속하지 않는다.

## 1. 환불 불가가 더 싼가 (가격 차이)
- Checkbook(소비자 매체, 2023-05 갱신, 약 2,000개 요금 수집): "대부분의 호텔이 환불 불가 요금에 **작은 할인**을 준다. 환불 불가는 예약 때 결제한다." 핫와이어·프라이스라인 시크릿 딜이 가장 많이 싸지만 이것도 환불 불가. https://www.checkbook.org/national/hotel-refund-policies
- 일반 업계 가이드(2차, 검색 요약만 확인, 원문 403): 환불 불가가 유연 요금보다 대략 5~15% 싸다는 설명. **원고에는 % 쓰지 않음**(공식 확인 불가 + 숫자 줄이기 원칙).
- 뉴욕 한정 최신 격차 수치는 확인 못 함 → "호텔·날짜마다 다르다. 직접 두 요금을 나란히 보라"로 처리.

## 2. 취소 마감
- Marriott 고객지원: 취소 정책은 **호텔과 선택한 요금**이 정한다. 마감은 **호텔 소재지 시간대** 기준. 예약 전 '객실 선택 → 요금 상세(Rate Details) → 취소 정책'에서 날짜·시각 확인, 예약 후엔 확인 메일. **마감 뒤 취소하면 보통 1박 객실료+세금** 상당 요금 가능. https://support.marriott.com/s/article/find-marriott-cancellation-policy
- Booking.com 개발자 문서: 무료 취소 마감은 숙소가 정하며 숙소·요금마다 다르다. 환불 불가 상품은 무료 취소 기한이 없다(null). 숙소에 권장하는 값은 "체크인 하루~이틀 전까지". https://developers.booking.com/demand/docs/orders-api/cancellation-policies
- Booking.com 소비자 글(검색 요약): 마감은 보통 **호텔 현지 시간대** 기준(뉴욕 호텔을 런던에서 예약해도 뉴욕 시간). 취소 후 **24시간 안에 확인 메일이 없으면 숙소에 직접 확인**. https://www.booking.com/articles/how-to-cancel-hotel-reservations.en-gb.html
- 마감 표기 방식 두 가지: "◯월 ◯일 23:59까지"(정확) vs "도착 3일 전"(어느 시각인지 계산 필요) — 여행 매체 설명(2차).
- 시차(직접 계산): 뉴욕은 2026-10 현재 서머타임(UTC-4) → 한국(UTC+9)과 **13시간 차**. 미국 서머타임은 2026-11-01(일) 종료 → 이후 UTC-5, **14시간 차**.

## 3. "플렉시블" 라벨의 함정
- Checkbook: 프라이스라인의 어떤 호텔 '플렉시블 취소'는 "기한 이후 취소 시 95% 위약금". 전체적으로 선결제 플렉시블 요금 중 상당수는 **환불이 30~50%뿐**, 체크인 24~72시간 이내 취소·노쇼는 **전액 몰수**. 라벨만으로는 이런 한계가 안 보인다. 일반 '환불 가능' 요금도 체크인 24시간 전까지, 늦으면 **1박 요금**. (미국 내 다수 호텔 조사이며 뉴욕 전용 아님 — 원고에서 그렇게 밝힌다.)
- **노쇼**: 사정이 바뀌면 수수료가 있어도 반드시 취소. 안 하면 호텔이 노쇼로 처리해 "완전 환불 가능" 요금이어도 전체 숙박을 청구할 수 있다. (Checkbook)
- 환불 불가인데 사정이 생기면 호텔에 문의: 날짜 변경·같은 체인 다른 지점 이동을 허용하는 경우가 많았고 가끔 환불도 있었다(보장 아님). (Checkbook)

## 4. 가격이 내려갈 때 (무료 취소의 진짜 값)
- One Mile at a Time(2014-11, 오래된 글이지만 원리는 계속 통용): 호텔은 빈 방이 많으면 임박해서 요금을 낮추는 일이 있다. 유연 요금은 가격이 내려가면 취소하고 다시 예약할 수 있다. 저자는 대개 유연 요금을 고르고, 며칠 안 남았고 환불 불가가 확 싸면 예외. https://onemileatatime.com/the-most-frustrating-hotel-rate-changes/ (뉴욕 Hyatt Herald Square 사례: 유연 요금이 48시간 전 취소 조건, 도착 전날 요금 하락)
- 순서 원칙(일반 상식, 내 안내): **새 예약이 확정된 뒤** 기존 예약을 취소.

## 5. 총액 표시 규칙 (취소 조건은 대상 아님)
- FTC '불공정·기만적 수수료 규칙'(16 CFR 464), **2025-05-12 시행**: 호텔 등 단기 숙박은 의무 수수료(리조트 피 포함)를 넣은 **총액**을 가장 눈에 띄게 보여 줘야 한다. 세금은 제외할 수 있으나 결제 전 공개해야 한다. 수수료 금지 규칙이 아니다. **FAQ는 취소·환불 조건 자체를 정하지 않는다.** → "총액은 법이 챙겨 줘도 취소 조건은 내가 읽어야 한다"는 포인트. https://www.ftc.gov/business-guidance/resources/rule-unfair-or-deceptive-fees-frequently-asked-questions , https://www.ftc.gov/news-events/news/press-releases/2025/05/ftc-rule-unfair-or-deceptive-fees-take-effect-may-12-2025
- 세금·리조트 피 세부 금액은 기존 원고(`원고/뉴욕숙소`)가 다루므로 이번 원고에서 반복하지 않는다.

## 6. 확인 못 한 것 (원고에서 단정하지 않음)
- 뉴욕 호텔 평균 취소 마감(24/48/72시간) 통계, 환불 불가의 뉴욕 평균 할인율, 한국 카드사 환불 소요일, 힐튼 공식 취소 페이지(403).
- 모든 요금·마감은 호텔·요금·날짜별로 다르므로 "예약 화면 문구가 최우선"으로 처리.
