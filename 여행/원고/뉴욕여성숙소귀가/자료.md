# 자료 — 여성 혼자 뉴욕 숙소, 귀가 동선

조사일: 2026-10-08 (사용자 주제 문구 입력 → 웹 검색 + MTA 공식 페이지 열람). 확인 등급: **[확인]** 원문 페이지 직접 열람 / **[검색요약]** 검색 결과 요약만 확인 / **[미확인]** 근거 부족. 원고에는 [확인]과 일반 안전 수칙으로 공통 확인되는 것만 단정 없이 쓰고, [미확인]은 쓰지 않는다.

사용자 입력(주제): "여성 혼자 뉴욕 숙소, 관광지 거리보다 귀가 동선을 먼저 보세요 / 하차 지점부터 숙소 출입문까지 동선·야간 출입 조건"

## 1. MTA 공식 안전 안내 [확인]
출처: https://www.mta.info/safety-and-security/subway-and-bus-security (WebFetch 2026-10-08)
- 혼잡하지 않은 시간대(off-hours)에는 **지정된 대기 구역**에서 열차를 기다린다. (off-hours의 정의는 페이지에 없음)
- 한산한 시간대에는 **차장 칸(conductor car)** 을 탄다. 열차 **가운데**에 있다.
- **빈 칸은 피한다.**
- 역 출입구는 **사람이 가장 많은 쪽, 보통 24시간 부스가 있는 쪽**을 쓴다. 단, 모든 역에 있지는 않다.
- 주변을 살핀다. 도움이 필요하면 **Help Point 인터콤**, MTA 직원·경찰, 긴급이면 **911**.
- 보조(검색요약): 플랫폼 끝이나 빈 플랫폼은 피하고 중간 대기 구역 이용 / 한적한 밤엔 끝 칸 피하기 / 헤드폰은 주변 인지를 떨어뜨림 (NYPD 팁 요약, emergency.nyls.edu, CUNY 안전 안내) [검색요약]
- Help Point: 파란 불 인터콤. 초록 버튼=정보, 빨간 버튼=긴급(MTA 설명). 다만 2023년 5~10월 감사 보고에서 긴급 호출 1,000여 건이 응답 못 받았다는 지적이 있음(amNY 보도) → 원고에서는 "버튼만 믿지 말고 직원·911도 함께"로 쓴다. [검색요약]

## 2. 지하철·PATH 야간 운행 [부분 확인]
- 뉴욕 지하철은 전 역 24시간 운행 체계. 심야에는 노선 일부가 셔틀로 바뀌거나 급행이 완행으로 서는 등 **패턴이 바뀐다**(MTA 2012 지도 설명, 현재 세부는 다를 수 있음). 원고에서는 "심야엔 노선이 바뀌고 간격이 길어질 수 있으니 앱으로 확인"만. [검색요약]
- PATH: 2025-12 Port Authority 공지에서 **9 St·23 St 역이 밤 11:59~오전 5시 야간 폐쇄**(점검). 가까운 대안은 크리스토퍼 St·33 St. 2026-10 현재 유지 여부는 미확인 → 원고에서는 "심야에는 역이 닫히거나 간격이 길어질 수 있으니 막차·심야 운행을 당일 공식 앱에서 확인". 구체 간격 숫자는 쓰지 않는다. [검색요약, roi-nj.com 2025-12-02]

## 3. 숙소 보안 체크 항목 (여성 혼자 여행 가이드 공통 항목, 개인 조언 성격) [검색요약]
- 24시간 프런트 데스크, 객실 층에 올라갈 때 키카드가 필요한 엘리베이터, 복도·공용 공간 CCTV, 다른 혼자 여성 여행자의 후기. (smartertravel, travelhoppers, sixtyandme 등)
- 1층·지상 가까운 객실은 피하고 높은 층 요청. (globalrescue 등)
- 낮에만 보지 말고 밤 길을 확인: 거리뷰와 최근 후기, 지하철역에서 도보 **약 10분 이내**를 권하는 가이드 (adventurouskate 등 — 개인 의견). 이 "10분"은 가이드 권고 중 하나일 뿐이라 원고에서는 "도보 몇 분"보다 "역 출구에서 출입문까지 가는 길을 직접 그려 본다"로 쓴다.
- 호텔 벨 데스크로 택시를 부르면 이름·승차 위치·목적지 기록이 남는다는 조언. [검색요약]
- 에어비앤비류: 직원이 없고 출입 통제가 약할 수 있음, 키박스 코드를 이전 투숙객이 알 수 있는 점이 늦은 도착에 부담(Hostaway 등 업계 글). 뉴욕시는 30일 미만 단기 임대에 제한이 있고 한 건물에 키박스가 여럿이면 무허가 단기 임대 신호일 수 있다는 지역지 설명(villageview.nyc 2023). [검색요약] → 원고에서는 법 해석 없이 "직원이 없고 출입 방식이 불분명하면 첫 도착이 어렵다" 정도만.
- 늦은 체크인: 호텔마다 다름. 24시간 프런트가 있는지, 체크인 마감 시간과 늦은 도착 안내를 예약 확인서·호텔 공식 안내로 확인하라는 일반 조언. 공식 정책을 한 문장으로 일반화할 근거는 없음. [미확인 → 일반 조언으로만]

## 4. 택시·차량 호출 [검색요약]
- 탑승 전 앱에 뜬 차량 번호판·차종·색·기사 이름을 대조 (Manhattan College 공공안전실, Lyft 안내).
- Uber는 "Verify Your Ride" PIN을 켤 수 있고 매번 또는 야간만 설정 가능. 여정 공유(Share My Trip), 앱 내 긴급 신고 버튼. (Uber 안전 페이지 — 해외판 페이지라 한국 앱 화면과 다를 수 있음 → 원고는 "앱 설정에서 확인").
- 호텔 앞에서 호출하면 기다리는 동안 문 안(로비)에서 차를 확인하고 나가는 습관.

## 5. 이번 주제에서 쓰지 않는 것
- 범죄 통계 수치(지하철 중범죄 증감 등): 출처 간 차이가 크고 [검색요약]뿐이라 쓰지 않는다. 기존 `뉴욕혼자여행/자료.md §4`에 있으나 이번 영상은 수치 대신 **행동 순서**로 간다.
- "OO동네는 안전/위험" 단정, 특정 호텔·동네 추천. 근거가 개인 후기뿐.
- 사용자 경험 중 제공되지 않은 것(밤 귀가 사건, 성별에 따른 불안 경험 등). 사용자가 제공한 경험은 `내경험.md`의 뉴저지 장기 체류·펜 스테이션 근처 체류 두 건뿐.

## 6. 원고에 쓰기 전 재확인 목록 (사용자가 직접 확인)
1. 이용할 숙소의 24시간 프런트 여부, 체크인 마감, 객실 층 키카드 엘리베이터 (해당 숙소 공식 페이지·최근 후기)
2. PATH 야간 운행·역 폐쇄 (PATH 공식 앱)
3. Uber/Lyft 앱의 야간 PIN 설정 화면 (한국 앱 기준)
4. MTA 안전 안내 문구 최신 여부 (mta.info)
