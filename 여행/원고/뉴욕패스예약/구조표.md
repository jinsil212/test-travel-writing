## 1. 구조 비교표 — 뼈대 S13 ↔ 이번 주제

뼈대: **S13 일본 주의사항 15가지** (유형3). 큰 틀만 맞추고 억지로 끼우지 않았다.

| 순서 | S13에서 한 일 (읽은 대목) | 이번 주제에서 한 일 | 맞은 정도 |
|---|---|---|---|
| 도입 | 만만하게 보던 시청자를 흔든다 → 처음엔 같았다 → 직접 겪은 것만 추렸다 → 끝까지 보면 당황할 일을 피한다 → "그럼 바로 시작해 볼게요" | 패스 사고 안심한 시청자를 흔든다 → 처음엔 같았다([각색]) → 읽은 안내만 추렸다 → 끝까지 보면 내 패스 예약 방법을 안다 → "그럼 바로 시작해 볼게요!" | 같은 틀 |
| 첫 항목 | 가장 중요한 주의(흡연 여부·콘센트)를 먼저 | 가장 중요한 사실(패스마다 예약 순서가 다르다)을 먼저. S14의 "결론 먼저 던지기" 빌림 | 같은 틀 |
| 각 항목의 모양 | ① 공감되는 장면 ② "알고 보니" 규정·문화 설명 ③ 그래서 이렇게 하라는 대안 | ① "~했다가 당황스럽잖아요" 장면 ② "알고 보니" 패스별 규정 ③ 대안(구매 메일 열기 / 일몰은 따로 구매 / '나중에'로 두기 / 큰 가방 숙소에) | 같은 틀 |
| 항목 사이 | 짧게 이어 감 | 항목 끝에 다음 항목 예고 한 줄씩 | 같은 틀(조금 더 촘촘) |

| 개인 경험 | 항목마다 직접 겪은 일 | 쓰지 않음(경험 없음). 대신 "~하게 되면" 가정 장면 | **다름**(경험을 지어낼 수 없음) |
| 마무리 | 한 줄 요약 → "한 가지 더 꼭 얘기하고 싶은 게 있어요" → 빽빽한 일정 대신 비우기 | 오늘 할 일 한 가지 → 다섯 가지 요약 → "한 가지 더…" 본전 뽑으려고 예약을 빽빽하게 채우지 말기 | 같은 틀 |

## 2. 촘촘한 흐름표 — 시청자 궁금증이 이어지는 구조

| 순서 | 내용 | 이 앞에서 품는 궁금증 | 이 구간이 남기는 다음 궁금증 |
|---|---|---|---|
| 도입 | 샀다고 끝이 아님 → 입구에서 못 들어갈 수 있음 → 순서 / 일몰 / 사용 기간 / 환불 4가지 예고 | 이미 샀는데 놓친 게 있나? | 내 패스는 어디서 예약하지? |
| 1. 순서 | 빅애플패스 = 결제 때 요청사항란에 일시, 시티패스 = 산 뒤 앱, 고시티 = 앱 등록 뒤 예약, 첫 방문 때 시작 → 구매 확인 메일부터 열기 | 내 패스는 어디서 예약하지? | 그럼 어디를 예약해야 하지? |
| 2. 예약 필요한 곳 | 패스마다 목록이 다름 → 앱·옵션 화면 표시 확인 / 일몰은 패스로 하지 않기 / 왕관은 별도 | 어디를 예약해야 하지? | 언제 예약하지? |
| 3. 시기 | 시티패스 9일은 예약 첫날부터 셀 수 있음, 고시티는 열리는 날이 곳마다 다름, 빅애플은 확정 뒤 구매 | 언제 예약하지? 빨리 하면 좋은 거 아냐? | 일정이 바뀌면 어떻게 되지? |
| 4. 변경·취소 | 빅애플 확정 후 환불 불가('나중에'), 시티패스 앱에서 변경(명소별 기한), 고시티 앱 확인 | 일정이 바뀌면? 환불 불가가 이 얘기였구나 | 예약 다 했는데 당일엔 뭐가 막히지? |
| 5. 당일 입구 | 충전·여권·앱 화면, 여신상 시간 = 보안 줄 시간·큰 가방 불가, 인트레피드 라운지 바우처, 9/11 마지막 입장 | 당일에 뭘 조심하지? | 그럼 오늘 당장 뭐부터 하지? |
| 마무리 | 구매 확인 메일부터 열기 → 다섯 가지 요약 → 본전 뽑으려고 빽빽하게 예약하지 말기 | 오늘 당장 뭐부터? | — |

도입의 열린 고리(순서 → 일몰 → 사용 기간 → 환불)는 본문 1 → 2 → 3 → 4장에서 같은 순서로 회수된다.
