## 0. 영상 위치
- 준비편(이 영상): 당일치기로 가기로 정한 사람이 출발 전에 챙길 것. 투어 상품 비교·판매는 **다음 영상**, 이 영상은 마지막에 "고정 댓글"로만 연결(사용자 계획 2026-10-10).
- 같은 도시 앞선 원고 `나이아가라당일`(v1~v4: 당일 vs 1박 판단·상품 시간표)은 비교편 씨앗 자료로 보존, 이 영상에서는 판단 기준·상품 비교를 쓰지 않는다.

## 1. 서류·국경
| 사실 | 등급 | 출처 |
|---|---|---|
| VWP(ESTA) 대상 여행자는 2022-10-01부터 **육로 입국도 승인된 ESTA 필요**. 캐나다에서 육로로 도착해 ESTA가 없으면 입국 신청을 철회하고 캐나다로 돌아가야 하며, 캐나다에서 ESTA를 신청할 수 있다. | 공식 | CBP Buffalo 보도자료(2023-04-11) https://cbp.gov/newsroom/local-media-release/cbp-buffalo-reminder-esta-requirement-land-border-ports-entry |
| ESTA는 여행 계획이 시작되면 바로, 늦어도 도착 72시간 전까지 신청 권고. | 공식 | 같은 자료 |
| ESTA 승인은 입국 보장이 아님(현장 심사관이 판단). | 공식 | 같은 자료 |
| 육로 입국 시 VWP 여행자는 I-94 수수료를 내지만, 현재 90일 VWP 입국 기간 안이면 면제. | 공식 | 같은 자료 (금액은 바뀔 수 있어 원고에서 말하지 않음) |
| 캐나다 eTA는 항공 입국용. 한국 여권은 무비자(관광). 미국→캐나다 육로 입국엔 eTA 불필요. | 검색 | canada.ca 두 페이지에서는 육로 면제 문구를 확인하지 못함 → 원고에서 "항공 입국에 해당, 육로는 필요 없다고 알려져 있으나 공식 확인" 표현 |
| VWP로 입국한 뒤 캐나다에 다녀오면 새 90일이 아니라 처음 입국 때의 남은 기간으로 재입국되는 것이 원칙(8 CFR 217.3(b)), 새 기간 부여는 심사관 재량. | 검색 | 여러 2차 자료 → 원고에서는 "남은 기간이 이어진다고 알려져 있다, 오래 체류 중이면 확인" |
| 국경 대기 시간은 CBP 사이트(bwt.cbp.gov)에서 시간 단위로 갱신, 4월 어느 날 12분/5월 어느 날 1분 같은 스냅샷이 있을 만큼 편차 큼. | 검색 | CBP 피드 스냅샷 |
| 투어 상품 페이지 두 개(당일·1박) 모두 **국경 통과·여권 안내가 적혀 있지 않았다.** | 상품 | WAUG 상품 페이지 (2026-10-08) |
| 당일 투어에 스카이론 타워 점심·입장이 포함 — 스카이론은 캐나다(온타리오) 쪽 전망대. | 상품+상식 | WAUG 당일 투어 |
