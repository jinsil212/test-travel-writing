## 0. 사용자가 준 참고 링크 확인
- https://experiences.myrealtrip.com/products/3509787 → **나이아가라 상품이 아니라 "빅애플패스(뉴욕 입장권 패스)"** 상품 페이지였다 (판매사 타미스, 쿠폰가 128,000원~). 출발·도착·폭포·보트 정보 없음.
- 따라서 이 링크는 나이아가라 근거로 쓰지 않고, 뉴욕 일정 안에서 "패스 쓸 날 vs 나이아가라 갈 날" 정도의 곁가지로만 의미가 있다(원고에는 쓰지 않음). 사용자가 다른 링크를 의도했다면 교체 필요.

## 2. 한국어 투어 상품 실제 일정 (WAUG, 2026-10-08 확인)
**당일 투어** https://www.waug.com/ko/activities/129456 (페이지 URL 번호와 상품이 다를 수 있어 아래는 fetch한 상품 기준)
- 맨해튼 새벽 3:30 픽업(6번가), 뉴저지 3:50 픽업(웨스트뉴욕). 10분 전 도착.
- **총 19시간 30분 소요** 표기. 폭포 도착·체류 시각표는 페이지에 없음.
- 할인가 약 35만 3천 원(정가 약 39만 2천 원). 포함: 왕복 차량, 가이드, 스카이론 타워 전망대 입장+점심.
- 불포함: 전망대 레스토랑 팁 1인 $20, 선택관광(저니 비하인드 더 폴스 $30, 나이아가라 시티 크루즈 $35).
- → 계산: 육로 왕복 12~14시간을 19.5시간에서 빼면 **현지에서 쓰는 시간은 대략 6~7시간**(점심·국경 대기 포함). *(추정 계산. 시각표 미공개)*

**1박 2일 투어** https://www.waug.com/ko/activities/129456 에서 fetch된 내용 (※ 위 당일 상품과 같은 URL로 다른 상품이 나왔음 → 상품번호가 혼동되므로 가격은 "대략"으로만 쓴다)
- 새벽 5:00 타임스퀘어, 5:30 포트리 픽업.
- 약 61만 9천 원(할인가 약 60만 7천 원). 포함: 차량·가이드, 캐나다 쪽 호텔 1박(쉐라톤 또는 브록), 스카이론 점심, 2일차 조식.
- 후기에 폭포 야경 + 다음 날 아침 숙녀호(Maid of the Mist) 탑승 언급.
- 한국일보(2026-05-19) 요약(검색 결과 인용): 당일 투어는 캐나다 쪽 중심 약 8~9시간 체류, 1박 투어는 양쪽 폭포 + 야간 조명(여름 불꽃놀이). 기사 원문은 410이라 직접 확인 못 함 → 원고에서 한국일보를 근거로 쓰지 않는다.

## 4. 국경·입국 (한국 여권)
- 캐나다 육로 입국에는 eTA 불필요(eTA는 항공 입국용). 한국 여권 무비자(관광).
- 미국 재입국: ESTA 승인 필요(CBP는 2022-10부터 육로 입국도 ESTA 요구). 뉴욕에 ESTA로 들어와 있다면 같은 ESTA로 돌아오는 경험담이 있으나 **개인 경험담이라 공식 확인 필요**. 원고에서는 "ESTA 승인 상태 확인, 투어사에 국경 통과 안내 문의"까지만 말하고 세부 서류(I-94 등) 단정 안 함.
- 겨울(11~4월)에는 숙녀호·바람의 동굴 운영이 멈출 수 있음(tripstore).
