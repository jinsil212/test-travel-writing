# 자료 — 뉴욕 겨울 여행 준비 (날씨·한국 비교·옷·즐길 거리)

조사일: 2026-10-20. 사용자 지시: 가을 빼고 겨울 여행 준비 컨셉. "겨울이 얼마나 춥지? 한국이랑 비교하면? 옷은 어떻게? 겨울에 즐길 거리는?" + 사람들이 겨울 뉴욕에서 많이 궁금해하는 것 조사.
등급: **[확인]** 공식 자료 / **[검색요약]** 검색 요약만 / **[미확인]** 근거 부족.
`뉴욕가을옷차림`(10~11월, v5)은 별도 편으로 둔다. 이 폴더는 12~2월.

## 1. 기온 — 뉴욕 vs 서울
| | 1월 낮 평균 | 1월 밤 평균 | 출처 |
|---|---|---|---|
| 뉴욕 센트럴파크 | 39.5°F ≈ 4°C | 27.8°F ≈ −2°C | NWS 1991–2020 평년값 (nycjan.pdf, Daily Max/Min Normals) [검색요약, NWS PDF 인용] |
| 서울 | 1.5°C | −5.9°C | 기상청 2011년 1월 기후 자료, 1981–2010 평년값 [검색요약, 기상청 PDF 인용] |
- 12월(앞 폴더 자료): 낮 9°C → 5°C, 밤 3°C → −1°C.
- 결론: **평균 기온은 뉴욕이 서울보다 3~4도 높다(덜 춥다).** 평년값 기간이 다름(1991–2020 vs 1981–2010) → 원고에선 "몇 도쯤 높다" 정도로만.
- 체감: 빌딩 사이 바람으로 체감이 크게 떨어진다는 후기 다수(트립스토어 12월 글 등) [검색요약]. "뉴욕은 덜 춥다"로 끝내지 말고 바람 얘기를 붙인다.
- 1~2월 추위가 혹독할 수 있다는 현지 여행 블로그(wherearethosemorgans) vs "뉴욕은 연중 비교적 온화"(Frommer's 편집장, straight.com) — 의견 엇갈림.

## 2. 눈
- 뉴욕 연평균 적설 약 30인치(≈76cm), 주로 1~2월 [검색요약: citiesinsider 2026. NWS 1991–2020 수치(29.8")는 직접 확인 못함].
- 해마다 편차 큼: 2024–25 시즌 13인치(citiesinsider) [검색요약].
- 서울 12~2월 적설 평균 25.1cm(1981–2010, 기상청 — 아시아경제 2020 인용) [검색요약].
- 폭설 때 항공편 지연·도로 미끄러움(Bloomberg 2024-02), 적설 8인치쯤이면 지상 구간 지하철 중단·지연 가능(citiesinsider) [검색요약].
- 원고 판단: "눈이 서울보다 많이 온다"는 단정 대신 "해마다 다르고, 한 번 오면 몰아서 와서 항공·교통에 영향" 정도. 눈 구경 목적이면 1~2월이 확률이 높지만 보장 안 됨.

## 5. 중복 확인 (예비)
- `뉴욕가을옷차림`: 10~11월 옷·짐 → 시기가 다름. 옷 대목 일부 겹침(실내 난방·신발) → 겨울 편은 옷을 한 장으로 줄이고 날씨 비교·즐길 거리·준비사항 비중을 키운다.
- `뉴욕비오는날대체일정`·`뉴욕전망대비예보`·`뉴욕비예보`: 날씨 대안 일정 → 실내 대안은 한두 문장만.
- `뉴욕예약순서`·`뉴욕주의사항`: 일반 준비 → 겨울 특화(연휴 휴관·눈·일몰)만 다룬다.
- 원고/ 폴더명에 겨울·12월·크리스마스 편 없음.
