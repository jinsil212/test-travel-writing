# 재설계안 v2 (초안 — 사용자 확인 전, 2026-10-09)

> 앞의 `기획_재설계안_초안.md`(뉴욕 일수별 선택)를 대체한다. 사용자 방향: 뉴욕에 간 김에 근교에 가고 싶지만 실제로는 많이 못 가는 사람 → 대표 세 곳(필라델피아·보스턴·워싱턴)의 매력을 간단히 소개하고, 자체로 가 본 입장에서 **투어로 가면 어떤 이점이 있는지** 알아보고 싶게 만들어 마이리얼트립 상품 구매로 이어지게 한다. 상품 자료는 `자료.md` 4-2.

## 1. 타깃·핵심 질문
- 타깃: 뉴욕 일정에서 하루 정도만 근교에 쓸 수 있고, 어디가 좋을지 고르지 못한 사람.
- 핵심 질문: "뉴욕 간 김에 딱 하루만 내서 간다면 어디가 좋고, 어떻게 가야 덜 힘들까?"
- 핵심 메시지(안): 세 곳은 매력이 다르고, 하루만 낼 때는 **직접 가면 이동·체크인에 반나절씩 사라지는 곳**(보스턴·워싱턴)일수록 투어가 시간을 아껴 준다. 필라델피아는 직접 가기도 쉬워서 투어를 고르는 이유가 "대학·역사 묶음"뿐이다. 솔직한 비교 → 맞는 사람에게만 상품을 추천.

## 2. "뉴욕 일수별 선택"은 어떻게 달라지나
- **삭제한다.** 일수별 표는 "며칠 쓸 수 있나"를 묻는 사람용이었다. 이번 타깃은 하루만 낼 수 있다고 전제하므로 한 문장으로 줄인다("뉴욕 일정에서 하루만 뺄 수 있다면").
- 대신 새로 들어가는 선택 기준: ① 어떤 매력을 원하나(도시별 1:1 매칭) ② 직접 vs 투어(체력·예산·시간 기준).
- 이동·체크인 반나절 계산(v3 1장)은 **투어의 이점을 증명하는 근거**로 재사용한다. 직접 1박으로 가면 뉴욕 일정이 이틀 가까이 줄지만, 투어는 뉴욕 숙소에서 하루만 쓴다는 비교.

## 4. 도시별 투어 판단 (제 판단 + 자료.md 근거)
- 보스턴: 열차로 편도 4시간대라 직접 당일치기는 비효율. 투어(14시간)가 이득이 가장 큼. 단 상품이 "아이비리그 + 보스턴 하이라이트" 구성이라 프리덤 트레일을 천천히 걷는 일정은 자체 1박이 맞음.
- 워싱턴: 기념관들이 멀리 떨어져 있어 차량 이동이 있는 투어가 편하다는 후기가 많음. 투어 적합.
- 필라델피아: 열차로 1시간 15분~1시간 반이라 직접 당일치기가 쉬움. 투어를 고를 이유는 프린스턴·펜 대학과 역사 장소를 한 번에 묶는 것. 후기 수가 28개로 적은 점은 영상에서 밝힌다.
- 추천 상품 1순위(안): 워싱턴 [조아 뉴욕] 3443088, 보스턴 [조아 뉴욕] 3443090, 필라델피아 [트립 어스 뉴욕] 4170759. 가격·출발일은 올리는 날 재확인.
