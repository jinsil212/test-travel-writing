# 재설계안 v3 (초안 — 사용자 확인 전, 2026-10-09)

> 앞의 `기획_재설계안_v2.md`(투어 상품을 영상 안에서 소개)를 대체한다. 사용자 지시: 이 영상에서는 투어 상품을 팔지 않는다. 시청자가 영상을 보고 "아, 나는 여기 가야겠다"는 답을 얻게 한다. 투어 비교는 도시별로 쪼갠 별도 영상(3편)에서 한다. 상품 조사 자료는 `자료.md` 4-2에 보관(후속 편에서 사용).

## 1. 이 영상의 역할 (3+1편 시리즈의 허브)
- **허브(이 영상):** 뉴욕 간 김에 하루 낼 수 있는 사람이 필라델피아·보스턴·워싱턴 중 **어디로 갈지 고르는** 영상. 답: 취향 두 질문으로 한 곳이 나온다.
- **후속 3편(별도):** 필라델피아 / 보스턴 / 워싱턴 각각 "직접 vs 투어로 가기" 본격 비교. 여기서 상품이 나온다.
- 허브에는 상품명·가격·구매 유도가 없다. 투어 얘기는 도시 카드 끝의 "이 도시는 투어로 가는 방법을 따로 영상으로 정리했어요" 한 줄과 마무리 안내뿐이다. 이 한 줄에는 상품 링크·가격이 없으므로 제휴 표시가 필요 없다(후속 편에서 상품 링크를 쓸 때 표시).

## 2. 타깃·핵심 질문·핵심 메시지
- 타깃: 뉴욕 일정 중 하루만 근교에 쓸 수 있는데 어디가 좋을지 고르지 못한 사람.
- 핵심 질문: "뉴욕 간 김에 하루만 낸다면 필라델피아·보스턴·워싱턴 중 어디가 나한테 맞을까?"
- 핵심 메시지: **무엇을 보고 싶은지(질문 1)와 하루를 얼마나 길에 써도 되는지(질문 2) 두 가지로 답이 나온다.**

## 3. 클릭 요소 → 도입 → 본문 → 마무리 연결

| 클릭 요소 | 제목·썸네일 | 도입에서 말하는 곳 | 본문에서 강화 | 마무리 회수 |
|---|---|---|---|---|
| 선택 피로 해소: "어디 가야 하지?" | `하루만 낸다면?` | 도입 ① 첫 문단에 상황(하루만 낼 수 있다) + "두 가지 질문으로 답이 나온다" 선공개 | 2장 도시 카드마다 "이런 분께는 여기"를 반복, 3장에서 질문 두 개를 한 표로 | 마무리에서 "나는 여기" 한 줄씩 |

## 4. 구조 (S05 뼈대: 도입 → 감 잡기 → 지역별 소개 → 스타일별 선택 → 마무리)

| 순서 | 내용 | 틀 | 분량(안) |
|---|---|---|---|
| 도입 | ① 뉴욕 일정 중 하루만 내서 근교를 가고 싶은데 어디가 좋을지 막막하다 + 두 질문으로 답이 나온다 ② 세 도시를 다 다녀왔고, 길에서 하루를 다 쓰고 후회하는 경우도 있다(경험 슬롯) ③ 친한 친구에게 알려 준다는 설정 + 고르는 기준 공개(보고 싶은 것 / 길에 쓸 시간) ⑤ "그럼 바로 시작해 볼게요!" (보상 단계 없음) | S01·S15 도입 + 01 5단계 훅 | 500~600자 |
| 1. 감 잡기 | 뉴욕을 기준으로 세 도시의 편도 시간: 필라델피아 가까움(열차 1시간 15분~1시간 반), 워싱턴 3시간 반, 보스턴 4시간 조금 넘게 | S05 지형 감 잡기 | 400자 |
| 2. 도시 카드 ×3 | 각 카드: ⓐ 한 줄 매력 ⓑ 하루에 이런 장면 ⓒ 이런 분께 ⓓ 내가 가 본 느낌 ⓔ 아쉬운 점 ⓕ(마지막 한 줄) 투어로 가는 법은 따로 영상 | S05 지역별 소개 + 유형5의 솔직 단점 | 각 800~900자 |
| 3. 두 질문으로 고르기 | 질문 1 무엇을 보고 싶나(역사·영화 / 대학·산책 / 박물관·기념관), 질문 2 길에 얼마나 쓸 수 있나(가벼운 하루 / 하루 종일). 표 한 장으로 "나는 여기" | S05 스타일별 선택 + S12 성향별 결론 | 700자 |
| 4. 이런 분은 고르지 마세요 | 도시별 한 줄 비추천(역설적 비추천) | 02-③ | 300자 |
| 마무리 | 질문 두 개 다시 요약 + 내 추천 한 줄(사용자 확정) + "각 도시를 투어로 가는 건 따로 영상" 안내 | S05 마무리 | 400자 |

합계 약 5,000~5,800자(12~14분).
