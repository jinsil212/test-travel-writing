# 재설계안 (초안 — 사용자 확인 전, 2026-10-09)

> 사용자 요청: 날짜를 9일로 고정하지 말고, "뉴욕 간 김에 필라델피아·보스턴·워싱턴까지 가고 싶은 사람"을 타깃으로. 사용자는 세 도시를 모두 다녀옴(`내경험.md`에 기록, 세부는 미확인). 대본 v1~v3은 건드리지 않고 비교용으로 보존한다.

## 1. 타깃
- **새 타깃:** 뉴욕이 목적지인데 "온 김에" 근교 도시(필라델피아·보스턴·워싱턴)도 가 볼까 고민하는 사람.
- **이전(v1~v3) 타깃:** 세 도시를 9일에 넣는 일정표를 짜는 사람. 제목 씨앗("뉴욕·보스턴·워싱턴, 9일에 다 넣으면…")을 문자 그대로 읽은 것이라, 사용자가 말한 "간 김에" 사람과 달랐다.

## 2. 핵심 질문과 메시지
- 시청자 질문: "뉴욕 간 김에 어디까지 가도 후회 안 할까?"
- 핵심 메시지(안): 근교 도시는 취향 싸움이 아니라 **뉴욕에서 편도 시간**으로 갈린다. 필라델피아는 뉴욕 하루를 쓰는 당일치기, 워싱턴·보스턴은 1박 이상이라 뉴욕 일정을 이틀 가까이 내줘야 한다. 그러니 "뉴욕 며칠 중 몇 일을 내줄 수 있나"로 고른다.
- 근거 자료(확인됨): 뉴욕–필라델피아 열차 약 1시간 15분~1시간 반(애그리게이터·가이드 기준, 올리기 전 암트랙 재확인), 뉴욕–워싱턴 약 3시간 반, 보스턴–뉴욕 4시간 조금 넘게, 호텔 체크인 오후 3~4시/체크아웃 오전 11시 (`자료.md`).

## 3. 제목·썸네일 1안 (확정안 아님, 방향 확인용)
- 제목: 🇺🇸뉴욕 여행 전 필수시청! 간 김에 필라델피아·보스턴·워싱턴도 갈까? 뉴욕 일정을 얼마나 내주고 다녀올지 편도 시간으로 정리 [뉴욕근교여행, 필라델피아당일치기, 보스턴여행, 워싱턴여행, 암트랙, 뉴욕일정]
- 썸네일: 상단 `간 김에 갈까?`(노란 박스) / 하단 `뉴욕 며칠 내줘요`(검은 박스) / 뉴욕 중심 지도에서 세 도시로 뻗는 선과 편도 시간(1.5h·3.5h·4h)
- 이유: 제목·썸네일·첫 문장이 같은 약속("간 김에 가면 뉴욕이 얼마나 줄어드나")을 한다. 9일 대신 "뉴욕 일정이 줄어드는 만큼"이 손실 감각이다.

## 4. 기존 흐름 (S05 오키나와 총정리, 전문 통독 기준)
도입(상반된 매력 → 어설프게 알아보면 실망 → 친한 친구에게 알려 준다) → 지형 감 잡기 → 남·중·북 지역별 소개(어떤 사람에게 맞고 대표 즐길 거리) → 스타일별 박 배분(3박4일 기준, 마지막 날은 공항 가까운 곳) → 지역별로 몰아서 짜기 → 맛집 3곳 → 숙소 → 교통 → 시즌 → 마무리.
같은 유형 도입 원문 확인: S01(인기 + 근교 도시까지 즐길 거리 → 잘 세우면 푹 빠지고 어설프면 지침 → 친구에게 알려 준다), S10(막막한 질문을 연달아), S12(규모 커서 동선 잘못 짜면 이동에 시간을 다 씀).

- **3개 각각 넣을까?** → 넣는다. 다만 같은 분량으로 소개하는 영상이 아니라 "뉴욕에서 거리별 선택지 3단계"를 비교하는 영상으로 만든다. 1~2개만 넣으면 "어디까지 갈까"에 답이 안 된다. 도시별 상세 코스는 후속 단독 편(필라델피아 당일치기 / 보스턴 1박 / 워싱턴 1박)으로 분리해 겹치지 않는 원고를 늘린다.
- **분량:** 도시 카드 3장 때문에 길어지므로 상한 6,500자(12~15분)로 도시 카드당 700~900자.
- **중복 재확인:** 이전원고 `us-east-coast-days`(4도시 며칠씩, 원고 없음)와 도시 조합이 비슷하나 질문이 다름. 기존 `나이아가라당일`과는 "당일 vs 1박" 틀이 닮았지만 도시가 달라 겹침 적음. 후속 편 낼 때 재확인.

## 6. 사용자 확인 필요 (답 주시면 반영)
1. 세 도시 각각: 가서 며칠(몇 박) 있었는지, 어떻게 갔는지(기차/버스/비행기), 좋았던 것 하나, 아쉬웠던 것 하나.
2. 필라델피아·보스턴·워싱턴 중 "이건 뉴욕 간 김에 꼭 갈 만하다 / 굳이 안 가도 된다"는 개인 판단.
3. 이 방향(뉴욕 중심 + "내주는 시간" 비교)으로 가도 되는지. 맞으면 `기획.md`·제목·썸네일을 이 방향으로 바꾸고 v4를 쓴다.
