## 표 2. 후보 구조 비교 — 이번 주제에 가장 맞는 것 하나 고르기

이번 주제의 성격: 앞 단계의 답이 다음 단계의 질문이 되는 **순서형 의사결정**(확인 → 분류 → 마감 → 날짜 → 맞바꾸기 → 이동 → 대비)이고, 손실 회피("취소하면 손해")가 클릭 이유.

| 후보 | 큰 구조 (문단 흐름) | 앞이 뒤를 끌고 가는 순서형인가 | 개념을 먼저 가르는가 | 가장 궁금한 것부터인가 | 질문에 바로 답하는 장치 | 이번 주제와 맞는 정도 |
|---|---|---|---|---|---|---|
| **S07 비행기 반입 물품** | 헷갈리는 지점 → 실패담 → 약속 → 기본 개념(기내/위탁) → "알았으니 이제 구체 품목" → 가장 궁금한 품목부터 → 나머지 범주 → 추가로 생각도 못 한 것 → 마무리 | ○ ("~알았다면 이제 ~") | ◎ 개념 구분이 먼저 | ◎ 가장 궁금한 것(보조배터리)부터 | ◎ "근데 어떻게 확인해요?"에 바로 답 | **◎ 채택** |
| S13 일본 주의사항 15가지 | 안심 흔들기 → 항목마다 당황한 장면 → 이유 → 대안 (식당·돈·쇼핑·교통·반입 묶음) | △ 항목이 서로 독립 | × | △ | △ | ○ 항목 단위의 "경고→이유→대안"만 부분 차용 가능(v2에서 사용) |
| S14 세부 꿀팁 9가지 | 가장 중요한 팁 결론부터 → 위치·이동시간 → 스타일별 매칭 → 맛집 → 기타 정보 | ○ | ○ 구역 가르기 | ◎ 결론부터 | △ | ○ 도입 직후 결론 먼저 방식만 보조 |
| S18 인천공항 출국절차 | 막막함 → 나도 처음엔 → 핵심만 → 시간순 단계("했다면 이제") → 입국까지 | ◎ 시간순 | × | × | △ | ○ 장 사이 "했다면 이제" 브릿지만 보조 (손실 회피 장치가 없음) |
| S08 대만 꿀팁 | 부담 낮춤 → 숙소·교통·근교·기념품 팁 나열 | △ | × | △ | △ | △ 나열형이라 흐름 연결이 약함 |

**왜 v2의 S13에서 S07로 바꿨나:** S13은 서로 독립된 경고를 묶음별로 모은 구조인데, 이번 원고는 "취소하면? → 그럼 마감은? → 그럼 어느 날로? → 어떻게 바꿔?"처럼 앞 장의 답이 다음 장의 질문이 되어 S07이 더 가깝다. S07도 규정 확인 영상이라 "헷갈리는 규정을 먼저 구분하고 구체 항목으로 들어간다"는 점이 세 칸 분류와 대응된다. 억지로 끼운 부분은 없고, 유사한 건 큰 틀(도입 → 개념 구분 → 가장 궁금한 것부터 → 나머지 → 추가 함정 → 마무리)이다.

## 표 3. 채택 구조(S07) 대 이번 주제 대입

| S07 문단 | S07의 기능 | 이번 원고 대응 | 비교 |
|---|---|---|---|
| 1 | 헷갈리는 지점 짚기 | 도입 1문단 "이걸 다 취소해야 하나 헷갈리시죠?" | 같은 기능 |
| 2 | 실패담 + 해결 약속 + 시작 | 도입 2~3문단: [각색] 실수 세 가지 + 세 칸·질문 세 개 약속 + "그럼 바로 시작해 볼게요!" | 같은 기능. 실패담이 실제 경험이 아님이 차이 |
| 3 | 기본 개념(기내 vs 위탁) | 1장 예약 세 칸 나누기 | 같은 기능 (두 개 vs 세 개) |
| 4 | "알았다면 이제 구체적으로" 브릿지 | 1장 끝 "취소 버튼부터 누르면 어떻게 되는지부터요" | 같은 기능 |
| 5~6 | 가장 궁금한 품목 + "어떻게 확인해요?" 답 | 2장 취소하면? + 예매 메일 확인 세 가지 | 같은 기능 |
| 7 | 추가로 바뀐 규정 | 3장 마감은 파는 곳마다 다름(대행·취소 보호·날씨 보장) | 같은 기능 |
| 8~9 | 가장 많이 뺏기는 것 + 구체 기준 | 4~5장 날짜 정하기·맞바꾸기·전망대 시야 | 같은 기능 |
| 10~12 | 나머지 범주 차례로 | 6장 못 옮기는 칸 이동 묶기 | 같은 기능 |
| 14~15 | 생각도 못 했던 것, 마지막으로 | 7장 예약을 더 사지 말 것 + 비상 후보 | 같은 기능 |
| 16~17 | 링크 안내 + 마무리 | 마무리 + "한 가지 더"(일정 빈칸) — 링크 보상은 안 약속 | 링크 대신 질문 세 개로 대체 |

## 표 4. 리텐션·핵심 내용 설계 (앞에서 품는 궁금증 → 이 구간 → 남기는 다음 궁금증)

| 순서 | 내용 | 이 앞에서 품는 궁금증 | 이 구간이 남기는 다음 궁금증 |
|---|---|---|---|
| 도입 | 일주일 내내 우산 그림 → 취소해야 하나 → 실수 세 가지 → "예약은 살리고 세 칸으로 자리 바꾸기" 약속, 질문 세 개 보상 | (제목·썸네일을 누른 시청자) 내 예약 다 취소해야 해? | 취소 말고 뭘 한다는 거지? 세 칸이 뭐야? |
| 1. 세 칸 | 비 상관없음 / 날씨 탐 / 시간 고정, 달력에 우산 칸·해 칸 | 내 예약들은 어떻게 정리하지? | 근데 취소하면 정확히 어떻게 되는데? |
| 2. 취소하면 | [각색] 환불 문의 장면, 탑 오브 더 락은 환불 안 되고 재발급, 메일에서 세 가지 확인 | 겁나서 취소하면 어떻게 돼? | 그 '마감'이 언제까지인데? 산 곳에 따라 달라? |
| 3. 마감 | Edge 두 시간 전 vs 탑 오브 더 락 하루 전 vs 재판매처 일주일, 대행 상품 규정, 취소 보호는 구매 때만 | 언제까지 옮길 수 있어? | 옮길 수 있다면 어느 날로 옮겨? |
| 4. 날짜 | 일주일 전 예보 말고 사나흘 전 시간대별 예보, 가장 나은 날 하나 찍기 | 어느 날이 비 오는 날이야? | 그래서 실제로 어떻게 바꾸는 건데? |
| 5. 맞바꾸기 | 화요일·목요일 맞바꾸기 예시, 새 자리 먼저 확인, 비 오는 날 전망대 비추천, 여신상 보안 줄 | 어떻게 바꿔? 전망대는 어느 칸이야? | 공연·식당처럼 못 옮기는 건? |
| 6. 못 옮기는 칸 | 같은 구역 실내끼리 묶기, 하루 두 구역 줄이기, 센트럴파크·브루클린 브리지 비추천 | 못 옮기는 예약은 어떡해? | 그래도 하루가 비면? 불안하면? |
| 7. 함정·비상 | 불안해서 예약 더 사면 맑은 날 자리 없음, 예약 필요 없는 후보 두 개, 짐 한 줄 | 빈 날엔 뭘 해? 더 사 둬야 안심 아냐? | 그래서 오늘 뭘 하면 돼? |
| 마무리 | 한 줄 요약, 오늘 밤 질문 세 개, "한 가지 더"(일정에 빈칸) | 오늘 당장 뭘 해? | — (행동: 예매 메일 열기) |

**연결이 끊기던 곳(v2)과 v3에서 고친 것**
- v2는 취소 얘기(규칙 1)가 칸 분류(규칙 2)보다 먼저 와서 "칸"이라는 말이 도입에서 약속됐는데 두 번째에야 나왔다 → v3는 도입 약속 직후 1장에서 세 칸을 설명하고, 1장 끝에서 "취소하면 어떻게 되나"로 넘김.
- v2는 여신상(날씨 타는 칸)이 못 옮기는 칸 장(규칙 6)에 섞여 있었다 → v3는 날씨 타는 칸 장(5장)으로 이동.
- 장마다 끝 문장을 "다음 궁금증"(위 표 마지막 열)으로 통일했다.

**남은 약점**
1. 도입 ② 실패담이 [각색]이고 도입이 531자로 조금 길다.
2. 탑 오브 더 락·서밋·Edge 날씨 세부 정책은 공식 페이지 403이라 재판매처 안내 기준.
3. "사나흘 전" 권고는 일반 예보 특성에 근거한 제 판단.
