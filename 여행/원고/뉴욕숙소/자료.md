## 2. 맨해튼 호텔 자체 추가요금(리조트피·데스티네이션 피)
- 뉴욕시 규정: 2026-02-21부터 호텔 광고·표시 가격에 의무 수수료(destination/resort/hospitality fee 등)를 포함한 **총액 표시** 의무. 신용카드 보증금(hold)도 고지. 위반 과태료 첫 위반 $525, 두 번째 $1,050, 세 번째 이상 $3,500. [검색요약] — Herrick(법무법인 공지), Skift 2026-01-22 보도.
- 연방(FTC) 총액표시 규정도 시행 중이라는 보도. [검색요약] Skift.
- 금액 사례(전부 오래되거나 2차 출처): 어반 데스티네이션 피 $25~$50/박(2018년경 보도), New York Hilton Midtown $25+세금(2018), Millennium Times Square $30(오래된 목록), Kimpton Era Midtown **$51.64/박(2026-05 목록)**. [검색요약] — **2026년 평균 수수료는 찾지 못함 [미확인]**. 원고에서 "평균 얼마"라고 말하지 않는다. 호텔별 예약 최종 화면 금액을 직접 확인한 사례만 쓴다.
- 확인 도구: resortfeechecker.com (호텔별 수수료 조회).
- 주의: 의무 수수료에 판매세가 추가로 붙는지는 이번에 확인하지 못함 [미확인].

## 3. 뉴저지(허드슨 강 건너편) 호텔 세금
| 항목 | 값 | 등급 | 출처 |
|---|---|---|---|
| 주 판매세 | 6.625% | [확인] | nj.gov 호텔/모텔 페이지 |
| 주 점유 수수료(State Occupancy Fee) | 기본 5%. 뉴어크·저지시티 등은 1%로 낮다는 설명이 있으나 출처 간 충돌(Airbnb 안내는 뉴어크·애틀랜틱시티만 1%로 표기) | [미확인] | roommaster.com vs Airbnb 도움말 |
| 지방 점유세 | 주법상 일반 도시는 최대 3%까지 조례로 가능. **호보컨 3%** (단기임대 사이트 기준). **저지시티·뉴어크·엘리자베스는 별도 법으로 자체 호텔세** | [검색요약] | 단기임대 정보 사이트, NJ 법 설명 |
| 저지시티 합산 | 페이지 계산상 6%(시) + 1%(주) + 6.625% = **13.625%** (공식 확인 못함) | [미확인] | roommaster.com |
| 호보컨 합산 | 6.625% + 5% + 3% = **14.625%** (공식 확인 못함) | [미확인] | 단기임대 집계 사이트 |
| 위호켄(Weehawken) | 지방세 채택 여부 불명. 기본 11.625%, 3% 추가 시 14.625% | [미확인] | — |
| 뉴어크 | 2026-01부터 별도 1일 $3 소방 서비스 부과금 | [검색요약] | roommaster.com |
| **맨해튼식 정액 요금($3.50)** | 뉴저지에는 같은 형태가 없음(이번 조사에서 확인 못함) | [미확인] | — |

**핵심 해석(원고용):** 세율만 보면 맨해튼 14.75%, 뉴저지 약 13.6~14.6%로 **큰 차이가 없다**. 뉴저지가 싸다면 세금 때문이 아니라 객실료 차이와 교통비 때문이다. 정확한 시별 세율은 NJ 조세국 `munitaxlist.pdf`(이번에 PDF 본문 추출 실패)와 시 조례에서 확인해야 한다.

## 4. 객실료 수준 (맨해튼 vs 뉴저지)
- 뉴욕시 전체 평균 객실 요금(ADR): 2025년 $334 [검색요약, NYC Tourism + Conventions]. 2026년 6월 단월 약 $378 [검색요약, NYC Comptroller]. 중간 등급 호텔 약 39,000실 평균 ADR 약 $215 (2026년 5월 갱신) [검색요약, NYC Tourism].
- 뉴저지: 2026 평균 데이터 **못 찾음 [미확인]**. 2024-10 조사에서 중심가 3성급 이상 비교 시 뉴욕 평균 $284, 저지시티는 가장 싼 더블룸이 $310으로 미국 2위로 비싼 도시라는 보도가 있었음 [검색요약, thebulkheadseat.com 인용, 2024-10]. 호텔 검색 사이트에 저지시티 $150~$180, 위호켄 Sheraton Lincoln Harbor $250 같은 날짜 불명 스냅샷 [미확인].
- **결론:** "뉴저지는 무조건 싸다"는 근거가 이번 조사에서 확인되지 않았다. 원고에는 쓰기 전에 **같은 날짜·같은 조건으로 두 곳을 검색한 실제 가격**을 직접 캡처해서 비교해야 한다(촬영/화면 자료 필요).

## 5. 뉴저지 숙소의 교통비 (맨해튼 출퇴근비)
- PATH 1회 요금 **$3.25** (2026-05-04 인상). 10회 $31, 20회 $62, 40회 $124, 1일권 $12.50, 7일권 $42.75, 30일권 $131.50. 이후 매년 25센트씩 올라 2029년 $4. [검색요약, fox5ny / hobokengirl / 6sqft 보도 종합]
- 2026-05-17부터 PATH 전 노선 7일 운행(약 25년 만에 주말 호보컨-WTC 직행 부활). [검색요약]
- 계산 예: 하루 왕복 2회 = $6.50, 4박 5일 일정이면 5일 × $6.50 ≈ $32.5. 7일권($42.75)이 더 나을 수 있음. (원고 계산용 가정이며 일정에 따라 다름)
- NJ Transit 뉴어크 펜 → 뉴욕 펜 요금: 신뢰할 출처 못 찾음 [미확인]. 뉴어크 공항~맨해튼 요금도 확인 못함.
- 맨해튼 혼잡통행료(차량 이용 시): 평시 $9, 야간 $2.25 보도 있으나 [검색요약], 자가용 여행자가 아니면 부차적. 홀랜드 터널 통행료도 별도 확인 필요 [미확인].
