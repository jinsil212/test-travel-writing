# 자료 — 뉴욕 지하철 처음 타는 순서 (2026-10-09 조회)

표시: **[공식]** 교통기관·관청 공식 페이지에서 직접 확인 / **[검색요약]** 검색 요약·기사·가이드 / **[미확인]** 근거 부족 → 원고에서 뺀다.
환율은 `원고/뉴욕공항선택`·`원고/뉴욕숙소`와 같은 **1달러 약 1,340원**으로 맞춤 (2026-10-08 서울 외환시장 종가 1,338.5원, 머니투데이·철강금속신문).
이관 메모: 이 주제는 `미드폼 작성/여행/이전원고/nyc-subway-guide`(2026-08-24 작성)의 교체본이다. 그 폴더의 검증 자료를 가져와 **2026-09-17과 2026-10-09에 다시 확인**했고, 확인이 안 되는 항목은 아래 7번으로 내렸다.

## 8. 공항 이동

이 편에서 **다루지 않는다**(사용자 결정 2026-09-17, 새 폴더에서도 유지). 공항→시내는 `원고/뉴욕공항선택`이 이미 단독 편으로 다룬다. 원고에서는 "공항에서 시내로 들어오는 건 따로 정리해 둔 게 있다" 정도로만 지나간다 — 아직 올리지 않은 영상을 약속하지는 않는다.
