- 개별 합계: 54,121 + 36,762 + 32,860 + 26,852 = **150,595**
- 시티패스: 5곳짜리라 4곳만 가도 **186,888** → 개별보다 +36,293. (5번째로 탑 오브 더 락 40,348을 더 가면 개별 합계 190,943 → 패스가 4,055 저렴)
- Go City 4곳: **195,042** → +44,447
- 빅애플패스 빅4: 169,268 + 추가금(엠파이어 21,494 + 자연사 8,060 + 크루즈 0 + 구겐하임 0 = 29,554) = **198,822** → +48,227 (크루즈는 여신상 섬 페리와 다른 상품)

### 3-2. 빽빽한 일정 — 유료 시설 7곳 (엠파이어, 탑 오브 더 락, 자연사, 여신상 페리, 9/11, 인트레피드, 구겐하임)
- 개별 합계: 54,121 + 40,348 + 36,762 + 32,860 + 29,112 + 44,221 + 26,852 = **264,276**
- 시티패스: 엠파이어·자연사 포함 + 선택 3곳을 비싼 순(인트레피드 44,221, 탑 오브 더 락 40,348, 여신상 32,860)으로 → 남는 9/11(29,112)·구겐하임(26,852) = 55,964 단품. 186,888 + 55,964 = **242,852** → 개별보다 **21,424 저렴**

- 빅애플패스 빅7: 296,891 + 추가금(엠파이어 21,494 + 탑락 8,060 + 자연사 8,060 + 크루즈 0 + 9/11 2,687 + 인트레피드 0 + 구겐하임 0 = 40,301) = **337,192** → +72,916

### 3-3. 읽는 법 (곳당 단가)
- 시티패스 5곳 평균 약 37,400원/곳. 빽빽 일정에서 고른 5곳의 단품 평균은 약 41,700원이라 이득.
- Go City는 7곳이면 곳당 약 42,800원. 빽빽 일정 7곳의 단품 평균은 약 37,800원이라 손해. **곳 수를 채울수록 곳당 값은 내려가지만, 이득은 '단품이 그 곳당 값보다 비싼 곳'을 고를 때만 난다.**
- 한 곳이 개별 3만 원대인 곳(자연사, 9/11, 구겐하임, 여신상 페리)을 개수 채우려고 넣으면 손해 쪽으로 기운다.
