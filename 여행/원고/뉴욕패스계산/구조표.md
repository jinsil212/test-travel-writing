# 구조표 — 뉴욕 패스 (v3 설계 근거)

핵심 주제: **뉴욕 입장권 패스는 "많이 가서"가 아니라 "한 곳당 패스 값보다 비싼 곳을 갈 때만" 이득이다.**

## 표 1. 도입이 제목·썸네일·지침에 맞는지 점검 (v2 실제 문장 → v3 조치)

| 점검 항목 | v2의 실제 문장 | 판정 | v3 조치 |
|---|---|---|---|
| 첫 문장이 제목·썸네일의 약속("무조건 이득?")을 바로 받는가 (01-4) | "뉴욕에 가면 엠파이어 스테이트 전망대, … 들어가 보고 싶은 곳이 줄줄이 생기죠." — 시설 나열로 시작, "무조건 이득"은 2문단에서 처음 나옴 | △ 약속 확인이 늦음 | 첫 문장을 "뉴욕 패스, 많이 갈수록 무조건 이득이라는 말 들어 보셨죠?"로 바꿈 |
| 썸네일 줄1 `2026년 10월 최신가` | 도입 전체에 가격 기준 시점 언급 없음 | × 약속이 도입에서 이어지지 않음 | 3문단에 "10월 초에 확인한 가격 기준" 추가 |
| 썸네일 줄3 `일정별 견적 완벽정리` | "느슨한 일정과 빽빽한 일정, 두 가지로 나눠서 최종 견적까지 뽑았고요" | ○ | 유지 |
| 5단계 훅 ① 통증 | "입장권을 하나씩 따로 사야 하나, 패스 하나로 묶어야 하나 계산하다가 브라우저 탭만 잔뜩 늘어난 분들" | ○ | 유지(첫 문장 뒤로) |
| ② 경험담 | "저도 이번에 직접 계산해 보기 전까지는 무조건 이득인 줄 알았어요. [각색]" | ○ `[각색]` 표시 유지 | 유지, 사용자 확인 대기 |
| ③ 손실 차단·약속 | "친한 친구에게 알려준다는 생각으로 … 같은 조건에서 비교해 봤어요" | ○ | 유지 |
| ④ 보상 | 없음 | 의도적 생략(준비한 체크리스트·링크 없음) | 유지 |
| ⑤ 고정 멘트 | "그럼 바로 시작해 볼게요!" | ○ | 유지 |
| S01 도입 3단(인기 → 극과 극 → 친한 친구 + 약속) | 1문단 인기, 2문단 극과 극, 3문단 약속 | ○ | 유지 + 핵심 한 줄 |

## 표 2. 벤치마크 구조(타이거투어 S01 오사카 핵심요약) ↔ 이번 주제 대입 비교

억지로 끼우지 않고 큰 틀만 맞춘다. 맞지 않는 S01 장은 쓰지 않는다.

| 순서 | S01의 구조·장치 (원고 행) | 이번 주제 대입 | 유사도 |
|---|---|---|---|
| 도입 ① | 대상이 인기 있고 매력이 다채롭다 (9행) | 뉴욕은 가 보고 싶은 유료 시설이 줄줄이, 패스가 인기 | ○ 같은 역할 |
| 도입 ② | 준비 따라 극과 극 + 직접 준비한 근거 (11행) | 잘 고르면 아끼고 어설프면 개수 채우다 손해 + 직접 계산 | ○ |
| 도입 ③ | 친한 친구에게 알려준다 + 약속 + 시작 멘트 (13행) | 같음 + **핵심 한 줄**(S08 결론 선공개 장치 보조) | ○ |
| 큰 틀 먼저 | 오사카를 3구역으로 설명, 구역마다 [특징 → 잘 맞는 사람 → 반면 안 맞는 사람] (15~21행) | 패스 3종 설명, 패스마다 [구조 → 잘 맞는 분 → 반면 안 맞는 분] + **한 곳당 값** | ○ 가장 유사 |
| 전환 | "이제 ~알았으니까 ~" (23행) | "이제 패스가 어떻게 생겼는지 알았으니까 내 일정부터" | ○ |
| 갈 곳 정하기 | 갈 만한 곳 중 내 스타일에 맞는 몇 곳만 고른다 (23~25행) | 내가 갈 유료 시설을 정하고 느슨(4곳)/빽빽(7곳)으로 나눔 + 계산 규칙 | △ 형태는 다르나 역할 같음 |
| 스타일별 매칭 | "~하신 분들은 X / 반면 저희처럼 ~는 Y" (29~31행) | "여유롭게 다니는 분들은 개별권 / 반면 부지런히 도는 분들은 시티패스부터" + 견적 | ○ |
| 확장판 + 확인 | 프리미엄 조이패스 + "사용할 수 있는 곳 반드시 미리 확인" (33행) | 고시티·빅애플은 이럴 때만 + 포함 안 된 것·예약·환불 확인 | ○ |
| 선택지 장단점 → 내 선택 | 공항 이동 3가지 장·단점 → "그래서 저희는 ~" (49~53행) | 패스 3종을 한 곳당 값으로 장·단점 → 일정별 결론 | △ 일부만 사용 |
| 꿀팁 + 무리하지 말라 | "꿀팁 하나 더" + "뽕 뽑으려 무리하지 말라" (35행) | 개별권 비교 팁 + 대입 3단계 + 핵심 한 줄 재반복 | ○ |
| 마무리 | "해 주고 싶은 얘기가 많아 길어졌는데" (61행) | 같음 | ○ |
| (쓰지 않음) | 맛집 3곳(37~47행), 이코카 카드·현금·환전(55~59행) | 주제와 무관 | × 억지로 넣지 않음 |

## 표 3. 궁금증 연쇄 설계 (한 구간이 남기는 궁금증을 다음 구간이 푼다)

| 순서 | 내용 | 이 앞에서 품는 궁금증 | 이 구간이 남기는 다음 궁금증 |
|---|---|---|---|
| 도입 | "많이 갈수록 무조건 이득?" 상식을 의심 → 10월 초 가격 기준, 일정별 최종 견적 약속 → 핵심 한 줄(한 곳당 값) | 패스 사면 진짜 이득일까? | 패스가 세 가지라는데 뭐가 어떻게 달라? |
| 1. 패스 세 가지 | 시티패스(5곳 고정)·고시티(2~10곳 선택)·빅애플패스(개수 + 곳별 추가금), 각각 한 곳당 값과 맞는 분/안 맞는 분 | 세 가지가 뭐가 달라? | 그래서 내 일정이면 어느 쪽이야? |
| 2. 내 일정·계산 규칙 | 느슨(4곳)/빽빽(7곳) 정의, 갈 곳만 넣기·후기 최다 개별권·성인 1인·낮 일반 시간대 | 내 일정이면 어떻게 비교해? | 느슨한 일정은 실제로 얼마가 나와? |
| 3. 느슨한 일정 | 개별 약 15만 / 시티 약 19만 / 고시티 약 19.5만 / 빅애플 약 20만. 단품 평균 3.8만 < 패스 한 곳당 4.7~4.9만 → 개별권 | 4곳만 가는데 패스가 손해? | 그럼 많이 가면(7곳) 이득 아니야? |
| 4. 빽빽한 일정 | 개별 약 26만 / 시티 약 24만 / 고시티 약 30만 / 빅애플 약 34만. 시티만 이득(고르는 3곳은 비싼 곳, 9일 안), 고시티는 곳 수는 같아도 손해 | 많이 가면 이득 맞아? | 그럼 고시티·빅애플은 쓸 일이 없어? |
| 5. 이럴 때만 + 확인할 것 | 고시티는 고른 곳이 전부 한 곳당 값보다 비쌀 때, 빅애플은 예약 편의에 값을 치르는 상품. 포함 안 된 것·예약/앱·환불 | 그 둘은 언제 써? 사기 전에 뭘 조심해? | 그래서 내 일정엔 뭘 해 보면 돼? |
| 6. 꿀팁 + 대입 | 개별권도 상품마다 가격 다름 → 2~3개 비교 / 3단계 대입 / 결론 / 핵심 한 줄 재반복 | 내 일정에 바로 써먹는 법은? | — |
