# 기획 — 아이와 함께하는 뉴욕, 신경 쓸 것과 주의할 것

작성일 2026-10-08 · 자료: `자료.md` · 관리표 제작 ID 34a26c2abb20 · 입력: 사용자 키워드("아이와 함께하는 뉴욕에서 신경 쓸 것·주의할 것")

## 중복 확인
- 확인한 목록: 테스트 `원고/`(나이아가라당일, 뉴욕7일경비, 뉴욕숙소, 뉴욕패스계산, 뉴욕혼자여행, 브로드웨이영어) / `미드폼 작성/여행/원고/`(뉴욕기념품샵, 뉴욕베이글, 뉴욕숙소, 뉴욕주의사항, 뉴욕첫여행) / `이전원고/` 29개 / 관리표 `check`(유사 후보 없음)
- 판정: **중복 아님.** 가장 가까운 것은 뉴욕주의사항(일반 여행자 대상 "걱정할 건 따로 있다")과 이전원고 nyc-travel-cautions인데, 아이 동반이라서 생기는 항목(유모차·카시트·공연 연령·단기임대 규정·시차)은 둘 다 다루지 않는다.
- 겹치는 부분 처리: 소매치기·호객·팁 일반론은 쓰지 않는다. 팁은 "아이 할인 전 금액 기준" 한 문장만.
- 사용자 지시 "기존 원고와 너무 유사하면 스킵": 해당 없음 → 진행.

## 1. 핵심 메시지 (1줄)
아이와 뉴욕은 "아이가 위험해서 어렵다"가 아니라 "어른 둘일 때는 없던 계단·검색대·연령 제한·좁은 방 때문에 일정이 막힌다"는 걸 미리 아는 여행이다.

## 2. 후킹 포인트 3개 (실제 자료 근거)
1. **의외성:** 지하철 역 중 엘리베이터가 있는 곳은 대략 세 곳 중 한 곳 (자료 §1). 유모차 들고 계단을 오를 각오가 필요.
2. **손실 회피:** 브로드웨이 극장 대부분은 만 4세 미만 입장 불가이고 무릎에 앉힐 아이도 표가 필요 (자료 §4). 비싼 표를 사고 못 들어갈 수 있다.
3. **비교:** 집 전체 에어비앤비 대신 호텔 — 뉴욕은 30일 미만 단기임대가 집주인 동거·손님 2명 제한이라 가족 통째 빌리기가 사실상 어렵다 (자료 §6, 현행 여부 단서).
