# 구조 점검표 v5 — 10~11월 뉴욕 옷차림·짐

핵심 주제: 10~11월 뉴욕은 두꺼운 옷 하나가 아니라, 아침저녁·건물 안·걷는 시간에 맞춰 입고 벗는 "얇은 3겹"으로 준비한다.

| 순서 | S03 내용 | 이 주제 | 유사도 |

| 미리 할 것 | 바우처·보험·등록 | 날짜 구간 정하기 · 예보 확인 (내용만 다름) | 높음 |

## 4. 궁금증 설계 — 앞에서 품는 질문 → 답 → 남기는 다음 질문

| 순서 | 내용 | 이 앞에서 품는 궁금증 | 이 구간이 남기는 다음 궁금증 |
|---|---|---|---|
| 도입 | 21도→9도, 패딩 하나로는 아침저녁·건물 안·걷는 시간이 문제 → 답은 얇은 세 겹 → 롱패딩도 마지막에 답 | 패딩 하나면 정말 끝일까? | 얇은 세 겹이 뭐고, 내 날짜엔? 롱패딩은? |
| 1장 날짜 구간 | 세 구간(낮·밤 숫자) + 예보 확인 | 내 날짜엔 얼마나 추워? | 낮 15도·밤 8도면 겉옷 하나로 되나? |
| 필수 1 아침저녁 | 낮밤 차이 + 서머타임 일몰 → 패딩 하나의 문제 → 구간별 겉옷 | 겉옷은 뭘 입지? | 그 겉옷이 건물 안에선 문제가 되는데? |
| 필수 2 건물 안 | 난방 → 안쪽 얇은 두 겹 → 벗은 겉옷은 가방에 | 안에선 어떻게 해? | 하루 종일 걸으면? |
| 필수 3 걷는 시간 | 열 나서 살짝 서늘하게 시작 + 신발·양말·하의 | 걸을 땐 뭐가 문제? | 세 상황을 합치면 하루가 어떻게 흘러가? |
| 하루 합치기 | 박물관·공원·전망대 하루 예시 | 정말 세 겹으로 하루가 되나? | 더하면 좋은 건? |
| 3장 꿀템 | 머플러·비니·장갑 / 접이식 보조 가방 / 방풍 외투·우산 | 작은 걸로 뭘 더해? | 이걸 캐리어엔 어떻게 담지? |
| 4장 캐리어 | 입고 탈 것 / 기내 / 캐리어, 한국 날씨 주의 | 어떻게 싸지? | 새로 사야 하는 건? 롱패딩은? |
| 5장 롱패딩·안 사도 되는 것 | 11월이면 롱패딩 불필요한 경우 많음 + 단벌 니트 + 새 신발 | 롱패딩 사야 해? | 한 줄로 정리하면? |
| 마무리 | 패딩 하나 질문에 답 + 세 상황 정리 + 날짜별 한 줄 | 결국 어떻게 입지? | — |
