# 자료 — 부모님과 뉴욕 (도보·환승·계단·휴식)

조사일 2026-10-08 · 관리표 제작 ID edcfa98ecad3
형식: 사실 / 출처 / 신뢰도(공식·후기·블로그). 원고에는 숫자를 최소로 쓰고, 세부 근거는 여기에만 둔다.

## 1. 지하철 엘리베이터 (계단 파트)
- MTA가 말하는 접근 가능(엘리베이터 등) 지하철역은 약 160개, 2026년에도 계속 추가 중. 출처마다 증가분 표기가 달라 정확한 올해 숫자는 불확실. → [MTA 장애 인식의 달 2026](https://www.mta.info/article/accessibility-disability-pride-month-2026), [MTA 접근성 개선 사업](https://www.mta.info/project/station-accessibility-upgrades) (공식, 검색 요약으로 확인)
- 전체 지하철역 수는 MTA 공식 472개(환승 구간을 노선마다 따로 센 방식, 2019년 자료). 복합역을 하나로 세면 약 423개. → [MTA 지하철·버스 사실](https://www.mta.info/agency/new-york-city-transit/subway-bus-facts-2019) (공식, 오래됨)
- ⇒ 원고 표현: "전체 역 가운데 엘리베이터 되는 역은 대략 3분의 1 안팎" (정확한 비율을 단정하지 않음).
- 실시간 엘리베이터·에스컬레이터 상태 확인 페이지가 따로 있고 "출발 전에 확인하라"고 MTA가 안내. → [MTA 접근 가능 역](https://www.mta.info/accessibility/stations) (공식, 직접 열어 확인)
- 후기: 엘리베이터가 고장 나거나 역 끝에 있어 멀다는 불만 반복 (Tripadvisor·검색 요약, 후기).

## 2. 걷는 길 (도보 파트)
- 브루클린 브리지: 다리 길이 약 1.1마일(약 1.8km). 보행로 건너는 데 30분~1시간(사진 멈춤 포함) 정도로 안내됨. 출처마다 차이, 블로그급. 공식 수치 아님 → 원고엔 "걷는 데 한 시간 가까이 걸릴 수 있다" 정도로만.
- 센트럴파크: 남북 약 2.5마일(약 4km), 폭 약 0.5마일. 끝에서 끝까지 쉬지 않고 걸으면 45분~1시간. 블로그급. 원고엔 "남북으로 4킬로미터쯤"으로만.
- 자유의 여신상: 미국 국립공원관리청(NPS) 이동 안내가 "섬에서 긴 도보와 배·보안 줄 대기가 있어 휠체어·전동스쿠터를 가져오길 권한다"고 표시. 섬 도착 후 무료 대여 휠체어는 3대, 선착순, 신분증 필요. → [NPS 이동 편의 안내](https://www.nps.gov/stli/planyourvisit/physical-mobility.htm) (공식, 직접 열어 확인)
- 왕관 입장: 엘리베이터 없이 162계단. 하루 약 500장만 발매, 수개월 전 매진. 신분증 일치·최소 키 규정. 가격은 출처마다 달라 원고엔 쓰지 않음. (블로그 다수, 공식 확인은 NPS/Statue City Cruises에서 필요 — 원고에선 "계단뿐"이라는 점만 사용)
- 보안 검색 2회 (블로그 다수 일치).

## 3. 대체안: 스태튼 아일랜드 페리
- 무료, 24시간 운행, 티켓 불필요. 평일 혼잡 시간 15~20분 간격, 그 외 30분 간격. 양쪽 터미널에 엘리베이터·에스컬레이터. → [Staten Island Ferry 공식](https://www.siferry.com/) (공식, 직접 열어 확인)
- 편도 약 25분(블로그 다수, 공식 페이지엔 소요시간 없음), 자유의 여신상 옆을 지나지만 내리지 않음, 반대편에서 전원 하선 후 다시 타야 함(블로그). 여신상 보려면 스태튼행은 오른쪽, 돌아올 땐 왼쪽(블로그).
- 후기 스레드에서도 "여신상은 페리에서 보고 상륙은 건너뛰라"는 조언 반복 (Tripadvisor, 후기).

## 4. 앉는 곳 · 휴식
- 브라이언트 파크: 움직이는 철제 의자 수천 개를 무료로 쓸 수 있음, 무료 독서실 있음. 잔디 개방 시간은 일정치 않음, 10월엔 잔디를 걷고 스케이트장 준비. (블로그, 시기에 따라 다름 → 원고엔 "공원에 무료 의자가 많다"만)
- 메트로폴리탄 미술관: 휠체어 한정 수 무료 대여, 선착순, 입장 홀 안내 데스크 (더 클로이스터스 안내 문구 확인). 5번가 본관 접근 가능 입구는 5번가 81번가 쪽과 80번가 주차장 쪽. 본관 좌석 안내 문구는 코로나 시기 문장이 남아 있어 현황 불확실. → [Met 접근성](https://www.metmuseum.org/visit/accessibility) (공식, 검색 요약)
- 더 클로이스터스: 정문에서 안내 데스크까지 약 60계단, 계단 없는 입장은 무료 셔틀 안내. → [Met Cloisters 접근성](https://www.metmuseum.org/ko/visit-guides/accessibility-at-the-met-cloisters) (공식)
- 엠파이어 스테이트: 대체로 접근 가능하나 정오 전후와 일몰 전후 줄이 길다는 재판매 사이트 설명(공식 아님). 원고엔 쓰지 않거나 "붐비는 시간 피하기"로만.

## 5. 교통 수단
- 버스: 계단이 없고 리프트·낮은 승차 높이, 우선 좌석 (후기·검색 요약 반복). 단, 교통 정체로 느릴 수 있음 → 원고 반영.
- 택시: 도로 상황에 따라 비용·시간 변동, 차에 타고 내리기가 불편할 수 있다는 후기. 원고엔 "택시를 타라"만 하지 않고 "도보 10분 넘는 이동"을 택시 기준으로 제안(필자 기준, 공식 아님).
- 시니어 할인(65세 이상 MTA Reduced-Fare): 공식 페이지에서 외국인 방문객 적용 여부 확인 불가 → **원고에서 말하지 않음**. 사전 신청·발급 필요하다는 안내(오래된 기사)만 확인.

## 6. 후기·질문글 근거 ([각색] 도입용)
확인한 건수는 많지 않다. 아래는 실제로 열어서 읽은 것.
1. Tripadvisor "Visiting NYC with elderly parent" (답글 9개): 휠체어 대여 권유, 여신상 상륙 건너뛰기·페리로 보기, 지하철보다 버스, 첫 배 이용, 줄 길다는 경고. → [링크](https://www.tripadvisor.com/ShowTopic-g60763-i5-k1948066-Visting_NYC_with_elderly_parent-New_York_City_New_York.html)
2. Tripadvisor "With elderly parents" (답글 84개 중 첫 10개만 열림): 부모님이 오래 못 걸어 택시·버스·페리 위주 계획, 소형 투어 버스 추천. → [링크](https://www.tripadvisor.com/ShowTopic-g60763-i5-k14505820-With_elderly_parents-New_York_City_New_York.html)
3. CityGuideNY 시니어 여행 팁: 택시가 낫다, 타임스스퀘어는 건너뛰거나 차 안에서 보기. 요금 정보는 2016년 자료라 쓰지 않음. → [링크](https://www.cityguideny.com/article/NYC-Senior-Travel-Tips-)
4. 검색 요약(영문 포럼 다수): 지하철 계단, 출퇴근 혼잡, 쉬는 시간 부족이 반복 불만.
⇒ 반복 주제: ① 지하철 계단·엘리베이터 불확실 ② 여신상 상륙 줄·걷기 ③ 앉을 곳·휴식 ④ 휠체어/좌석 이용. 한 사람만의 사건이 아니라 반복되는 어려움이라 도입 [각색]의 근거로 씀. 건수가 적으므로 **사용자 확인 전까지 [각색] 유지**.

## 7. 확인하지 못한 것 (원고에서 단정 금지)
- 올해 정확한 접근 가능 역 개수 (출처 간 불일치)
- 시니어 할인의 방문객 적용 여부
- 왕관 티켓 최신 가격
- 각 명소의 현재 입장·보안 대기 시간
