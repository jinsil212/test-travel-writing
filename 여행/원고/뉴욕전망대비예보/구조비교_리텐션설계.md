# 뉴욕 전망대 비 예보 — 구조 비교 · 리텐션 설계 (v4, 2026-10-09)

핵심 주제: **비 예보만 보고 전망대 예약을 취소하거나 바꾸면 손해라서, 바꾸기 전에 "어디서 샀나·무슨 표인가·취소 마감이 언제인가" 세 가지를 확인하고, 진짜 변수는 비가 아니라 시야·바람이다.**

## 3. 기존 구조 vs 이번 원고 대입 비교 (S07 ↔ 전망대)

| 순서 | S07 비행기 반입 물품 (기존 구조) | 이번 원고 (전망대 비 예보) | 유사도 / 억지 여부 |
|---|---|---|---|
| 도입 1 | 헷갈리는 지점 짚기 | 비 예보에 취소/변경 고민 | ◎ |
| 도입 2 | 실패담으로 손해 가능성 | "돈만 날리는 분들"(공식 규정 근거; 경험담은 없음) | ○ 경험담 대신 규정 |
| 도입 3 | 해결 약속 + 기본 개념으로 | 세 가지 결론 선공개 + 진짜 변수·보증 예고 | ◎ |
| 기본 개념 | 기내 vs 위탁이 뭔지 | 비로는 안 닫는다 / 바꿀 수 있는지는 표가 정한다 | ◎ |
| 가장 궁금한 것 ① | 보조배터리: 규정 + 확인하는 법 | 확인 ① 어디서 샀나: 환불되나 + 예약 메일 확인법 | ◎ |
| 가장 궁금한 것 ②③ | 액체류 → 전자기기 (규정 반복) | 확인 ② 무슨 표 → ③ 마감 (규정 반복) | ◎ 이 주제의 핵심이라 S07보다 크게 다룸 |
| 품목별 반복 | 담배·음식물·육류 | 전망대별 날씨 대응(엠파이어·엣지·써밋·탑오브더락) | ○ 품목 → 전망대로 단위만 다름 |
| (S07에 있음) 그 밖의 품목 나열 | 전자기기·담배·음식물 | 진짜 변수(시야·바람) + 시간대 옮기기 한 장으로 합침 | △ 나열이 아니라 판단 한 장 — 억지로 늘리지 않음 |
| 생각도 못 한 것 | 곤약젤리 반입 금지 | 숨은 날씨 보증(엣지, 원 월드) | ◎ |
| 둘 다 안 되는 마지막 | 기내·위탁 모두 불가 품목 | 늦으면 표를 날림: 입장 시간·복장 | ○ |
| 직접 확인 안내 | 이 품목 밖은 직접 확인 | 이 영상 밖은 내 예약 화면 확인 | ◎ |
| 마무리 | 요약 + 자주 가도 헷갈림 | 썸네일 질문에 답 + 순서 요약 + 한 가지 더 | ◎ |

→ 큰 틀(헷갈림 → 기본 개념 → 가장 궁금한 것부터 규정+확인법 → 항목 반복 → 숨은 것 → 마지막 주의 → 직접 확인 → 요약)은 S07과 같다. 달라진 점: ① 가장 궁금한 항목(환불·표 종류·마감)을 세 장으로 크게 다룸 ② 품목 나열 구간은 판단 한 장으로 합침.

## 4. 리텐션·궁금증 설계 (순서별로 이어지는 궁금증)

| 순서 | 내용 | 이 앞에서 품는 궁금증 | 이 구간이 남기는 다음 궁금증 |
|---|---|---|---|
| 도입 | 우산 표시 고민 + 돈 날림 경고 + 규정을 읽고 정리 + 세 가지 결론 + 진짜 변수·날씨 보증 예고 | 비 예보인데 취소해야 하나? | 세 가지가 뭐고, 왜 취소하면 손해? 진짜 변수는? |
| 먼저 알아둘 두 가지 | 비로는 안 닫는다(엣지 실내, 엠파이어·써밋 날씨 환불 없음) / 바꿀 수 있는지는 표가 정함 | 비가 오면 문 닫는 거 아냐? | 그럼 환불은 되긴 해? |
| 확인 ① 어디서 샀나 | 공식 사이트 표는 환불 없음 → 취소 후 맑아지면 재구매 / 판매처는 판매처 규정 / 예약 메일 열기 | 환불되나? | 같은 곳에서 샀어도 바꿀 수 있어? |
| 확인 ② 무슨 표 | 엣지 플렉스만 변경, 크레딧·취소 보호 / 써밋은 날짜·시간 유효, 이전은 재량 / 상품 이름 확인 | 내 표는 바꿀 수 있나? | 언제까지 바꿀 수 있어? |
| 확인 ③ 마감 | 엣지 2시간 전, 판매처는 상품별 / 마감 직전에 예보로 결정 / 세 가지 끝 선언 | 예보 보고 언제 결정? | 그럼 진짜 변수는 뭔데? |
| 전망대별 | 엠파이어(변경 규정 없음, 조기 폐쇄) / 엣지(실내 열림) / 써밋(실내 중심) / 탑오브더락(직원에게 확인) | 어느 전망대가 비에 강해? | 비가 문제가 아니면 뭘 봐야 해? |
| 진짜 변수 | 시야·바람, 시간대별 예보, 같은 날 시간대 옮기기 | 어떤 날은 올라가도 되고 어떤 날은 접어? | 마감이 지났거나 바꿀 수 없으면 포기해야 해? |
| 숨은 날씨 보증 | 엣지(바 쿠폰/재예약, 입장 처리 전) / 원 월드(시야 없는 날 재방문 초대) / 직원에게 물어보기 | 현장에서 쓸 방법은 없어? | 올라가기 전에 또 조심할 건? |
| 놓치면 못 올라가요 | 엣지 입장 후 30분, 써밋 날짜·시간 유효, 일찍 출발, 방수 재킷, 예약 화면 캡처 | 비 오는 날 시간 지키는 게 중요해? | 정리하면 뭘 하면 돼? |
| 마무리 | 첫 질문에 답, 확인 순서 요약, 예약 화면 확인, 한 가지 더(낮 시간 실내 일정) | 정리가 필요 | — |

## 5. 아직 남은 약점 (정직 기록)
- **탑오브더락이 얇다.** 공식 FAQ가 403으로 안 열려서 규정을 뺐고 "직원에게 물어보세요"로만 처리했다. 한국에서 인기 많은 곳이라 공식 확인이 되면 꼭 보강해야 한다.
- **써밋의 변경 기한·방법**은 약관에 없어서 "예약 화면에 변경 버튼이 있는지 보세요"로만 말한다.
- **원 월드 See Forever Commitment**는 소개 문구만 확인했고 세부 조건·기한은 못 봤다.
- **판매처(클룩·마이리얼트립) 조건**은 확인하지 못해 "상품마다 다르다"로만 썼다.
- **경험담이 없다.** 5단계 훅 ②는 규정을 읽었다는 행동으로만 대체했다.
- **분량 5,026자**로 규격 하한(5,000자)에 겨우 걸린다. 사실 삭제로 줄어든 만큼 억지로 채우지 않았다.
- **제목·썸네일이 v3(실수 8가지)에서 v1(먼저 확인할 3가지)로 되돌아갔다.** 사용자가 8가지 쪽을 원하면 알려 주세요.
