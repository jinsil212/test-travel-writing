## 9. 대본에서 빼거나 바꾼 것 (C등급·확인 불가)

| 항목 | 처리 |
|---|---|
| 리조트 1박 요금(4곳 전부), 패키지 가격, 인천–칸쿤·뉴욕–칸쿤 항공권 가격 | **전부 뺀다.** "예약 화면 결제 직전 총액으로 비교하세요"로 대체 |
| 칸쿤공항 택시·셔틀 요금($25~40 / 현장 $100+) | 금액 빼고 "미리 예약 / 현장은 훨씬 비싸다는 후기" + 확인 행동으로 |
| 팁 금액(하우스키핑 하루 $3~5 등) | 금액 빼고 "현금 팁 관행이 있다, 잔돈 준비" |
| VISITAX 금액(283 vs 293페소 엇갈림) | 금액 빼고 "출국 전 공식 사이트에서 결제" 행동 안내 |
| 셀하·엑스플로르 입장료, 치첸이사 투어 요금 | 금액 빼고 "파크 포함 리조트냐 아니냐로 갈린다"로 |
| 스칼렛 아르떼 공항 소요시간(후기 1.5~2시간) | "공항에서 먼 편" + "이동 시간 확인하고 고르세요" |
| 칸쿤 우기·강수량 월별 수치 | 뺀다. 허리케인 시즌(A)만 사용 |
| 제트블루 수하물 요금 | 뺀다. "구간마다 수하물 조건이 다르니 발권 전 확인" |
| 뉴욕 호텔세·리조트피 수치 | 이번 편에서는 숫자 없이 "결제 총액이 달라진다"로만(뉴욕숙소 편과 중복 회피) |
| 대한항공 스톱오버 | 언급하지 않는다 |
