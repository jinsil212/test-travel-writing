버린 각도

**확정:** "혼자일 때 어색한 지점을 기준으로 고른 5곳 + 마지막 조심할 점." S11처럼 "누구를 위한 영상인지"를 제목에서 좁히고, 5곳 번호 체계로 완료 심리를 쓴다.

**제목:** 🇺🇸뉴욕 혼자 여행이 처음이라면? 필수 시청! 혼자라서 더 편한 곳 5곳과 마지막 조심할 점 [뉴욕혼자여행, 뉴욕혼밥, 스태튼아일랜드페리, 하이라인, 메트로폴리탄미술관, 브로드웨이, 뉴욕여행주의사항]
- 블록1: 🇺🇸뉴욕 혼자 (국기 + 대상 지정)
- 블록2: 여행이 처음이라면? 필수 시청! (대상을 부르는 말 + 의무감)
- 블록3: 혼자라서 더 편한 곳 5곳과 마지막 조심할 점 (핵심 혜택 + 숫자)
- 블록4: 검색 단어 7개 (S11 방식으로 이 사람이 궁금해할 항목)

**썸네일:** 상단 `혼자 가도 될까?`(노란 박스) / 하단 `혼자라서 편한 5곳`(검은 박스, 흰 글씨) / 메인 오브젝트: 빈 의자 1개와 공연 티켓 1장 / 배경: 해 질 녘 맨해튼 스카이라인(사람 얼굴 없음)

**도입 첫 2~3문장:** "뉴욕 혼자 가도 괜찮을까요? 후기를 찾아보면 커플이나 가족 사진뿐이라서, 혼자 가면 뭘 해야 할지 막막하셨죠. 저는 미국에서만 석 달 넘게 혼자 지냈는데, 그 경험으로 혼자라서 더 편한 곳 다섯 곳만 골랐어요."

**왜 누르고 싶어지나:** "혼자 가도 되나?"라는 속마음을 제목과 썸네일이 그대로 묻고, 5곳이라는 숫자와 "처음이라면"이 지금 나를 부른다.

**삼각 연관성:** 제목(혼자 + 편한 곳 5곳 + 조심할 점) = 썸네일(혼자 가도 될까? / 혼자라서 편한 5곳) = 도입(혼자 가도 괜찮을까요? / 다섯 곳). 셋 다 같은 약속이다.

**확정 이유:** 후킹 포인트 1(세계 6위)이 "괜찮다"는 답이 되고, 후킹 포인트 3(무료·할인)이 "5곳"을 구체화한다. 질문이 다른 기존 원고와 겹치지 않는다.
