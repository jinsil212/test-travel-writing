# 자료 — 브로드웨이 관람 꿀팁 (새 원고 예정, 2026-10-20 조사)

- **배경:** 사용자 결정(2026-10-20) — `브로드웨이영어`는 작품 추천만 남기고, 관람 꿀팁은 이 폴더에서 새 원고로 따로 쓴다.
- **중복 주의:** 표 사는 법(TKTS·로터리·러시·할인)은 `브로드웨이예매`가 다룬다 → 이 원고에서는 빼거나 한 줄 안내만.
- **조사 한계:** 사용자가 요청한 미여디·네이버 카페·네이버 블로그는 이 작업 환경의 네트워크 정책에서 `search.naver.com`·`cafe.naver.com`·`m.blog.naver.com` 접속이 막혀 직접 읽지 못함. 웹 검색에도 네이버 글은 잡히지 않음. 아래는 영문 가이드·국내 매체·마일모아·브런치 검색 요약이며, 원문 대조 전이라 **확인 수준: 미확인(검색 요약)**. 원고에 쓰기 전 원문·공식 출처로 다시 확인할 것.
