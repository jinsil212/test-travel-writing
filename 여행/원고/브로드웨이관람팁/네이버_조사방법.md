# 네이버(미여디·카페·블로그) 조사 방법 — 2026-10-20

## 이번에 못 읽은 이유
- 클라우드 작업 환경의 네트워크 정책이 `search.naver.com`·`cafe.naver.com`·`m.blog.naver.com` 접속을 막았다.
- 웹 검색 도구(WebSearch)는 미국 기준 검색이라 네이버 글이 거의 잡히지 않는다.
- 그래서 `자료.md`는 영문 가이드·국내 매체·마일모아·브런치 검색 요약으로만 채웠다.

## 환경별로 되는 것
| 환경 | 네이버 블로그 | 네이버 카페(미여디 등) |
|---|---|---|
| 사용자 PC의 Claude Code | 대부분 가능. 링크로 직접 열어 읽는다. 페이지 여는 도구(WebFetch)가 네이버를 거부하면 명령 창(curl)으로 받아 읽는다 | 회원 전용 카페는 로그인이 안 돼 제목·미리보기 정도만 |
| 클라우드(지금 환경) | 네트워크 설정에서 위 세 주소를 허용하면 가능 | 위와 같음 |

- 클라우드 허용 방법: 세션 제목줄의 클라우드 환경 메뉴 → Edit → Network access → Allowed domains에 세 주소 추가(또는 접근 범위 넓히기). 안내: https://code.claude.com/docs/en/cloud-environments#network-access

## 다음에 할 일
1. 카페 글: 사용자가 괜찮은 미여디·카페 글을 복사해 붙여 주면 `자료.md`에 출처와 함께 정리한다(가장 확실).
2. 블로그 글: 네트워크가 열린 환경에서 "브로드웨이 뮤지컬 꿀팁", "브로드웨이 관람 후기 화장실", "브로드웨이 스테이지도어" 등으로 찾아 읽는다.
3. 찾은 팁은 `자료.md` 표에 더하고, 원고에 쓰기 전 원문·공식 출처로 확인한다(CLAUDE.md "확실하게 확인 안 된 사실은 뺀다").
