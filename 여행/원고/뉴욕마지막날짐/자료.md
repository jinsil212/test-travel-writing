# 자료 — 뉴욕 마지막 날, 밤 비행기인데 체크아웃은 낮일 때 짐 처리

조사일 2026-10-08. 아래 중 **확인된 것**과 **확인 못 한 것**을 구분한다. 확인 못 한 것은 원고에서 단정하지 않고 "미리 확인하세요"로만 쓴다.

## 1. 호텔 짐 보관 (일반 정보)
- 출처: NerdWallet 「Hotel luggage storage」 (https://www.nerdwallet.com/article/travel/hotel-luggage-storage), RiverLanding 블로그 (https://riverlanding.com/blog/will-a-hotel-store-your-luggage-after-check-out/)
- 확인된 것: 대부분의 호텔이 투숙객 짐을 벨 데스크·보관실·락커에 무료로 맡아 준다고 안내됨. 번호표(태그)를 받는다. 일부 호텔은 소액 요금을 받거나 시간 제한을 둘 수 있다. 폭발물·인화성 물질은 보관 불가. 벨맨 팁은 의무는 아니고 관행(라스베이거스 안내 $2~3, 뉴욕은 더 높게 주라는 안내).
- 확인 못 한 것: **뉴욕 개별 호텔의 보관 정책**(시간·요금). → 원고에서 "호텔마다 다르니 체크인 때 물어보세요"로만.
- 레이트 체크아웃: 보장되지 않고 성수기엔 더 어렵다. 요금은 요청할 때 안내받는다. 뉴욕 호텔의 레이트 체크아웃·데이유즈 요금은 확인 못 함 → 숫자 쓰지 않음.

## 2. 역·터미널에는 짐 보관함이 없다
- 출처: Bounce 안내 페이지 (https://bounce.com/stores/new-york/mGtVDA 외), Amtrak 포럼 (https://amtraktrains.com/threads/storage-lockers-at-nyp-and-or-gct.75180/post-803454)
- 확인된 것: Bounce 페이지가 "펜 스테이션에는 공용 짐 보관함이 없다", "그랜드 센트럴 안에는 짐을 맡길 수 없다"고 안내(업체 마케팅 페이지라 공식 정책은 아님). 포럼에는 보안 문제로 보관함이 사라졌다는 개인 의견만 있고 공식 설명은 못 찾음.
- 포럼에 펜 스테이션 수하물 데스크 $10 같은 언급이 있으나 **최신 여부 미확인** → 원고에서 쓰지 않음.
- 원고 표현: "역 안에서 보관함을 찾기는 어렵다고 안내돼요. 그래서 역 근처 보관소를 쓰는 경우가 많아요."

## 3. 앱 기반 짐 보관소 (Bounce 사례)
- 출처: Bounce 뉴욕 지점 페이지들 (위 링크 및 bounce.com/stores/new-york/…)
- 확인된 것: 지점별 하루 요금 약 $5.50~$7.95 (펜 스테이션 근처 $5.50·$7.50, 포트오소리티 $7.50, 시어터 디스트릭트 $5.50). 홈페이지 "하루 $2.90부터"는 일반 시작가. 펜 스테이션 24/7 지점은 24시간 운영(다른 지점은 오전 9시~오후 6시, 10시~7시 등 제각각). 앱/웹 예약, 맡기고 찾는 시간 선택, 무료 취소, 예약당 $10,000 가방 보호 포함. 가방 크기 추가요금 없다고 비교표에 표기.
- 확인 못 한 것: 2026년 정확한 최신 요금(페이지 날짜 불명), 신분증 요건, 최대 보관일. → 원고에서 "대략 하루 몇 달러"로만, 지점 영업시간을 반드시 확인하라고 안내.
- 같은 종류 서비스: Radical Storage 등도 JFK 근처 지점 안내(https://radicalstorage.com/luggage-storage/new-york/jfk-airport). 특정 업체 광고로 읽히지 않게 원고에서는 "짐 보관 앱"으로 쓰고 Bounce는 예시로 한 번만 언급.

## 4. JFK 이동
- 출처: JFK 공식 에어트레인 안내 (https://www.jfkairport.com/transportation/airtrain)
- 확인된 것: 에어트레인 요금 $8.75 (자메이카역·하워드비치역에서 타고 내릴 때). 공항 터미널 사이 이동은 무료. OMNY 등 탭 결제 가능. (여름 반값 프로모션 보도는 지금 끝났을 가능성 → 쓰지 않음)
- 시내→자메이카역 구간(지하철·LIRR) 요금과 소요 시간은 이번 조사에서 공식 확인 못 함 → 원고에서 "대략 한 시간 안팎, 여유 있게" 식으로만 쓰고 숫자를 단정하지 않음. 기존 원고 `이전원고/jfk-to-manhattan`이 상세 경로를 다룬 적 있으므로 상세는 중복 피하고 "별도 영상" 대신 핵심만.

## 5. JFK 터미널 변경 가능성
- 출처: CBS News 뉴욕 (https://www.cbsnews.com/newyork/news/hochul-jfk-airport-new-international-terminal/), The Points Guy 뉴 터미널 원 업데이트 (https://thepointsguy.com/news/new-york-jfk-airport-terminal-one-rebuild-update/)
- 확인된 것: 새 터미널 원 1단계가 2026년 중반 개장 계획으로 보도, 대한항공 이전 예정으로 보도. 실제 개장 여부와 아시아나 위치는 이번 조사에서 확인 못 함.
- 원고 표현: "JFK는 터미널 공사 소식이 있으니 출발 며칠 전 항공사 안내로 내 터미널 번호를 꼭 다시 확인하세요." 특정 항공사 이전을 단정하지 않음.

## 6. 체크인 시각
- 항공사별 JFK 체크인 카운터 오픈 시각은 확인 못 함 → "너무 일찍 가면 위탁이 안 열려 있을 수 있으니 항공사 앱·안내에서 체크인 시작 시각을 확인"으로만.
- 국제선 공항 도착 권장 3시간 전: 기존 사례 원고(S18)가 인천공항 기준으로 말한 일반 권고. 원고에서는 "항공사가 안내하는 시각 기준"으로 쓰고 숫자는 예시 계산에만.

## 7. 기존 원고와의 중복 확인에 쓴 근거
- 검색어: 체크아웃, 짐 보관, 밤 비행기, 레이트, Bounce, 락커, 캐리어 맡 등. 결과: 이 주제를 다룬 원고 없음. 스치는 언급만 — 테스트/뉴욕숙소/대본_v2 87행 "첫날과 마지막 날 큰 캐리어 이동"(일반론 한 문장), 미드폼/뉴욕첫여행 기획3안 84~92행 "체크인·짐 보관 사전 확인"(도착 첫날 한 줄), 이전원고/nyc-art-museums "미술관 입구 무료 짐 보관, 대형 캐리어 불가"(미술관 한 대목).

## 8. 확인 수준 재판정 (2026-10-09, 지침 "확실하게 확인 안 된 사실은 뺀다" 적용 → 대본 v4)
- 유지(공식 또는 두 곳 이상 일치): 호텔 짐 보관은 호텔마다 다름(§1 두 곳), 역 안 공용 보관함 찾기 어려움(§2 두 곳, "안내돼요"로만), 공항 안 터미널 간 열차 무료(JFK 공식), JFK 새 터미널 공사 소식(CBS·TPG, 개장 여부는 미확인), 보조배터리 위탁 불가 — FAA PackSafe https://www.faa.gov/hazmat/packsafe/lithium-batteries
- 뺌(업체 한 곳뿐): 보관소 하루 요금·원화 환산, 펜 스테이션 24시간 지점, 무료 취소·가방 보호, 벨맨 팁 금액
- 뺌(숫자 줄이기 우선): 에어트레인 요금(공식 확인은 됨)
- 가정으로만: "항공사가 세 시간 전 도착을 안내한다고 해 볼게요"
