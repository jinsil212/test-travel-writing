# 여행 원고 2단계: 대본

**주제 폴더:** `원고/$ARGUMENTS/`

아래에 이번 단계의 참고 자료 전문이 자동으로 들어와 있다.

## 순서

1. `원고/$ARGUMENTS/`의 `자료.md`, `기획.md`, `선택.md`를 전부 읽는다. `선택.md`가 없으면 1단계 확정안을 먼저 만들어 `선택.md`에 적는다(사용자에게 고르라고 하지 않는다).
2. **흐름 원고 찾기** (CLAUDE.md 2단계): `03` 색인에서 같은 유형 후보 → 주제 단어로 `참고/사례원고/` 검색 → 주제 대목만 읽고 뼈대 1편(+보조 1편) 선정 → 대본 위쪽에 **흐름 대응표**. 그 흐름 위에 주 유형 파일 **B 파트** 장치를 얹는다.
3. 도입은 `01`의 5단계 훅, 문장은 `02`의 기술(완충형 어미·역설적 비추천·원화 환산·브릿지·손실 회피)로 쓴다.
4. 분량은 `00_유형분류.md`의 유형별 분량을 따른다.
5. 숫자·가격·규정은 `자료.md`의 최신 정보만 쓴다. 참고 파일 속 예시 숫자를 그대로 쓰지 않는다.
6. `대본_v1.md`로 저장한다. 끝에 `02`의 **점검표** 결과와 출처 목록을 붙인다(없으면 차단 장치가 저장을 거부한다).
7. CLAUDE.md 2단계 6번대로 `대본_v1_읽기용.txt`를 만들어 파일 창에 띄운다. 사용자에게는 md가 아니라 이 읽기용 txt를 보여 준다.
