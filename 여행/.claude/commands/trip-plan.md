# 여행 원고 1단계: 기획

**입력:** $ARGUMENTS

아래에 이번 단계의 참고 자료 전문이 자동으로 들어와 있다. 이 내용을 근거로만 작업한다.

## 순서

0. **중복 확인** (CLAUDE.md 0단계): 기존 원고 목록과 대조해 겹치지 않는 주제·각도를 정한다. 입력이 비어 있으면 겹치지 않는 주제를 직접 고른다.
1. **주제 폴더:** `원고/{짧은 주제명}/`을 정한다.
2. **자료 조사 → `자료.md` 저장.**
   - 키워드만 받았으면 웹 검색으로 최신 정보를 찾는다.
   - 참고 소스(웹사이트·유튜브)를 받았으면 소스를 먼저 전부 읽고, 부족하거나 오래된 정보만 검색으로 보완한다.
   - 정보마다 출처와 확인 날짜를 적는다.
3. **기획 → `기획.md` 저장.** 한 번에 완성해서 저장한다. 아래 항목이 모두 있어야 저장된다(차단 장치가 검사).
   - 중복 확인: 확인한 기존 원고 목록과 판정
   - 핵심 메시지 1줄 / 후킹 포인트 3개
   - 유형 점검: 유형1~유형5를 한 줄씩 ○/△/× + 이유 → 주 유형(+보조)
   - 사례 비교표: `03_사례21.md`의 모든 사례 번호(S01~)를 한 줄씩 — 이번 주제와의 적합도(○/△/×)와 가져올 점
   - 확정안 1개: 제목 + 블록 1~4 구성 / 썸네일(상단·하단 텍스트와 박스 색, 메인 오브젝트, 배경) / 도입 첫 2~3문장 / 클릭 이유 / 확정 이유(버린 각도와 이긴 이유)
   - 경험담은 `내경험.md`의 실제 경험 또는 `[각색]` 표시 + 근거
4. `선택.md`에 "Claude 확정안"과 확정 이유를 적는다. **사용자 선택을 기다리지 않고** 바로 2단계(`/trip-script`와 같은 순서)로 대본까지 쓴다.
