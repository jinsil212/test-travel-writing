# 유형 4. 짐싸기 & 공항 출국 / 준비물 체크리스트형

- **대표 영상:** 비행기 반입 물품 총정리, 일본 여행 준비물, 인천공항 출국절차 5분 정리
- **특징:** 시간/공간 타임라인순(기내 vs 위탁 구분, 출국~입국 절차), 규정 및 품목 체크리스트 중심
- **분량:** 분석에 명시 없음 (단독 이슈 기준이면 12~15분, 약 5,000~6,500자)

---

# A. 제목·썸네일·도입 (1단계용)

**"공항 가서 당황하기 전에 이것만 보고 가라"**라는 메시지를 3단계로 일치시켜 초반 이탈을 막는다.

```
[제목] 타깃 명시 + 시간/범위 압축 ("이 영상 하나로 끝", "5분만에", "반드시 봐야 할")
  ↓
[썸네일] 기내 vs 위탁 직관적 비교 그래픽 (⭕가능 / ❌불가) + 핵심 품목(보조배터리, 화장품, 무선고데기)
  ↓
[도입부 훅] "첫 해외여행이거나 오랜만에 출국해서 공항 가기 막막하시죠? 새로 산 물건 공항에서 뺏기지 않게 딱 정리해 드릴게요."
```

## ① 제목 문법 공식

- **문법:** `[상황/대상: 해외 여행 가기 전 / 인천공항]` + `[완결성/속도: 이 영상 하나로 끝 / 5분만에 완벽 정리]` + `[손실 회피: 반드시 봐야 할 / 짐싸기 꿀팁]` + `[검색 키워드: 기내반입금지물품, 보조배터리, 캐리어, 출국절차]`
- **템플릿:** `[상황] 가기 전 반드시 봐야 할 비행기 반입 물품 총정리✈️ 이 영상 하나면 준비 끝! 짐싸기 꿀팁🧳 [기내반입금지, 보조배터리, 액체]`

실제 사례:
- "인천공항 출국절차 이 영상 하나로 끝!✈️ 5분만에 해외여행 출국부터 입국까지 완벽 정리하기"
- "해외 여행 가기 전 반드시 봐야 할 비행기 반입 물품 총정리✈️ 이 영상 하나면 여행 준비 끝! 캐리어 짐싸기 꿀팁🧳"

## ② 썸네일 연출

| 항목 | 내용 |
|---|---|
| 상단 텍스트 | `기내 vs 위탁` |
| 하단 텍스트 | `5분 출국 정리` |
| 이미지 | 캐리어 가방 + 보조배터리/화장품 용기에 ⭕/❌ 스티커 그래픽. 그 밖에 기내용 캐리어 vs 위탁 수화물 상자, 스마트패스 게이트 그래픽 |
| 다른 카피 후보 | `5분 완성`, `공항서 압수?`, `보조배터리 규정`, `출국절차 끝` |

## ③ 도입부(0~30초) 100% 매칭 대사

누르자마자 공항에서 경험했던 **실패 및 지연 사례(1인칭)**를 언급하며 공감을 이끌어낸다.

- **출국 절차:** "첫 해외여행을 앞두고 비행기표도 사고 짐도 다 쌌는데 막상 공항 가면 도대체 뭐부터 어떻게 해야 할지 막막하신 분들 계실 거예요. 저도 첫 해외여행 때는 공항에서부터 그렇게나 긴장을 많이 했던 기억이 있거든요."
- **반입 물품:** "해외 갈 때 어떤 물건을 기내에 가지고 타야 되고 어떤 물건을 위탁수화물로 보내야 되는지 헷갈리시는 분들 많으시죠? 저도 막상 공항 갔더니 금지 물품이라 가서 쓰려고 새로 산 피 같은 물건을 눈앞에서 뺏겨본 적도 있고, 기내에 가지고 타야 할 물건을 위탁 수화물에 잘못 싸는 바람에 다시 정리하느라 초조했던 적이 있어요."
  - 같은 영상의 다른 버전 마무리: "...최악의 경우 비행기를 못 타게 될 수도 있거든요. 오늘 깔끔하게 정리해 드릴게요."

# B. 본문 전개 — 짐싸기/출국 영상 4대 리텐션 장치 (2단계용)

## ① 공간 분할형 기내(Carry-on) vs 위탁(Checked) 이분법

시청자가 머릿속으로 캐리어를 싸듯 **"기내 소지(O) / 위탁 전용(O) / 절대 불가(X)"**의 3단계로 명확히 나눈다.

## ② 직관적인 암기 단위 변환 (숫자 공식)

어려운 항공/전기 용어를 시청자 눈높이에 맞게 즉시 변환해 준다.

- **보조배터리 규정:** "100Wh 이하"라는 기준 대신 **"27,000mAh 이하 배터리는 승인 없이 기내 반입 가능, 단락 방지(테이프/캡) 후 선반이 아닌 몸에 소지"**로 즉시 번역해 준다.
- **액체류 규정:** "100ml" 기준을 **"용기 크기 기준이며, 내용물이 조금 남아있어도 용기가 100ml 넘으면 전량 압수"**라고 확실한 경고를 던진다.

## ③ 시간순 타임라인(Space-Time Sequence) 구성

공항에 도착해서 비행기를 타고 현지 입국장을 나설 때까지의 동선을 이 순서로 직진 전개한다.

```
터미널 확인 → 카운터/모바일 체크인 → 수화물 무게 → 스마트패스/보안검색 → 자동출입국심사 → 게이트 대기 → 현지 입국심사
```

## ④ 역설적 압수 품목(Confiscation Warning) — 영상 중후반부 배치

**"한국 올 때 세관에서 전량 폐기당하는 귀국 추천템"**을 배치하여 끝까지 이탈을 차단한다.

| 대표 압수 아이템 | 비고 |
|---|---|
| 플라스틱 컵 곤약젤리 | 파우치/튜브형만 가능 |
| 배터리 일체형 무선고데기 | 기내/위탁 둘 다 불가 |
| 성분 미확인 진통제 | EVE, 파브론 등 |
| 육가공품 | 소시지, 육포, 만두 |

> 항공·세관 규정은 바뀐다. 원고에 쓸 때는 반드시 최신 규정(항공사·국토부·관세청 등)으로 다시 확인한다.
