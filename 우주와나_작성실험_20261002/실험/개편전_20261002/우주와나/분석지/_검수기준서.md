# 우주와나 검수 기준서 — 초고를 벤치마크형 원고로 다듬기

> **이 문서를 받는 사람:** 초고를 검수·수정하는 AI.
> **목적:** 작성자가 쓴 우주와나 초고를, 조회수가 높았던 벤치마크 원고 18편의 특징에 맞게 **문맥·흐름·한국어 표현을 다듬어** 완성도를 높인다.
> **수정 범위:** 전면 재작성은 하지 않는다. 문맥, 흐름(순서·연결·전환), 문장과 표현은 고칠 수 있다. 핵심 주제·확정 문구·사실은 바꾸지 않는다(0장).
> 원칙의 자세한 설명과 예는 같은 폴더의 `_원고쓰는법.md`에 있다. 이 문서의 **기준 번호 1~25는 그 안내서 8장 검사표 번호와 같다.**

---

## 0장. 먼저 지킬 것

### 0-1. 채널 조건

| 항목 | 조건 |
|---|---|
| 채널 | 우주와나 — 우주를 이해하기 쉽고 재미있게 설명하는 채널 |
| 시청자 | 우주를 잘 모르지만 알아가려는 초보자. **중학생도 따라갈 수 있어야 한다.** 쉬운 단어가 아니라, 사전 지식 없이 대상과 벌어진 일을 따라갈 수 있어야 한다 |
| 말투 | **쉬운 존댓말**(“~합니다”, “~해요”, “~죠” 섞어 씀). “~했다/~이다”로 끝나는 다큐 내레이션 금지 |
| 분량 | 공백 제외 글자 수 기준 **최소 10분 이상**(분당 400자로 읽어도 10분 이상 = 4,000자 이상). 요청서에 상한이 있으면 그 안에서. 수정 후 분량은 초고의 ±10% 안 |
| 화면 | AI 이미지 중심. 대사를 실사 사진이 있어야만 성립하게 바꾸지 않는다 |

### 0-2. 고치면 안 되는 것 (고정)

1. **제목·썸네일 문구** — 요청서에 적힌 확정 문구. 한 글자도 바꾸지 않는다.
2. **사용자가 확정한 도입부** — 요청서에 “도입 확정”이라고 적혀 있으면 그 문단들은 그대로 둔다. 문제를 발견하면 수정하지 말고 보고서의 ‘확정 구간 의견’ 칸에 적는다.
3. **핵심 주제와 핵심 답** — 초고가 답하는 질문과 그 답을 바꾸지 않는다.
4. **사실·숫자·출처** — 숫자, 연도, 연구 결과를 바꾸거나 새로 넣지 않는다. 사실이 틀려 보이면 고치지 말고 보고서에 적는다.
5. **초고 하단의 제작 메모·출처·실사 링크** — 그대로 둔다.

### 0-3. 하면 안 되는 수정

| 금지 | 이유 |
|---|---|
| 새 소재·새 사례·새 챕터 추가 | 곁가지가 생긴다. 이 채널은 한 편에 질문 하나에 집중한다 |
| 문단 통째 삭제로 분량 줄이기 | 핵심 설명이 빠질 수 있다. 줄일 때는 중복 문장부터 |
| “~했다” 내레이션으로 바꾸기 | 벤치마크 중 세모과학의 말투지만 우리 채널 말투가 아니다 |
| 채널 캐릭터 개그·유행어 넣기 | 벤치마크 중 리뷰엉이의 자산이지 우리 것이 아니다 |
| “충격적인”, “소름”, “미친” 같은 감정어 추가 | 기대를 키운 만큼 주지 못하면 실망을 산다(기준 17) |
| 뜻을 멋있게 비틀기 | ‘꾸민 번역투’가 된다(기준 15) |
| 설명을 줄이려고 조건·비교 기준 빼기 | 초보자가 이해하지 못한다(기준 20) |
| 다음 편 예고 넣기 | 우리 채널은 마무리에 이전 영상 추천을 쓴다 |

## 1장. 작업 순서

아래 순서를 바꾸지 않는다. 각 단계의 표는 보고서(6장)에 그대로 넣는다.

1. **초고 전문을 끝까지 읽는다.** 제목·썸네일·요청서도 함께 읽는다.
2. **진단 표 세 개를 채운다**(2장): 약속 사슬 표 → 구간 지도 → 계측표.
3. **기준 1~25로 판정한다**(3장). 기준마다 통과 / 수정 필요 / 확정 구간이라 보고만.
4. **고친다.** 우선순위: ① 반드시 기준 ② 권장 기준. 한 곳을 고치면 앞뒤 문장과 연결을 다시 읽는다.
5. **수정본을 처음부터 다시 읽고**, 진단 표 세 개를 수정본 기준으로 다시 채운다.
6. **보고서를 낸다**(6장): 수정본 전문 + 변경표 + 수정 전후 진단 표.

## 2장. 진단 도구

### 2-1. 약속 사슬 표 (가장 먼저)

시청자는 제목·썸네일이 던진 질문 하나 때문에 누른다. 그 질문이 도입·본문·마무리까지 이어져 답이 나오는지 본다.

| 자리 | 초고의 실제 문장 | 위치(%) | 제목 질문과 같은 이야기인가 |
|---|---|---|---|
| 제목 | | — | — |
| 썸네일 | | — | |
| 첫 문장 | | 0 | |
| 도입 마지막 문장 | | | |
| 핵심 답이 나오는 문장 | | | |
| 썸네일 문구가 풀리는 문장 | | | |
| 마무리에서 처음 것을 다시 부르는 문장 | | | |

**위치(%) 재는 법:** 초고 낭독문(대괄호 안 제작 메모 제외)을 공백을 뺀 글자로 센다. 그 문장이 시작하기 전까지의 글자 수 ÷ 전체 글자 수 × 100.

### 2-2. 구간 지도

문단마다 한 줄. 이 표로 흐름이 한눈에 보인다.

| 문단 | 시작 위치(%) | 첫 구절 | 이 문단이 하는 일 | 표시 |
|---|---|---|---|---|
| 1 | 0 | | (예: 대상 세우기 / 뜻밖의 사실 / 질문 / 기준 세우기 / 전환 / 반박과 답 / 씨앗 / 핵심 답 / 회수) | 전환·씨앗·반박·핵심 답·회수 자리에 표시 |

### 2-3. 계측표

벤치마크 18편에서 잰 범위를 옆에 두고 비교한다.

| 항목 | 재는 법 | 벤치마크 범위 | 우리 합격선 | 초고 값 |
|---|---|---|---|---|
| 분량 | 공백 제외 글자 수 | — | 4,000자 이상(요청서 상한 안) | |
| 도입 비율 | 도입 마지막 문장 끝 위치(%) | 2.1~23.2%(절반이 6% 이하) | **12% 이하 권장** | |
| 뜻밖의 사실 위치 | 도입에서 처음으로 ‘어? 뭐라고?’가 나오는 문장 번호 | 대부분 2~9번째 | **3번째 문장 이내 권장** | |
| 제목 핵심어의 최장 공백 | 제목의 핵심 단어(또는 같은 뜻의 말)가 나오는 위치들 사이 가장 긴 간격(%p) | 약속을 지킨 영상은 중간에 씨앗·예고로 다시 부름 | **30%p 미만** | |
| 핵심 답 위치 | 2-1의 핵심 답 문장 위치 | 대체로 50~80% | 40~80% | |
| 첫 전환 위치 | 흐름의 방향이 바뀌는 첫 문장(“그런데/하지만 …”으로 기준이 깨지는 곳) | 44~68%가 대부분 | 40~70% | |
| 후반 전환 | 80~91% 구간에서 뜻을 바꾸는 문장 | 18편 중 7편 | 있으면 좋음(필수 아님) | |
| 마무리 비율 | 마무리 시작 위치부터 끝까지 | 0.7~18.5% | 15% 이하 | |
| 말투 | 문장 끝 어미 세기: ~니다 / ~요 / ~죠 / ~다(평서) | 리뷰엉이: 니다·요 섞임 | **~다(평서) 0개** | |
| 질문 비율 | 물음표로 끝나는 문장 ÷ 전체 문장 | 2~15% | 3~12% | |
| 문장 평균 길이 | 공백 제외 글자 ÷ 문장 수 | 36~59자 | 참고만(초보자용으로 짧은 것은 괜찮다). 한 문장에 새 정보는 하나 | |

## 3장. 기준 1~25

**등급:** 🔴 반드시(발견하면 고친다) · 🟡 권장(흐름을 해치지 않는 범위에서 고친다) · ⚪ 보고만(확정 구간이거나 사실 문제라 고치지 않고 적는다)

각 기준은 **무엇을 보나 → 벤치마크 근거 → 재는 법·합격선 → 고치는 법 → 고친 예**로 적었다.

### A. 클릭 이유를 끝까지 책임지는가

#### 기준 1. 핵심 주제가 다섯 자리에 모두 이어진다 🔴
- **본다:** 제목·썸네일·첫 문장·도입 끝·마무리가 같은 질문을 이야기하는가.
- **근거:** 「타이탄」 — 제목 “생명체가 존재할 가능성이 높다고 합니다”, 썸네일 “타이탄의 바다에 / 생명체가 있다고?”, 도입 끝 “이 타이탄의 생명체 존재 가능성을 한번 자세히 알아보자.”, 본문은 근거 다섯 개, 마무리는 “있을 것 같다 없을 것 같다” 투표. 한 점에 모인다.
- **합격선:** 2-1 표의 모든 칸이 같은 질문.
- **고치는 법:** 어긋난 자리의 문장을 제목 질문 쪽으로 돌린다. 제목·썸네일·확정 도입은 고정이므로 본문·마무리 쪽을 고친다.

#### 기준 2. 도입 마지막 질문 = 제목의 질문 🔴(도입 확정이면 ⚪)
- **근거:** 약속을 어긴 두 영상은 모두 여기서 질문을 바꿨다. 「파도행성」 제목 “3시간이 23년이라는 게 정말 가능할까?” → 도입 끝 “어째서 속도가 빠르면 빠를수록 시간은 느리게 흐르는 걸까?” / 「양자역학」 제목 “신이 존재하지 않는다는 결정적인 증거” → 도입 끝 “도대체 이들은 어쩌다가 이런 생각에 이른 걸까?” 반대로 「노벨 물리학상」 제목 “미친 업적인 이유” → 도입 끝 “왜 이것이 중요한 발견일까?”
- **재는 법:** 도입 마지막 두 문장을 제목 바로 아래에 붙여 읽는다.
- **고치는 법:** 도입 끝 문장이 제목의 핵심 단어를 받게 한다. 질문을 두 개로 늘리지 않는다.

#### 기준 3. 도입은 작은 답을 주고 핵심 답은 남긴다 🟡
- **근거:** 「숫자 2.697」은 숫자는 주고 뜻은 12분 뒤로 미뤘다. 「블랙홀 난제」는 “풀었다”는 결과만 주고 무엇을·어떻게는 감췄다.
- **재는 법:** 도입에서 준 것 / 남긴 것을 각각 문장으로 적는다. 핵심 답이 도입에 이미 다 나와 있으면 수정 필요.
- **고치는 법:** 도입에 나온 핵심 답 문장을 본문의 답 자리로 옮기거나 ‘무엇’만 남기고 ‘왜·어떻게’를 뺀다.

#### 기준 4. 핵심 답이 가는 길에 질문을 잊지 않게 한다 🔴
- **근거:** 답을 늦게 준 영상도 가는 길에 붙잡는 장치가 있었다.
  - 씨앗: 「블랙홀 난제」 27% “그리고 바로 이 부피가 아닌 넓이라는 사실은 훗날 서울 과학고 연구팀이 발견한 문제에 중요한 실마리가 된다.”
  - 안심 구간 닫기: 「무한」 “여기까진 괜찮았다.”
  - 스스로 무너뜨렸다 세우기: 「공룡 멸종」 65% “일치하는 크레이터가 하나도 없었기 때문입니다.” → 72% “거대한 크레이터가 발견됩니다.”
  - 첫 장면 회귀: 「숫자 2.697」 83% “1982년 새벽 4시 모니터에 찍힌 숫자는 더 이상 흔들리지 않았다.”
- **재는 법·합격선:** 계측표의 ‘제목 핵심어 최장 공백’ **30%p 미만.**
- **고치는 법:** 공백 구간의 중간쯤, 설명이 한 단계 끝나는 문단 끝에 **핵심 질문과 지금 설명을 이어 주는 한 문장**을 넣는다. 답을 미리 말하지 않는다.
- **고친 예(우리 원고):** 초고에서 ‘땅 밑’이 13% 뒤 60%까지 안 나옴(47%p) → 39%에 “과학자들이 도시를 땅 밑에 짓자고 하는 것도, 사라진 두 방패를 대신할 무언가가 필요해서예요.” 추가 → 최장 공백 약 25%p.

#### 기준 5. 약속과 상관없는 곁가지가 없다 🟡
- **근거:** 약속을 지킨 영상은 핵심 주제 기준 곁가지가 거의 0. 약속 밖 내용이 제목 기준 70%를 넘은 「파도행성」「양자역학」「파피루스」는 부분·불일치 판정.
- **재는 법:** 구간 지도에서 핵심 질문과 이어지지 않는 문단을 찾고, 비율을 적는다.
- **고치는 법:** 그 문단이 핵심과 어떻게 이어지는지 **한 문장으로 연결**할 수 있으면 연결 문장을 넣는다. 이어지지 않으면 줄이되, 통째 삭제는 보고서에 이유를 적는다.

#### 기준 6. 썸네일 문구의 약속이 풀린다 🔴
- **근거:** 「블랙홀 난제」 썸네일 “죄송합니다. / 이건 꼭 한 번 다뤄야겠습니다.”는 본문에서 회수되지 않아 약점으로 지적됐다.
- **재는 법:** 썸네일 문구가 묻거나 약속한 것이 본문 몇 %에서 풀리는지 적는다.
- **고치는 법:** 풀리는 문장이 없으면 핵심 답 근처나 마무리에서 썸네일의 말을 받는 문장을 만든다(썸네일 문구 자체는 고정).

#### 기준 7. 마무리는 처음 것을 새 뜻으로 거두고, 새 정보가 있다 🔴
- **근거:** 「숫자 2.697」 도입의 “패배자” → 마무리 “자신을 가장 위대한 패배자로 만들지라도 …”. 「무한」 첫 문장 “영원히 닿을 수 없다는 것” → 마무리 “닿을 수 없는 무한을 향해 … 손을 뻗는 그 용기”. 반대로 「1광년」은 “자 이렇게 … 알아봤습니다.”로 목차만 되풀이해 약점.
- **고치는 법:** 도입의 장면·단어 하나를 골라 마무리 첫 부분에서 다시 부르고, 본문을 거친 뒤 달라진 뜻이나 새 그림을 한 문장 붙인다. 요약만 하는 문장은 줄인다.

### B. 도입과 흐름

#### 기준 8. 뜻밖의 사실이 세 문장 안에 🟡(도입 확정이면 ⚪)
- **근거:** 18편 중 12편은 첫 문장만으로 놀랍지 않았고, 충격은 2~9번째 문장에 있었다. 잘된 예는 두 문장 안에 끝냈다 — 「보이저」 “244억 km … 거리입니다.” → “보이저 1호가 알 수 없는 말을 반복하고 있다”, 「블랙홀 난제」 “2026년 6월 한국 과학계에 놀라운 소식이 전해졌다.” → “한국의 고등학생들이 블랙홀의 오랜 난제를 풀었다.”
- **고치는 법:** 뜻밖의 사실 문장을 앞으로 당기거나, 그 앞의 배경 문장을 줄인다.

#### 기준 9. 도입 12% 이하 🟡(도입 확정이면 ⚪)
- **근거:** 도입이 15%를 넘은 「1광년」(23.2%)·「카르다쇼프」(15.0%)·「삼체」(19.8%)는 모두 ‘너무 길다’는 지적을 받았다.
- **고치는 법:** 도입 안에서 질문과 상관없는 배경·좌표·정의부터 뺀다. 도입의 사실은 모두 질문 하나를 향해야 한다.

#### 기준 10. 전환은 중반에, 필요하면 후반에 한 번 더 🟡
- **근거:** 첫 전환 44~68%가 대부분. 7편은 80~91%에서 뜻을 바꿨다(결론 의심, 숨겨 둔 사람 공개, 첫 장면 회귀).
- **고치는 법:** 전환 문장이 없으면 기준이 깨지는 문단 첫머리를 “그런데/하지만 + 무엇이 달랐는지”로 분명히 한다. 새 내용을 만들어 전환을 만들지 않는다.

#### 기준 11. 시청자 반박을 먼저 말하고 바로 답한다 🟡
- **근거:** 「무한」 “여기서 이런 의문이 들 수 있다. 한 100억 번째 숫자랑은 같지 않을까?” → 답. 「타이탄」 “원래 같으면 다 얼어야 되는 거 아니야?” → “맞습니다.”
- **고치는 법:** 초보자가 품을 반박이 뻔한 자리(예: ‘그럼 이렇게 하면 되지 않나?’)에 반박 한 문장 + 즉답 한 문장. 한 편에 2~3번이면 충분.

#### 기준 12. 앞에 심은 것은 모두 거둔다 🔴
- **근거:** 「보이저」 도입의 “244억 km”가 중반에 발목을 잡는 이유로 돌아온다. 반대로 「암세포」 도입의 “종양 위에 날고기를 얹어 두기도 했다”는 같은 생각인 본문 해법과 이어지지 않아 ‘가장 아까운 대목’으로 지적됐다.
- **재는 법:** 도입과 본문 앞부분의 고유명사·장면·숫자를 목록으로 적고, 뒤에서 다시 쓰이는 위치를 짝짓는다.
- **고치는 법:** 짝이 없는 것은 뒤에서 한 문장으로 이어 주거나, 앞에서 뺀다(확정 도입이면 뒤에서 잇는다).

#### 기준 13. 개념 용어는 설명이 먼저, 이름은 나중. 사실이 먼저, 비유는 나중 🟡
- **적용 범위:** 법칙·현상·원리 같은 **개념 용어**(자기장, 태양풍, 용암동굴 등). 사람·탐사선·천체 같은 **대상**은 기준 23(정체와 이름을 함께)을 따른다.
- **근거:** 「무한」 방법을 보여 준 뒤 “이것이 바로 칸토어가 찾아낸 무한을 재는 새로운 자였다.” 반대로 「파도행성」 “이것이 바로 광속 불변의 법칙입니다”처럼 이름부터 부른 5편은 지적받았다.
- **고치는 법:** 새 용어가 처음 나오는 문장에서 “무엇인지·무슨 일을 하는지”를 먼저 말하고 이름을 붙인다. 예: “눈에 보이지 않는 자석의 힘, 자기장이에요.”

#### 기준 14. 숫자는 아는 것으로 바꿔 준다 🟡
- **근거:** 「타이탄」 “우리 서해보다 7배나 깊은 거예요.” 「1광년」 “빛은 단 1초만 주어지면 지구를 일곱 바퀴 반 정도 돌 수 있고요.” 「보이저」 “왕복 이틀”.
- **고치는 법:** 핵심 숫자 옆에 이미 있는 비교가 없으면, 초고 안의 다른 사실로 만들 수 있는 비교만 쓴다. **새 수치를 만들어 넣지 않는다**(0-2). 만들 수 없으면 보고서에 제안으로 적는다.

### C. 문장과 말투

#### 기준 15. 사실 나열 뒤에 판단 한 줄, 꾸민 번역투 없음 🔴
- **판단 한 줄 근거:** 판단 없이 나열만 한 7편이 지적받았다. 「공룡 멸종」 “아주 이야기가 딱딱 들어왔죠.”
- **꾸민 번역투:** 쉽게 말할 수 있는 내용을 새롭고 신비롭게 들리게 하려고 돌려 말한 문장. 세 모양:
  - 어울리지 않는 동사: “도시를 땅 위에 두지 않습니다” → “땅 위에 짓지 말자고 합니다”
  - 추상적인 말을 장소·물건처럼: “이 선택 뒤에는 … 있습니다” → “이렇게 말하는 이유는 … 때문입니다”
  - 뭔지 안 밝히고 가리키기: “실제로 잰 숫자가 있습니다” → “큐리오시티가 방사선을 재 봤더니 약 80배였어요”
- **재는 법:** 소리 내어 읽고 ① 한국 사람이 이럴 때 이 동사를 쓰나 ② 이 말이 가리키는 게 뭔지 바로 말할 수 있나 ③ 비유를 빼면 더 쉬운가.

#### 기준 16. 말투는 쉬운 존댓말만 🔴
- **합격선:** ‘~다’ 평서 어미 0개. ‘~합니다·~해요·~죠’를 섞되, 같은 어미가 네 문장 넘게 이어지면 바꾼다. 반말은 시청자 속마음을 대신 말할 때만(“…거 아니야?”처럼 짧게).

#### 기준 17. 과장하지 않는다 🔴
- **근거:** 「파피루스」 “충격적인 내용” → 내용 구간이 짧아 댓글이 건너뛸 시간을 적음. 「암세포」 “굶겨 죽이는 방법” → 실제로는 경쟁시키는 방법이고 동물 실험 단계. 「삼체」 “1mm”는 틀린 수치라 화자가 나중에 정정.
- **고치는 법:** 연구 제안을 확정 계획처럼(“~합니다” → “~하자고 합니다”), 가능성을 확정처럼(“~입니다” → “~일 수 있습니다”) 쓴 문장을 바로잡는다. 감정어를 넣지 않는다.

#### 기준 18. 대상·행동·조건을 문장 안에서 밝힌다 🔴
- **왜:** 초보자는 “무엇이 무엇 때문에 어떻게 됐는지”가 빠지면 따라오지 못한다.
- **반려됐던 문장 → 고친 방향(우리 채널 실제 사례):**
  - “안쪽으로 다가오는 물체가 얼마나 버티는지” → 무엇이(바위) 어디로 떨어지며 무엇 때문에(앞뒤로 당기는 힘의 차이) 어떻게 되는지(길게 늘어나다 찢어짐)를 밝힘
  - “큰 쪽에서는 아직 제 모양을 유지하는 물체” → 어느 위치에서 비교하는지 밝힘(“경계를 지나 안으로 들어갈 때까지도”)

#### 기준 19. 평가만 하는 문장, 설명을 예고로 대신하는 문장이 없다 🔴
- **반려됐던 문장:** “예상과 실제로 벌어지는 일이 갈라집니다”(앞 말을 평가만 함), “이 차이를 이해하려면…”(설명은 안 하고 예고만), “채우지 못한 칸”(무엇인지 알 수 없음).
- **고치는 법:** 문장을 지우고 앞뒤를 이어 읽어 뜻이 그대로면 삭제. 필요하면 실제 결과나 다음 원인으로 바꾼다.

#### 기준 20. 숫자와 비교에는 기준을 같은 문장에 🔴
- **왜:** “80배”만 말하면 무엇의 80배인지 모른다. 정상값 없이 이상함을 말하면 “원래 그런 거 아냐?”가 나온다(반려 사례: “산소가 사라졌는데 어디로 갔는지 아무도 모릅니다” → “산소가 당연히 사라지겠지”).
- **고친 예:** “지구에서 평범하게 1년을 사는 동안 자연에서 받는 방사선의 약 80배”

#### 기준 21. 문단 사이에 다리가 있다 🔴
- **왜:** 앞 문단에서 생긴 궁금증을 받아 다음 문단이 시작해야 한다.
- **반려됐던 흐름:** “유리 건물이라 했는데 결국 우주선이라는 거야?”(대상이 갑자기 바뀜), 위험 설명 뒤 바로 “결과는 이랬습니다.”
- **고친 예:** 위험을 설명한 뒤 “그럼 화성 땅 위에서 1년을 살면, 이 방사선을 얼마나 맞게 될까요?” → 측정 결과

#### 기준 22. 제목·썸네일의 단어를 본문에서 바꿔 부르지 않는다 🔴
- **반려됐던 예:** 제목은 “도시”인데 도입이 “기지”로만 말함 → “잠깐 머물다 돌아오는 기지가 아니라, 사람들이 몇 년씩 계속 살아갈 도시”로 구별해 이음.
- **고치는 법:** 같은 대상을 가리키는 말은 제목의 단어로 통일하고, 다른 말을 쓸 때는 차이를 밝힌다.

#### 기준 23. 대상(사람·탐사선·천체)은 처음 나올 때 정체와 이름을 함께 밝힌다 🟡
- **적용 범위:** 대상. 개념 용어는 기준 13을 따른다.
- **반려됐던 예:** “그 기계는 … 태양계를 벗어났다” → “그 기계의 이름은 보이저 1호입니다. 보이저 1호는 …”
- **고치는 법:** 새 대상은 처음 나올 때 정체와 이름을 함께. “화성에 내려간 탐사 로봇 큐리오시티가 …”

#### 기준 24. 같은 설명·같은 질문을 되풀이하지 않는다 🔴
- **반려됐던 예:** 인사·답장 예시 뒤 대상만 달로 바꿔 같은 왕복을 다시 설명 / 같은 질문(“어떻게 이렇게 커졌을까요”)을 세 번.
- **고치는 법:** 되풀이하는 문장을 지우고, 다시 부를 필요가 있으면 새 뜻을 붙인다.

#### 기준 25. 한국어로 자연스럽다 🔴
- **보는 것:** 주어와 서술어가 맞는가 / 지시어(이·그·저것)가 무엇을 받는지 분명한가 / 한 문장에 새 정보가 둘 이상 몰리지 않았는가 / 쉼표로 이어 붙여 문장이 늘어지지 않았는가 / 같은 조사·어미가 연달아 반복되지 않는가(“~는데 ~는데”, “~셈입니다 … 셈이죠”) / 불필요한 피동·명사형(“~하는 것이다”, “~에 있어서”)
- **고친 예:** “자기장이 없어진 화성은 이 태양풍을 공기가 그대로 맞았고” → “자기장이 없어지자 화성의 공기는 이 태양풍을 그대로 맞았고” / “화성 사람 머리 위의 공기” → “화성 땅 위에 선 사람의 머리 위 공기”

## 4장. 원형 4편 — 초고 옆에 펼쳐 놓고 비교하기

자막 오타는 고쳤다. 도입 전문과 각 문장이 하는 일, 본문 뼈대를 싣는다.

### 4-1. 「타이탄」 — 약속을 그대로 지키는 기본형 (도입 3문장, 2.2%)

| # | 원문 | 하는 일 |
|---|---|---|
| 1 | 토성의 위성 타이탄에는 땅도 있고 바다도 있고 유기물질도 풍부해요. | 근거 셋을 한 문장에 |
| 2 | 그래서 과학자들은 타이탄의 생명체가 있을 가능성이 높다고 합니다. | 결론(제목과 같은 말) |
| 3 | 이 타이탄의 생명체 존재 가능성을 한번 자세히 알아보자. | 본문 진입 |

**본문 뼈대:** 정체와 첫인상(“지구랑 비슷해요”) 17.6% → 실상(영하 179도) 9.0% → 그래도 과학자들은 긍정 4.0% → 근거 ① 대기 ② 분자 ③ 표면 ④ 바다(“서해보다 7배”) ⑤ 수소(“가장 중요한 단서”) 약 50% → 탐사 계획 14.0% → 투표 2.8%.
**배울 점:** 첫 문장의 세 근거가 그대로 본문의 목차가 되고, 노는 요소가 없다. 근거를 약한 것부터 센 것 순으로.
**따라 하지 말 것:** 첫 문장이 밋밋하고, 결론을 제목·썸네일·도입에서 세 번 말한다. 이름을 먼저 부르고 정체는 나중.

### 4-2. 「보이저」 — 숫자로 여는 형 (도입 5문장, 11.6%)

| # | 원문 | 하는 일 |
|---|---|---|
| 1 | 244억 km. 위대한 항해자라고 불리는 우주 탐사선 보이저 1호와 지구 사이의 거리입니다. | 숫자 → 정체 |
| 2 | 2012년 8월 25일 태양계를 벗어난 보이저 1호는 10년이 넘은 지금까지 심우주를 탐사하며 지구와 통신을 주고받고 있었습니다. | 원래 상태 |
| 3 | 그런데 얼마 전인 12월 12일 나사에 한 글이 올라옵니다. | 전환 |
| 4 | 보이저 1호가 알 수 없는 말을 반복하고 있다. 나사 엔지니어들에 따르면 … 0과 1이 반복되는 신호가 지속적으로 수신되고 있다고 합니다. | 공식 발표 인용 = 뜻밖의 사실 |
| 5 | 보이저 1호에게 과연 무슨 일이 일어난 것일까요? | 질문 |

**본문 뼈대:** 위업(그랜드 투어) 24.5% → 이상 신호 13.1% → 원인 분석 12.2% → 왜 고치기 어려운가(“244억 km” 회수 → 왕복 이틀) 18.5% → 이전에도 있었던 고장·노화 14.1% → 이별 6.1%.
**배울 점:** ‘원래 상태 → 그런데’로 이상함을 세운다. 도입의 자랑(244억 km)을 중반의 족쇄로 되쓴다.
**따라 하지 말 것:** 도입 질문 뒤 연결 문장 없이 60년 전으로 되감는다. 결말(고쳤는지)을 주지 않는다.

### 4-3. 「숫자 2.697」 — 앞에 심고 뒤에서 거두는 형 (도입 5문장, 5.6%)

| # | 원문 | 하는 일 |
|---|---|---|
| 1 | 1982년 이른 새벽 프랑스의 한 실험실 모니터 위에 숫자 하나가 찍혀 있었다. | 장면 |
| 2 | 2.697. 겉보기엔 아무 의미 없어 보이는 이 숫자는 아인슈타인이 죽는 날까지 지키고 싶어 했던 그 세상이 무너지고 있음을 보여주는 숫자였다. | 숫자의 무게만(뜻은 감춤) |
| 3 | 흔히 사람들은 이렇게 생각한다. | 한 박자 |
| 4 | 아인슈타인은 양자 역학을 이해하지 못하고 끝내 받아들이지 못한 고집스러운 천재이자 패배자였다고. 하지만 이런 오해와는 달리 아인슈타인은 사실 양자 세계의 문을 연 가장 대담한 개척자 중 한 명이었다. | 흔한 오해 → 반박 |
| 5 | 이야기는 20세기 초로 거슬러 올라간다. | 시작점 지정(바로 다음 문장이 1905년) |

**본문 뼈대:** 광전효과로 문을 연 사람 → 불편해짐 → 논쟁·EPR → 잊힘 → 존 벨의 한계선 “2” → 실험의 벽 → 해법(물속 초음파) → **83.5% 첫 장면 회귀 “1982년 새벽 4시 모니터에 찍힌 숫자는 더 이상 흔들리지 않았다. 2.697”** → 이후 → 마무리 “가장 위대한 패배자”.
**배울 점:** 도입의 숫자·장면·단어(패배자) 세 개를 모두 뒤에서 새 뜻으로 거둔다. 노는 요소 0.
**따라 하지 말 것:** “~했다” 내레이션(우리 말투 아님). 실험 방법 구간이 너무 어려워 댓글이 “2.697까지만 이해했다”.

### 4-4. 「블랙홀 난제」 — 답을 늦게 주면서 붙잡는 형 (도입 4문장, 2.1%)

| # | 원문 | 하는 일 |
|---|---|---|
| 1 | 2026년 6월 한국 과학계에 놀라운 소식이 전해졌다. | 뉴스 |
| 2 | 한국의 고등학생들이 블랙홀의 오랜 난제를 풀었다. | 모순 = 뜻밖의 사실 |
| 3 | 서울 과학고 학생 세 명과 한 명의 물리 교사가 함께 쓴 논문이 … 국제 물리학 학술지에 게재된 것이다. | 사실 확인(이름은 감춤) |
| 4 | 대체 이들은 블랙홀에서 어떤 문제를 발견했고 그 문제를 어떻게 해결할 수 있었던 것일까? | 제목과 같은 질문 |

**본문 뼈대:** 통념 깨기(블랙홀에 온도가 있다) → 엔트로피 → 모순과 첫 답 → **24~27% 씨앗 “이 부피가 아닌 넓이라는 사실은 훗날 … 중요한 실마리가 된다”** → 이론 계보 → 균열·미봉책 17.6% → 74% 방향 전환 “문제는 … 우리가 선택한 변수에 있는 것은 아닐까?” → 해법 → 88.3% 사람 공개 → 태도 마무리.
**배울 점:** 핵심 답이 74% 이후에 나오지만, 27%의 씨앗과 ‘미봉책’ 판정으로 끝까지 붙잡는다.
**따라 하지 말 것:** 썸네일 “죄송합니다”를 회수하지 않음. 중간 수식 구간이 어렵다.

## 6장. 요청서와 보고서 양식

### 6-1. 요청서 (사용자가 채워서 검수 AI에게 준다)

```
[요청서]
대상 원고 파일:
제목(고정):
썸네일 문구(고정):
도입: 확정 / 미확정   (확정이면 고정 구간: 첫 문단 ~ "……" 문단)
핵심 주제 한 문장:
참고할 원형: 타이탄 / 보이저 / 숫자 2.697 / 블랙홀 난제 / 기타(       )
분량: 최소 10분(4,000자 이상), 상한(       )
특히 봐 줄 것: (예: 흐름 연결, 한국어 표현, 중반 지루함)
```

### 6-2. 보고서 (검수 AI가 돌려준다)

1. **수정본 전문** — 문단 나눔 유지. 제작 메모·출처는 그대로 뒤에.
2. **변경표** — 바꾼 곳마다 한 줄.

| # | 위치(%) | 고치기 전 | 고친 뒤 | 기준 번호 | 이유(한 줄) |
|---|---|---|---|---|---|

3. **진단 표 전후 비교** — 약속 사슬 표, 구간 지도, 계측표를 초고 값 / 수정본 값으로.
4. **기준 1~25 판정표** — 기준마다 통과 / 수정함 / 보고만, 근거가 된 실제 문장.
5. **확정 구간 의견** — 고정이라 고치지 않았지만 기준에 걸린 곳(예: 도입이 12%를 넘음).
6. **사실 의견** — 틀려 보이지만 고치지 않은 숫자·주장.

**보고서 규칙:** ‘자연스럽게 다듬음’처럼 뭉뚱그리지 않는다. 모든 변경은 기준 번호가 있어야 한다. 기준 번호를 댈 수 없는 수정은 하지 않는다.

## 7장. 흔한 실수 — 검수 AI가 하지 말 것

- 벤치마크 문장을 그대로 옮겨 붙이기(구조와 기능만 가져온다).
- 흐름을 고친다며 문단 순서를 크게 바꿔 핵심 답 위치를 앞당기기(기준 3·4 위반 위험).
- 분량을 맞추려고 같은 설명을 다른 말로 한 번 더 쓰기(기준 24).
- 쉬운 말로 바꾼다며 조건·비교 기준을 빼기(기준 18·20).
- “더 재미있게”라며 감정어·과장·질문을 늘리기(기준 17, 질문 비율 12% 초과).
- 고정 문구를 ‘조금만’ 다듬기(0-2 위반).
