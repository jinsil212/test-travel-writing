### 포장 약속·공개 유보·분량

제목은 배치 완료와 조기귀환의 대비를 공개한다. 썸네일은 ‘위성 보낸 스타십 / 체류 줄인 이유?’로 주체와 행동을 밝히고 같은 대비를 묻는다. 도입은 체류를 줄인 이유를 묻는다. 끝은 상승 엔진 문제를 고려한 단축이라는 답과 실제 목표 해역 귀환으로 닫는다. 이유형이며 초반에 공식 이유를 말한 뒤 ‘그래서 어떻게 돌아왔나’를 같은 판단의 실행 과정으로 설명한다. 도입에 이유·점화·착수 결과를 모두 몰아넣지 않는다. 기체가 통제를 잃었다는 인상을 포장으로 만들지 않는다.

분량 재료: 1파트800자(배치 확인·남은 우주선 비행), 2파트1050자(엔진 문제·GO와 체류 단축의 차이), 3파트1100자(머무는 경로와 귀환 경로), 4파트650자(사전 해역·교통 조건), 5파트1000자(실제 귀환 단계·확인 범위) = 본문약4600자. 별도 도입·클로징350~450자 포함 약4950~5050자, 약12.4~16.8분 가정. 4파트650자는 구역·교통 조건과 5파트 목표 도달 사이 연결에 필요한 상한 가정이며 군사·해상 관제 이야기를 새로 넣지 않는다. 실제 작성에서 설명 중복으로 본문4000자 미만이면 같은 이유를 반복해 늘리지 말고 기획·파트 수 조정으로 반환한다.

- 영상 전체의 픽셀과 실제 장면은 기획 담당이 확인하지 않았다. 지금의 질문과 답은 공식 결과와 설명 도식으로 성립한다. 실제 영상이 필요하면 해당 장면 확인·출처·사용 조건을 제작 단계에서 확보한 뒤 사용한다. ‘이 장면을 보세요’라는 확인 안 된 대사는 넣지 않는다.
- AI/그래픽 화면은 설명용이며 실제 궤적·엔진 외형·장면·회의를 재현한 사실 자료로 표시하지 않는다. 경로는 비축척, 해역은 대략 위치만 그린다. 화면과 자막은 주장 ID의 확인 범위 안에서 만든다.
- 직전2편으로 지정된 원고는 제공되지 않았다. 보이저49년 합격원고를 임의로 직전편이라고 지정하지 않는다. 최근 두 편과 도입·중간 반문·끝 문장의 매너리즘 비교는 조건부 미적용으로 남긴다. 견본과 동일 문장·동일 장벽 수·개인 감상 결말을 반복하지 않는 검토는 적용했다.
- 이 단계의 제목·썸네일은 질문 방향 검증용 가안 1개씩이다. 정식 포장 후보·도입·본문·클로징은 작성하지 않는다. 사용자 기획 선택 뒤 포장 담당이 정식 후보를 작성한다.

## 추천과 다음 담당에게 넘길 계약

**A안을 추천한다.** 엔진 정지라는 사건이 ‘이후에 쓸 엔진을 확인했다’는 공식 답으로 직접 이어진다. 경로를 먼저 설명해야 하는 이유도 분명하고, 같은 엔진·경로 도식을 도입부터 귀환까지 다시 쓸 수 있다. 원본의 ‘포기했다가 번복’과 재난 과장 대신 검증된 판단 조건을 새 가치로 준다.

B안은 ‘이번 시험 전체가 왜 다른가’를 원할 때 선택할 다른 축이다. 다만 여러 성과의 목록으로 흐르기 쉬우므로 우주 도달/궤도/실제 배치라는 같은 기준으로 묶어야 한다. C안은 성과 뒤에도 남은 문제와 운영 결정을 함께 보는 다른 축이다. 공식 이유를 밝힌 뒤 귀환 과정을 계속 보는 필요가 약하면 분량을 채우기 위해 설명을 늘릴 위험이 있어 기본 추천에서 제외했다. 두 안은 사실 불성립으로 버린 것이 아니라 보상과 분량 위험을 비교한 대안이다.

사용자 선택 전에는 어느 안도 확정하지 않는다. 선택된 안의 네 칸·마지막 답·중심 주장 ID를 고정해 넘긴다. A의 포장 담당은 결과를 공개하고 확인 조건을 보상으로, B는 배치 사실을 공개하고 같은 기준의 차이를 보상으로, C는 배치 완료·체류 단축을 공개하고 공식 이유와 실행 과정을 보상으로 유지한다. 엔진 원인·회의·결정 번복·대재앙을 후킹 재료로 추가하려면 현재 계약과 근거를 벗어나므로 조사/기획으로 반환한다.
