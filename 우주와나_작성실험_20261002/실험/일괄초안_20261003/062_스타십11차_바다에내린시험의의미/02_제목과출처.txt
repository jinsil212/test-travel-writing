공식 확인일: 2026-10-03 KST
기획: 2025년11차의 양단 계획 해상 착수와 V2 마지막 시험의 의미. 발사·분리·제어 하강·데이터·다음 설계 사이 판단 범위. 44번첫비행 사고, 26번시스템개발, 66번회수후재비행과 구분.
1. NASA OIG IG-26-004(2026-03-10), 보고서본문6–7쪽/PDF11–12쪽: Flight11 2025-10-13; Flight10·11 양단 계획 착수; V2 마지막 시험. 기체내 탱크 추진제 이동과 기체간 이동 별개. 유인 안전/운용 요구는 별도 검증 대상. 보고서 당시 향후 목표를 2026-10 현재 미완료라고 단정하지 않음.
https://oig.nasa.gov/wp-content/uploads/2026/03/final-report-ig-26-004-nasas-management-of-the-human-landing-system-contracts.pdf
2. SpaceX 재사용/개발 공식 검색 본문: 실제 비행 개발, 우주 랩터 재점화·제어 재진입 성과, 여러 비행에서 타일 제거 및 구조 부담 기동으로 시험. 해당 문서의 여러 비행 설명을 11차 개별 상세로 확정하지 않음.
https://www.spacex.com/updates/reusability
3. SpaceX 11차 공식 페이지 확인 시도: web 본문0줄, 직접 요청 연결 거부, alternate URL 접근 불가. 세부 엔진 개수/배치·모형 위성 개수·11차별 타일 위치/손상 상태는 공식 직접 확인 범위 부족으로 본문에서 생략함. 일반 화물 배출/비행경로 설명은 개발 기능을 이해하기 위한 해설이며 11차 개별 성과 목록으로 주장하지 않음.
https://www.spacex.com/launches/starship-flight-11
한계: 11차는 2025년 사건. 현재 가장 최근 비행이라고 쓰지 않음. 최신 14차 등 후속 결과와 숫자 섞지 않음. 시험 목표/각 행동의 기능을 설명하지만 모든 비행 중 사건을 초 단위 재현한 완결 조사라고 주장하지 않음. 해상 착수는 발사대 회수·정비·재비행 완료와 별개. 열 차폐 색만으로 손상량을 정하지 않음. 모형 배출≠운용 위성 서비스, 재점화≠모든 궤도/장기 조건 검증.
전체영상 번역이 아닌 독립 한국판 초안. 독립 사실·흐름 검수 전. 3분은 작성 목표이며 달성/음성시간 보장 없음.
