모든 담당은 `공통_원문.md`를 추가로 읽습니다. 실제 원문 전체, 이번 편 요청과 확정 기록, 채택 견본 원문·분석지 전문 정독 의무는 유지합니다. 특정 편의 옛 승인·개수·문구와 작업자 해석을 새 사용자 결정으로 쓰지 않습니다. 상태 기록은 해당 편의 최신 진행상태로 확인합니다.

각 역할 원문에는 공동 책임 때문에 같은 조항이 들어갈 수 있습니다. 작성 담당은 적용하고 독립 검수는 실제 결과를 확인합니다. 공통 배정은 모든 담당에게 전달하는 의무이며 삭제된 항목이 아닙니다. 기준17/20의 사실 정확성은 사실 담당이, 검사표 전체와 약속·표현·흐름은 흐름 담당이 맡습니다.

## 이번에 보강한 실행 확인

- 기획 네 칸·비교와 상세 흐름·필요성 검사·분량/화면을 구체 원문에 연결.
- 포장 후보 하한·문구 단독 이해·보상 공개 범위·전용 이미지 프롬프트를 구체 원문에 연결.
- 도입 사전 견본/약점 대조·13개 채널 규칙·초보자 실패 유형·사용자 실제 수정 전문에 연결.
- 본문 파트 집필·삭제 시험·경계/전체 중복·클로징 새 회수·실사 자료를 구체 원문에 연결.
- 최종 검사표1~25의 개별 실제 근거를 관문에서 요구.

## 검증 범위

분리본이 원문 블록을 그대로 포함하는지, 적용 대상 블록에 담당이 배정됐는지, 원문/묶음 변경과 열람 누락이 차단되는지 확인합니다. 이것은 실제 대본의 재미·이해도나 사용자 합격을 검증한 결과가 아닙니다. Native 자동 인식·훅 활성화의 별도 확인 상태는 기존 기록대로 유지합니다.

혼합 블록 처리: 극한실화 댓글 예외 뒤에 같은 heading 아래 붙은 공용 타임스탬프 형식은 실제 원문 줄에서 따로 나눠 공통/총괄/본문/흐름 담당에게 보존했습니다. 가상 경계 제목은 위치 안내이며 원문 문장에 삽입하지 않았습니다. 판정 등록은 사실 PASS 뒤 흐름으로 진행하고 읽기 검토의 병렬성은 유지합니다.
