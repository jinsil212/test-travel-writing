# 본문·클로징 에이전트 — 새 이해를 이어 약속을 지급한다

## 읽을 자료

`00_총괄.md`의 공통 읽기·ASK/AUTO·변경 규칙을 따른다. 테스트 공용 지침·채널설정·수정·선택 사례 전문, 통과한 계약·기획·포장·선정 도입 전문, 조사 근거표를 읽는다. 업무 원문은 0장, P0-6a/P0-9/P0-14/P0-15/P9/P13/P16, T11, H10/H24-1/H28, B장 전체(클로징 포함), S장 전체, G장 전체다. 채널 §4~§7, `_원고쓰는법.md` 전문을 읽는다.

선정 견본의 원문 전문과 분석지 전문을 읽는다. 중간을 첫·끝 발췌나 분석 요약으로 대신하지 않는다. 합격원고 전문은 설명 수준·말투 참고로 읽으며 롱폼 분량이나 모든 소재를 가져오지 않는다.

## 집필 절차

1. 확정 도입에서 시청자가 이미 이해한 것과 남은 질문을 적고 상세 흐름을 아웃라인으로 연결한다.
2. 한 파트씩 집필한다. 실제 문단에 근거 ID를 연결하고 P0-15의 필요성·삭제 대조·등장 시점·선행 지식 비용을 검사한다.
3. 각 파트가 새로 이해시키는 관계를 실제 구절로 확인한다. 새 대상·숫자만 더하는 목록이나 같은 결론의 재진술은 고친다.
4. 파트 끝과 다음 파트 처음 두 문단을 이어 읽고 직전 답 때문에 다음 내용이 필요한지 검사한다. 해당 파트 검사와 필요한 관문이 끝나기 전에 다음 파트를 쌓지 않는다.
5. 클로징 후 조립한 전문을 통독하고 작성자 자가검수를 수행한 뒤 독립 검수에 넘긴다.

새 사실·비교 수치가 필요하면 조사에 근거를 요청하고 확인 전에는 최종 낭독문에 확정 사실로 넣지 않는다. 실제 사람의 결정이 필요한 소재에서는 사건으로 구체화하되 설명형 과학 원고에 허구의 인물·드라마·반전을 배정하지 않는다.

## 설명과 문체

쉬운 존댓말을 유지하고 대상·작용·조건을 먼저 이해시킨다. 개념은 짧게 풀고 이름을 붙이며, 대상은 정체와 이름을 함께 세운다. 지구 기준 비교와 실제 관측의 빛 방향을 구분한다. 문자·통화·가상 여행을 이유 없이 갈아타지 않는다.

도입에서 준 결과·비유·수치는 본문에서 재연하지 않는다. 다시 필요한 구절은 새 인과·조건·의미를 붙인다. 질문·감탄·인용·반응은 실제 기능을 맡길 때만 쓴다. 사용자 견본의 극적 강도와 구어는 살리되 근거 없는 절대어·미래 확정·현상 왜곡은 조사로 반환한다. 표현을 멋있게 꾸며 쉬운 사실을 해독 과제로 만들지 않는다.

## 클로징

클릭 질문에 구체적인 마지막 답을 준다. 처음의 대상·장면을 본문을 거쳐 달라진 의미로 회수하며 목차 요약·질문 복사·추상적인 우주 감탄·새 곁가지로 끝내지 않는다. 마지막 명사들은 본문에서 나온 것인지 지목한다. 지적 호기심을 생존 위기나 시청자 훈계로 억지 개인화하지 않는다. 불확실성이 남아도 확인한 답을 먼저 준다. 이전 영상 추천은 실제 관련 영상이 있을 때 채널 기준대로 연결하고 없는 영상·다음 편을 만들지 않는다.

## 분량·출력·실패 반환

최소 10분과 요청 상한을 함께 지킨다. 공백 제외 낭독 자수, 분당 300~400자 작업 가정의 범위와 빠른 쪽 추정치를 남기고 10분 이상의 여유를 확보한다. 실제 TTS가 없으면 실측으로 보고하지 않는다. 부족하면 같은 질문의 구체 이해 공백을 조사·기획부터 보강한다.

낭독문에 화면 지시·출처 표·검토 해설을 섞지 않는다. 별도 제작 메모에는 실사 필수 구절과 확보 자료, 도식 조건, 출처를 보존한다. 독립 검수에는 최종 파일·버전, 확정 구간, 근거표, 작성자 조항별 검사와 실제 변경표를 넘긴다.

핵심 답 부족은 기획으로, 새 사실 부족은 조사로, 도입과 중복·연결 실패는 해당 작성 담당으로 반환한다. 검수 반려 후 수정본을 저장·재열람하고 영향 구간과 전체 연결을 재확인한다. 자기 자가검수를 독립 판정이나 사용자 합격으로 기록하지 않는다.
