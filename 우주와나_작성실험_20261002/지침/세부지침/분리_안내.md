# 우주와나 기존 세부 지침 — 역할별 분리 안내

공통 필수와 담당 업무를 나누되 원문은 그대로 보존했습니다. 각 묶음의 블록 ID로 원문 조항·반려/수정/선택 사례와 실제 결과를 연결합니다. 다른 채널 전용 조항만 배정표에 미적용 근거를 남겼습니다.

모든 담당이 `공통_원문.md`를 함께 읽습니다. 공통 블록은 각 담당 묶음에 다시 복사하지 않습니다. 여러 역할이 적용·검수하는 업무 조항은 각각의 묶음에 남깁니다. `원문_배정표.json`의 `roles`는 책임, `packet_roles`는 실제 수록 위치이며 `reading_overlap`으로 공통과 담당 묶음의 중복 여부를 확인합니다.

전문 읽기·같은 버전 기록 연결·최신 요청과 과거 사례의 구별·원문 변경 절차·검수 판정 순서는 `지침/운영.md`를 따릅니다. 이 안내는 수록 위치를 설명하며 실행 규칙 사본으로 사용하지 않습니다.

## 이번에 보강한 실행 확인

- 기획 네 칸·비교와 상세 흐름·필요성 검사·분량/화면을 구체 원문에 연결.
- 포장 후보 하한·문구 단독 이해·보상 공개 범위·전용 이미지 프롬프트를 구체 원문에 연결.
- 도입 사전 견본/약점 대조·13개 채널 규칙·초보자 실패 유형·사용자 실제 수정 전문에 연결.
- 본문 파트 집필·삭제 시험·경계/전체 중복·클로징 새 회수·실사 자료를 구체 원문에 연결.
- 최종 검사표1~25의 개별 실제 근거를 관문에서 요구.

## 검증 범위

분리본이 원문 블록을 그대로 포함하는지, 적용 대상 블록에 담당이 배정됐는지, 원문/묶음 변경과 열람 누락이 차단되는지 확인합니다. 이것은 실제 대본의 재미·이해도나 사용자 합격을 검증한 결과가 아닙니다. Native 자동 인식·훅 활성화의 별도 확인 상태는 기존 기록대로 유지합니다.

혼합 블록 처리: 극한실화 댓글 예외 뒤에 같은 heading 아래 붙은 공용 타임스탬프 형식은 실제 원문 줄에서 따로 나눠 공통/총괄/본문/흐름 담당에게 보존했습니다. 가상 경계 제목은 위치 안내이며 원문 문장에 삽입하지 않았습니다. 검수의 실행 순서는 운영 문서에서 확인합니다.
