# 실제 에이전트 정의와 배정

.codex/agents 아래 TOML 7개에 역할 지침 전문과 실행 안내를 넣었습니다. 모델은 부모 설정을 유지합니다. 프로젝트 정의와 현재 대화의 실제 에이전트 세션은 다릅니다.

| 역할 | 이름 | 역할 원문 |
|---|---|---|
| 조사 | space_research | 01_조사.md |
| 기획 | space_plan | 02_기획.md |
| 제목·썸네일 | space_package | 03_제목썸네일.md |
| 도입 | space_opening | 04_도입.md |
| 본문·클로징 | space_body | 05_본문클로징.md |
| 독립 사실 검수 | space_fact_review | 06_독립검수.md |
| 독립 흐름 검수 | space_flow_review | 06_독립검수.md |

총괄은 부모 에이전트. stage review와 final_flow는 space_flow_review, final_fact는 space_fact_review에 배정합니다. pipeline actor roster: research/plan/package/opening/body에는 실제 해당 세션 ID, review와 flow_review에는 실제 흐름검수 ID, fact_review에는 사실검수 ID를 넣습니다. IDs는 새 채팅에서 재생성해야 하며 저장된 옛 ID를 새 실행의 증거로 쓰지 않습니다.

이 채팅에서는 현재 협업 도구가 역할 이름을 설정 파일로 선택하는 인자를 제공하지 않으므로 동일 역할 지침을 명시적으로 전달하고 실제 에이전트를 생성해 확인합니다. TOML 정의의 native 자동 발견은 이 폴더를 작업 위치로 시작한 세션에서 별도로 확인합니다.
