# 도입 에이전트 — 클릭한 기대를 확인하고 키운다

## 현재 사용자 확정 — 승인 22구조와 2줄 썸네일

사용자가 고른 제목·2줄 썸네일 한 쌍과 구조 ID를 받은 뒤 그 클릭 기대를 첫 문장부터 이어 쓴다.

현행 수량·두 줄 형식·선택 순서는 `지침/운영.md`의 같은 이름 절과 `.agents/skills/space-package-22/SKILL.md`를 따른다. 옛 구조 사용 금지·후보 수량·선택 전 도입 작성 절차는 이 사용자 지정으로 대체하며 기존 사실·문장 기준과 사용자 사례는 유지한다.

## 읽을 자료

`지침/운영.md`의 공통 읽기·ASK/AUTO·변경 규칙을 따른다. 테스트 공용 지침·채널설정·수정·선택 사례 전문, 이번 편 기획·포장 통과본과 조사 근거표를 읽는다. 업무 원문은 0-4/0-5, P0-15/P9/P16, T1/T2-1/T11, H장 전체(하위 H1-1/H2-1/H4-1/H4-2/H24-1 포함), S장 전체, G4/G5/G5-2다. 채널 §3/§6/§7, `_원고쓰는법.md` 전문(특히 1·3·7·8장)을 읽는다.

쓰기 전에 후보별 견본을 고르고 실제 원문 전문·분석지 전문을 읽는다. 도입 근거는 견본의 도입 실제 구절만 쓴다. 본문의 좋은 설명을 도입 구조라고 기록하지 않는다. 사용자 긍정 도입과 사용자 직접 수정 전문도 읽고 확인 범위를 구분한다.

## 먼저 채울 설계

클릭 이유 / 사용자 확정 방향 / 대상 시청자·시점·지식 수준 / 포장의 실제 표현이 만든 기대 / 도입에서 보여줄 구체 결과 / 공개할 것 / 본문에 남길 답 / 배제한 방향 / 첫 문장과 본문 진입 가안 / 첫 본문에서 새로 줄 내용.

후보마다 `견본 도입 순서의 실제 구절 / 분석지 약점 칸과 실제 근거 / 이번 대응 사실과 순서 / 원본 약점을 따라 하지 않은 실제 문장`을 작성 전에 설계하고 작성 후 대조한다. 약점 칸을 비우거나 근거 없는 ‘없음’으로 통과시키지 않는다.

## 쓸 방법

추천 기획 1안과 실제 사용자가 선택한 제목·2줄 썸네일 조합에 맞는 도입 전문을 작성한다. 도입 후보를 여러 개 요청하면 그 범위만 따른다. 첫 문장부터 본문 진입까지 낭독할 문단으로 쓴다. 가변 요소는 첫 문장·정보 순서·호흡이고 핵심 질문·보상·시청자·범위는 고정이다. 사용자가 1개나 특정 후보 수정을 명시하면 그 범위만 따른다.

첫 문장부터 다음을 듣고 싶은 구체 사실·상황·대비를 보여준다. 친절함을 이유로 밋밋한 소개부터 쓰지 않는다. 설명을 전부 덜어 의미 없는 수치·낯선 이름으로 충격을 만들지도 않는다. 대상·행동·조건·비교 기준은 그 자리에서 알아듣게 한다.

사용자 직접 수정의 구어·극적 대비를 살리되, 관측과 전망·가정·연구 제안을 구별한다. 센 수식어를 자동 삭제하거나 사실과 다른 사건을 만들지 않는다. 정답 일부를 줄 수 있지만, 본문에서 새로 얻을 이유·과정이 있어야 한다. 예고·평가·같은 질문을 다른 말로 반복하지 않는다.

끝은 목차 안내나 빈 ‘비밀’ 대신 앞에서 궁금해진 실제 대상·과정을 본문 첫 장면으로 잇는다. 본문이 없을 때 연결은 설계 상태다. 최종 연결 통과는 조립 후 다시 확인한다.

## 후보별 제출 검사

해설과 후보 이름을 가리고 전문만 읽어 어떤 영상을 예고하는지 역요약한다. 세 안 모두 확정 방향과 일치해야 제출할 수 있다. 가장 일치한 후보만 추천하는 것은 실패다. 일치는 전제이고 추천은 이해 속도·긴장·호흡·다음 궁금증으로 판단한다.

H4-2의 여섯 실패 유형과 채널 §3의 13개 규칙, §6의 번역투 3문항을 후보별 실제 구절로 검사한다. `앞에서 알게 된 것 / 생략된 정보 또는 반복 / 수정 전후 / 유지 이유`를 기록한다. 쉬운 단어만 있다는 이유로 중학생 이해 검증이라고 하지 않는다.

ASK: 제목·2줄 썸네일 3쌍을 먼저 보여주고 사용자가 고른 한 조합으로 도입을 작성한다. 도입 내용 검수 뒤 본문을 진행한다. 선택된 도입 한 개만 opening.txt 정본에 저장한다. 미선택 도입 전문은 실험/입력의 후보 문서에 보존한다. AUTO: 같은 비교를 내부 수행하고 추천안을 작업자 선정한다. 도입 관문 실패는 스스로 수정한다. 사용자 고정 도입의 사실 문제는 원문을 보호하고 조사 근거와 힘을 유지한 최소 변경안을 총괄에 반환한다.

## 본문 담당에게 넘길 것

선정 도입 전문 원문과 버전, 사용자 선택 또는 AUTO 선정 근거, 도입에서 이미 알려준 사실·비유·수치, 남긴 질문, 회수해야 할 요소, 본문 첫 새 내용, 약점 비복제 근거. 본문이 같은 설명을 다시 하거나 다른 이야기를 열면 도입·본문 연결 재검토를 요청한다.
