# 우주와나 실험 작업

이 폴더와 자손에만 적용한다. 사용자 승인: 2026-10-02, 테스트 안 우주와나만 분업 방식으로 전면 개편.

1. 먼저 `지침/운영.md` 전문과 맡은 `지침/에이전트/` 지침을 읽는다. 공용 `_대본지침서.md` 사본 전문, 채널설정, 수정·선택 사례와 실제 사용할 원문을 읽는다. 출력 잘림 구간은 다시 읽는다.
2. 총괄은 조사·기획·제목썸네일·도입·본문클로징·독립검수를 별도 에이전트 역할로 배정한다. 동시 총괄+3명 이내, 단계별 순차 진행. 최종 사실/흐름 검수는 별개 담당으로 수행한다.
3. 새 원고는 `실험/에피소드/` 관문 흐름으로 작업한다. 기존 복사본 `우주와나/원고/`는 보존·대조용이다. `도구/pipeline.py`로 prepare/write/review를 실행하며 선행 PASS 전 다음 단계 집필 금지.
4. 기획의 핵심 질문·답 → 제목썸네일 약속 → 도입의 궁금증 → 본문 새 답 → 클로징 회수를 이어간다. 확정된 포장을 도입에 맞춰 임의로 바꾸지 않는다.
5. ASK/AUTO와 사용자 선택/작업자 선정/사용자 합격을 구분한다. 시스템 개편 승인은 특정 편 AUTO 위임이 아니다.
6. 독립 검수는 진단·근거·판정, 수정은 작성 담당. 확정 문구에 문제 있으면 선택 단계에 보고하고 반환한다. 수치 권장값을 문체 강제 틀로 쓰지 않는다.
7. 모든 쓰기는 이 실험 폴더 안에 한정한다. 원본/상위 공용/다른 실험 채널/외부 보드는 이 개편 작업의 수정 대상이 아니다.
8. 훅 파일 설치·단위 시험과 실제 Codex 세션의 활성화/신뢰 상태를 구별해 보고한다. 직접 원고를 쓰거나 훅 신뢰를 우회하지 않는다.
