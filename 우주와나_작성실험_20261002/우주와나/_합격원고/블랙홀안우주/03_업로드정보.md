## 제목

**우리 우주가 블랙홀 안이라는 증거, 하나씩 따져봤습니다 — 사실이라면 우주 바깥에 또 다른 세계가 있습니다**

---

## 설명글

```
우리 우주의 무게를 블랙홀 공식에 넣어보면,
답이 우리 우주의 실제 크기와 소수점까지 일치합니다.

우연이라기엔 너무 정확해서, 1972년부터 지금까지
진지한 물리학자들이 이 문제로 논문을 써왔습니다. 네이처에도 실렸고요.

그런데 반세기가 지나도록 교과서는 이 이야기를 싣지 않습니다.
대부분의 우주론 학자들은 이 가설을 아예 쓰지 않아요.

계산은 맞는데 왜 아무도 안 믿을까요.

오늘은 이 주장을 하나씩 검증대에 올려봤습니다.
소수점까지 맞는 계산, 2025년 제임스 웹 관측, 그리고 이론까지
증거 세 개를 차례로 따져보고, 반대편 이야기도 들어봤습니다.

만약 사실이라면 이 우주는 전부가 아닙니다.
바깥 어딘가에 또 다른 세계가 있고, 우리는 거기서 태어난 자식인 셈이죠.
사실이 아니라면, 그 정확한 일치는 대체 무엇이었을까요.

미리 말씀드리면 어느 쪽이든 마음이 편하지는 않습니다.

00:00 계산은 맞는데 아무도 안 믿습니다
01:30 첫 번째 증거, 소수점까지 맞는 계산
04:30 두 번째 증거, 은하들이 한쪽으로 돈다
07:30 세 번째 증거, 이론은 말이 되는가
11:00 남은 것, 그리고 뜻밖의 아이러니
13:00 어느 쪽이든 서늘합니다

※ 타임스탬프는 영상 완성 후 실제 시간으로 교체할 것
```

## ⚠️ 대본에 반영한 정정 사항

| 떠도는 정보 | 대본에서 바로잡은 내용 |
|---|---|
| 슈바르츠실트 일치는 우연일 수 없다 | **평탄 우주에서는 수학적으로 당연한 항등식.** 우주가 평평하다는 것만 말해줌 |
| 계산이 딱 맞는다 | 인터넷 계산은 **허블 반지름(145억)과 관측가능 우주(471억)를 섞어 씀.** 제대로 하면 10배 어긋남 |
| NASA가 발표했다 | **NASA 성명 없음.** 캔자스주립대 연구자 1인의 분석 |
| JWST가 증거를 발견했다 | 논문·보도자료 제목에 **"블랙홀" 없음.** 저자가 관측 착시 가능성도 함께 제시 |
| 통계가 확실하다 | 독립 3팀이 **등방성과 일치한다고 반박 중.** 사실 자체가 미확정 |
| 노벨상 수상자가 경고했다 | **1차 출처 확인 불가 → 대본에서 인용하지 않음** (고정 댓글에서 사유 명시) |
| 블랙홀에 들어가면 다른 우주로 간다 | 어떤 모형에서도 불가능. 새 우주는 **인과적으로 끊어진 별개 공간** |
| 화이트홀이 확인됐다 | **후보 천체 0건.** 1974년에 미세 섭동만으로 붕괴함이 밝혀짐 |
