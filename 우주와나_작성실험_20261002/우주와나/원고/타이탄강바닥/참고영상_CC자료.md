# 타이탄 강바닥 — 화면 자료용 유튜브 CC 영상 (2026-09-20 조사)

- 요청: “관련영상 유튜브에서 찾아줘, cc 자유로워서 사용할수있는 … 가장 비슷하고 내용과 일치하는 장면 많은 순으로 링크 나열, 최소 5개 이상. … 최소 7분 이상.”
- 조사 방법: 유튜브 검색의 **Creative Commons 필터**로 26개 검색어(영어·한국어)를 돌려 후보 281개를 모았고, 7분 이상인 것 중 타이탄 관련 30여 개의 메타데이터를 열어 **라이선스가 ‘Creative Commons Attribution license (reuse allowed)’(CC BY)인지 직접 확인**했다. 아래 14개 모두 CC BY이며 7분 이상이다. 영상 파일은 내려받지 않았다.
- 순위 기준: 대본의 8개 장면 중 몇 개가 영상 안에 나오는가. 자동 영어 자막·챕터로 판정했고, 상위 항목은 자막 앞뒤 문장을 직접 읽어 타임스탬프를 확인했다. **화면을 직접 보지는 못했다**(슬라이드만 나오는 강연인지, 영상 자료가 나오는지는 링크에서 확인 필요).

## 쓰기 전에 알아둘 것

1. **CC BY는 출처 표시가 조건이다.** 영상 제목·올린 채널·링크·라이선스(CC BY)를 화면이나 설명란에 적는다.
2. **영상 안의 사진·그림은 대부분 NASA·ESA·대학 자료다.** CC BY 표시는 올린 사람의 권리만 뜻하고, 안에 들어 있는 제3자 자료·음악까지 보증하지는 않는다. 화면에 쓸 사진은 원래 기관 페이지에서 받고 크레딧(예: ESA/NASA/JPL/University of Arizona)을 붙이는 편이 안전하다. 하위헌스 표면 사진·하강 사진 페이지는 [도입부_v1.md](도입부_v1.md) 8절과 [타이탄강바닥_대본_v1.md](타이탄강바닥_대본_v1.md) 제작 메모에 있다.
3. 상위 1~8번은 대부분 **강연·웨비나(발표자 + 슬라이드)** 형태로 보인다. 깨끗한 영상 자료(B-roll)가 아니라 슬라이드 화면일 수 있다.
4. 4번(Clips Unlimited)은 조회수 26회의 소규모 채널이고, 자막에 “따뜻한 물의 바다”, “생명체” 같은 부정확한 표현이 있다. **해설은 쓰지 말고 화면만** 참고한다.
5. ‘NASA’가 붙은 영상 중 3·5·6·8번은 NASA 쪽 채널(NASA Solar System, NASA Night Sky Network)이 올린 것이고, 2번은 다른 사람이 재업로드한 것이다. 출처가 가장 분명한 것은 3·6·8번이다.

## 부족한 화면은 Pixabay API로 채우기 (2026-09-20 요청)

유튜브 CC 자료로 채우기 어려운 일반 장면(안개, 자갈, 흐르는 강, 비, 사막, 드론 등)은 Pixabay 영상에서 찾는다.

- 도구: [_도구/pixabay_footage.py](../../../_도구/pixabay_footage.py) (검색만 한다. 내려받기는 `--download`를 따로 줘야 한다)
- 장면표: [화면_픽사베이_장면표.json](화면_픽사베이_장면표.json) — 대본 장면 12개, 장면마다 영어 검색어 2~3개
- API 키: 환경변수 `PIXABAY_API_KEY` 또는 `_도구/pixabay.key`(첫 줄에 키만). `.gitignore`의 `*.key`로 커밋되지 않는다.
- 실행: `python _도구/pixabay_footage.py --scenes 우주와나/원고/타이탄강바닥/화면_픽사베이_장면표.json --out 우주와나/원고/타이탄강바닥/화면_픽사베이_후보.md`
- 결과는 장면마다 상위 5개(검색어 여러 개에 걸린 영상이 앞, 1280px 이상), 영상 페이지 링크·길이·해상도·올린 사람·태그를 표로 낸다. 응답은 24시간 캐시하고 요청은 60초 100건 안쪽으로 조절한다.

주의
1. Pixabay에는 실제 타이탄 영상이 없다. 여기서 받는 것은 **지구의 일반 영상**이며, 타이탄 관측 영상처럼 소개하지 않는다(공용 P0-6a). 실제 타이탄 화면은 위 YouTube CC 목록이나 NASA·ESA 원본을 쓴다.
2. Pixabay 라이선스는 출처 표시 없이 상업 이용·수정이 되지만, 영상 그대로 재판매·오인시키는 사용, 알아볼 수 있는 사람·상표를 상품 광고에 쓰는 것은 금지다. 영상 페이지에서 얼굴·상표 등장 여부를 확인한다.
3. 검증 상태: 문법 컴파일과 자체 시험(가짜 응답 9항목)만 통과했다. **실제 API 호출은 키를 받기 전이라 하지 않았다.**
