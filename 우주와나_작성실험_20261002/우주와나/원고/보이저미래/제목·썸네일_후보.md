## 1. 고정한 방향 (P3·P4·T2-1)

| 항목 | 실제 문장 |
|---|---|
| 팩트 한 문장(P3) | 보이저 1호는 2030년대에 지구와 연락이 끊기지만, 엔진 없이도 같은 속도로 계속 날아가고 부딪힐 것이 거의 없어 50억 년이 넘게 남는다. 금색 레코드도 그때까지 적어도 일부는 온전할 가능성이 매우 높다. 그사이 지구는 태양이 밝아지면서 약 10억 년 뒤부터(연구마다 10억~20억 년) 바다가 마르기 시작한다. |
| 클릭 이유(P4) | 신호가 끊긴 보이저 1호가 그 뒤 어떻게 되는지, 정말 그렇게 오래(지구가 크게 변한 뒤까지) 남는지 궁금해서 |
| 통념과 실제(T8) | 통념: “전기가 다 되면 보이저는 끝난다(멈춘다·죽는다)” / 실제: 끊기는 건 연락뿐이고, 보이저는 50억 년 넘게 날아간다 → **‘끝’을 뒤집는 것이 이번 각도** |
| 시청자가 아는 말(T4) | 보이저 1호, 신호(연락)가 끊긴다, 지구의 바다, 태양, 50억 년. ‘금색 레코드’·‘성간공간’·‘오르트 구름’은 제목·썸네일에 쓰지 않는다(설명이 필요한 말) |
| 본문이 줄 보상 | 왜 안 멈추나(②) → 부딪힐 게 없다(③) → 먼지가 깎는 속도와 50억 년(④) → 같은 시간 지구의 바다와 태양(⑤) → 레코드 속 1977년 파도 소리(⑥) |
| 뺀 방향 | 첫 별 만남(B), 끝낼 후보 소거(C)는 본문 재료 일부로만. 「보이저 49년」 단어(49년, 7만 6천 년, 별까지, 태양계 못 벗어남)는 쓰지 않음 |

## 3. 벤치마크 썸네일 실측 (T14·T24)

이번 편 유형(아는 대상 + 뜻밖의 상태)의 벤치마크 썸네일을 직접 열었다: 014 보이저, 006 타이탄, 001 우주 끝, 013 숫자 2.697, 참고 영상.

| 축 | 관찰 |
|---|---|
| 구도 | 014·006·참고 영상: 대상(탐사선·천체)을 크게 한 개. 001·013: 이름이나 숫자 하나만 |
| 프레임·배경 | 우주 배경 위 실사풍 CG. 요소 2~3개 이하 |
| 카피 배치 | 014·006: **하단 왼쪽 2줄**(윗줄 흰색 또는 노랑, 아랫줄 강조). 014는 상단에 “보이저 1호” 작은 소제목 |
| 카피 형태 | 014 “알 수 없는 말을 / 반복하고 있다”(상태 인용), 006 “타이탄의 바다에 / 생명체가 있다고?”(대상+물음표) |

## 5. 썸네일 문구 후보 10 (T13·T15·T15-1·T16·T17·T18)

모두 같은 기획(끊겨도 끝나지 않고 아주 오래 남는다)을 향한다. **문구만 가리고 읽는 검사**를 전부 했다.

| # | 문구(2줄) | 유형 | 문구만 읽어 알 수 있는 것: 대상 / 상황 / 궁금증 | 말한 것 / 감춘 것 | 심리 ②→③ |
|---|---|---|---|---|---|
| **1 ⭐** | 지구의 바다가 말라도 / 보이저 1호는 남는다? | 조건 대비 + 감춘 물음표 | 보이저 1호 / 바다가 마를 만큼 먼 미래 / 정말? 어떻게? | 오래 남는다는 방향 / 얼마나, 왜 | 지구의 바다보다 오래라니 → 이유와 시간을 확인하고 싶다 |
| 2 | 신호 끊긴 보이저 1호 / 50억 년 뒤에도 남는다? | 숫자 + 물음표 | 보이저 1호 / 신호 끊김, 50억 년 / 어떻게? | 끊김·50억 년 / 이유 | 끊겼는데 50억 년? → 무엇이 지켜 주나 |
| 3 | 보이저 1호의 끝은 / 신호가 끊긴 날이 아니다 | 통념 부정 단정 | 보이저 1호 / 신호 끊김 / 그럼 끝은 언제? | 끊김 ≠ 끝 / 진짜 끝과 기간 | 내가 알던 끝이 틀렸다 → 진짜 끝을 알고 싶다 |
| 4 | 대답이 끊겨도 / 보이저 1호는 50억 년 간다 | 숫자 결과 단정 | 보이저 1호 / 연락 끊김 뒤 / 어떻게 50억 년? | 50억 년 / 방법·그사이 일 | 긴 시간에 놀람 → 그동안 무슨 일이 |
| 5 | 지구 위 흔적이 다 지워져도 / 보이저 1호는 남는다? | 인류 흔적과 비교 | 보이저 1호 / 사람이 남긴 것이 사라질 먼 미래 / 정말? | 오래 남는다 / 이유 | 우리 흔적보다 오래? → 무엇이 남는지 |
| 6 | 태양이 부풀어 올라도 / 보이저 1호는 남는다? | 태양 기준 대비 | 보이저 1호 / 태양이 커지는 먼 미래 / 정말? | 오래 남는다 / 이유·지구의 운명 | 태양이 변해도? → 그때 지구와 보이저를 비교하고 싶다 |
| 7 | 먼 미래, 바다가 마른 지구 / 보이저 1호는 아직 난다 | 장면 단정 | 보이저 1호 / 바다가 마른 먼 미래의 지구 / 어떻게 아직? | 지구 상태 / 시간·이유 | 장면이 그려짐 → 그 사이를 알고 싶다 |
| 8 | 보이저 1호가 싣고 간 파도 소리 / 지구 바다보다 오래 남는다 | 감정형 | 보이저 1호 / 실린 파도 소리, 바다가 사라질 미래 / 파도 소리가 왜? | 파도 소리가 남는다 / 무엇에 실렸는지·왜 | 보이저에 파도 소리? → 그 물건과 시간을 알고 싶다 |
| 9 | 50억 년 뒤에도 / 보이저 1호에 남아 있는 것? | 감춤(무엇) | 보이저 1호 / 50억 년 뒤 / 무엇이 남나 | 50억 년 뒤에도 남는다 / 그게 무엇인지 | 무엇일까 → 확인하고 싶다 |
| 10 | 전기가 다 떨어져도 / 보이저 1호는 안 멈춘다? | 흔한 반문 | 보이저 1호 / 전기 소진 / 왜 안 멈추나 | 안 멈춘다 / 이유·기간 | 상식과 반대 → 이유를 알고 싶다 |

**T16 하위 3개 지목과 처리(화이트만 나란히 읽음):**
- 9 “보이저 1호에 남아 있는 것?” — 질문이 ‘무엇’으로 옮겨 가 기획의 ‘얼마나 오래’보다 좁다. 본문 ⑥(레코드·파도 소리)이 답하므로 **확장 관계로 유지**하되 조합 추천에서는 뺐다.
- 10 “전기가 다 떨어져도 / 안 멈춘다?” — 본문 ②(왜 안 멈추나)만 약속해 보일 수 있다. 제목 1·3처럼 ‘50억 년’이 있는 제목과 짝지을 때만 유지.
- 7 처음 안 “10억 년 뒤 바다가 마른 지구” — ‘10억 년’은 연구마다 10억~20억 년이라 단정이 강했다 → **표의 현재 문구 “먼 미래, 바다가 마른 지구 / 보이저 1호는 아직 난다”로 고쳐 유지.**

부적합해서 뺀 문구(참고): “연락 끊긴 보이저 1호 / 지구보다 오래 간다?” — ‘지구보다’가 지구라는 행성이 없어진다는 뜻으로 읽혀 사실과 어긋날 수 있어 제외. “인류가 사라져도 / 보이저 1호는 남는다?” — 인류 멸종을 확정처럼 말해 과장(S6)이라 제외.

## 6. 추천 조합과 정합 판정 (T1·T2·T19)

**추천: 제목 1 + 썸네일 1**
- 제목: 보이저 1호는 곧 신호가 끊깁니다 — 그래도 50억 년 넘게 날아갑니다
- 썸네일: 지구의 바다가 말라도 / 보이저 1호는 남는다?

| T2 단계 | 판정 |
|---|---|
| ① 썸네일만 보고 기대 | 지구의 바다가 마를 만큼 먼 미래에도 보이저 1호가 남아 있다는데, 정말인지·어떻게인지 알려 줄 것 |

- **썸네일 사용자 제안 “지구가 멸망해도 / 보이저 1호는 남는다?” 검토**

| 확인 | 판단 |
|---|---|
| 문구만 읽어 이해 | 대상(보이저 1호)·상황(지구의 끝)·궁금증(정말 남나?)이 바로 읽힘. ‘바다가 말라도’보다 강하고 쉬움 |

| 사실 대조 | ‘멸망’을 **생명이 살 수 없게 되는 것**(약 10억~20억 년 뒤 바다 증발)과 **태양이 부풀어 오르는 것**(약 50억 년 뒤)으로 본문에서 풀면 성립. 태양이 지구를 실제로 삼킬지는 연구마다 다르므로 본문에서 “삼킨다”고 단정하지 않는다. 보이저 몸체는 그때도 날고 있고 레코드도 50억 년 넘게 일부가 온전할 가능성이 매우 높다(오버그) |
| 기대 어긋남 위험 | ‘멸망’은 소행성·전쟁 같은 갑작스러운 재앙을 떠올리게 할 수 있음 → 도입에서 곧바로 “지구의 끝은 태양이 가져온다”로 좁혀 주면 해소 |
