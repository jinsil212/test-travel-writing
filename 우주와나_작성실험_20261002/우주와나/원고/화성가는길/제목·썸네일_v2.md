# 화성 가는 길 — 제목·썸네일 v2 (핵심 주제가 드러나게, 사용자 선택 전)

- 2026-09-19 사용자: “a로 해주고 핵심주제 잘 드러나게 썸네일, 제목 10개 추천”
- 해석: ① 썸네일 이미지 = 1차 문서의 **프롬프트 A**(화성 평원의 스타십, 발밑의 우주비행사, 황혼 하늘의 먼 지구, 낮은 각도) 확정. 기획 A는 이미 확정 상태라 같은 뜻이어도 결과는 같다. ② 1차 후보는 질문만 던져 **핵심 주제(왜 돌아오기가 더 어렵나 → 돌아올 연료를 화성에서 만들어야 해서)**가 약했다 → 새 10개씩.
- 적용 규칙: 채널설정 §2 전체(다시 열어 확인), 특히 §2-7-1(원인·대상·해법 핵심어가 드러나야 — 같은 날 스타십정거장 편에서 추가, 이번 사례를 덧붙임), §2-9(정체형 기획은 정체를 감춤 — 이번은 ‘이유’형이라 답의 방향을 보여도 됨). 공용 T장, T0.

## 3. 썸네일 10개 (이미지 A와 짝)

이미지 A가 보여 주는 것: 화성 평원 + 스타십 + 우주비행사 + 아득한 지구(돌아갈 집). 문구가 더할 것: **연료**와 **화성에서 만든다**.

| # | 문구(2줄) | 문구만으로 읽히는 것(T15-1) | 질문 / 답의 방향 | 감춘 것 |
|---|---|---|---|---|
| 1 ⭐ | 화성에서 집에 오려면 / 연료부터 만들어야 한다 | 화성에서 지구(집)로 오려면 연료를 먼저 만들어야 함 | ○ 집에 오려면 / ○ 연료를 만든다 | 무엇으로·얼마나·왜 |
| 2 | 화성엔 주유소가 없다 / 돌아올 연료는 직접 만든다 | 채울 곳이 없어 직접 만든다 | ○ / ○ | 어떻게 |
| 3 | 돌아올 연료는 / 화성에서 만들어야 한다 | 화성 왕복의 돌아올 연료 | △ / ○ | 왜·어떻게 |
| 4 | 갈 연료는 지구에서 / 돌아올 연료는 화성에서 | 두 연료의 출처 대비 | △ 대비로 / ○ | 화성에서 어떻게 |
| 5 | 화성 가는 길보다 / 돌아올 연료가 더 문제 | 왕복 중 돌아오기가 더 어렵고 원인은 연료 | ○ / ○ | 왜·해결 |
| 6 | 스타십도 화성에선 / 연료를 만들어야 돌아온다 | 스타십도 돌아오려면 연료를 만든다 | △ / ○ | 어떻게 |
| 7 | 화성 공기와 얼음으로 / 돌아올 연료를 만든다 | 화성 재료로 귀환 연료 제작 | △ / ○ 재료까지 | 얼마나·왜 |
| 8 | 화성까지는 간다 / 돌아올 연료는 여기서? | ‘여기’ = 이미지의 화성 땅. 문구만으로는 ‘여기’가 흐림 | ○ / △ | 방법 |
| 9 | 화성 왕복의 진짜 벽 / 돌아올 연료 | 왕복에서 가장 큰 문제는 돌아올 연료 | ○ / ○ | 왜·해결 |
| 10 | 화성에 도착한 뒤가 진짜 문제 / 돌아올 연료를 만들어라 | 도착 뒤 연료 만들기가 과제 | ○ / ○ | 어떻게 |

**T15-1 단독 검사에서 고친 것**
- 8번: 사용자가 화성도시에서 직접 쓴 “여기?” 형식을 따랐지만, 문구만 읽으면 ‘여기’가 어딘지 모른다 → 이미지 없이는 흐림. 목록에 두되 추천에서 제외.
- 10번: 처음 안 “돌아올 연료가 없다”는 사실보다 셈(계획은 귀환 전제) → “돌아올 연료를 만들어라”로 고침. 명령형이 채널 말투와 다소 다름 → 추천 제외.
- 6번: 처음 “스타십도 화성에선 / 연료가 없다?” → 같은 이유로 “연료를 만들어야 돌아온다”.
- 9번: ‘진짜 벽’은 비유. 꾸민 번역투 검사 ① 한국어로 흔히 쓰는 말 ✓ ② 가리키는 것 = 가장 큰 어려움 ✓ ③ 빼도 뜻 같음 → 유지.

## 4. 추천 조합 (T2·§2-5 반복 금지·§2-7-1)

**⭐ 제목 1 + 썸네일 1 + 이미지 A**
- 제목: 화성 왕복을 어렵게 하는 건 먼 거리보다 돌아올 연료입니다
- 썸네일: 화성에서 집에 오려면 / 연료부터 만들어야 한다

| 검사 | 결과 |
|---|---|
| 썸네일만 보고 | 화성에서 지구로 오려면 연료를 직접 만들어야 한다는 영상 |
| 제목만 보고 | 화성 왕복에서 진짜 어려운 건 거리가 아니라 돌아올 연료라는 영상 |
| 같은 기대인가 | 같다. 제목은 ‘무엇이 어렵나(원인 = 돌아올 연료)’, 썸네일은 ‘그래서 무엇을 해야 하나(해법 = 화성에서 만든다)’ — 확장, 겹치는 말은 ‘연료’ 하나 |
| §2-7-1 원인·대상·해법 | 대상(화성 왕복·집에 오기) / 원인(돌아올 연료, 거리보다) / 해법 방향(연료부터 만든다) 모두 조합 안에 있음 |
| 기획 A와 같은가 | 같다 |
| 본문에 남은 것 | 왜 다 싣고 못 가나, 무엇으로 얼마나 만드나, 작은 배·멈추지 않는 우주선 |
| 이미지 A와 | 하늘의 먼 지구 = ‘집’, 화성에 선 스타십 = ‘여기서 해결해야 함’. 문구가 연료·만들기를 더함 |

**대안**
- 제목 9 + 썸네일 7: “화성까지는 갈 수 있습니다, 문제는 돌아올 연료입니다” + “화성 공기와 얼음으로 / 돌아올 연료를 만든다” — 재료가 주는 의외성이 가장 셈.
- 제목 5 + 썸네일 5: “화성에는 연료를 채울 곳이 없습니다, 돌아오는 게 가는 것보다 어려운 이유” + “화성 가는 길보다 / 돌아올 연료가 더 문제” — 반복 주의: ‘돌아오는 게 가는 것보다’ ↔ ‘가는 길보다’가 비슷해 짝으로는 약함 → 제목 5는 썸네일 1과 짝이 더 낫다.

짝으로 쓰지 않을 조합(같은 말 반복): 제목 2 + 썸네일 4, 제목 4·8 + 썸네일 1, 제목 7 + 썸네일 7.

## 5. 이미지 A 후편집 배치

- 프롬프트는 1차 문서 8장 A 그대로(“Photorealistic wide shot from a low angle on the surface of Mars at dusk … Earth is visible as a tiny faint blue dot … Leave clean empty space in the lower left third for text …”).
- 문구: 아래쪽 왼쪽 2줄. 첫 줄 흰 글씨 “화성에서 집에 오려면”, 둘째 줄 노랑 굵은 글씨 “연료부터 만들어야 한다”. 검은 테두리.
- 선택 사항(사용자 확인 전 적용 안 함): ‘집’이 더 잘 읽히도록 A의 “looking up at the ship”을 “looking toward the tiny blue dot of Earth in the sky”로 바꾼 A′.
- 실제 생성·작은 화면 확인은 하지 않았다.
