## 3. `_원고쓰는법.md` 8장 검사표 (실제 구절·위치)

**A. 클릭 이유**
1. 약속 사슬: 제목 “먼 거리보다 돌아올 연료” → 썸네일 “연료는 직접 만들어야한다?” → 도입 끝 “지구를 떠나는 것조차 불가능해지거든요”(6.9%) → 25.0% “연료를 먹는 건 거리가 아니라 속도를 바꾸는 일이에요” → 36.5% “돌아올 연료는 화성에서 만든다” → 95.9% “돌아갈 연료는 지구에서 실어다 주는 게 아니라, 거기서 만들어야 하니까요”. ✓
2. 도입 마지막 질문 = 제목 질문: 도입은 “왜 싣고 가면 안 되나”로 닫고, 그 답이 ①~③에서 제목의 ‘거리보다 연료’로 이어진다. ✓
3. 도입에서 준 것 / 남긴 것: 준 것 — 진짜 문제는 돌아올 연료, 화성에선 직접 만들어야 함, 싣고 가면 무거워진다. 남긴 것 — 얼마나 무거운지, 무엇으로 만드는지, 얼마나 만들어야 하는지, 다른 방법. ✓
4. 핵심 답 위치 36.5%(만든다) → 53.5~67%(얼마나). 제목 핵심어 ‘연료’가 30% 넘게 비는 구간 없음(최장 공백 약 9%). ✓
5. 곁가지: 2장 제외 목록. 남긴 덤은 원자로 한 문단뿐이고 “지구에서 실어 가야 한다”로 핵심에 붙여 놓음. ✓
6. 썸네일 약속 해소 위치: 37.4~47%(공기·얼음·목시). ✓
7. 마무리가 처음 것을 새 뜻으로: 도입의 “지구엔 공장도 발사대도 있지만 화성엔 아무것도 없다” → 마무리 “사람보다 먼저 가야 하는 건 연료 공장입니다”. 새 정보(머스크가 달을 먼저 택한 이유)도 있음. ✓

**B. 도입과 흐름**
8. 뜻밖의 사실: 도입 두 번째 문단(사용자 고정) “진짜 미션은 거리가 아닙니다”. ✓
9. 도입 비중 6.9%(권장 12% 이하). ✓
10. 첫 전환 53.5% “문제는 그다음이에요. 얼마나 만들어야 하느냐.”(44~68% 범위) / 후반 전환 74.5% “이 문제를 40년 전에, 전혀 다른 쪽에서 풀어 본 사람이 있습니다”, 82.3% 인물 공개. ✓
11. 시청자 반박 선취: 도입(싣고 가면 되지 않나) · 64.1% “그럼 태양광 말고 작은 원자로를 가져가면 되지 않을까요?” · 82.3% “말도 안 되게 들리지만”. ✓
12. 심은 것 회수: ‘주유소 역할을 하는 발사대’(도입) → 19% “우주 한복판까지 주유차가 올라오는 셈” → 37% “주유차를 또 올려 보내면 되니까요. 화성에서는 그게 안 됩니다”. ‘4,600톤’ → 42.2% 착륙 문단에서 빈 탱크로 회수. ✓

**C. 문장**
13. 설명 먼저 이름 나중: 처음 초고는 “이름은 목시. 화성 공기를 빨아들여…”, “스타보트라고 이름 붙인 작은 우주선입니다”로 **이름이 먼저** 나와 검사에서 걸렸다 → “화성 공기를 빨아들여 산소를 만들어 내는 장치인데, 이름은 목시입니다”, “스타십의 5분의 1 무게로 줄인 작은 우주선이에요. 이름은 스타보트라고 붙였습니다”로 고침. ✓(수정 후)
14. 숫자를 아는 것으로: 9미터 얼음 → “3층 건물만 한 얼음”, 6만㎡ → “축구장 여덟 개”, 122그램 → “작은 개 한 마리가 열 시간 숨 쉴 양”, 초속 6.5km → “총알보다 몇 배는 빠른”. ✓
15. 나열 뒤 판단: “사람이 살 집도, 먹을 것도 아니고 돌아올 연료 하나 때문에 말이에요.” / “양만 보면 귀엽죠. 하지만 …” ✓ 꾸민 번역투 검사는 4장.
16. 말투: 전 문단 ‘~습니다/~예요’ 존댓말, ‘~했다’ 내레이션 0, 채널 캐릭터 개그 0. ✓
17. 과장·단계 표시: “계산하는 곳마다 달라서”, “2026년 9월 지금까지 한 번도 해 본 적이 없어요”, “주브린은 …라고 계산했습니다”, “나사 연구진이 계산한 걸 보면”. 제안을 확정 계획처럼 쓰지 않음. ✓

**D. 한국어 문장 (18~25)**
18. 대상·행동·조건: “착륙 다리가 화성 흙에 닿는 순간, 이 거대한 우주선은 탱크가 바닥난 채로 서 있게 됩니다.” ✓
19. 평가만 하는 문장·예고 대체 없음: 확인 중 “어느 쪽을 골라도 결론은 비슷합니다”를 발견해 삭제(4장 수정표). ✓
20. 숫자에 기준: “지구의 1퍼센트도 안 되게”, “스타십의 5분의 1 무게”, “600톤에서 120톤으로”. ✓
21. 문단 사이 다리: “무슨 말인지 보려면”, “그래서 실제 계획은”, “그렇게 반년을 날아온”, “지구였다면 답이 간단했죠”, “여기까지 들으면 답이 다 나온 것 같습니다”. ✓
22. 제목·썸네일 단어를 바꿔 부르지 않음: ‘돌아올 연료’, ‘직접 만든다’를 본문에서 같은 말로 사용. ✓
23. 새 대상은 정체와 이름을 함께: 스타십(“스페이스X가 만드는”), 퍼서비어런스(“2021년 화성에 내린 탐사 로봇”), 주브린(“화성에 사람을 보내자고 30년 넘게 주장해 온 공학자”), 올드린(“1969년 달에 두 번째로 발을 디딘 사람”). ✓

보강으로 새로 넣은 세 문단(모두 핵심 답의 크기를 채우는 내용, 분량 채우기 아님):
- “사실 순서가 거꾸로예요 …”(엔진 연료를 메탄·산소로 고른 이유 자체가 화성)
- “그 얼음을 어떻게 캐느냐도 일입니다 …”(물 1톤에 열흘, 600톤이면 한 대로 16년)
- “왜 하필 500일이냐면 …”(다음 출발 시기까지 1년 반)

**꾸민 번역투 3문항(§6)**: 전 문단을 소리 내어 읽고 확인. ‘~뒤에는’, ‘~을 두다’, 가리키는 대상 없는 ‘그 숫자/그 차이’ 없음. 비유는 주유차·버스·택시 세 개뿐이고 모두 사실 문장 뒤에 붙였다(“두 우주선을 맞대고 연료를 옮겨 담는 거예요. 우주 한복판까지 주유차가 올라오는 셈이죠.”).
