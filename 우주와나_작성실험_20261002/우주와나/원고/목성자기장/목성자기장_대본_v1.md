# 목성 자기장 — 대본 v1 (작업자 완성본, 사용자 검토 전)

2026-09-20 사용자 확정·요청: 제목·썸네일 고정 + 스릴러/미션 수행 톤의 기획안(도입 역발상 → 파이어니어 10호 → 주노의 대응 → 여운) + “핵심 후킹·핵심 주제가 이어지는지, 자연스럽게 연결되는지, 쓸데없는 내용이 커지지 않게, 사족·중복 없이, 끝까지 이탈 없게. 20분 미만.”

- **확정 제목:** 폭풍은 미끼였습니다... 목성 근처에 간 탐사선이 단 2시간 만에 황급히 도망치는 이유
- **확정 썸네일:** (위) 2시간 안에 못 빠져나오면 / (아래) 우주선이 통째로 타버립니다
- 낭독문: `목성자기장_낭독본문_v1.txt` — 공백 제외 **4,954자**. 분당 400자면 약 12.4분, 300자면 약 16.5분. 채널 최소 10분 충족, 이번 요청 20분 미만 충족. 실제 TTS 미측정.
- 톤: 사용자 기획안대로 ‘스릴러·미션 수행’. 다만 채널 §6에 따라 과장 표현(타버린다, 암살자 같은 의인화)은 낭독문에 쓰지 않고, 긴장은 사건과 수치로 만든다.

집필 중 판정한 것: 금속 수소의 상세(목성속 편 몫), 갈릴레오 대기 탐사정, 실패한 별, 소행성대, 슈메이커-레비 9, 목성 방패 논쟁, 위성별 하루 방사선 수치는 넣지 않았다. 자기장이 생기는 이유는 한 문장(“속에 전기가 통하는 액체가 … 빠르게 돌면서”)으로만 두었다.

집필 중 되돌린 것: 초고는 3,621자(9.1~12.1분)로 채널 최소 10분에 못 미쳤다. 분량을 늘리려고 재진술을 넣지 않고, 같은 줄기에서 빠져 있던 것을 보탰다 — 파이어니어 10호의 발사·의미(“화성 바깥의 소행성대를 통과한 것도 … 이 탐사선이 처음”), 방사선이 부품에 남기는 누적 손상, 오로라라는 눈에 보이는 증거, 갈릴레오의 2002년 안전 모드와 테이프 장치 복구, 갈릴레오의 마지막, 사람이 가면 어떻게 되는지(유럽우주국), 유로파 클리퍼, 그리고 이오 사진의 회수.

## 5. 확인 요청 — 썸네일 문구의 사실 문제

썸네일 “2시간 안에 못 빠져나오면 / 우주선이 통째로 타버립니다”는 확정 문구라 그대로 두었지만, 방사선은 우주선을 태우지 않는다. 실제로는 맞는 양이 쌓여 부품이 망가진다(갈릴레오: 카메라·테이프 장치, 주노: 카메라). 낭독문 78% 자리에 “2시간이 지나면 갑자기 불이 붙는다는 뜻은 아니에요”라고 바로잡는 문장을 넣어 두었다. 문구를 유지하면 썸네일과 본문이 어긋나므로, 다음 중 하나를 사용자가 정해 주면 반영한다.

1. 2시간 안에 못 빠져나오면 / 탐사선이 먼저 망가집니다
2. 2시간이 넘어가면 / 탐사선이 버티지 못합니다
3. 2시간, 그 안에 빠져나와야 합니다 / 안 그러면 카메라부터 죽습니다
4. 현재 문구 유지 — 이 경우 본문의 정정 문장을 지우고, 대신 “타버린다”는 말을 쓰지 않으면서 결과만 세게 쓰는 문장으로 바꾼다(사실과 어긋나는 상태는 남음)

## 6. 제작 메모 (낭독문에는 넣지 않음)

- 화면: ① 밤하늘의 점과 망원경 속 폭풍 ② 파이어니어 10호가 텅 빈 공간을 지나며 빛줄기에 맞는 도식 ③ 자석과 나침반 → 목성 자기장 범위와 보름달 비교 ④ 이오에서 물질이 뜯겨 도넛처럼 쌓이는 도식 ⑤ 목성 오로라(허블·주노 실제 자료 필요) ⑥ 갈릴레오 고장 장면 도식 ⑦ 주노의 길쭉한 궤도와 북극→남극 통과 도식, 티타늄 상자 ⑧ 다시 밤하늘.
- 실사가 필요한 유일한 대사: 오로라 사진(“우주망원경과 주노가 찍은 목성 오로라 사진”). 쓰려면 NASA/ESA 공개 자료의 원본 링크와 크레딧을 원고 하단에 붙인다(공용 P0-6a). 안 쓰면 도식으로 바꾼다.
- 클로징에 ‘이전 영상 추천’(채널 §5-2)은 넣지 않았다. 업로드된 편 목록을 확인한 뒤 화성 도시 편 등을 한 문장으로 붙일 수 있다.
- 사인오프 “오늘은 편안한 밤 되세요”는 합격원고(보이저 49년)의 마무리를 따랐다. 채널 사인오프를 바꾸면 이 문장도 교체한다.
