# 청소년기 블랙홀 v2 — 실제 탈고 검사

2026-09-14. 대상: 청소년기블랙홀_대본_v2.md와 그 파일에서 제목·소제목을 제외한 낭독본문_v2.txt. 승인 도입 유지. 기존 핵심 집중 반려를 적용한 본문 수정본이며 사용자 합격을 뜻하지 않는다.

## 실제 실행

1. 기존 핵심집중 재설계와 승인 도입을 읽고 B·S·G 최신 적용 구간 확인. 016 노벨물리 원문 전문과 분석지 기획·흐름·전개 구간을 다시 읽었다. 이 작업은 기존 편의 이어쓰기이며 18편 전체 재분석을 했다는 뜻이 아니다.
2. 전반과 후반을 따로 집필. 전반은 방해→새 천체→빛의 이동, 후반은 바깥에 전달되는 에너지→유입·성장→관측 범위로 작성했다.
3. 조립한 전문을 실제 파일로 열어 통독했다. 밝기와 유입 관계를 이미 설명한 뒤 다시 정리하는 문단, 결말의 가스량·성장 속도 요약 문단을 삭제했다. 엉뚱한 우주 시계 해명은 들어온 가스 뒤에 다른 가스도 합류하는 설명으로 교체했다.
4. ‘어떤 곳을 지나왔는지 알아낸 겁니다’를 ‘추정한 겁니다’로 고쳐 관측 해석 범위를 바로잡았다. 저장 후 문단별 전문을 다시 출력하여 지칭·인과·새 이해를 대조했다. 도입 직후 ‘따라갈 수 있다고 상상해보세요’가 도입 마지막의 진입 요청을 반복하므로 삭제하고 앞뒤 문장을 다시 읽었다.
5. 최종 저장본에서 낭독문을 재생성하고 실제 길이 측정. 파일 복사 후 해시 일치는 저장 동일성 확인이며 내용 품질 검사를 대신하지 않는다. 실제 TTS·중학생 대상 시험은 미실행.

| 분량 | 최종 계측은 진행상태와 제작자료의 해당 v2 수치를 따른다. 실제 TTS 전에는 추정으로 표시한다. |
