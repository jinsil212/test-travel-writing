## 1. 고정한 방향 (P3·P4·T2-1)

| 항목 | 실제 문장 |
|---|---|
| 핵심 주제(약 50자, P5-1) | 지구가 옆으로 달리고 있어서 태양 바로 위로는 곧장 못 가고, 그래서 탐사선은 목성·금성의 중력으로 길을 꺾어 갔다 |
| 팩트 한 문장(P3) | 지구는 1초에 약 30km로 옆으로 달리고 있어 로켓이 태양 바로 위로 곧장 갈 수 없었기 때문에, 탐사선 율리시스는 1990년 발사 뒤 태양에서 지구까지 거리의 다섯 배쯤 떨어진 목성으로 돌아가 그 중력으로 길을 위쪽으로 꺾었고(1992), 카메라가 없어 재기만 했으며, 금성 중력으로 길을 조금씩 기울인 솔라 오비터가 2025년에 태양 남극 쪽을 사진으로 처음 찍었다 |
| 클릭 이유(P4) | 태양 바로 위로 가는 길이 왜 이렇게 이상한지(가까운 곳인데 목성으로 돌아가고, 명왕성보다 어렵다는데 왜인지) 궁금해서. 작업자 가설이며, 근거는 원본 영상 댓글 “위로 나가는 게 수십억 마일을 건너는 것보다 어렵다니 놀랍다”(2,100), “어릴 때 선생님께 이 질문을 했다”(1,300)뿐이다(시청 뒤 반응, 영어권) |
| 통념과 실제(T8) | 통념: “가까운 곳이 쉽고 먼 곳이 어렵다” / 실제: 태양 바로 위처럼 가까운 곳이 멀리 있는 명왕성보다 새로 내야 하는 속도가 크다(같은 기준으로 3.6·8.2·24km/s) → **‘가까운 위쪽이 어렵다’를 뒤집는 것이 이번 각도** |
| 시청자가 아는 말(T4) | 태양, 목성, 명왕성, 탐사선, 지구, 위·아래. ‘율리시스’·‘솔라 오비터’·‘황도면’·‘델타브이’·‘스윙바이’는 제목·썸네일에 쓰지 않는다(설명이 필요한 말) |
| 본문이 줄 보상(T11) | 제목의 “이유” → 판 위에서 옆으로 달리는 속도(②) → 위로 가려면 옆 속도를 없애야 해서 로켓으로는 불가(③) → 목성의 중력으로 꺾음(④) → 극 위에서 잰 것과 카메라 없음(⑤) → 금성으로 조금씩, 2025년 첫 사진(⑥) |
| 뺀 방향 | 태양권 모양, 오베르트, 위에서 내려다본 풍경은 제목·썸네일에 쓰지 않는다(이번 기획에서 제외) |
| 이번 단계 규칙 적용 | §2-7-1: 제목·썸네일 조합에 **대상(태양 바로 위) · 원인(옆으로 달리는 지구) · 결과·해법(목성)** 핵심어가 드러나야 함. §2-9: 이번 보상은 정체(무엇이 있나)가 아니라 이유·방법이므로 결과를 밝혀도 이유가 궁금하다 — 해당 없음으로 판단하되, 답의 마지막 부분(목성이 길을 어떻게 꺾나)은 감춘다 |

## 2. 후킹 포인트 (P5-1 “후킹되는 핵심 내용”, 제목·썸네일·도입이 함께 쓰는 재료)

1. **가까운 위쪽이 먼 명왕성보다 어렵다.** 지구 둘레 궤도에서 새로 내야 하는 속도: 화성 3.6, 명왕성 8.2, 옆으로 달리는 속도를 없애는 데만 24km/s(출처 기획 문서 10절).
2. **위로 가려는 탐사선이 태양에서 다섯 배 먼 목성으로 돌아갔다.** 1990년 발사, 1992년 2월 목성 옆에서 길이 거의 곧장 위로 꺾임.
3. **그렇게 가고도 카메라가 없어 보지 못했다.** 태양 바로 아래를 사진으로 처음 본 건 2025년.
4. **지금도 계단처럼 조금씩 오르는 중이다.** 솔라 오비터 17도(2025) → 24도(2026-12 예정) → 33도(2029 예정).
5. **시청자가 이미 품었을 질문**(“왜 위로는 안 가?”)에서 시작한다는 점(원본 댓글 근거, 영어권).

가장 센 클릭 재료는 1·2번이다. 3번은 본문·도입의 두 번째 궁금증으로 쓴다.

## 3. 과거 사용자 선택 형식 (T0)

수정·선택 사례 「제목·썸네일 선택 기록」(보이저 49년·세대우주선·관측 마지막 시대·블랙홀 안 우주·무서운 블랙홀·화성 도시·보이저 은하)과 그 뒤 항목(보이저 미래 제목 확정)을 읽었다. 사용자가 직접 고르거나 고친 문구만 근거로 삼는다.

| 사용자 선택·발언 | 형식(작업자 해석) | 이번 후보에 쓴 곳 |
|---|---|---|
| 화성 제목 “화성에 도시를 짓는다면, 땅 위가 아니라 땅 밑이어야 하는 이유” | 조건 + 아닌 것 대신 맞는 것 + 이유 | 제목 1 |
| 무서운 블랙홀 제목 “거대한 블랙홀보다 작은 블랙홀이 더 위험할 수 있는 이유” | A보다 B + 이유 | 제목 2·5 |
| 보이저 제목 “49년째 날고 있습니다 — 가장 가까운 별까지 7만 6천 년 남았습니다” / 보이저 미래 “곧 신호가 끊깁니다 — 그래도 50억 년 넘게 날아갑니다” | 사실 + 대시 + 뒤집는 결과 | 제목 3·6·8·9·10 |
| 보이저 은하 제목 “…영원히 날아가도 우리 은하를 벗어나지 못하는 이유” | 예상과 다른 쪽인 이유 | 제목 7 |
| 화성 썸네일 “화성에서 도시를 짓는다면 / 땅 위가 아니라 여기?” | 조건을 담은 첫 줄 + 감춘 물음표 | 썸네일 1·8 |
| 보이저 은하 썸네일 “보이저 1호는 우주 끝이 아니라 / 은하를 돌고 있다?” | A가 아니라 B? | 썸네일 8 |
| 보이저 썸네일 “아직 태양계도 못 벗어났어요” | 상식을 부정하는 존댓말 | 썸네일 5 |
| 사용자가 고칠 때: “탄 사람” 반려, 스타십정거장 “원인·대상을 제목에 드러내라”, 목성 속 “정체는 감춰라” | 핵심 대상·원인 단어를 문구에 보이게, 정체가 보상이면 감춤 | §2-7-1 적용(제목 4·5·9), §2-9 판단(1절) |

선택 기록은 여러 편이지만 모두 한 사람의 선택이고 작업자 추천을 그대로 확정한 경우가 많다. **반복 경향 관찰이지 확정 취향이 아니다.** 이번 편은 아직 사용자 선택이 없다.

## 4. 벤치마크 썸네일 실측 (T14·T24)

이번 편 유형(아는 대상 + 뜻밖의 상태·질문)의 벤치마크 썸네일을 직접 열었다: 001 우주 끝, 003 1광년, 004 파도행성, 006 타이탄, 013 숫자 2.697, 014 보이저, 016 노벨 물리학상, 017 암세포, 018 삼체, 그리고 참고 영상 썸네일. 나머지 유형(002·005·007~012·015)은 이번 질문 유형이 아니라 열지 않았다.

| 축 | 관찰 |
|---|---|
| 구도 | 대상 하나를 크게(006 타이탄, 014 보이저, 017 연기 덩어리) / 이름·숫자만(001 “우주의 끝”, 013 “2.697”) / 도해(016 소년·벽·공) / 문구 없는 장면 그림(004) |
| 프레임·아트·배경 | 검은 우주 배경이 다수. 실사풍·CG 혼합. 요소 2~3개 이하 |
| 카피 배치 | 하단 1~2줄(003 하단 1줄, 006·014 하단 왼쪽 2줄, 016·017 하단 1줄, 018 하단 2줄), 001은 상단 |
| 카피 형태 | 대상+물음표(006 “생명체가 있다고?”), 상태 문장(014 “반복하고 있다”), 의외의 사실+물음표(018 “고작 3개인데 답이 없다?”), 청유(003) |
| 색 | 흰색 + 노랑 강조가 다수, 017은 빨강 한 단어, 013은 빨강 숫자 |
| 참고 영상(원본) | 상단 흰 대문자 질문 “WHY CAN’T WE GO UP?” + 납작한 태양계 위로 솟은 화살표에 빨간 X |

**다수파(기본값):** 하단 1~2줄 흰/노랑 + 물음표 또는 상태 문장 + 대상 그림 하나. **소수파(변주):** 이름·숫자 하나. **원본 썸네일의 ‘납작한 태양계 + 위로 솟은 화살표 + 빨간 X’ 구도는 그대로 따라 하지 않는다**(원본과 같은 기대·같은 그림이 되기 때문, T5). 우리 프롬프트는 이 구도와 다르게 잡았다(9절).

**문구를 가리고 그림만 봤을 때(T21):** A는 “지구와 태양 사이에 놓인 작은 우주선, 텅 빈 위쪽”만 읽히고 ‘옆으로 달린다’는 화살표(후편집)가 있어야 이야기가 선다 — 그림이 대상·상황을 담고 원인은 문구·화살표가 맡는다. B는 목성 쪽으로 떠나는 탐사선이 읽혀 제목의 ‘목성’을 받쳐 주지만 문구의 ‘옆으로 달리는 지구’는 그림에 없어 **썸네일 2와는 A가 가장 잘 맞는다**(시험 추천 A). C는 전체 경로가 읽히나 ‘우주 도해’로 보일 수 있어 작은 화면 검증이 필요하다.
