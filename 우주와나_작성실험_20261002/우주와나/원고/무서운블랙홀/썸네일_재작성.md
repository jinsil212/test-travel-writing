# 썸네일 재작성 — 사용자 반려 반영

제목 확정: 거대한 블랙홀보다 작은 블랙홀이 더 위험할 수 있는 이유.
기획 1안 유지. 아래는 같은 기획의 표현 변형 10개이며 서로 다른 주제나 10개의 독립 유형이라고 표시하지 않는다. 사용자 선택 전.

| 번호 | 문구 | 문구만으로 읽히는 내용·제목 관계 |
|---|---|---|
| 1 추천 | 블랙홀에 떨어진다면 / 큰 것보다 작은 게 더 무섭다 | 낙하 상황, 블랙홀, 크기별 위험 역전이 모두 직접 나옴 |
| 2 | 거대한 블랙홀보다 / 작은 블랙홀이 더 위험할 수 있다 | 대상과 비교 결과가 명확함. 제목과 의미 중첩이 크지만 의미를 빼서 피하지 않음 |
| 3 | 큰 블랙홀이 더 무서울 줄 알았는데 / 작은 블랙홀에서 먼저 위험해진다 | 예상과 반대 결과. ‘먼저’는 낙하 시간 기록이 아니라 지평선 도달 전 파괴라는 조건으로 본문 설명 |
| 4 | 블랙홀은 클수록 무서울까? / 작은 쪽이 더 위험할 수 있다 | 크기 예상 질문과 조건부 반전 |
| 5 | 작은 블랙홀과 거대한 블랙홀 / 더 무서운 쪽은 작은 쪽이라고? | 비교 대상 둘과 의외의 위험 순서를 명시 |
| 6 | 블랙홀 크기만 보고 골랐다면 / 작은 쪽이 더 위험할 수 있다 | 블랙홀 크기로 고르는 가정과 위험 역전 |
| 7 | 거대한 블랙홀보다 작은 블랙홀이 / 몸을 먼저 망가뜨릴 수 있다 | 대상·크기 비교·구체 위험 결과. 신체 훼손 묘사는 확장하지 않음 |
| 8 | 작은 블랙홀이라 덜 무서울까? / 거대한 블랙홀보다 위험할 수 있다 | 작으면 덜 위험하다는 예상과 반례 |
| 9 | 블랙홀에 가까이 갈수록 / 큰 쪽보다 작은 쪽이 더 무서울 수 있다 | 접근 상황·크기별 위험을 제시. 모든 거리의 힘 비교로 일반화하지 않는 본문 조건 필요 |
| 10 | 거대한 블랙홀과 작은 블랙홀 / 떨어질 때는 작은 쪽이 더 위험할 수 있다 | 두 대상·낙하 상황·위험 비교가 전부 명시됨 |

1번 추천: 제목의 큰/작은 블랙홀 비교를 그대로 유지하면서 썸네일에 낙하 상황을 붙인다. ‘무섭다’의 근거는 낙하 중 물체 양끝 힘 차이이며, 모든 거리·환경에서 작은 쪽이 위험하다는 순위가 아니다. 짧은 반응만 남긴 이전 후보를 폐기했다.

검사 범위: 제목과 이미지를 가리고 10개 문구를 각각 읽었다. 모든 후보에 블랙홀 명칭, 크기 비교, 작은 쪽의 위험이라는 관계가 실제 단어로 들어 있다. 표 오른쪽은 문구에서 읽히는 내용이며 없는 대상을 보충하지 않았다. 기존 ‘같은 우주선 / 다른 결과’는 이름을 넣는 것만으로는 부족해 비교와 위험 결과까지 복구했다. ‘작은 블랙홀도 / 만만하지 않다’의 ‘도’는 역전 비교를 전달하지 못해 큰 쪽과 비교하는 말로 바꿨다.

이미지는 비교를 보강한다. 서로 다른 크기의 블랙홀에 같은 탐사선이 접근하는 두 장면. 각 경계 부근에서 물체 상태가 달라지는 재현이며 실제 촬영·정확한 외관 축척을 주장하지 않는다. 문구를 읽을 수 있게 공간을 먼저 확보한다. 실제 이미지 미생성, 축소 가독성 미검증. 영어 프롬프트 3개와 도입 전문 3개는 문구 선택 다음 단계다.

공용 T15-1의 문구 단독 이해·제목 관계·짧음보다 의미 우선·전 후보 검사와 T16의 동일 기획 안에서 변형 원칙 적용. 사용자 최종 합격·본문 검수·외부 카드 게시 완료가 아니다.
