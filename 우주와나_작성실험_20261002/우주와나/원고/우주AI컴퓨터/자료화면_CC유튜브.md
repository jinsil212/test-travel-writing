# 우주 AI 컴퓨터 — 자료 화면용 CC 유튜브 목록 (2026-09-20, 2차 확장)

- 검색 방법: 유튜브 검색의 **크리에이티브 커먼즈 필터**(sp=EgIwAQ)로 후보를 모으고, 영상마다 `license` 값과 길이를 yt-dlp로 직접 조회해 확인했다.
- 목록의 모든 영상: **크리에이티브 커먼즈 저작자 표시(CC BY)** 표시 + **7분 이상**.
- 확인한 것: 라이선스 표시, 길이, 채널, 제목, 설명. **확인하지 않은 것: 실제 프레임**(장면 판단은 제목·설명 기준이며 편집 때 구간을 직접 봐야 한다).
- CC BY는 출처 표기가 조건이다. 설명란에 채널명, 제목, 링크, “CC BY”를 적는다.
- 재업로드 주의: 업로더가 CC로 표시해도 원저작자가 따로 있는 경우가 있다. NASA 제작물은 대체로 공공저작물이라 안전하고, 스페이스X 발사 중계를 옮긴 영상은 권리자가 스페이스X다.

## 아직 CC 유튜브에서 못 찾은 장면

- 방열판 표면 접사, 액체 방울을 뿌려 식히는 방식(액적 방열기), 우주 쓰레기 충돌 시뮬레이션: 쓸 만한 CC 영상이 없었다. NASA 자료실이나 직접 만든 도식이 낫다.
- 국 냄비, 헤어드라이어, 보온병, 전기난로 같은 생활 장면: 유튜브 CC보다 무료 스톡(펙셀스, 픽사베이)이 빠르다.
