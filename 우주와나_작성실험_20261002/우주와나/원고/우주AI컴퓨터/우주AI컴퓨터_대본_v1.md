## 4. 채널설정 §4 ☑ (본문)

- **P0-15 표:** 2절.
- **도입 약속에 답하는 실제 구절:**
  - “왜 열이 빠져나가지 못하는가” → “그런데 우주에는 때릴 상대가 거의 없습니다. 아무리 심하게 떨어도 옆이 비어 있으면 그 떨림을 넘겨줄 데가 없는 거죠.”(약 20%)
  - “어떻게 식히는가” → “그래서 방법은 하나뿐이에요. 빛을 내보내는 면을 아주 넓게 만드는 겁니다.”(33%) / “그래서 방열판은 해를 마주 보지 않게 세웁니다.”(50%) / “칩을 뜨겁게 굴릴수록 판이 작아지는 겁니다.”(79%)
- **분량:** 공백 제외 6,075자, 분당 300~400자 가정 시 15.2~20.2분(추정). 사용자 요청 20분에 맞춰 같은 질문 안에서 깊이를 더했고, 새 주제를 붙여 늘리지 않았다(공용 S3-4).
- **전문용어 처리(§4-2):** ‘진공’은 “공기 알갱이가 지구 표면의 수백억 분의 1 수준” 뒤에 이름을 붙였고, ‘방열판’은 ‘판’으로 먼저 쓰다가 50% 지점에서 이름을 준다. ‘열화상 카메라’는 “그 빛을 잡아서 뜨거운 곳을 붉게 보여 주는 장치”로 풀었다.
- **비교는 지구 기준(§4-3):** 국 냄비, 데이터센터, 헤어드라이어, 전기난로, 농구장, 아파트 평수, 서울 면적.
- **도입 수치 되풀이 금지(§4-4):** 도입의 ‘영하 270도’는 본문에서 두 번만 쓰고(21%, 91.6%), 두 번째는 뜻을 바꾸는 회수로 썼다. ‘보온병’은 원리 설명(17%)과 마지막 회수(93%)에서 새 의미를 얻는다.

## 5. 채널설정 §5 ☑ (클로징)

1. **새 정보로 회수:** “다만 그 온도는 열을 실어 갈 공기도, 열이 옮겨 갈 상대도 없는 곳에서 잰 온도예요.” — 도입의 숫자에 본문에서 얻은 뜻을 붙였다.
2. **한 점으로 좁히기:** “우리가 노트북을 무릎에 올려놓고 쓰는 동안, 방 안의 공기가 그 열을 받아 가고, 건물이 받아 가고, 마지막에는 지구가 빛으로 우주에 내보냅니다.”
3. **이전 영상 추천:** “지구를 떠난 기계가 어디까지 갔는지 궁금하시면, 지난 영상 ○○도 함께 봐 주세요.” — 실제 업로드 목록이 없어 ○○로 두었다(편집 때 채움).
4. 다음 편 예고 없음, 번호 붙인 요약 없음, 2인칭 훈계 없음. 투표형 질문 한 번(006 타이탄 방식).

## 7. `_원고쓰는법.md` 8장 검사표 (실제 문장과 위치)

**A. 클릭 이유**
1. 사슬: 제목 ‘지구보다 식히기 어려운 이유’ → 썸네일 ‘열이 빠져나갈 곳이 없다’ → 첫 문장 ‘최근 일론 머스크가…’ → 도입 끝 ‘왜 열이 빠져나가지 못하는 걸까요? … 어떻게 식혀야 할까요?’ → 마무리 ‘차갑다는 것과 식혀 준다는 것은 처음부터 다른 말이었습니다’(91.6%). 모두 같은 질문.
2. 도입 마지막 질문 = 제목 질문 ✓ (왜 안 식나 = 왜 식히기 어렵나).
3. 준 것: 진공·보온병·계획. 남긴 것: 열이 옮겨 가는 방식, 빛, 판, 햇빛, 뜨거운 칩.
4. 핵심 답 위치: 31.6%(남은 길은 빛) → 47.3%(판) → 50%(햇빛 각도) → 79%(뜨거운 칩). 제목 핵심어 ‘식히기/열’이 30% 이상 비는 구간 없음(‘열’은 전 구간에 60회 이상 등장).
5. 곁가지: 우주복·펌프 사건·방울 방열판은 2절에서 필요성을 적었고, 각각 뒤에서 회수된다(물 대안 차단, 수리 불가, 판 대안 차단).
6. 썸네일 약속 해소 위치: 14.7~20%(왜 진공이 막는지), 31.6%(남은 길), 91.6%(회수).
7. 마무리에 새 정보: “지구가 이 일을 공짜로 해 주고 있었다”는 관점은 본문 49% 지점의 사실을 마지막에 시청자 자리로 옮긴 것.

**B. 도입과 흐름**
8. 뜻밖의 사실: 확정 도입 3번째 문장(“왜 지구보다 컴퓨터 식히기가 더 어렵다는 걸까요?”).
9. 도입 비율: 332자 ÷ 6,075자 = 5.5%(권장 12% 이하).
10. 첫 전환 31.6%, 두 번째 47.3%, 후반 전환 77.4%(판 → 온도). 벤치마크 첫 전환 범위(44~68%)보다 이른데, 이 편은 ‘세 길 중 하나로 좁히기’가 곧 구조라 그대로 둔다.
11. 반박 선취: “그래도 바깥이 영하 270도인데, 그 차가움이 열을 좀 가져가 주지 않을까?”(21%) / “그럼 위성에도 같은 방법을 쓰면 되지 않을까요?”(28%) / “판 말고 다른 방법은 없을까요?”(72%).
12. 심은 것 회수: 국 냄비(도입 장면 → 본문 전체 기준), 보온병(도입 → 17% → 93%), 데이터센터 물 1,000톤(12% → 29%), 헤어드라이어(33% → 67%), 펌프 사건(43% → 82%), 영하 270도(도입 → 91.6%).

**C. 문장**
13. 설명 먼저 이름 나중: ‘열은 알갱이의 떨림’ → 진공, ‘판’ → 방열판, ‘물이 흐르는 속옷’ → 설명만(이름 생략).
14. 숫자마다 아는 것으로 환산: 70킬로와트→농구장만 한 판, 100킬로와트→전기난로 50대, 700와트→헤어드라이어, 80·200제곱미터→24평·60평, 4킬로미터→걸어서 한 시간, 1,361와트→판이 버리는 양의 두 배, 2,000제곱킬로미터→서울 면적 세 배.
15. 나열 뒤 판단: “그러니까 지구에서 컴퓨터를 식히는 일은 사실상 첫째와 둘째 길, 공기와 물이 거의 다 해 주고 있는 셈입니다.”(14%) / “우주에서 열을 버리는 일은, 고장 나면 사람이 직접 나가야 할 만큼 중요한 일입니다.”(45%)
16. 말투: 전부 존댓말(~습니다/~해요/~죠). ‘~했다’ 내레이션 0, 채널 캐릭터 개그 0.
17. 과장·단계 표시: “아직은 연구 단계”, “어림수”, “발표에 따르면”, “계획입니다”.

**D. 한국어 문장(18~25)**
18. 대상·행동·조건 명시 ✓ (“냄비 표면의 알갱이가 공기 알갱이를 때려서 같이 떨리게 만드는 일”).
19. 평가만 하는 문장·예고로 설명 대체 없음(중간 정리 한 번은 리셋 목적).
20. 비교 기준 동봉 ✓ (“버리는 양보다 두 배 가까운 열”, “우주정거장의 판 여섯 장이 감당하는 열이 70킬로와트였죠”).
21. 문단 다리 ✓ (3절 전환표).
22. 제목·썸네일 단어 유지 ✓ (식히기, 열, 보온병, 빠져나가다, AI 컴퓨터).
23. 새 대상은 정체와 함께 ✓ (“국제우주정거장”, “한 회사”, “한 공학 전문지”).
24. 같은 설명 반복 없음 — 유사 문장쌍 자동 점검 0건(문장 간 낱말 겹침 50% 이상 없음).
25. 한국어 자연스러움: 소리 내어 읽고 6절의 다섯 곳을 고쳤다.

## 9. 제작 메모 (낭독문에는 넣지 않음)

- 화면 3지점: ① 국 냄비와 세 갈래 화살표 도식(공기·맞닿음·빛) ② 보온병 단면과 위성을 겹친 도식 ③ 우주정거장 방열판과 AI 위성 판 크기 비교(농구장, 24평·60평, 서울 면적)
- 실사 보강 후보: NASA 공개 이미지의 우주정거장 방열판, 2013년 12월 펌프 교체 우주유영. 사용 시 원본 페이지와 크레딧을 원고 맨 아래에 붙인다(공용 P0-6a).
- 클로징의 ○○ 자리: 실제 업로드된 우주와 나 영상 제목으로 교체.
- TTS: 가운뎃점·괄호 없음, 숫자는 아라비아 숫자 표기.

## 10. 남은 확인 사항

- 머스크 발표 원문(80퍼센트, 100킬로와트, 우주용 칩 사양) 1차 확인 — 현재는 2차 보도 기준.
- 우주정거장 표면 온도 NASA 1차 페이지 확인.
- 확정 도입부 두 곳은 사용자 문구라 그대로 두었고, 본문에서 모순이 나지 않게 처리했다: ‘완벽한 진공’ → 본문은 “사실상 진공”으로 받음, ‘열이 도무지 빠져나갈 곳이 없다’ → 본문에서 “남은 길은 빛 하나”로 이어받음. ‘보온병 물이 며칠씩’은 실제로는 몇 시간에서 하루 정도라, 사용자가 원하면 “하루가 지나도 따뜻한 것처럼”으로 고칠 수 있다(작업자 제안, 미반영).
- 실제 TTS 재생 시간 측정, 이미지 생성, 클릭업 등록 미실행.
