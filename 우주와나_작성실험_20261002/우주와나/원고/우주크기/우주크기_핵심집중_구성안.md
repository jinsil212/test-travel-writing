# 우주 크기 편 — 사용자 확정 5단계 구성

사용자 의견: 15분 미만 영상에 너무 많은 주제를 넣기보다 기획·제목·썸네일·도입에 가장 부합하는 내용에 집중한다.

확정 핵심 질문: 가장 가까운 별에 인사를 보내도, 왜 답장을 받는 데 8년 넘게 걸릴까?

| 소재 | 판단 | 이유 |
|---|---|---|
| 별에 보낸 인사와 즉시 답장 가정 | 유지 | 클릭 기대를 바로 확인하는 상황 |
| 지구에서 달·태양까지 빛의 이동 | 짧게 유지 | 같은 출발점에서 가까운 거리와 비교하는 발판 |
| 가까운 별까지 거리와 편도·왕복 | 중심 내용 | 기다림의 원인을 설명. 도입 상황을 그대로 재연하지 않고 이유를 발전시킴 |
| 광년의 뜻 | 필요한 만큼만 | 거리 이해를 돕는 짧은 설명으로 통합 |
| 별 사이 거리의 의미 | 마무리 | 가까운 이웃조차 인간의 생활 시간과 크게 다른 거리임을 회수 |
| 우리 은하·안드로메다의 크기 | 이번 안에서는 제외 | 별 사이 거리에서 은하 규모로 별도의 질문이 열림 |
| 오래전 모습을 보는 원리 | 별도 편으로 보류 | 송신 거리의 원인 설명에 필수적이지 않은 관측 주제 |
| 우주 나이·팽창·관측 범위·우주의 끝 | 별도 편으로 보류 | 여러 선행 개념과 독립적인 설명이 필요한 주제 |

추천 흐름: 도입의 기다림 → 달·태양과 짧게 비교 → 가까운 별까지의 거리와 빛의 이동 → 답장이 늦는 이유의 정리 → 가장 가까운 별조차 이 정도라는 의미로 마무리.

직전의 10구간 재배열보다 소재 범위를 먼저 줄이는 안을 우선한다. 단순 삭제로 짧게 만드는 것이 아니라 핵심 질문에 필요한 설명을 살린다. 예상 분량을 채우기 위한 보강은 하지 않는다.

제목 점검: 현재 제목의 ‘우주는 얼마나 클까?’는 전체 우주의 크기를 답할 것처럼 보일 수 있다. 추천 대체 제목은 ‘가장 가까운 별에 보낸 안녕, 답장까지 8년이 걸리는 이유’. 현재 제목과 본문은 아직 교체하지 않았다. 썸네일 ‘별에 보낸 안녕 / 답장까지 8년’과 긍정받은 도입은 유지 가능하다.

상태: 사용자가 핵심에 집중하는 아래 5단계 구성을 승인했다. 구성 확정이며 원고 전체 합격은 아니다. 본문 수정 및 최종 검토는 미완료. 은하와 관측 범위까지 확대하던 이전 제안을 그대로 최종 집필안으로 실행하지 않는다.

## 사용자 확정 흐름

| 흐름 | 시청자에게 전달할 내용 | 집필 시 구별할 역할 |
|---|---|---|
| ① 즉시 답했는데도 8년 | 익숙한 인사에 뜻밖의 기다림을 붙여 궁금증을 만든다. | 결과와 궁금증을 제시한다. |
| ② 달이나 태양이라면? | 지구에서 출발한 같은 빛으로 가까운 거리부터 짧게 비교한다. | 거리 감각을 잡는 발판으로만 쓴다. |
| ③ 그런데 가까운 별은 왜 이렇게 멀까? | 초·분 단위의 비교가 년 단위로 커지는 차이를 충분히 설명한다. | ‘가깝다’는 말과 실제 거리의 차이를 이해시킨다. 별이 그곳에 생긴 원인을 다루는 별도 주제로 확대하지 않는다. |
| ④ 기다림의 원인은 거리 | 상대의 답장 속도와 상관없이 신호가 왕복해야 한다는 점을 납득시킨다. | 앞에서 이해한 편도 거리를 답장까지의 시간에 적용한다. 도입의 문장과 상황을 그대로 재연하지 않는다. |
| ⑤ 이 별이 가장 가까운 이웃이라는 사실 | 처음의 인사를 회수하며 별 사이의 거리가 얼마나 큰지 남긴다. | 새로운 천체·은하 설명을 시작하지 않고 핵심 의미로 닫는다. |

이 표가 현재 집필 기준이다. 기존 10구간 확장안보다 우선한다. 제목의 정확한 문구 선택과 본문 반영 상태는 별도로 확인한다.
