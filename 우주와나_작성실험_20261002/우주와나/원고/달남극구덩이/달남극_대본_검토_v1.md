# 달 남극 — 대본 v1 검토 (G4·G5-2, 사실 근거, 사용자 지시 대조)

- 검토 대상: [달남극_대본_v1.md](달남극_대본_v1.md) 저장본(공백 제외 4,979자). 저장 후 다시 열어 처음부터 끝까지 읽고 수정한 뒤 다시 저장했다. 같은 작성자의 재검토이며 실제 중학생 이해 검증이 아니다.
- 사용자 지시(2026-09-20): 도입 고정 + 5단계 구성 + 분량 20분 미만 + 조언(도입에서 정답을 주고 새 호기심 열기, 텐션 배분, ‘500ml 생수 배송비’ 같은 구체 비유).

## 1) 사용자 문구·구성 중 사실과 달라 바로잡은 곳

도입은 고정이라 한 글자도 바꾸지 않았다. 대신 **본문이 그 문장을 자연스럽게 바로잡게** 했다. 고정 도입을 고칠 수도 있으니 아래 제안은 사용자 선택이다.

| 사용자 문구 | 문제 | 본문에서 처리한 실제 구절 | 고정 도입을 고친다면(선택) |
|---|---|---|---|
| “달 유일의 ‘우주 주유소’ 명당” | 남극 근처에 이런 자리가 여러 곳(LPSC 2012 ‘좁은 지역에서 두 환경이 공존’), 미국 후보 지역도 아홉 곳 | 3단계 “도입에서 달에 유일하다고 했지만, 정확히는 이런 자리가 달 남극 근처에 몇 곳 있고, 섀클턴 테두리는 그중에서도 손꼽힌다는 뜻입니다.” | “달에서 손꼽히는” |
| “혜성들이 남긴 얼음이 고스란히 보존된 천연 자원 창고” | 얼음이 있다는 확정이 아니고(섀클턴 바닥은 카메라에 겉 얼음 안 보임), 혜성은 기원 후보 중 하나. 5단계 반전과도 모순 | 3단계 “제가 앞에서 혜성이라고 말했지만, 혜성은 가장 잘 알려진 후보일 뿐 확정된 답은 아닙니다.” / 5단계 “도입에서 제가 ‘고스란히 보존된 자원 창고’라고 했지만, 정확한 표현은 ‘있을 가능성이 매우 높다’입니다.” (사용자가 설계한 반전을 살림) | “얼음이 보존돼 있을 것으로 보이는” |

| “영토 전쟁” | 우주조약이 국가의 영유권 선언을 금지, 실제 다툼은 자리 선점과 규칙 | 4단계 “영토 전쟁이라고 했지만, 땅을 빼앗는 전쟁은 아닙니다. … 진짜 다툼은 … 누가 먼저 자리를 잡고, 그 주변의 규칙을 누가 만드느냐입니다.” | “치열한 자리 다툼” |

**유지한 구절과 이유**
- “우리 집 냉동실이 영하 18도입니다.” — 영하 160도의 차가움을 재는 익숙한 눈금(006 서해 환산과 같은 기능). 빼면 숫자만 남는다.
- “이것이 이른바 중력의 저주입니다.” — 사용자 구성 단계 이름을 낭독문에 한 번만. 새 사실은 없지만 앞 문단 원리를 한 문장으로 묶는 이름이라 유지(과하면 삭제 가능).
- 꾸민 번역투 3문항: “목숨을 건다”(사용자 도입, 한국어에서 쓰는 과장), “함정입니다”(비유 바로 앞에서 ‘들어오기만 하고 나가지 못한다’로 풀음), “얼음 창고”(가리키는 대상이 분명). 걸린 곳 없음.

## 5) 사용자 5단계 구성 대조

- 사용자 제시 조언 대조: ① 클릭 보상을 도입에서 즉시 제공 → 사용자 도입이 지급. ② 오픈 루프 → 도입 마지막 두 질문을 3단계 “첫 번째 질문”, 4단계 “두 번째 질문”으로 각각 회수. ③ 텐션 배분 → 2·3단계 지식, 4단계 갈등, 5단계 반전. ④ 생수 배송비 비유 → 2단계에 반영.
- 도입과 본문 중복(H10): 도입의 ‘무게가 곧 돈’, ‘분해해 연료’, ‘어둠과 태양이 붙음’은 본문에서 **숫자·원리·이유**를 새로 붙여 다시 나온다. 같은 문장 반복 없음(직접 대조).
- 분량: 4,979자 → 분당 300~400자 가정 12.4~16.6분. 사용자 시간 배분(20분)보다 짧다. **20분 미만·10분 이상은 충족**, 실제 TTS 시간은 미측정.
