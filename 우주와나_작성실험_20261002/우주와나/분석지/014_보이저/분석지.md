# 분석지 014 — 보이저 1호로부터 이상한 데이터가 날아오고 있다 (세모과학)

## 1. 핵심 방향 한 문장 — 제목·썸네일·첫 문장이 거기서 어떻게 나왔나

▶ 쓰는 곳: 지침서 0-2 ③ 기획("핵심 방향을 사실로 쓴 한 문장 → 제목·썸네일·첫 문장 파생") · A10 같은 곳

**핵심 방향(사실형)**: 244억 km 밖 보이저 1호가 0과 1만 반복하는 무의미한 신호를 보내오고 있고, 원인은 FDS로 짐작되지만 40년 된 기계라 고치기 어려우며, 어차피 2025~2030년에 전력이 끊긴다.

| 파생물 | 원문 | 한 문장의 어느 부분에서 나왔나 |
|---|---|---|
| 제목 | 보이저 1호로부터 이상한 데이터가 날아오고 있다 | 증상만. **현재진행형**으로 |
| 썸네일 문구 | 보이저 1호 / **알 수 없는 말을 / 반복하고 있다** | 같은 증상을 **"데이터"가 아니라 "말"**로 바꿔 부른다 |
| 첫 문장 | **244억 km** 위대한 항해자라고 불리는 우주 탐사선 보이저 1호와 지구 사이의 거리입니다. | 수치를 첫 단어로 던지고 뒤에 정체를 붙인다 |

**제목은 "데이터", 썸네일은 "말"이다.** 같은 사실을 기계어와 사람말로 나눠 말했고, **이 한 단어 차이가 댓글 전체를 결정한다** — 7번 칸에서 본다.

| | |
|---|---|
| 시청자가 믿고 온 것 | 보이저에 무슨 일이 났나 |
| 영상이 보여준 것 | 고장의 정체 + 왜 못 고치는지 + **그리고 어차피 끝이 다가온다** |
| 시청자가 마지막에 받는 것 | 정보가 아니라 **이별의 예감** |

## 2. 시청자 감정 흐름 — 처음부터 끝까지

▶ 쓰는 곳: ⑤-2 "그래서 나랑 무슨 상관"의 답이 어디 있나 · 기획 때 "후반에 감정 방향이 바뀌는가"

| 구간 | 시청자가 느끼는 것 | 그 감정을 만든 문장 (원문) |
|---|---|---|
| 훅 | 걱정 — 뭔가 잘못됐다 | 보이저 1호가 알 수 없는 말을 반복하고 있다 |
| 그랜드 투어 | **자부심** — 175년에 한 번 온 기회를 잡았다 | 이는 175년에 한 번 발생하는 아주 귀중한 기회였습니다. |
| 별명 | 존경 | 이러한 이유로 보이저호에게는 역사상 가장 위대한 항해자라는 별명이 붙게 되었습니다. |
| 이상 신호 | **서늘함** — 의미 없는 말을 혼자 한다 | 아무런 뜻도 내용도 없는 나사 엔지니어의 표현을 빌리자면 **혼자 중얼거리는 말**이었습니다. |
| 원인 분석 | 답답함 — 리부트도 안 통한다 | 시스템을 내렸다가 다시 올리는 리부트를 진행하는 등의 기본적인 시도를 했지만 이것만으로는 해결되지 않았습니다. |
| 왜 어려운가 | **무력감** — 만든 사람도 없고 왕복 이틀 | 이를 제작한 전임자들은 모두 일선에서 물러난 상태이고 해결책을 찾기 위해서는 수십 년이 넘은 원본 문서를 뒤져봐야 하는 것입니다. |
| 노화 | 슬픔 — 보온 장치까지 껐다 | 조금이라도 동력을 아끼기 위해 보온 장치를 포함한 부가적인 장비들을 아예 가동 중단한 상황입니다. |
| 끝 예고 | 체념 | 빠르면 2025년 늦어도 2030년에는 전력 부족으로 인해 지구와의 통신이 끊어질 것입니다. |
| 클로징 | **이별** | 언젠가 먼 미래에 머나먼 우주 끝자락에서 다시 만날 수 있기를 소망해봅니다. |

**감정의 방향이 바뀌는 곳은 두 번.** 11.6%(걱정 → 자부심)와 **36%(자부심 → 서늘함)**. 그리고 79.8%부터 끝까지 한 방향으로 내려간다. **자랑을 먼저 시켜 놓고 쇠락을 보여주는 배치**라서 마지막 슬픔이 커진다.
**시청자와 연결되는 자리**: "여러분" 0회, "우리" **0회** — 열여덟 편 중 유일하게 시청자를 한 번도 안 부른다. **그런데 댓글은 열여덟 편 중 가장 정서적이다.** 화자가 부르는 대신 **나사의 표현("혼자 중얼거리는 말")을 인용해 흘려 놓고**, 시청자가 알아서 의인화한다 — 1위(2,200): *"거의 50년을 퇴근 안하고 일햇는데 50년동안 야근하면 나같아도 그럴듯"*, 9위(309): *"0=쉬는날 없다 1=일만한다"*, 6위(374): *"기계지만 그 깜깜한 심연의 우주에 혼자서 돌아다니는 게 참"*.

**→ 화자가 슬퍼하지 않고 사실만 늘어놓는데 시청자가 대신 슬퍼한다.** 대상이 이미 시청자에게 감정 자산인 경우(보이저 같은) 화자는 정보만 정확히 주고 정서는 시청자에게 맡기는 게 낫다.

**회수 문형(원문)** — "게다가 보이저 1호는 지구에서부터 244억 km 떨어져 있습니다." — **훅의 첫 단어였던 자랑스러운 거리가 여기서 족쇄가 된다.** 같은 숫자인데 처음엔 위업의 크기였고 여기서는 고칠 수 없는 이유다. **숫자 하나의 뜻이 뒤집히는 회수**이고, 이 편에서 가장 잘된 한 수다.

**반전 자리** — **61.3%.** "그렇다면 좀 더 다방면의 해결 방법이 필요하다는 건데 이게 그렇게 단순하지 않다는 것이 문제입니다." 고칠 수 있을 줄 알았던 것이 못 고칠 수도 있는 일이 된다. 다만 이 편의 진짜 전환은 **79.8%(전례와 노화)**에 있다 — 이번 고장을 고쳐도 어차피 끝난다는 사실이 나오면서 이야기가 수리 기사에서 이별 이야기로 바뀐다.

**착지 유형** — **이별 착지.** "인류에게 우주를 알려주었던 위대한 항해자와의 이별이 서서히 다가오고 있습니다. 언젠가 먼 미래에 머나먼 우주 끝자락에서 다시 만날 수 있기를 소망해봅니다." 열여덟 편 중 이 유형은 여기뿐이다. **CTA는 없지만 채널 서명은 있다** — "지금까지 세모과학이었습니다." 이 채널 여덟 편 중 **서명이 있는 유일한 편**이고, 여덟 편 중 가장 오래된 편(2023년 12월)이라 초기 규격으로 보인다.
