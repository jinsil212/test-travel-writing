# 벤치마크 교차 노트 A — 001~006 (리뷰엉이: Owl's Review)

근거: 각 폴더 `분석지.md` 전문 + `원문.txt`(자동자막) 대조 + `정보.md`.
표기 규칙
- **[관찰]** = 원문·정보.md·분석지 수치에서 바로 확인되는 것. **[해석]** = 분석지 작성자 또는 이 노트의 판단.
- 인용은 자막 원문. 명백한 자막 오류만 `[ ]`로 교정(예: 아내→[안에]). 자막에 문장부호가 없어 문장 경계는 분석지의 분절을 따름.
- 어미 집계는 자막 전체에서 `니다.`/`니다?` 와 `요·죠·예요·에요.`를 grep한 대략치(문장부호 누락 때문에 근사값). "우리"·"여러분" 횟수도 원문 grep 값.
- 없는 항목은 '미기재'.
