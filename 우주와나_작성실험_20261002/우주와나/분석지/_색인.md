## 해석 기준 — 2026-09-12 사용자 요청 반영

작성 기준은 루트 `_대본지침서.md`의 P0이다. 아래 18행은 기존 관찰과 분석자의 해석을 보존한 자료다. 원문 사실 검증이나 새 기획의 효과 검증을 완료했다는 표시가 아니다.

- 행 안의 개수·비율·순서·‘필수·반드시·안 맞음’은 원본의 선택 또는 과거 적용 가설로 읽는다. 그 숫자를 맞추지 못했다고 자동 탈락시키지 않는다.
- ‘같은 질문에 답하려면 필요한 근거’와 ‘원본이 선택한 형식’을 구별한다. 예: 비교를 이해시킬 기준은 필요할 수 있어도 비교 도구 8~12개가 항상 필요한 것은 아니다.
- 1편 관찰, 여러 편에서 반복 관찰, 성과의 원인 입증은 서로 다르다. 횟수가 늘었다고 인과 효과가 입증되지 않는다.
- 원본 관찰과 해석을 더 세밀하게 분리하려면 해당 분석지와 원문을 직접 대조한다. 이번 업데이트는 색인 사용 기준의 정리이며 18편을 새로 전수 분석한 것이 아니다.

## 참고 자료 고르는 순서

1. 링크·키워드에서 이번 주제를 확인한다. 주제 자료와 기획 견본의 역할을 구분하며 URL이라는 이유만으로 분석 완료·등록으로 처리하지 않는다.
2. 결정표 전체에서 핵심 질문과 전개 기능이 맞는 후보를 살핀다. 같은 번호에 고정하지 않는다.
3. 후보마다 관찰한 방식, 필요한 기능, 원본만의 형식, 이번 주제의 대응 사실, 부족한 근거와 대안을 기록한다. 형식 개수만으로 탈락시키지 않는다.
4. 사용할 분석지와 원문을 끝까지 읽고 공용 P0의 기준으로 판단한다. 실제 자료가 없으면 미확보라고 적는다.
5. 일반 제출은 공용 P5-1의 핵심 비교표와 뒤 설명, 오토는 0-4에 따른 내부 비교·선정으로 진행한다. 이 색인의 옛 양식이 공용 지침을 덮어쓰지 않는다.

## 등록과 근거 갱신

- 영상 1편마다 고유 폴더를 사용한다. 등록 시 확보한 자료와 미확보 항목, 확인 날짜를 밝힌다.
- 영상별 관찰은 분석지에, 비교 요약은 이 색인에 둔다. 작성 규칙은 공용 지침서에서 관리한다.
- 같은 방식이 반복되면 대조한 영상과 공통점·차이·반례를 적고 ‘반복 관찰 n=2’처럼 표시한다. 효과 확인이나 성공 공식으로 표시하지 않는다.
- 이관 시점의 실적은 당시 기록이다. 갱신 시 새 측정 날짜와 경과일을 명시한다.
