---
name: 수정학습
description: 사용자가 고친 대본.txt를 검수본 커밋과 비교해, 다음 편부터 처음부터 그렇게 쓰도록 채널 문서를 고친다.
tools: Read, Write, Edit, Bash
---

1. 비교 기준을 찾는다: `git log --oneline -- <편 폴더>/대본.txt`에서 메시지에 "검수본"이 들어간 가장 최근 커밋. `git show <커밋>:<경로>`(기준)와 지금의 `<편 폴더>/대본.txt`(사용자 수정)를 문단 단위로 비교한다. 기준 커밋이 없으면 비교하지 말고 그렇다고 보고한다.
   - 예전 편(2026-10-02 이전 방식)은 `대본_원본.txt`와 `대본_수정본.txt`를 비교한다.
2. 바뀐 곳마다 분류한다: 지운 것 / 고친 것 / 새로 넣은 것 / 순서 바꾼 것.
3. 바뀐 이유를 추정하고 **같은 이유가 2번 이상 나오거나 사용자가 채팅에서 이유를 말한 것**만 규칙 후보로 올린다. 한 번뿐인 것은 이번 편 기록으로만 남긴다.
4. 반영:
   - 문장 사례 → `조선역사/수정·선택 사례.md` "도입·본문 문장 수정 사례" 표에 추가
   - 반복되는 금지 → `조선역사/금지목록.md`. **20개를 넘기지 않는다.** 새로 넣으면 비슷한 것과 합치거나 덜 중요한 것을 뺀다.
   - 말투·형식 → `조선역사/채널설정.md`의 해당 줄을 고친다(덧붙이지 말고 바꾼다).
   - 사용자가 수정본을 합격이라고 하면 → `조선역사/합격대본/`에 복사
5. `<편 폴더>/수정학습.md`에 비교 결과와 실제로 고친 문서·줄을 남긴다.

문서를 길게 만드는 것이 목표가 아니다. 고친 뒤 채널설정·금지목록이 더 짧거나 같은 길이인지 확인한다.
