# 대본쓰기 — 조선역사

목표: 참고 영상의 핵심 사실로 **우리 시청자에게 먹히는 새 15분 대본**을 만든다.
우선순위: **흐름(기승전결·맥락) > 사실 > 말투.**
좋은 예시는 **벤치마크 원고 전문**(`조선역사/분석지/0NN_*/원문.txt`)과 그 해부(`조선역사/견본/`), 금지는 `조선역사/금지목록.md`, 형식·말투는 `조선역사/채널설정.md`. 이것 말고 긴 지침을 읽지 않는다.

편 폴더: `조선역사/원고/<주제>/`. 단계가 끝날 때마다 `진행상태.md`에 한 줄 남긴다.

## 1. 참고 영상 → 재료 (서브에이전트 1개)
`참고영상분석` 에이전트에 링크와 편 폴더를 준다 → `01_참고영상.md`.

## 2. 사실 확인 (서브에이전트 2~3개 동시)
`01_참고영상.md`의 핵심 사실 목록을 성격별로 2~3묶음으로 나눠 `사료조사` 에이전트를 **동시에** 띄운다
(예: 사건 경과 / 제도·숫자 / 인물·생활 장면). 결과 → `조사/*.md`. 메인이 `02_사실표.md`로 합친다.

## 3. 기획 → 사용자 선택 (메인)
`채널설정.md`·`다룬주제.md`·`수정·선택 사례.md`·`견본/_색인.md`를 보고 `03_기획.md`:
- 기획 3안. 각 안: 핵심 질문 한 줄, 이 시청자가 클릭할 이유 한 줄, 어울리는 견본 번호, 흐름 5줄
- 추천 1안과 이유
- 추천안의 제목 후보 5개, 썸네일 2줄 후보 5개 (사용자 과거 선택 형식에 맞춰)

채팅에는 번호 목록으로 짧게 보여주고 **사용자가 고를 때까지 기다린다.**

## 4. 흐름 설계 → 사용자 승인 (메인)
먼저 고른 안에 맞는 벤치마크 1편을 `견본/_색인.md`로 정하고, 그 **원고 전문**(`분석지/0NN_*/원문.txt`)과 견본 분석을 읽는다. 그 원고가 질문을 걸고, 답을 나눠 주고, 심고 갚는 방식을 이번 주제의 사실로 다시 짠다.

`04_흐름설계.md`:
- **기준 벤치마크**: 번호와 고른 이유
- **한 줄 이야기**: 시청자가 처음에 무엇을 궁금해하고, 무엇을 차례로 알게 되고, 마지막에 무엇을 가져가는가 (세 문장)
- **기승전결 표**: 막 / 위치(%) / 하는 일 / 시청자가 새로 아는 것 / 감정 / 끝날 때 남는 궁금증. 가장 큰 반전은 중간쯤.
- **답 나눠 주기**: 도입 질문의 답을 몇 % 지점에서 몇 조각으로
- **심기→회수 지도**: 심을 것 / 어디서 / 어디서 갚나 / 갚을 때 붙는 새 의미
- **사실 배치**: 사실표 번호마다 어느 막에서 쓸지, 버릴지. 같은 사실을 두 번 설명하지 않는다.

사용자에게 **한 줄 이야기와 기승전결 표 중심으로** 보여주고 승인받는다.

## 5. 집필 → 흐름 검수 → 문장 검수
대본 파일은 **`대본.txt` 하나**다. 단계마다 새 파일을 만들지 않고 같은 파일을 고친다. 무엇을 고쳤는지는 각 기록 파일에 남긴다. (2026-10-02 사용자 지정)
1. `대본작가` 에이전트 **1명**이 전체를 처음부터 끝까지 쓴다. 흐름설계와 사실표 경로를 준다 → `대본.txt`, `작성기록.md`.
2. `흐름검수` 에이전트(맥락 없이 경로만) → `대본.txt`를 직접 고침, `흐름검수기록.md`.
3. `최종검수` 에이전트(맥락 없이 경로만) → `대본.txt`를 직접 고침, `검수기록.md`.
4. 메인이 편 폴더를 커밋한다(메시지에 "검수본" 포함). 이 커밋이 6단계 비교 기준이다.
5. 사용자에게: 제목, 썸네일 2줄, 한 줄 이야기, 글자 수와 예상 분량, 검수에서 고친 곳 요약, 남은 걱정. 대본 전문은 파일 링크로.

서브에이전트는 **조사(동시)와 검수(독립)**에 쓴다. 대본은 나눠 쓰지 않는다. 흐름은 한 사람이 전체를 쥐고 써야 산다.

## 6. 수정본 비교 학습 (사용자가 고친 뒤)
사용자가 `대본.txt`를 고치고 "비교해서 배워"라고 하면 `수정학습` 에이전트를 띄운다. 비교 기준은 5단계의 "검수본" 커밋이다.
결과로 바뀐 문서와 줄을 사용자에게 보여준다.

## 지키는 것
- 사용자 선택(3단계 기획, 4단계 개요) 없이 다음 단계로 가지 않는다. 사용자가 "알아서 끝까지"라고 하면 추천안으로 진행하고 마지막에 무엇을 골랐는지 밝힌다.
- 참고 영상의 문장·에피소드 순서를 대본에 쓰지 않는다. 핵심 사실만 가져오고, 사실은 사료로 다시 확인한 것만.
- 외부(클릭업 등) 등록은 사용자가 따로 요청할 때만.
