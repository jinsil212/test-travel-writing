## 나머지 추가 후보의 발전 메모

- **04 아이 돌봄** — 썸네일 `아이가 아프던 밤 / 조선의 육아 기록`. 양아록에 남은 성장·질병·돌봄 [S3]에서 아이의 병→가족의 대응→회복을 바라는 기록으로 잇는다. 개별 회복 사건의 결말은 원전 확인 후 쓴다. 돌·백일 의례 [S4]는 보조 맥락이며 전체가 사망률 때문에 생겼다고 단정하지 않는다. 첫해만 다루려면 그 시기 기록이 충분한지 추가 확인한다. 화면은 양육 일기·돌봄 재현·성장 기록. 감정 연결 우선 후보다.
- **06 전염병 환자** — 썸네일 `도성에 번진 병 / 환자는 어디로?`. 병 발생→수용·구료 기관→치료와 당시 믿음의 공존→대응의 범위 [S2]. 원본의 사망 규모 대신 대응을 보여준다. 05가 일반 환자의 의료 접근이면 06은 전염병 유행 때의 대응이다. 한 구체 유행 사건 확보 후 집필하며 05와 같은 기관 소개만 남으면 합친다. 화면은 도성 지도·수용 공간 재현·구료 기록.
- **07 천연두 예방법** — 썸네일 `천연두를 막는 법 / 어떻게 퍼졌나`. 지석영의 배움→접종 재료의 공급 문제→제조·저장과 교육→지역 보급 [S6]. 발견만으로 곧바로 보급되지 않는 과정을 보여준다. 인두·우두·항생제를 같은 기술로 설명하지 않는다. 전 생애 전기는 제외하고 보급 과정에 집중한다. 화면은 이동 지도·접종 도구·교육과 공급 흐름. 직접 의료 반응과 연결되지만 조선 후기로 시대를 명확히 한다.
- **09 안경** — 썸네일 `조선에도 안경 / 그런데 못 썼다?`는 전면 금지로 오해될 수 있어 최종 가안은 `조선의 안경 / 쓰는데도 예법?`. 눈이 침침한 불편→안경의 존재→착용과 예법→도구가 있어도 사용 조건이 달랐다는 답 [S7]. 최초 전래 연도는 미확정으로 둔다. 사전의 개별 왕실 일화는 원전을 추가 대조한다. 노년 댓글에서 파생했으나 안경 직접 수요는 미확인. 화면은 실물·착용 재현·예법 기록.
- **10 여성 진료** — 썸네일 `아픈 여성들 / 누가 진찰했을까`. 남자 의원에게 진료받기 꺼리는 상황→의녀 설치→교육과 배치→여성의 진료를 담당한 인력과 신분의 제약 [S10]. 모든 여성이 남자의 진료를 법으로 금지당했다고 바꾸지 않는다. 장덕·귀금은 치통 편에 남기고 여기서는 제도 도입·교육에 집중. 화면은 진료 재현·교육 도식·기관 배치.
- **12 출산 뒤 돌봄** — 썸네일 `관비의 출산 / 남편도 쉬게 했다`. 관청에서 일하는 여성의 출산→휴식 조처→남편의 돌봄 필요→대상과 범위의 한계 [S11]. 현대의 모든 근로자 육아휴직과 같다고 하지 않는다. 정확한 일수·시행 변천을 말할 때 실록 해당 날짜 전문을 추가 대조. 화면은 복무 기록·휴식 기간 도식·가족 돌봄 재현. 원본의 출산 사망 설명과 다른 정책 이야기.
- **13 씻기** — 썸네일 `비누 대신 무엇을?`. 세정 재료·물·노동→몸·머리·의복 관리 차이→신분·지역별 제약을 조사한다. ‘조선 사람은 안 씻었다’는 단정을 반전시키는 구상. 조두 관련 2차 기사만 확보했으므로 아직 핵심 확인 목록에는 넣지 않는다.
- **14 겨울** — 썸네일 `온돌은 있는데 / 땔감이 없다면?`. 난방 구조→연료 마련→가구 형편별 대응을 조사한다. 백성의하루 기존 편의 겨울 설명과 중복 비교 필요. ‘항상 땔감이 없었다’는 역사적 결론은 아직 없다.
- **15 물** — 썸네일 `수도 없던 한양 / 물은 누가 날랐나`. 물의 출처→길어오는 사람→보관·관리→생활 비용을 조사한다. 샘·우물·하천을 모두 오염수로 묶지 않는다. 물장수의 시대별 존재와 구체 활동은 추가 확인 대상이다.

## 중복 관리와 제작 순서 제안

기존 3개는 모두 호감이 확인되었지만 먼저 만들 편은 미선정이다. 순서 가안은 **치통 → 가난한 환자 → 노인 대우 → 여름 얼음 → 관리의 퇴직 → 아이 돌봄 → 혼인 지원 → 안경**이다. 같은 의료·노년 주제를 연속으로 소진하지 않으려는 편집 판단이며 업로드 일정이 아니다.

05 의료기관과 06 전염병은 일반 의료 접근과 유행 시 대응을 구분하지 못하면 통합한다. 02 노인 대우와 11 퇴직은 잔치·보상과 직무 종료를 구분한다. 01 치통과 10 의녀는 장덕·귀금을 중복 주인공으로 쓰지 않는다. 04 양육과 12 출산 휴식은 가족의 기록과 국가의 조처를 나눈다. 08의 노동자 시점은 제목 변형이며 별도 검증 주제 수에 포함하지 않는다.

## 진행상태

요청 범위: 추가 주제 수집과 보관. 결과: 기존 3개 유지 + 새 후보 12개(핵심 확인 9개, 탐색 보관 3개), 포장 변형 6개, 추가 답글 원본 저장. 우선순위는 제안이며 사용자의 제작 선택 미확정. 다음에는 선택한 번호의 사건 원문을 보강하고 완성 기획·제목·썸네일·도입으로 진행한다. 외부 등록·자동 대본 작성은 요청받지 않았다.
