# v8 경계 대조 — 작성자 점검

검토자의 역사 지식이나 뒤 문단은 선행 설명으로 인정하지 않는다. 아래는 규칙이 아닌 이번 원고의 대조 기록이다. 사실 확인과 독자 독립 검토를 대신하지 않는다.

| 경계 | 직전까지 들은 상태 | 다음 장면의 주체·시점·목적을 먼저 알려주는 문장 | 판단 |
|---|---|---|---|
| 도입→왕자 시절 | 효종이 불렀고 송시열은 건의 수용을 요구함 | ‘효종이 아직 왕이 되기 전, 왕자였을 때 공부를 가르쳤던 스승이었죠.’ | 왜 이 사람을 믿고 불렀는지의 첫 근거. 과거로 돌아가는 말이 있다 |
| 스승→왕위 뒤 초빙 | 왕자의 공부와 판단을 가르치는 관계 | ‘효종이 왕위에 오른 뒤에는 청나라에 맞설 힘을 기르려는 구상 속에서 송시열을 조정으로 불렀습니다.’ | 신분 변화·주체·부른 목적이 함께 있다 |
| 초빙→공사 대화 | 효종 설득을 받아 나온 상태 | ‘두 사람이 만난 1658년 가을의 기록이 남아 있습니다.’와 뒤의 공주 집 건의 | 만남을 예고한 뒤 대화로 들어감. 이전 건의는 이미 건의했다고 밝혀 둠 |
| 공사→백성 구제 배경 | 효종은 다시 짓지 않겠다고 답함 | ‘이 대화 뒤에도 송시열은’에 이어 ‘다른 신하’와 ‘함께 있던 고위 관리’의 문답 | 송시열의 공사 반대 원문이 구휼 때문이었다고 창작하지 않는다. 대화의 실제 순서를 지키고 구휼의 촉구자와 비축 부족을 말한 사람을 구별한다 |
| 효종→숙종 | 효종은 공주 집 건의에 짓지 않겠다고 답함 | ‘효종 다음에는 아들 현종이, 그다음에는 현종의 아들 숙종이 왕이 되었습니다.’에 이어 ‘숙종도 송시열을 거듭 조정으로 불렀습니다.’ 및 서울 근처에 온 뒤 글·신하를 보내 권한 경위 | 계보와 입성 경위를 별도로 제공. 20여 년을 모두 서술할 필요는 없음 |
| 서울 방문→퇴장 | 숙종의 초빙을 받고 서울에 와서 조언함 | ‘예전에 송시열을 유배 보내자고 주장했던 사람이었거든요.’→접대 난색→숙종 파직→불안→이틀 만 퇴장 | 등장 없이 퇴장하는 문제를 없앰. 과거 당쟁을 새 본론으로 풀지 않고 현재 관계의 이유만 한 문장으로 제공 |
| 퇴장→민정중 변호 | 1682년 10월 송시열은 떠났고 왕의 귀환 명령에도 응하지 않고 수원으로 감 | ‘같은 해 11월’과 민정중이 왕의 속뜻을 의심하는 소문을 전하고 대응함 | 시점·계기·소문 전달자 분리. 귀환 명령과 실제 불응을 함께 설명 |
| 재초빙 요청→옹호 금지 | 숙종이 다시 부르자는 요청을 옳게 여김 | ‘그런데 7년 뒤, 같은 숙종이’ | 동일 왕의 다른 반응을 비교. 방금 장면의 연속으로 오해시키지 않음 |
| 옹호 금지 예고→왕자 출생 | 7년 뒤 왕의 반응을 미리 알려줌 | ‘그 전해, 숙종은 후궁에게서 아들을 얻었습니다.’ | 잠깐 앞선 배경으로 되감는 표지가 있다 |
| 왕자→원자 호칭 논의 | 후궁에게 아들이 생겼고 왕비에게는 아들이 없음 | 왕의 맏아들 뜻→원자 호칭→아직 세자 책봉 아님 | 정체를 설명하고 용어를 부름. 태어나지 않은 왕비 아들은 가정으로 분리 |
| 회의→송시열 글 | 반대와 왕의 거부를 거쳐 호칭 결정이 끝남 | ‘숙종은 결국…그 결정을 알렸습니다. 그 뒤 송시열이 글을 올립니다.’ | 사전 논쟁과 결정 뒤 상소를 구별 |
| 송시열 처벌→옹호 신하 | 글 수납 금지와 변호자 처벌 경고 | ‘왕의 명령을 전달하는 일을 맡은 신하’ 및 ‘민정중과는 다른 사람’ | 앞 조연과 합쳐 읽히지 않도록 구별. 처벌 대상은 용서를 청한 신하로 다시 명시 |
| 삭출→제주 유배 | 송시열의 벼슬 박탈과 옹호자 조사 명령 | ‘송시열의 처벌은 벼슬을 빼앗는 데서 끝나지 않았습니다. 그 명령이 내려진 지 사흘 뒤, 관리들이 더 무거운 벌을 내려 달라고 청했습니다.’ 및 숙종의 제주 안치 명령 | 뒤 결말의 설명을 기다리지 않고 격화의 시간·청원자·왕명을 앞에서 알 수 있음 |
| 제주 유배→압송 | 제주로 보내 가시울타리를 두르고 가두라는 왕명 | ‘그해 4월에는 송시열을 반대하는 관리들이 그를 잡아다 조사하라고 요구했습니다.’ 및 선왕 관련 글 문제 제기·왕의 수용 | 실제 출발일을 4월로 못박지 않는다. 예송 등 별도 혐의의 역사를 강의하지 않고 조사 요구가 나왔음을 설명 |
| 압송→사약 | 왕이 조사 요구를 받아들여 서울로 끌려오는 중 | ‘송시열이 서울에 도착하기 전’→고위 관리들의 조사 없는 처분 주장→왕의 사약 명령→정읍 집행 | 조사 결과 처형이 아니라 조사 전에 처형한 경위가 분명함 |
| 사망→복관 | 1689년 왕명으로 사약을 받음 | ‘5년 뒤’ 및 지지 측이 다시 주도하게 된 변화 | 왕의 후회만 단일 원인으로 만들지 않음 |
| 복관→책임 요구 | 왕이 빼앗은 벼슬을 되돌리고 제사를 명함 | ‘명예를 되돌려 주라는 왕명이 나온 지 나흘 뒤, 다른 관리들이’ | 시점·새 행위자·새 요구 분명. 죽음 경과의 재설명 대신 책임으로 진행 |

## 판정 질문과 직접 근거

- 늘 왕 곁에 있었기 때문인가 → 아니다 → 물러나거나 불러도 나가지 않은 때가 있음. 오래 재직한 직위 문제와 다른 명제를 섞지 않음.
- 후궁 아들이라 왕이 될 수 없었나 → 아니다 → 왕비의 미래 아들이 생겼을 경우 순서를 걱정한 당시 반대 신하들의 논거.
- 지지가 목숨을 지켜주었나 → 그러지 못함 → 처분 격화와 사약. 사망 결과만 말하지 않고 경위를 앞에서 설명했다.

## 중복 대조

| 기존 반복 | 조치 | 남는 기능 |
|---|---|---|
| 건의를 꺼냈다→인사만 받고 넘어가지 않았다 | 뒤의 재설명 삭제 | 곧바로 공주 집이라는 구체 안건 |
| 훅의 출사·퇴장·불응→본문의 같은 나열 | 본문 나열을 줄임 | 왕자 시절 스승과 효종의 초빙 목적이라는 새 근거 |
| 거듭 부르는 왕→함께 일할 관리도 부르라고 함 | 실제 민정중 요청 뒤 한 문장으로 이동 | 개인 신임을 넘어 관리의 행동까지 확인한 자리 |
| 경고에도 용서 요청→왕이 방금 경고했는데도 | 후자 삭제 | 곧바로 숙종의 답 |
| 왕의 후계 지정 기대와 신하의 대기 주장→후반 재요약 | 후반 요약 삭제 | 용서를 청한 신하에 대한 조사 명령으로 진행 |
| 결말에서 유배·압송·죽음 경과를 처음 상세 설명 | 앞에 경과 배치, 끝에서는 책임 범위만 설명 | 이미 안 처분에 대해 누가 책임져야 하는지 새 요구 |
