## 안 A — 추천: “정말 안 씻었나” 통념 검증
1. 제목: 조선 사람들은 정말 안 씻었을까? 매일 한 일과 끝내 못 한 일
2. 썸네일: 「매일 씻었는데 더러웠다?」 / 「조선 사람이 온몸만 못 씻은 이유」
3. 관심: ‘조선은 더러웠다’ 영상이 조회수를 모으고, 댓글은 “정말 그랬나”를 따지거나 자기 경험을 꺼낸다(추론).
4. 벤치마크: 005 주막(통념 → 실제 작동 → 사람의 삶), 조회수÷구독자 129.2배
5. 재료: 매일 세수 예절(백과), 조두·쌀뜨물·분세수, 여름 냇가·겨울 부엌·양반 목간통, 맨몸 기피 → 1920년대 공중목욕탕 거부, 왕의 온천 치료
6. 예상 등급: 중상. 수요 근거가 있고 경쟁작과 반대 방향. 포화 주제, 인물 장면 약함

흐름: ①매일 아침 세수 → 왜 더러웠다고들 하나 → 얼굴과 온몸을 나눠 봐야 함 ②조두·쌀뜨물 → 재료는 있었는데 왜 몸은 못 씻었나 ③냇가·부엌·목간통 → 신분 차이는 더운물을 누가 나르느냐 ④맨몸 규범 → 1920년대 목욕탕 거부 ⑤왕의 온천도 치료였음 → **끝:** 얼굴은 예의로 매일, 온몸은 물·땔감·노출 규범 때문에 드물게. ‘1년 두 번’ 같은 빈도는 근거 없음

## 안 B — 탐색: “비누라는 말은 이미 있었다”
1. 제목: 비누가 없던 조선? 350년 전 이미 ‘비노’가 있었습니다
2. 썸네일: 「비누 없었다고요?」 / 「조선 사람들이 쓴 ‘비노’의 정체」
3. 관심: 경쟁작이 ‘비누도 없었다’를 전제로 씀. 재료 중심 제목의 영상은 조회 192~476회 → 관심 근거 약함
4. 벤치마크: 005(물건의 정체 풀기)
5. 재료: 박통사언해 ‘비노’(원문·어원 미확정), 조두, 창포, 잿물, 석감 명칭, 양비누
6. 예상 등급: 중하. 핵심인 ‘비노의 정체’가 미확정

흐름: ‘비노’ 기록 → 곡물 가루 → 머리는 창포, 옷은 잿물 → 양비누가 이름을 가져감 → **끝:** ‘비누’는 물건이 바뀌며 뜻이 바뀐 말

## 안 C — 탐색: “비누 없이 흰옷은 어떻게 하얬나”
1. 제목: 비누도 없던 조선, 흰옷은 왜 그렇게 하얬을까
2. 썸네일: 「눈이 부시게 하얗다」 / 「조선 여인들이 흰옷에 들인 시간」
3. 관심: 방송 클립 조회가 높지만 조건이 다름. 같은 규모 채널은 2,534회. 댓글 근거 미수집
4. 벤치마크: 005
5. 재료: 솔기 뜯어 빨기, 콩깍지 재 잿물(지역차), 삶기, 다듬이, 비숍의 관찰
6. 예상 등급: 중. 외국인 관찰자 장면 있음. 노동 주체·빈도 자료 부족

흐름: 비숍이 본 흰옷 → 뜯기·잿물·삶기·다듬이 → 누가 했나 → **끝:** 흰옷의 흰색은 세제가 아니라 노동으로 만든 것
