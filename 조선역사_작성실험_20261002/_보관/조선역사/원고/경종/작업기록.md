## 이전 검토본 — 2026-09-14 / 6단계 흐름 승인 후

- 중심 질문: 영조는 왜 형을 독살했다는 의심을 받았고, 기록은 그 의심을 얼마나 뒷받침하는가. 인삼은 의혹을 검토하는 구체적 치료 사건으로 다룬다.
- 승인 순서: 병상의 충돌과 독살 의혹 → 이인좌 등의 왕 교체 시도 → 사망 이틀 전부터 쓰인 인삼 → 추가 투약 경고와 영조의 반발 → 일시 변화·재악화·죽음 → 의혹의 존재와 입증 여부를 구분하는 결론.
- 반란은 누가 어떤 주장을 내세워 무엇을 하려 했는지만 설명했다. 전투·당파 계보·게장·신치운·이천해·후대 의관 처벌은 넣지 않았다. 반란에서 제기한 독살설의 기원이 인삼차 논쟁이었다고 단정하지 않는다.
- 기존 확정 제목: 경종의 마지막 밤, 의관이 말린 인삼을 동생은 왜 고집했나. 기존 썸네일: 의관이 말려도 인삼을 고집한 동생 / 그가 다음 왕, 영조였다.
- 최신 제안 제목: 형을 독살했다는 의심을 받은 영조, 경종의 마지막 밤 무슨 일이 있었나. 최신 제안 썸네일: 형을 독살했다는 의혹 / 왕이 된 동생, 영조. 새 앵글·흐름 승인은 확인됐지만 이 문구 자체를 별도로 최종 선정한 것으로 기록하지 않는다.
- 클릭 정합: 클릭 이유는 영조의 형 독살 의혹 / 제목의 핵심 질문은 마지막 밤에 실제로 한 일 / 썸네일은 형을 잃은 동생의 왕위 계승으로 의혹의 무게를 드러냄 / 첫 문장은 의관의 반대와 영조의 반발이라는 확인 가능한 행동으로 받음.

## 집필·수정 근거

벤치마크: 정순왕후 원문 전체를 이번 편 준비 과정에서 정독했다. 선택·반응 뒤에 필요한 설명을 붙이는 점을 채택했다. 혼례 질문을 지급하지 못하는 점, 침묵한 사료를 과도한 추론으로 메우는 점은 가져오지 않았다. 송시열 승인 원고의 존댓말·관계 설명을 기준으로 삼되 권력이 누적되는 인물 일대기 구조는 반복하지 않았다.

파트별 초고를 작성한 뒤 조립했다. 첫 수정은 클릭 범위와 설명 배치, 두 번째 수정은 조립본 전체를 낭독하듯 읽으며 중복·관계·인용·경계를 확인했다. 실제 음성 낭독을 실행했다는 뜻은 아니다.

| 내부 수정 전 | 수정 후 |
|---|---|
| 전날 인삼 사용을 설명한 뒤, 같은 의미를 별도 해설 문단으로 반복 | 해설 문단 삭제. 전날 투약과 당일 처방 충돌을 바로 연결 |
| 기운을 회복시키려 했다는 이유를 세 차례 풀이 | 중복 풀이 삭제, 동생이 내세운 주장이라는 한계만 짧게 유지 |
| 신치운의 '먹지 않았으니'를 '먹지 않았습니다'로 끝맺은 직접 인용 초고 | 정확한 원문 대조 후 간접화법으로 전환 |
| 종묘·사직 이름만 사용 | 왕실의 조상과 나라의 신들에게 회복을 비는 의식으로 풀어 설명 |
| 이공윤 처벌 날짜를 거듭 강조 | 같은 병상이 치료 논쟁에서 반역 처벌로 바뀐 점으로 설명 진전 |
| 후계자 확정과 실제 권한 위임의 차이를 서술로만 전달 | 왜 후계자를 정하고도 싸웠는지 묻고 즉시 이유를 답함 |

## 계측과 남은 한계

- bench-metrics.py: 문장 사이 공백을 제외한 문장자수 6,222자, 186문장. 전체 문자열 자수와 다른 정의다.
- 훅 331자/10문장, 본편 5,453자/165문장, 클로징 438자/11문장.
- 평균 길이 훅 33.1자, 본편 33.0자. 60자 이상 문장 1%.
- 질문 10개(5%), 감정 표지 후보 2개. 질문은 각기 다른 확인점에 답하며, 같은 의혹을 미지급 상태로 재질문하지 않도록 점검.
- 동일 도구로 견본 전체를 다시 계측: 질문 55개(7%), 만자당 27.1회. 이번 편은 16.1회로 더 적다. 숫자 맞추기를 위해 동일 질문을 추가하지 않았다.
- 견본 도입부는 도구상 33문장/849자. 자동 문장 분리법 차이 때문에 수작업 36문장 및 원시 문자열 길이와 다르다.
- 견본 재계측의 클로징 표지는 '마지막으로 하나만 더 말씀드리고 마치겠습니다.'로, 끝 무덤 이야기와 CTA만 잡은 좁은 구간이다. 분석지의 넓은 클로징 구간과 직접 비교하지 않는다.
- 15분 가정 시 415자/분. 견본 속도 및 채널 참고치 400~440자/분 적용 시 약 14.1~15.6분. 실제 TTS 시간 미측정.
- 인물은 당시 역할을 붙였다: 경종(왕), 동생 영조(후계자), 이공윤(처방 의관), 이광좌(진료 참여 대신), 이천해(군사), 이인좌(반란), 신치운(조사받는 인물).
- 마지막 치료의 사인은 확정하지 않는다. 부자 사용을 요청한 말과 실제 투약이 명시된 인삼차를 구분했다. 일시 호전을 인삼의 효과 입증으로 쓰지 않았다.
- 이천해 진술 중 기록하지 못하게 한 내용을 창작하지 않았다. 영조의 해명과 의관 처벌 명령도 왕 자신의 판단으로 귀속했다.
- 클릭 약속과 연결되지 않는 지식 설명은 넣지 않았다. 단, 후반의 사료 해석 설명은 이 편의 추리 성격상 필요해 유지했다. 흡입력이나 성과가 검수 수치로 보장되지는 않는다.
