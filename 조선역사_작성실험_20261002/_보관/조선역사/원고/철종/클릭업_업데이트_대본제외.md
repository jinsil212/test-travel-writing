# 철종 v2 수정·검토 결과 — 전체 대본 제외

## 현재 결과
- 기존 v1 원본 보존, 별도 v2 수정안 작성.
- 원본 160문장 전부 1:1 대조: 유지 34문장, 수정 71문장, 삭제 55문장. 새 문장 31개 추가.
- 기획 1안과 확정 썸네일, 도입 첫 문장·마지막 문장 유지.
- 썸네일: 왕실의 후계가 끊기자 / 강화도 청년이 왕이 됐다
- 제목 가안: 삼대가 죽은 뒤 왕이 된 남자, 철종
- 사용자의 이번 요청에 따라 전체 낭독 대본은 등록하지 않음. 전체 대본을 포함하는 160문장 전체 대조표도 첨부하지 않고, 아래 주요 수정 사례만 수록.

## 주요 변경
정치적 선택을 반복해서 설명하던 부분을 한 구간으로 모았다. 덕완군 칭호를 받은 시점을 바로잡았으며, 결말은 1851년 혼인으로 넘어가지 않고 즉위 당일 첫 교재를 정하는 장면에서 끝낸다.

## 중요한 수정·유지 대조
| 기존 실제 구절 | 수정 결과 | 이유 |
|---|---|---|
| 새 왕을 돕는다는 명분으로 정치의 중심에 설 수 있는 것입니다. | 삭제하고 ‘경험과 지지 세력이 부족한 철종을 세운 것이 순원왕후와 안동 김씨의 권력 유지에 유리했다고 봅니다.’에 통합 | 순원왕후의 정치적 이익을 여러 문단에서 반복하던 문제 수정. |
| 철종은 궁궐에 들어오며 덕완군이라는 칭호를 받았습니다. | 궁궐에 들어오기 전날인 음력 6월 8일로 정정 | 칭호 명령과 입궁·즉위 시점을 구별. |
| 이제부터 무엇을 배우고 어떻게 처신해야 할지 일러 준 것입니다. | 이어 대신들에게는, 훗날 왕의 행동이 이 당부에서 벗어나면 오늘 자신이 한 말을 들어 바로잡으라고 했습니다. | 앞말을 요약하는 대신 왕후가 대신들에게 내린 실제 지시 추가. |
| 2년 뒤에는 안동 김씨 집안의 딸을 왕비로 맞았습니다. | 해당 혼인 문단 삭제 | 1851년으로 갔다가 즉위일로 돌아오던 결말의 시간 왕복 제거. |
| 자기 힘으로 나라를 이끄는 일은 이제 시작이었습니다. | 반복 결말을 삭제하고 사략을 첫 교재로 정하는 장면에서 종료 | ‘왕이 된 뒤 배워야 했다’는 말을 결말에서 거듭하지 않도록 수정. |
| 당시 조선의 왕은 순원왕후의 남편인 순조였습니다. | 그대로 유지 | 이미 소개한 순원왕후와 연결해 순조가 갑자기 등장하지 않게 함. |

## 추가 보완
- ‘큰형의 역모 사건’을 ‘큰형을 왕으로 세우려던 역모 사건’으로 바꿔 큰형의 직접 가담을 단정하지 않음.
- 은언군 자손을 보호한 순조의 조치와 가족 형성 과정을 보완.
- 즉위 전날 은언군 부부의 왕족 지위를 회복시키라는 명령을 추가해 처벌된 집안이 왕실로 돌아오는 절차를 설명.
- 형의 어머니 신분에 관한 족보 기록이 일치하지 않는다는 연구상의 한계를 명시.
- 독서 권유 → 철종의 실제 답변 → 교재 선택으로 문답 전개를 복원.
- 재상은 ‘높은 관리’로 먼저 설명하고, 유배 기간의 ‘5년째’를 ‘5년쯤 이어진’으로 정정.

## 분량과 실제 검토
- 최종 낭독 본문 공백 제외 4,290자(문장부호 포함).
- 분당 300자 가정 약 14분 18초.
- 기존 분당 315자 가정 약 13분 37초.
- 빠른 분당 400자 가정 약 10분 43초.
- 15분 목표의 추정치이며 실제 음성은 생성·측정하지 않음.
- 마지막 수정본 저장 후 전문 재열람.
- 원본 160문장의 대조 누락·중복 없음, 원문 텍스트 불일치 0.
- 대조표의 수정 문장을 이어 붙인 결과와 저장된 v2 본문이 일치함을 확인.
- 자체 검토 결과이며 사용자 최종 합격·실제 시청 유지율 검증으로 기록하지 않음.

## 적용한 지침의 핵심
- H4-2·S8: 새 인물과 용어의 관계·뜻을 필요한 자리에서 설명.
- S3·G6: 정치적 이익, 양자 관계, 반복 마무리를 원고 전체에서 대조하고 수정.
- S9·S10: 사실 시점과 연구 해석의 범위, 시간 이동을 구분.
- B1·B9·G3: 벤치마크의 실제 문답 전개를 참고해 행동·반응·다음 행동을 연결.
- G5-2: 마지막 저장본을 다시 열어 전체를 읽고, 실제 수정·유지 근거를 기록.
