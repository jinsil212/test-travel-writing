# 정조 · 혼인 지원 — 확정안: 포장 + 도입부 + 큰 흐름 (승인 전)

- 2026-09-17. 사장님 지시: "3안 말고 가장 좋은 거로 딱", 추천 제목·썸네일, 도입부, 이어지는 핵심 흐름. 곁가지·튀는 내용 금지, 기획 방향 충실.
- 기획 방향(고정): 김희집·신씨 사례로 **혼인을 막은 형편**과 **나라의 지원**을 설명한다.
- 선택: 2안(끝까지 남은 두 사람). 제목에 '가난'을 넣어 '형편' 축을 드러냄.
- 뺀 곁가지(B7-1): 이승훈의 천주교 이력, 희곡 동상기, 성종·중종 사례(2차·미대조), 채제공의 광주 남매 보고, 이덕무의 '비가 내렸다', 경국대전 조문(미대조).
- 조연 실명(S1-8): 김희집·신씨·정조만 유지. 구익·이승훈·조정진·이병모·신덕빈은 역할로 부른다(서울 책임자 / 서쪽 구역 담당 관리 / 호조판서 / 쌀 관청 책임자 / 신부 아버지).

## 포장

- 제목: 가난에 파혼까지 당한 노총각과 노처녀, 정조는 왜 혼주를 직접 세워 줬나
- 썸네일: 가난에 파혼까지 / 왕이 혼주를 대신 세웠다
- 이전 사장님 확정안(참고): 파혼당한 노총각과 노처녀, 정조는 왜 두 사람의 혼주를 직접 정했나 / 파혼 당한 조선시대 남녀 · 왕이 대신 혼주를 세웠다

대조표 네 줄(P16)
- 클릭 이유: 가난에 파혼까지 당한 두 사람을, 왕은 왜 부모 자리까지 채워 결혼시켰나
- 제목 질문: 두 사람의 처지(가난·파혼) + 왕이 혼주를 세운 이유
- 썸네일: 1줄이 처지를, 2줄이 왕의 개입을 말해 둘의 거리로 '왜'를 키움
- 첫 문장: 가난한 집 신랑이 나라가 내린 말에 오르는 장면 → 혼주 → 파혼 → 질문

## 도입부 v3 · 흐름 v2 (사장님 지적: 마지막 문장이 이미 도입부에서 답한 '왜 남았나'를 다시 묻는다. 핵심은 가난한 집·파혼인데도 왕이 도와 결혼했다는 놀라움)

진단: 도입부가 파혼 사유를 이미 줬는데 끝 문장이 "어쩌다 끝까지 못 하고 남았는지"를 다시 물음 → 기다리는 답이 같은 질문 반복(S3-5). 흐름 1·3번도 파혼 사유를 다시 설명하는 구조였음.
처리: 끝 질문을 도입부가 아직 답하지 않은 것 — 가난한 백성의 파혼을 왕이 어떻게 알았고 왜 여기까지 도왔나 — 로 바꿈. 흐름은 파혼 사유 재설명을 없애고, 나라가 찾아 나섬 → 돈을 줬는데도 둘만 남음 → 짝을 찾아 준 관리들 → 두 집의 대답 → 왕이 혼주를 세운 이유와 혼례 순으로 새 정보만 쌓음.

도입부 v3

1791년, 정조 때 서울에 각자 약혼했다가 둘 다 파혼당한 남자와 여자가 있었습니다. 남자는 상대 집안이 집안 격이 맞지 않는다며 딸을 주지 않겠다고 했고, 여자는 약혼한 상대가 다른 사람과 결혼해 버렸습니다. 두 집 다 몹시 가난했습니다.

그런데 얼마 뒤, 이 두 사람이 서로 결혼합니다. 그것도 왕이 챙겨 준 결혼식이었습니다. 결혼식에서 부모 자리를 맡는 사람, 혼주를 왕이 나라의 높은 대신 두 사람으로 직접 세웠습니다. 한 대신에게는 신랑을 아들처럼, 다른 대신에게는 신부를 딸처럼 여기라고 했죠. 신랑이 탈 말과 잔칫상까지 왕이 내렸습니다.

가난한 집에 파혼까지 당한 두 사람을, 왕은 어떻게 알게 됐고 왜 이렇게까지 도왔을까요? 시작은 그해 봄, 정조가 서울에서 가난 때문에 결혼하지 못한 사람을 빠짐없이 찾아내라고 내린 명령이었습니다.

흐름 v2: 대화창 제시본과 같음(5덩어리).

## (이전) 도입부 v2 (사장님 지적: 너무 길고 어렵다, 제목·썸네일 내용이 바로 보여야 한다)

1791년, 정조 때 서울에 각자 약혼했다가 둘 다 파혼당한 남자와 여자가 있었습니다.

남자는 상대 집안이 집안 격이 맞지 않는다며 딸을 주지 않겠다고 했고, 여자는 약혼한 상대가 다른 사람과 결혼해 버렸습니다. 두 집 다 몹시 가난했습니다.

얼마 뒤, 이 두 사람이 서로 결혼합니다.

그런데 결혼식에서 부모 자리를 맡는 사람, 혼주가 집안 어른이 아니었습니다. 왕이 나라의 높은 대신 두 사람을 직접 골라 세웠습니다. 한 대신에게는 신랑을 아들처럼, 다른 대신에게는 신부를 딸처럼 여기라고 했죠. 신랑이 탈 말과 잔칫상까지 왕이 내렸습니다.

가난한 백성 둘의 결혼에, 정조는 왜 부모 노릇까지 해 줬을까요? 답은 두 사람이 어쩌다 끝까지 결혼을 못 하고 남았는지에서 시작합니다.

v1 → v2 고친 것 (같은 원인을 전체에서 찾음, G6)
- 제목·썸네일 내용(파혼 / 왕이 혼주)이 뒤에 나오던 순서 → 첫 문장이 파혼, 넷째 문단이 혼주
- 혼례 행렬 묘사(말·관복·초롱·호위), 가난한 집 묘사(사립문·부엌 연기) 삭제 → 본문 5·6으로 옮김
- 어려운 직함(호조판서, 쌀 거둬들이는 관청 책임자), 혼인 편지 대작 삭제 → "나라의 높은 대신 두 사람"
- '혼주'는 쉬운 말 먼저: "결혼식에서 부모 자리를 맡는 사람, 혼주"
- 약 720자 → 약 330자
- 흐름 연동: 5번 "도입부에서 본 그 집" → 그 집 모습을 5번에서 처음 보여줌 / 6번 "도입부 행렬로 돌아감" → 혼례 행렬을 6번에서 처음 보여줌
