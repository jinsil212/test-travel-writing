## 썸네일 문구 후보 비교
모두 백성의 하루라는 동일 주제 안에서 강조점만 달리했다. ‘충격적 실체’, ‘모두 거짓말’은 본문에 없는 폭로를 약속하므로 차용하지 않았다.
| 문구 ( / 는 줄바꿈) | 강조점 | 판단 |
|---|---|---|
| 조선 백성의 하루 / 무엇을 먹고 어떻게 살았을까? | 생활 전체에 대한 호기심 | 추천 사용안 |
| 조선 농촌의 하루 / 아침밥부터 잠자리까지 | 시작과 끝 | 대체 후보 |
| 조선 백성의 하루 / 부엌과 논에서 벌어진 일 | 공간 | 대체 후보 |
| 조선 농민의 하루 / 밥 먹고 쉬는 시간은 언제였을까? | 휴식 | 하루 범위 안에서 사용 가능 |
| 조선 농촌의 하루 / 들에 나간 사람, 집에 남은 사람 | 사람의 역할 | 하루 범위 안에서 사용 가능 |
| 조선 백성은 하루를 / 어떻게 보냈을까? | 직접 질문 | 의미 명확하나 제목 반복 큼 |
| 조선 농촌의 여름날 / 이웃과 함께 일하던 하루 | 공동 노동 | 하루 범위 안에서 사용 가능 |
| 조선 백성의 하루 / 들일이 끝나면 무엇을 했을까? | 귀가 이후 | 하루 범위 안에서 사용 가능 |

| 조선 백성의 하루 / 점심은 누가 들로 가져왔을까? | 식사 준비와 운반 | 하루 범위 안에서 사용 가능 |

## 실제 문장 대조와 유지 이유
- 제목 ‘아침밥부터 잠자리까지’ → 도입 ‘아침에 눈을 떠 밤에 잠들 때까지’ → 마지막 ‘이제 눈을 감습니다’. 하루 전체를 따른다는 동일한 약속이다.
- 썸네일 ‘무엇을 먹고 어떻게 살았을까?’ → 본문 ‘보리밥과 찬국, 상추쌈’, ‘여러 사람이 한 논에 들어가’, ‘실을 쥐던 손으로 아이를 안고’. 식사와 노동·돌봄으로 답한다. 숨겨진 음모나 특별한 사건을 약속하지 않는다.
- 주막 썸네일에서 상단 두 줄·큰 대비 글자·사람과 식사 공간이 함께 보이는 구도를 참고했다. 그림체는 공용 T20의 실사 기본값으로 설계했다. 이미지는 미생성으로 축소 가독성은 미검증이다.
- 이전 ‘## 한낮 — 밥이 도착하는 자리’ 삭제. ‘이제 부엌에서 마련한 음식이 들로 나올 차례입니다’ 다음 ‘점심을 맡은 사람은…’으로 이어져 표제 없이도 전환된다.
- 이전 ‘## 오후 — 돌아온 집에서 이어지는 손일’ 삭제. ‘대문 안에 들어서면…’ 다음 ‘먼저 들에서 가져온 그릇을 내려놓습니다’의 행동 연결 유지.
- 승인 도입 ‘같은 자리에 앉아 있어도, 저마다 하는 일은 달랐던 거죠’ 유지. 낭독 내용에 새로운 수정 없이 표제·소제목만 삭제했다.
- 최종 업로드패키지 저장 후 제목부터 마지막 낭독문까지 전문 재열람. 설명글·태그·출처는 낭독 영역 밖에 있고 낭독문 중간 소제목은 없다. 실제 음성·이미지 생성·성과 검증은 하지 않았다.
