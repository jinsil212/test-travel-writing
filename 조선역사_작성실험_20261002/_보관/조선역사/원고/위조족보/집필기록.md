# 위조 족보 — 집필 기록 (2026-09-18)

- 사용자 발언: “이어서대본 써봐, 흐름 잘맞게해서 15분 분량” → 사용자 작성 도입(`도입부_확정후보.txt`)을 확정본으로 보고 본문 집필. 미드폼 공용 절차(0-2: 아웃라인 → 파트별 집필 → 조립 → 검수)에 따름. 별도 흐름 승인 단계는 미드폼 지침에 없고, 사용자가 대본 작성을 바로 요청함.
- 목표: 15분. 분당 380~400자(공백 제외) 가정 → 약 5,700~6,000자. 10분 하한(B6) 필수.
- 핵심 질문: 남의 조상이 적힌 족보를 관아는 왜 알아보지 못했나. 줄 답: 종이는 대부분 진짜였고(진짜 족보·진짜 임명장·같은 모양 활자), 관아는 문서만 보고 판단했으며, 거짓을 가려낼 옛 호적 대조는 어려웠다. 사고파는 사람과 위조를 권하는 양반까지 있었다.

제외: 족보 기원·성화보, 대구 호적 70%, 심상운 환부역조, 100냥의 현재 가치 환산(근거 없음). ※ 1868 종친 과거는 처음 제외했으나, 집필 중 ‘족보를 진짜 명단과 대조하면 가짜가 드러난다’는 답의 근거로 필요해 5파트에 넣음(1864와 다른 역할). 균역법(1750, 두 필→한 필, 양반 행세로 빠진 집에도 따로 거둠)도 ‘나라는 알고 있었다’의 근거로 4파트에 넣음.

분량 설계(B8): 도입 약 300 + 1구간 1,100 + 2구간 800 + 3구간 1,600 + 4구간 1,100 + 5구간 1,000 ≈ 5,900자.
