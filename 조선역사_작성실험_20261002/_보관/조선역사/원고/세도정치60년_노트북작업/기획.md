### 0-1. 진행 모드 판정

사용자가 "오토"라고 지시하지 않았다. 그러나 **기획 방향·제목 방향·감정선·길이를 이미 지정한 뒤 "대본 작성"을 요청**했으므로, 0-4의 "이미 사용자가 확정한 선택은 유지한다"에 따라 기획 3안 선택 단계를 다시 열지 않는다. 남은 선택 단계(제목 문구 확정·썸네일 확정·도입 후보 선택)는 대본 산출에 필요한 범위에서 **작업자가 선정하고 대체 후보를 함께 제출**한다. 이를 사용자 위임이나 합격으로 기록하지 않는다.

## 1. 대조표 네 줄 (P16)

```
클릭 이유 (제목을 본 사람이 궁금한 것)
  : "조선이 망한 게 1910년인데, 그 전에 이미 죽어 있었다고? 그 60년 동안 대체 뭐가 어떻게 썩었는지 순서대로 보고 싶다."

  ├ 제목이 던진 질문
  :   "나라가 썩어간 과정이 정확히 무엇인가" — 결과(이미 죽어 있었다)는 주고, 과정은 감춘다

  ├ 썸네일이 그걸 어떻게 키우나
  :   제목이 말하지 않은 '누가'와 '무엇으로'를 한 겹 더 얹는다.
      → 확정 문구 "왕은 셋 바뀌었다 / 주인은 한 집안 그대로" — 제목의 '과정'에 '바뀌지 않은 것'을 더해 확장한다

  └ 도입부 첫 문장이 그걸 어떻게 받나
  :   "조선에서 군포를 가장 성실하게 낸 사람은, 이미 죽은 사람이었습니다."
      → '썩었다'는 추상어를 첫 문장에서 구체 장면 하나로 바꿔 받는다. 같은 질문(어쩌다 이 지경이 됐나)을 연다
```

판정 근거: 셋 모두 **"어쩌다 이 지경이 됐나"** 하나로 모인다. 제목이 '과정'을 팔았으므로(T11) 본문은 **단계를 순서대로 지급**해야 한다 → 5장 구성표에서 6단계로 지급한다.

### 1-1. 제목 — 사용자 제시안의 사실 문제와 보완 (P11 2026-09-17 보완 / T7 게이트 1)

| | |
|---|---|
| 사용자 제시안 | `"조선은 망하기 60년 전에 이미 죽어 있었다"..왕이 3명 바뀌는 동안 나라가 썩어간 과정 ㄷㄷ` |
| 사실 대조 | 조선이 망한 해는 1910년이다. 그 60년 전은 1850년으로, 이번 편이 다루는 60년(1800~1863)과 맞지 않는다. 세도정치 60년의 끝(1863)은 **망하기 47년 전**이고, 시작(1800)은 **110년 전**이다 |
| 전달하려던 것 | ① "망한 건 1910년이지만 그보다 훨씬 전에 끝나 있었다"는 낙차 ② "60년"이라는 긴 시간 ③ "왕이 3명 바뀌는 동안"이라는 무력감 |
| ⭐ 확정안 | `"조선은 망하기 전에 이미 죽어 있었다"..왕이 3번 바뀐 60년 동안 나라가 썩어간 과정 ㄷㄷ` |
| 무엇을 고쳤나 | **"60년"을 '망하기 전'이 아니라 '왕이 3번 바뀐 기간'에 옮겨 붙였다.** 낙차·60년·왕 3명이 모두 살아 있고, 틀린 연산만 사라진다. 동사("죽어 있었다")와 명사("과정")는 그대로 둔다(T12) |

## 9. 팩트 주의사항 (P17-11)

1. "안동 김씨 60년"이라고 말하지 않는다. 경주 김씨 3년 → 안동 김씨 → 풍양 조씨 → 안동 김씨다.
2. 관직 값은 **기관 개설서의 서술**이다. "실록에 적힌 가격표"라고 하지 않는다.
3. 「애절양」의 내용은 **정약용이 남긴 기록**이라는 범위로 말한다. 본문에서 신체 훼손의 방법·과정을 묘사하지 않는다(B18).
