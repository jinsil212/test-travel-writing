원본 조선역사, 원본 공용 지침, 다른 채널은 변경하지 않는다. 테스트 폴더에서 수정한 내용을 운영 원본으로 자동 반영하지 않는다.

## 이번 실험에서 바꾸는 방식

기존 조건과 실제 견본은 유지한다. 집필 단계에서 필요한 원문 구간과 대응 사례를 가까이 두고, 하나의 작성자가 파트를 순서대로 쓴다. 파트 경계의 실제 문단과 이미 준 답을 이어받는다. 검수자는 작성자의 해설 없이 낭독문을 읽고, 지적에는 문제 구절과 연결이 끊기는 이유를 적는다.

검수자를 먼저 과거 사례로 시험했다. 문장 단독 시험에서 사용자의 선택을 모두 재현하지 못했다. 문맥을 보충하자 판단이 바뀐 사례가 있어, 문맥을 전달하는 방식으로 수정했다. 소수 사례에 대한 일치가 새 원고의 품질 보증은 아니다.

## 비교 조건

편: 위조족보. 기존 기획 방향·확정 제목·2줄 썸네일·사용자 작성 도입의 흐름을 유지한다. 도입의 가족관계·군역 대상·세금 표현 세 구절을 수정해 전후를 남겼다. 목표는 기존 요청과 같은 15분 내외. 현재 제출본은 공백 제외 5,043자이며 분당360~400자 가정 약12.6~14.0분이다. 음성은 미제작해 15분 실측 달성으로 기록하지 않는다.

비교 대상은 `조선역사/원고/위조족보/대본_v1.txt`다. 사용자 합격본이 아니라 기존 AI 초고다. 새 본문을 만들 때 이 초고 전문을 문장 견본으로 사용하지 않고, 완성 후 비교 자료로 사용한다. 기존 `집필기록.md`의 구조와 사용자의 확정 선택은 확인했다.

전체 합격 원고의 재현 시험, 같은 조건의 무작위 A/B 시험, 학습에 쓰지 않은 여러 소재의 성능 검증은 아직 수행한 것이 아니다. 이번 결과로 대본 작성 문제를 해결했다고 단정하지 않는다.

사용자가 새 시험본을 검토하면 기존 원고 대비 크게 고쳐야 하는 구간과 실제 수정 시간을 기록한다. 검토 전에 수정 부담이 줄었다고 보고하지 않는다.
