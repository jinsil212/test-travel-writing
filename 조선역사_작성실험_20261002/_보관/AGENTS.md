# 조선역사 작성 실험의 작업 범위

2026-10-02 사용자 요청으로 만든 독립 사본이다. 원본 조선역사와 상위 공용 지침을 수정하지 않는다. 이 폴더 안의 사본과 실험 결과만 변경한다.

공용 원문은 이 폴더의 `_대본지침서.md`, 채널 조건은 `조선역사/채널설정.md`다. 새 집필을 시작할 때 원문 전문을 읽으며, 단계별 집필에서는 해당 조항의 원문과 실제 견본 구간을 다시 사용한다. 이 안내를 축약 지침으로 대체하지 않는다. 다른 채널의 조건은 이 실험에 적용하지 않는다.

이번 사용자 선택은 기존에 많이 고친 편을 같은 제목과 기획 방향으로 재작성하는 것이다. 편은 사용자 수정·선택 근거가 남아 있는 위조족보로 선정했다. 제목·썸네일을 재선정하지 않는다. 사용자 작성 도입의 흐름과 문단을 유지하며 사료상 필요한 최소 수정은 전후를 기록한다. 본문 전체의 사용자 합격 기록은 없다.

실험은 `실험/위조족보/`에서 진행한다. 복사한 과거 원고는 비교 자료이며 새 결과를 그 위에 덮어쓰지 않는다. 새 문장과 사용자의 실제 채택 문장을 구분한다. 검수용 문장 쌍에는 출처·선택 라벨을 숨기고 앞뒤 문맥을 함께 전달한다. 독립 검수자에게 작성자의 의도·자기평가를 먼저 주지 않는다.

파트마다 이미 설명한 사실, 남은 질문, 이번에 줄 답, 다음 구간으로 넘길 질문과 실제 경계 문단을 전달한다. 전체 집필자는 한 명으로 유지한다. 사료 확인·독립 검수는 별도 역할로 수행한다. 조립 뒤 전체 연결과 중복을 재검토하고 마지막 수정본을 재열람한다.

이 폴더는 로컬 작성 실험이다. 복사본 안의 과거 클릭업·영상 제작 위임을 이번 실험의 외부 등록 요청으로 해석하지 않는다. 사용자가 별도로 요청할 때만 외부 전달을 진행한다. 새 결과는 시험본이며 사용자 합격이나 개선 효과가 검증된 운영 기준으로 기록하지 않는다.
