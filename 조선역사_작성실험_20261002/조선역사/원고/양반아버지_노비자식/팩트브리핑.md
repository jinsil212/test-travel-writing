# 아버지는 양반인데, 왜 자식은 노비였을까 — 0단계 팩트 브리핑

- 작성: 2026-09-17. 채널: 조선역사(미드폼). 러닝타임: 사용자 지정 15분 내외. 진행: 일반(ASK).
- 출발: [주제은행 09](../후속주제추천_20260917/주제은행.md). 사용자 메모의 조건(양반 아버지를 둔 아이가 모두 노비라고 쓰지 않기, 모든 시대에 어머니를 따랐다고 쓰지 않기, 서얼과 노비 혼용 금지)을 그대로 적용한다.
- 조사: 조선왕조실록 기사 7건의 국역과 원문을 직접 열어 대조했다. 한국민족문화대백과 항목 4건(노비종모법, 서얼금고법, 보충대, 송익필)을 열었다. 경국대전 형전 「천처첩자녀」 조문 원문은 한국사데이터베이스 화면이 스크립트로 불러와져 **열지 못했다**.
- 국역문은 요지로 적고 한문 원문은 짧게만 인용한다.

## ① 한 줄 요약

조선에서 아이의 신분은 원칙적으로 부모 중 한쪽이라도 노비면 노비였고, 그 아이는 **어머니를 소유한 주인의 재산**이 됐다. 양반 아버지가 여종에게서 낳은 아이가 노비가 된 이유다. 태종은 1414년 "재상의 핏줄을 어머니를 따라 종으로 부리는 것은 온당치 않다"며 아버지를 따르게 했지만, 이 법은 오래가지 못했다. 이후에는 아버지가 벼슬아치이고 정해진 절차를 밟았을 때만 아이가 노비에서 벗어날 수 있었다.

## ③ 그 전의 배경

- 고려 이래 노비끼리 혼인이 원칙이었고, 부모 한쪽이 천인이면 자식도 천인, 자식은 어머니 쪽 주인에게 속했다(천자수모). 여종의 아이는 여종 주인의 재산이 늘어나는 일이었다.
- 1401년 권중화 상소: 노비 남자가 양인 여자에게 장가들어 낳은 자식이 모두 사노비가 되어 나라 일을 질 양민이 줄어든다 → 이미 조선 초부터 '양민이 줄어든다'가 법을 바꾸는 이유였다 ([태종 1년 7월 27일 2번째](https://sillok.history.go.kr/id/kca_10107027_002)).
- 1432년 세종 때 양인과 천인의 혼인 금지를 다시 논의하며 "음서를 받을 만한 자손 이상은 천첩 소생이라도 양인이 되는 것은 의심할 것 없다"는 의견이 나왔다 ([세종 14년 3월 27일 2번째](https://sillok.history.go.kr/id/kda_11403027_002)). 벼슬 높은 집 자식과 평민·천인 사이 자식을 다르게 본 것이다.

## ④ 널리 알려졌지만 사실이 아닌 것 / 조심할 것

| 통념 | 실제 |
|---|---|
| 양반 아버지의 자식이면 첩 자식이라도 양반, 적어도 양인이었다 | 어머니가 노비면 원칙은 노비. 양인이 되려면 아버지가 벼슬아치이고 신고·복무·대신 바칠 노비 등 절차가 필요했다. 1414~1460년대 일부 시기에는 아버지를 따랐다 |
| 조선은 처음부터 끝까지 무조건 어머니를 따랐다 | 태종 때 아버지를 따르게 했다가 되돌렸다. 후기의 '종모법'은 오히려 노비 아버지+양인 어머니의 자식을 **양인**으로 만든 법이다 |
| 서얼 = 노비 | 서얼은 첩의 자식 전체. 양첩 소생(서자)은 양인, 천첩 소생(얼자)도 절차를 밟으면 양인. 노비로 남는 것은 절차를 못 밟은 경우 |
| 양반들이 노비를 늘리려고 여종에게 아이를 낳게 했다(댓글 5좋아요) | 여종의 자식이 주인 재산이 된 것은 법의 결과로 확인. 이를 목적으로 한 일반적 관행이었다는 근거는 이번에 확보하지 못함 → 대본에서 단정 금지 |
| 조선 양반가 조상 중 노비 자식이 허다했다(댓글 13좋아요) | 빈도 근거 없음. 개별 사건(송익필)만 사용 |

## ⑤ 확보 실패 항목

- 경국대전 형전 「천처첩자녀」·「보충대」 조문 원문(대소원인 천첩 자녀 신고 절차, 남의 여종에게서 난 자식의 처리, 복무 일수).
- 종부법이 폐지된 정확한 시점·폐단 내용(세종 14년 무렵 제한 → 세조 14년 재시행 → 예종 1년 환원 여부).
- 송익필 소송의 원사료(『안가노안』 등) 직접 대조, 70여 명 수치, 판결 논리의 1차 근거.
- 1886년 노비 세습 폐지·1894년 노비제 폐지는 이번에 출처를 열지 않음(사용 시 확인).
- 양반 아버지가 여종 자식을 실제로 몇 명이나 속량했는지 같은 통계는 없음.
