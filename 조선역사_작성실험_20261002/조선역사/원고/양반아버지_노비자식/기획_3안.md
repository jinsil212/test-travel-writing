## 2. 안별 설명과 흐름표 (P5·P6)

### ⭐ 1안 — 아이는 누구의 것이었나

- **니즈(P8):** 역사킴 댓글의 신분 다른 관계 상상(41·41좋아요), “양반가 조상 중 쌍놈 자식”(13좋아요)에서 **그 관계에서 태어난 아이는 어떻게 되나**로 확장한 가설. 001의 선택권 없는 처지에 대한 공감(1,100·476좋아요)과 기록·야사 구분 호평(97좋아요). 클릭 동기로 관측된 것은 아니다.
- **견본(P0-4):** 001 정순왕후 — ‘왕비 자리는 누구나 탐낸다’는 상식 → ‘딸을 내는 집이 서른도 안 됐다’는 모순 → 흔한 설명(외척 두려움) 제시 후 ‘절반만 맞다’로 다시 뒤집고 앞에 심은 사실(상궁 사전 방문, 나이 규정)로 회수. 이번엔 ‘양반 아버지면 양반 자식’ 상식 → 태종 발언이라는 기록 모순 → ‘첩 자식은 서얼일 뿐’이라는 흔한 설명 → 절반만 맞다(절차를 못 밟으면 종) → 송익필 사건으로 회수.
- **재료:** 실록 태종 14년·세종 12년·예종 1년·세조 7년 기사, 백과 보충대·서얼금고법·송익필.

## 4. 매너리즘 대조 (P15)

직전 원고(지석영 우두, 조선 안경)의 첫 문장·착지 유형은 **아직 대조하지 않았다.** 도입부 후보 단계에서 두 편 검토본을 열어 대조한다. 세종 관비 편과는 ‘관청 여종’ 소재가 겹치므로 여종의 출산·휴가 이야기는 쓰지 않는다.
