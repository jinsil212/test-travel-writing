## 고친 곳 (고치기 전 → 고친 후 → 이유)
1. "왕우와 격구를 하던 자리에서" → "왕우와 말을 타고 공을 치는 격구를 하던 자리에서" → 낯선 단어(금지 14). 격구가 무엇인지 먼저 풀었다.
2. "한 달 남짓 뒤 태조는 더 분명하게" → "그로부터 두 달이 채 안 돼 태조는 더 분명하게" → 사실 오류. 격구는 1393.4.4, 거제 왕씨 이주 발언은 5.26(F05, F06). 52일 차이라 "한 달 남짓"이 아니다.
3. "대간과 형조 관리들은 아예 일손을 놓아 버립니다" → "상소를 올리던 관리들은 아예 일손을 놓아 버립니다" → 앞에서 설명하지 않은 관청 이름(금지 14). 사실(조사 A 연표 2.26)은 그대로.
4. "외삼촌이 이씨 이름을 붙여 키운 겁니다" → "외가의 성인 이씨로 살아온 겁니다" → 이름을 누가 붙였는지는 기록에 없다(F37은 "외삼촌 이밀충 집에서 '이양'이란 이름으로 자람"). 같은 문단의 "외삼촌 집에서 자란" 반복도 줄었다.
5. "왕씨 후손은 숨기지 못하게 나라에서 막아 둔 터였어요" → "왕씨 후손을 숨겨 주는 건 나라에서 금한 일이었어요" → 흐름검수기록에서 모호하다고 남긴 곳. 실록 "국령으로 숨기지 못하게 했다"(조사 A 7번, B 4번)에 맞춰 무엇을 금했는지 분명히 했다.
6. "추운 철에 옥사를 오래 끄는 건" → "추운 철에 사람들을 오래 옥에 가둬 두는 건" → '옥사'는 귀로 낯선 말(금지 13, 14). 조사 D의 태종 말 요지와 같다.
7. "태종의 왕씨가 백 명이라도, 이 말이 바로 그 자신감입니다." → "왕씨가 백 명이라도 무엇이 걱정이냐는 태종의 말이 바로 그 자신감입니다." → 소리로 들으면 "태종의 왕씨"로 붙어 들려 뜻이 헷갈린다.
8. "왕씨 성을 쓰지 말라던 나라가, 이번에는 왕씨라서 땅과 이름을 내준 겁니다." → 삭제 → 같은 말 반복(금지 7). "~하던 나라가 이번에는 ~"라는 대비가 도입, 법화경, 세 번째 조각, 마지막 문단에 이미 있고, 바로 뒤 숭의전 문단과 마지막 문단이 같은 대비를 다시 말한다.

## 남은 걱정
- 계절 표현: "1392년 여름"(음력 7.12), "1393년 봄"(음력 4.4)은 양력 기준으로는 맞지만 음력 관례로는 각각 가을, 여름이다. 실록 날짜가 음력이라는 걸 아는 시청자가 지적할 수 있다. 고치지 않았다.
- "밭 10결"의 '결'은 시청자에게 낯선 단위다. 쉬운 말로 바꿀 대응 숫자가 사실표에 없어 두었다.
- 숭의전 이름과 공신 16명은 단종 즉위년(1452.7, 12월) 기록인데, 대본은 문종 때 이뤄진 일로 묶어 말한다(61행 근처 "문종 때 다시 이뤄진 겁니다"). 마전 봉사 결정은 문종 2년 3월이라 틀린 말은 아니지만 엄밀히는 문종에서 단종에 걸친 일이다.
- 구조 문제(고치지 않음): 흐름검수기록이 지적한 마무리 앞 문단(1878, 1770, 박지원 전승, 인구 숫자)의 나열감은 그대로다. 1482년 "양반은 아닌 듯"이 1467년 세조 잔치 뒤에 나오는 순서도 설계와 다르지만 그대로 두었다.
- 분량: 공백 제외 4,785자로 목표(약 5,000자)보다 조금 짧다.
- 직전 편과의 첫 문장, 진입 선언, 착지 비교(금지 19)는 직전 편 대본이 없어 검사하지 않았다.
