# 인현왕후 — 기획과 검토

2026-09-17. 사용자: “조선 역사 원고 작성. 15분 내외. 인현왕후 — 왕비를 내쫓았던 숙종은 왜 다시 불러들였나”. 확장주제12안.md의 7번 후보를 제목 작업안 그대로 지정하고 원고를 요청했다. 인목대비 편(“1로 해서 원고써봐”)과 같은 직접 집필 요청으로 보고 완성 초안을 제출한다. 도입 3안 선택 단계는 사용자 직접 집필 요청에 따라 생략했다. 오토 위임이나 사용자 합격으로 기록하지 않는다. 같은 대화에서 먼저 요청했다가 중단한 경안군 편은 미착수.

## 기획 연결 (P0·P8)
- 선택 견본 001의 작동 방식: 통설(늙은 왕이 딱한 소녀를 데려갔다)을 세움 → 기록으로 다른 설명(미리 골라 둔 집안)을 제시 → 출처의 성격을 스스로 밝힘 → 처음 질문에 답.
- 이번 대응 사실: 통설(장희빈에게 속았다가 뉘우쳐 데려왔다, 인현왕후전·드라마) ↔ 실록 날짜(1694년 4월 1일 남인 축출 → 4월 12일 복위, 1689년 서인 축출 → 5월 2일 폐위)와 숙종이 적은 책임 전가의 말.
- 관심 근거: 경혜공주 영상 댓글 표본의 추락과 역전, 권력자에 대한 대응 관심(확장주제12안 기록). 이번 주제의 클릭 동기는 작업자 가설이며 조회 성과 보장 아님.
- 원본을 본 사람에게 줄 새 가치: 001은 간택 이면의 계산, 이번은 폐위와 복위 두 결정의 날짜를 나란히 놓아 왕비 자리가 조정 교체와 함께 움직였음을 보여 줌.

제목 작업안(사용자 지정): 인현왕후 — 왕비를 내쫓았던 숙종은 왜 다시 불러들였나
썸네일 작업안: 내쫓았던 왕비를 / 5년 뒤 다시 부른 숙종
클릭 기대: 숙종이 인현왕후를 되돌린 진짜 이유. 제목 명사 ‘왜’ → 원인 설명이 본체(T11). 지급 위치: 본문 “두 번의 결정이 내려진 때를 나란히…”부터 “자신이 경솔했다는 말도…”까지.

## 대조표 네 줄 (P16)
- 클릭 이유: 숙종은 왜 쫓아낸 왕비를 다시 불렀나.
- 제목이 던진 질문: 같은 질문.
- 썸네일: ‘내쫓았던 / 5년 뒤 다시’로 같은 뒤집힘을 키움.
- 도입 첫 문장: “같은 왕이 같은 여인을 두고, 5년 사이에 정반대의 말을 남겼습니다.” → 두 발언으로 뒤집힘 제시, 도입 끝 “정말 뉘우쳤기 때문에 그녀를 다시 불러들였을까요.”
