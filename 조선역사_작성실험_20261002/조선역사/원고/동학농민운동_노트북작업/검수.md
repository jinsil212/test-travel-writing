# 동학농민운동 — 자가검수 (G장)

> 검사 대상 파일: `동학농민운동_대본_v1.md`. 2026-09-18 마지막 수정본을 다시 열어 낭독 원고 전문을 연속으로 읽고 검사했다(G5-2).
> 이 검사는 같은 작성자의 재검토다. 외부 검증이나 실제 시청자 이해 확인이 아니다.

## G5-2 최종 제출 검사표

| 검사 | 실제 근거 |
|---|---|
| **핵심 집중** | 이번 핵심 질문은 "정부가 자국민 진압에 외국군을 불렀고, 그 결정이 어떻게 굴러갔나"다. 곁가지로 판단해 뺀 것: ① 동학의 교조신원운동과 최제우의 생애 — 본문에는 "동학을 만든 최제우는 이미 30년 전에 세상을 어지럽힌 죄로 처형된 뒤였고요" 한 문장만 남겼다. ② 갑오개혁의 조항 — 일본이 철병을 거부한 명분("함께 조선의 제도를 뜯어고치자") 한 문장으로만 남겼다. ③ 청일전쟁의 전황 — "평양에서 싸웠고 황해에서 싸웠습니다" 한 문장으로 압축했다. ④ 남접과 북접의 노선 갈등 — 합류 사실만 남겼다. **가장 삭제를 검토한 설명**은 1장의 조병갑 학정 세부(비석값 1,000냥, 2만여 냥)다. 유지한 이유는 클로징의 "물세로 가져간 곡식 700여 석을 돌려 달라는 것이었습니다"가 이 구간의 구체성에 기대어 성립하기 때문이다. 삭제하고 읽어 보니 요구의 소박함이 주장으로만 남았다 |
| **초보자 이해와 등장 시점** | ① **수정한 곳**: 초고에는 "동학"이 7장에서 처음 설명 없이 등장했다("충청도 쪽 동학 조직"). 낯선 명사가 설명 없이 먼저 나오는 S1-1 위반이다. 1장 이용태 대목에 "사람은 누구나 저마다 한울을 모시고 있다, 그러니 귀한 사람과 천한 사람을 나눌 수 없다. 이런 가르침을 내건 종교가 당시 조선의 농촌에 빠르게 퍼져 있었습니다. 그게 동학이에요."를 넣어 기능을 먼저 설명하고 이름을 뒤에 붙였다. ② **수정한 곳**: "9년 전으로 가 보겠습니다. 그보다 앞서 조선에서 정변이 일어났을 때" → "10년 전으로 가 보겠습니다. 1884년, 조선에서 정변이 일어났을 때 ... 두 나라는 ... 이듬해에 조약을 하나 맺어요." 시점이 두 번 튀어 몇 년 전 이야기인지 따라갈 수 없던 것을 고쳤다. ③ **유지한 설명**: 1장의 "보"에 대한 풀이. 앞에서 "물세를 돌려 달라"는 요구가 먼저 나오므로 "물세가 뭔데"라는 의문이 생긴 자리에서 설명이 시작된다 |
| **중복과 전환** | ① **합친 곳**: 초고 도입에 "청나라 군대가 2,800여 명, 일본 군대가 8,000여 명이었습니다. 부르지 않은 쪽이 세 배 가까이 많았습니다"가 있었고, 4장 끝에 "부르지 않은 군대가 세 배 가까이 많아진 겁니다"가 또 있었다. 같은 수치와 같은 판단의 반복이라 도입에서 수치를 빼고 "더 이상한 건 규모였습니다. 부르지 않은 쪽이 훨씬 많았어요."로 바꿨다. 수치는 4장이 날짜와 함께 지급한다(H7·H10) ② **삭제한 곳**: 초고 3장에 김병시의 인용문을 통째로 다시 넣었다가, 회수가 아니라 복사라서 뺐다(B13·B23). 대신 "민영준이 사람을 보내 그의 뜻을 몰래 물었다"는 새 사실을 넣었고, 인용문 자체는 도입과 클로징 두 곳에만 둔다 ③ **줄인 곳**: "그리고 이야기는 여기서 끝나지 않습니다. 일본군의 진압은 우금치에서 멈추지 않았어요."는 같은 말을 두 번 한 것이라 "그리고 진압은 우금치에서 끝나지 않았습니다." 한 문장으로 합쳤다 ④ **바꾼 곳**: "여기서부터가 이 이야기의 핵심입니다", "여기서 무기 이야기를 해야 합니다", "그 폐단이 무엇이었는지도 보고 가겠습니다"가 모두 같은 안내 문형이라 각각 "부르지도 않은 일본군이 어떻게 들어왔는지, 이제 그 경로를 볼 차례입니다", "이 싸움의 결과를 가른 건 사람 수가 아니라 무기였습니다", "농민들이 고쳐 달라고 한 것은 이런 내용이었습니다"로 바꿨다(B14·S12) |
| **제목과 썸네일 약속 회수** | 제목의 따옴표 `"자기 백성 죽이려고 외국군을 불렀다"` → 도입 첫 문장 "남의 나라 군대를 빌려다가 우리 백성을 죽인다니, 이게 있을 수 있는 일입니까."와 클로징 "김병시가 한 말은 기록에 그대로 남아 있습니다"로 지급. 제목의 **"결정적 한 달"** → 4장과 5장의 "6월 2일 / 6월 6일 / 6월 8일 / 6월 9일 / 6월 11일 / 6월이 끝나기 전까지"로 지급. 제목의 **"스스로 나라를 넘긴"** → 6장의 "7월 23일 새벽, 일본군이 경복궁으로 들어갔습니다"와 "두 달이 지나자 조선은 남의 나라 전쟁터가 되어 있었습니다"로 지급. 썸네일 `부른 군대는 하나 / 들어온 군대는 둘` → 4장 "조선 정부가 부른 군대보다 부르지 않은 군대가 세 배 가까이 많아진 겁니다"로 지급 |
| **사실과 분량** | 핵심 주장의 출처는 [팩트브리핑.md](팩트브리핑.md)에 항목별로 기록했다. 관측과 해석을 구별한 곳: ① 청군 요청을 원세개가 어느 정도 유도했는지에 대해서는 연구가 갈리므로 대본은 "조선 정부가 요청하기로 했다"까지만 말한다 ② 폐정개혁 조목은 후대 정리 기록이라 본문에서 "항목의 수와 표현은 자료마다 다릅니다"라고 밝혔다 ③ 희생자 수는 "끝내 세어진 적이 없습니다. 연구자들은 최소 3만 명에서 5만 명으로 봅니다"로 범위와 한계를 함께 적었다. **분량**: 낭독 본문 공백 제외 5,561자. 분당 350자 가정 15분 53초, 분당 330자 가정 16분 51초, 가장 빠른 430자 가정에서도 12분 56초로 최소 10분을 넘는다. 실제 음성은 생성하지 않았다 |

## G4 통독에서 걸린 것과 조치

| 걸린 지점 | 판정 근거 | 조치 |
|---|---|---|
| "동학"이 7장에 설명 없이 등장 | "무슨 말이야?"(S1-1) | 1장에 기능 설명을 먼저 넣고 이름을 뒤에 붙임 |
| "9년 전으로" 뒤에 "그보다 앞서" | "어? 그게 맞나?"(S9 ②) | 1884년 정변, 이듬해 조약으로 연도를 명시 |
| 도입과 4장의 "세 배" 반복 | "아까 들은 것 같은데"(S3) | 도입에서 수치와 판단을 제거 |
| 3장의 김병시 인용 재등장 | 회수가 아니라 복사(B23) | 인용 대신 새 사실로 교체 |
| "도망친 병사가 그만큼 많았던 겁니다" | 사료가 확인해 주는 범위를 넘는 단정 | "대열에서 빠져나간 병사가 그만큼 많았던 겁니다"로 수정 |
| "1년 뒤 새벽의 교수대" | 1894년 2월부터 1895년 4월까지는 14개월 | "이듬해 봄 새벽의 교수대"로 수정 |
| 클로징에 김덕명, 최경선, 성두한이 처음 등장 | 클로징의 명사는 본문에 나온 것만(B24) | "손화중을 비롯해 함께 붙잡힌 지도자 네 사람"으로 바꿈 |
| "화승총이라고, 심지에 불을 붙여 쏘는 총이었어요" | 앞 문장도 "있었어요"로 끝나 어미가 겹침 | "총이었습니다"로 수정 |

## 조항별 확인 (0-5)

| 조항 | 판정 | 실제 근거 |
|---|---|---|
| 0-2 작업 순서 | 지킴 | 벤치마크 002와 004 원문 전문 정독 → 사료 확인 → 기획 문서 → 파트별 집필 → 자가검수 순으로 수행. 파트별 집필 후 P0-15 표를 문단 기준으로 재대조 |
| 0-3 문체의 기능 | 지킴 | 002의 질문 전환("이게 왜 그렇게 무서운 일일까요? 한번 따라와 보세요")을 수량이 아니라 기능으로 가져왔다. 이번 대본의 대응 자리는 "왜 청나라가 그걸 일본한테 알렸을까요."다. 앞 문장(이홍장이 일본에 통보)에서 실제로 생기는 의문이고, 바로 뒤 문단이 답한다 |
| 0-4 진행 모드 | 해당 | 사용자가 기획과 감정선을 확정해 제시하고 대본을 지시했다. 도입 후보는 내부 선정하되 3안 전문을 함께 제출해 선택 가능 상태로 남겼다. **작업자 선정이며 사용자 합격이 아니다** |
| B1 사람이 한 결정으로 | 지킴 | 민영준이 방법을 내놓고, 김병시가 반대하고, 고종의 정부가 결정하고, 이홍장이 통보하고, 전봉준이 물러나기로 판단한다. 조건문으로 쓰지 않았다 |
| B2 챕터는 반전 단위 | 지킴 | 1장 요구의 소박함 → 2장 정부의 공포 → 3장 알고도 한 결정 → 4장 조약이 낳은 두 번째 군대 → 5장 명분의 소멸 → 6장 그래도 안 나감 → 7장 무기 격차. 각 장 끝에서 예상이 한 번씩 바뀐다 |
| B6 분량 | 지킴 | 위 계측 참고. 사건을 늘려 시간을 채우지 않았고, 추가한 분량은 동학 설명과 폐정개혁 요구 두 곳이며 둘 다 이해 공백을 메운 것이다 |
| B11 숫자 표기 | 지킴 | 아라비아 숫자 사용. 날짜는 1894년 6월 2일 형태로 통일. 시간 표기가 문장 첫머리에 오는 비율이 4장에 몰려 있으나, 그 장이 "한 달"을 지급하는 구간이라 의도한 배치다 |
| B17 TTS | 지킴 | 가운뎃점 0회(실제 검색 결과). 나열은 쉼표와 "그리고"로 처리 |
| B18 수익화 기준 | 지킴 | 학살과 처형을 다루되 방법과 과정을 단계별로 묘사하지 않았다. 우금치는 무기 성능 차이와 남은 인원으로, 처형은 날짜와 사실로 썼다. 도입에는 가장 센 장면을 넣지 않았다 |
| B19~B24 클로징 | 지킴 | 번호 붙인 요약 없음. 넓히며 끝내지 않고 고부의 보 하나로 좁혀 닫았다. 2인칭 훈계 없음 |
| S13 시청자 연결 | 지킴 | 현대 사건과 억지로 잇지 않았다. 002의 네팔 연결형 클로징은 가져오지 않았다 |
| T11 제목의 명사 | 지킴 | 위 회수표 참고 |
| H2 도입 후보 | 지킴 | 전문 3개 작성, 비교표와 선정 근거 기록. 탈락 후보도 기획 적합성 검사를 통과한 것만 남겼다 |
| P0-6a 실사 의존 | 해당 없음 | 실제 촬영 자료가 있어야 성립하는 문장을 쓰지 않았다. 화면 제안은 조건부로만 적었다 |

## 남은 한계

- 조선왕조실록과 일성록 등 원사료 원문을 직접 대조하지 않았다. 김병시의 발언은 우리역사넷 신편한국사가 인용한 문구를 근거로 썼다.
- 실제 음성을 만들지 않았으므로 재생 시간은 추정이다.
- 썸네일 이미지를 생성하지 않았고 축소 화면 가독성도 확인하지 않았다.
- 이 검사로 내용 품질이나 조회수가 보장되지는 않는다. 사용자 합격과는 별개다.
