# 리서치 C — 민간의 치료자·비국가 치료 수단 (조선, 가난한 사람은 아프면 어디로 갔나)

조사일 2026-09-17. 범위: 사람(민간 의원)과 국가기관 밖의 치료 수단. 혜민서·활인서 운영과 후기 약재시장은 다른 조사 담당이라 교차점만 짧게 표시.

**표기 규칙**
- 인용 칸은 원문 그대로 옮겼다. 한문만 있는 자료(공식 국역 없음)는 한문을 인용하고, 뜻은 주의점 칸에 `작업 번역`으로 따로 달았다. 작업 번역은 공식 국역이 아니므로 대본에 따옴표로 쓰지 않는다.
- ITKC 링크는 `https://db.itkc.or.kr/dir/node?dataId=…` 형식으로, 이번 조사에서 실제로 본문을 받아 확인했다.
- 확인 상태: **1차 원문 확인**(원문 또는 원문+공식 국역을 직접 읽음) / **2차 자료만** / **미확인**
- "정약용이 썼다"는 것은 **정약용의 서술**이다. 사실로 확정된 것과 구분한다.

## 대본 작성 시 꼭 지킬 것 (요약)

1. **이헌길 = 홍역(마진).** 국역본의 "마마", "1715"를 그대로 옮기지 않는다.
2. **정약용이 이헌길 덕에 살았다**는 것은 정약용 자신의 말이다(1798 서문). 나이와 해는 없다. 7세 천연두(삼미자)는 별개의 병이고 이헌길과 무관하다.
3. **피재길 전기의 저자는 홍양호다.** "글자도 몰랐다"는 양반 관료의 평가임을 드러낸다.
4. **백광현 전기(정래교)는 한문 원문만 있다.** "마의" 관직명을 단정하지 않는다(원문은 「善醫馬」). 침이 과격해 사람이 죽기도 했다는 대목까지 원문에 있다.
5. **무당:** 국가도 무당을 치료 인력으로 쓰고(1415·1429) 세금을 걷었다. 영조는 여항 사람들이 병나면 곧 무당을 쓴다고 했다. 굿의 세부 절차는 20세기 채록이므로 조선 당대 묘사로는 이규경(19세기)과 허준 발문(1601)을 쓴다.
6. **책:** "부녀자·아이도 펼쳐 보게"(구급간이방 서문 1489), "깊은 규방 부녀도 증세를 보고 처방을 찾게"(언해두창집요 발문 1601). 실제 보급 범위와 문해력 효과는 미확인이다.
7. **유의태는 소설 인물이다.** 실존 유이태(1652~1715)와 구별한다.
