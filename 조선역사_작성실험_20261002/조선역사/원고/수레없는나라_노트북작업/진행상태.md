# 수레도 도로도 없던 나라 — 진행상태

## 사용자 지정 (2026-09-19)

- 채널: 조선 역사. 주제: 「수레도 도로도 없던 나라 — 조선은 왜 가난했나」.
- 제시한 제목안: `"바퀴 달린 수레가 없었다"..바로 옆 나라와 300년 격차가 벌어진 진짜 이유 ㄷㄷ`
- 제시한 기획 의도: 상업 천시 → 화폐 미발달 → 물류 부재 → 시장 부재 → 자본 축적 실패의 구조로 설명해 감정 논쟁을 피한다. 박제가 『북학의』를 인용 소스로 지정.
- 요청: **대본 작성, 15분 미만.**
- 오토 지시는 없었다.

### 진행 모드에 대한 작업자 판단 — 사용자 확인 필요

공용 0-4의 일반 진행(ASK)은 기획 3안과 도입부 3안에서 사용자 선택을 기다린다. 그러나 이번 요청은 산출물을 **대본**으로 명시했고 기획 방향·제목안·인용 소스까지 함께 줬다. 그래서 **각 선택 단계의 후보와 비교·선정 근거를 모두 문서에 남기되, 작업자가 선정해 대본까지 진행**했다. 이는 0-4의 오토 실행으로 기록하지 않으며, 모든 선정은 **작업자 선정**이고 사용자 합격이 아니다. 사용자가 다른 안을 고르면 그 범위만 다시 쓴다. 이 해석이 틀렸다면 다음 편부터 기획 3안 제출에서 멈추는 방식으로 되돌린다.

## 사용자 제시 제목안의 처리 (P11 2026-09-17 보완)

| 요소 | 처리 |
|---|---|
| 「바퀴 달린 수레가 없었다」 | 사실과 어긋난다(박지원: *"전혀 수레가 없음은 아니나"*). **버리지 않고** 당사자의 다음 문장 *"이는 수레 없는 것과 마찬가지이다"*로 옮겨 같은 세기를 유지했다. 대체 제목 2번이 이 어조를 그대로 쓴다 |
| 「300년 격차」 | 어느 지표로 몇 년인지 계산한 근거를 찾지 못해 **대본·제목·썸네일 어디에도 쓰지 않았다** |
| 「바로 옆 나라」 | 살렸다. 박제가(1778)·박지원(1780)이 실제로 보고 온 **청나라**로 본문 후반에 지급했다 |
| 전달하려던 무게 | ‘운송 하나가 없어 나라가 뒤처졌다’는 규모감을, **같은 나라 안에서 값이 0과 한 푼으로 갈린 당대 기록**으로 대체했다. 사실 확인을 이유로 평범한 소개로 약화하지 않았다 |
| 기획 의도의 연쇄 | 사용자가 준 5단 연쇄를 그대로 쓰되 순서를 재배열했다. ‘상업 천시’는 독립 국면이 아니라 **길을 넓힐 주체가 없었던 이유**로 본문에 녹였다(P0-15에서 신분제 설명 자체는 제외) |

## 미확정·다음 단계

1. **사용자 선택 대기**: 제목(1번 vs 2번), 썸네일 문구 확정 개수(T13은 사장님이 정한다), 도입 A안 승인 여부.
2. **썸네일 이미지 미생성.** 영어 프롬프트 3개만 제공했다. 생성·축소 가독성 확인은 하지 않았다.
3. **클릭업 미등록.** 채널설정의 클릭업 전달 기준(공간 901813689406 / List 901821806849)은 사용자가 ‘클릭업에 올려줘’라고 요청할 때 실행한다. 이번에는 요청이 없었다.
4. **검증 보강 여지**: 열하일기 「일신수필」 거제와 북학의 해당 편의 한문 원전 대조, 영조척 실제 길이, 조선 후기 지역별 수레 사용 규모. 확보하면 도로 규정 구간에 수치를 되살릴 수 있다.
5. 001·003·004 분석지는 이번 편에 적용하지 않았다. 다음 편에서 다른 구조가 필요하면 그때 원문을 읽는다.
