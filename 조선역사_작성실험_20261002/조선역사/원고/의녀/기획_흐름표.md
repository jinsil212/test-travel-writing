# 의녀 — 기획·사건 흐름표 (오토 진행, 2026-09-17)

실록 기사 주소는 `https://sillok.history.go.kr/id/` + ID.

## 기획 확정 (사용자 제시 방향 그대로)

- 클릭 이유: 남자 의원에게 몸을 보이기 꺼렸다면, 조선 여성은 아플 때 누구에게 진찰받았나
- 팩트: 1406년 허도의 건의로 관청의 어린 여종에게 맥·침을 가르친 의녀가 생겼다. 글자부터 배우고 매달 시험을 쳤지만, 의술은 의원만 못하다는 평을 받았고 연회·수색에 불려 다녔으며 신분은 낮았다.
- 벤치마크: 005 주막(제도의 기능을 생활어로 풀고 사람의 쓰임으로 이동) 전문 정독. 화자의 감정 보고·과장·'직계 후손' 단정은 가져오지 않음.
- 러닝타임: 15분 미만. 문장자수 약 5,300~5,900자 목표(400~440자/분 참고, 실제 음성 미측정).

### 대조표 4줄
- 클릭 이유: 조선 여성은 아플 때 누구에게 진찰받았나
- 제목: 남자 의원을 꺼린 조선 여성, 아플 때 누구에게 진찰받았을까
- 썸네일: 1줄 "의원이 와도 몸을 안 보였다" / 2줄 "조선 여인의 병은 누가 봤나" — 같은 질문을 '죽음까지 갔다'는 대가로 키움
- 첫 문장: "병이 난 여인에게 남자 의원이 맥을 짚으러 옵니다." → 바로 '보이지 않아 죽기도 했다'로 질문을 받음

### 제목 후보 10 (추천 1)
1. ★ 남자 의원을 꺼린 조선 여성, 아플 때 누구에게 진찰받았을까 — 클릭 질문 직결
2. 조선 여성은 아파도 의원에게 몸을 보이지 않았다 — 통념 확인형
3. 글도 모르던 여종 아이가 조선 여성의 의원이 되기까지 — 과정형
4. 매달 시험, 떨어지면 다시 노비로… 조선 의녀의 공부 — 긴장형
5. 여인을 고치라고 만든 의녀, 왜 잔치와 수색에 불려 갔나 — 모순형
6. 조선 왕실 여성의 맥은 누가 짚었나 — 궁중 범위형
7. 부끄러워 죽기까지… 조선이 의녀를 만든 이유 — 스테이크형
8. 대장금 이전, 의녀는 어떻게 만들어졌나 — 인지도 키워드형(치통 편과 인물 중복 우려로 비추천)
9. 조선 여성 환자와 의녀, 드라마와 다른 진짜 기록 — 통념 정정형
10. 의원은 있었는데, 조선 여성은 왜 치료받지 못했나 — 역설형

### 썸네일 문구 10 (1줄 후킹 / 2줄 주제)
1. ★ 의원이 와도 몸을 안 보였다 / 조선 여인의 병은 누가 봤나 (모순)
2. 부끄러워 죽기까지 했다 / 조선 여성의 진찰 (스테이크)
3. 글도 모르던 여종 아이 / 조선 여성의 의원이 되다 (반전)
4. 떨어지면 다시 노비로 / 의녀의 매달 시험 (긴장)
5. "의녀의 의술은 의원만 못하다" / 조선 의녀의 현실 (대사)
6. 병 고치라 뽑았더니 잔치에? / 조선 의녀의 두 얼굴 (모순)
7. 왕비의 맥은 누가 짚었나 / 조선 궁중 의녀 (지목)
8. 남자 의원은 안 된다 / 조선 여인의 진료실 (금기)
9. "의녀를 둔 본뜻이 아니다" / 왕이 꾸짖은 이유 (대사)
10. 열 살 여종에게 침을 가르쳤다 / 조선 의녀의 탄생 (수치)

### 첫 문장 3
- A ★ 장면형: 병이 난 여인에게 남자 의원이 맥을 짚으러 옵니다. (직전: 김육 문서 인용, 송시열 모순)
- B 모순형: 의원이 곁에 있었는데도, 병을 보이지 않다가 숨진 여인들이 있었습니다.
- C 수치형: 열 살에서 열다섯 살, 관청에서 일하던 여종 아이들이 한양으로 올라갑니다.

선택 근거: A는 클릭 질문(누가 진찰했나)을 곧바로 '남자 의원이 있어도 진찰이 안 됐다'로 키움. B는 송시열 편과 같은 모순형, C는 1423년 사실이라 1406년 시작과 시점이 튐.
