# 송시열 분량 보완과 전체 재검토

2026-09-16 사용자 `다해`: 앞서 보고한 분량 보완·재검수 완료 요청으로 처리한다. 아직 보지 않은 새 대본의 최종 승인이나 외부 등록 승인으로 만들지 않는다.

## 입력 재확인

공용 지침 1~1623행을 다시 읽었다. 최초 전체 출력과 420행 출력의 잘린 구간은 작은 범위로 다시 열어 확인했다. 이원익 원문 17,433자는 이번에도 두 연속 구간으로 끝까지 읽었다. `채널미정/_합격원고/` 경로 없음 재확인. 제목·썸네일·승인 다섯 흐름 유지. 직전 두 편의 발행 순서는 여전히 미확인이다.

## 두 번째 수정과 통독

파트별 보완 후 조립한 v6 전체를 앞뒤 경계까지 이어 읽었다. 공주 집과 기근은 같은 자리의 배경이며 군사사로 가지 않는다. 1682년 왕의 개인적 초빙 노력 뒤 민정중의 조정 내 요청이 더해지는 진행이다. 원자 결정 전 회의의 ‘한 신하’와 결정 후 송시열을 변호한 ‘왕명 전달 신하’는 다른 시점·역할로 분리한다. 사후 청원자는 ‘다른 관리들’로 먼저 구별한다. 앞의 지지자를 그대로 사후 청원자로 연장하지 않는다.

효종 때 거취와 숙종 때 벼슬 위협은 같은 결론 반복이 아니다. 전자는 송시열이 왕에게 자기 말의 채택을 요청하는 선택, 후자는 왕이 반대하는 신하들에게 물러나라고 요구하는 선택이다. 자동 감정 표지는 0이지만 선택에 따른 실제 위험과 대응이 긴장을 담당한다. 조회수나 시청 지속 효과를 보장하지 않는다.

## v6 계측

- 원시 문자 6,706, 문장 자수 6,469. 이원익 실측 기준 409자/분을 적용한 예상 15.82분. 채널 참고 범위 400~440자/분이면 약 14.70~16.17분이다. 실제 TTS 재생시간은 미측정이며 15~20분 목표의 텍스트 추정치로만 판정한다.
- 훅 419자/12문장, 본편 5,525자/144문장, 클로징 525자/13문장. 평균 길이 34.9/38.4/40.4자. 견본의 문장 길이를 강제해 필수 관계를 압축하지 않는다.
- 연도 3개 중 문장 첫머리 1개. 숫자 문장 6개 중 첫머리 50%. 숫자 3개 이상 문장 연속 없음.
- 질문 8개(만자당12.4), 직접 인용 2개. 질문은 원인·범위·오해에 답하는 역할이며 수치만 채우려고 재질문하지 않는다.
- 훅 끝 ‘이어가 보겠습니다.’ 다음 ‘효종에게 송시열은 낯선 신하가 아니었습니다.’에서 첫 근거 시작. 시계가 아니라 내용으로 경계 판정.
- 가운뎃점·본문 소제목·작업 주석 0. 실명은 송시열·효종·현종·숙종·민정중·장희빈. 추가한 국면에서 실명을 늘리지 않았다.
- 마지막은 명예 회복→클릭 질문의 짧은 답→사후 책임 요청→숙종의 응답으로 한 번 닫는다. 의미 기능과 별개로 어휘 빈도만 보고 반복이라 판정하지 않는다.

별도 사실 검토와 독자 네 축 검토는 v6 전체의 새 해시로 요청했다. 이 문서의 작성자 판정만으로 독립 검토 통과를 대체하지 않는다.
