# 견본 001 — 정순왕후 (15세 왕비 × 66세 영조)

> 구조 견본. 원 대본 문장을 옮기지 않고 분석자 말로 기술함. 따옴표 직접 인용은 기법 자체인 짧은 구절 4종뿐(기억 표시, 자기정정, 헤지 문형, 결론 두 글자).
> 시간% = 해당 시점(초) ÷ 2,950초.

## 1. 기본

| 항목 | 값 |
|---|---|
| 제목 | 15살에 66세 영조와 결혼한 정순왕후, 그날 밤 영조가 잠을 못 잤다 [조선왕조실록] |
| 채널 | 조선왕조실록이야기 (구독 17,700) |
| 길이 | 49분 10초 (2,950초), 813문장, 약 21,100자 |
| 조회수 | 570,480 (41일) → **구독자 대비 32.2배**, 좋아요율 2.35% |

## 2. 이 영상이 잡은 시청 이유

**15 대 66이라는 숫자 하나가 주는 불편함**을 끝까지 끌고 가며, 그 결혼이 소녀에게 행운이었는지 파멸이었는지를 시청자가 직접 판정하게 만든다 — 댓글 1~8위가 전부 나이 차이에 대한 분노·연민이다.

## 3. 핵심 질문과 답

- **걸린 질문(3.1%)**: 이 혼인은 소녀에게 벼락 같은 행운이었나, 인생의 끝이었나.
  - 부질문(2.9%): 혼례날 밤 무슨 일이 있었나(제목의 약속).
- **답의 배치**
  - 36.1% — 간택 직후 같은 질문을 한 번 더 걸고 아직 판단을 미루며 유보.
  - 69.6% — 부질문의 답: 별궁 일화 → 잠 못 이룬 밤의 전승. 곧바로 출처 없음을 고백(74.9%까지 신뢰 회복용 증거 예고).
  - 94.6~96.4% — 핵심 질문의 답: **"둘 다"**. 얻은 것 목록(가문·지위·의례 부활·임금의 애정)과 잃은 것 목록(집·자식·청춘)을 나란히 놓는 저울형 결론.
- 보조 미스터리(55.7%에 걸고 91.6%에 회수): 외척을 경계한다던 임금이 왜 왕비 친정에 도성 병력을 맡겼나 → 정조 즉위 후 오빠의 유배로 답.

### 막 구조 요약 (5막)

- **1막 0–4%**: 콜드오픈 + 역설 + 이분 질문 (도입)
- **2막 4–34%**: 왕비 자리가 빈 경위 → 기피 → 간택 절차 → 삼간택 일화 → 출처 고백 (사건의 시작)
- **3막 34–56%**: 이 아이와 가문은 누구인가 → 통설 뒤집기 → 사전 내정 결론 → 군권 미스터리 (중간 반전)
- **4막 56–86%**: 혼례·행렬 → 그 밤의 전승과 출처 → 궁 안의 고독 → 친잠례·비석 → 무자식 (정점과 아이러니)
- **5막 86–100%**: 뒤주 플래시백 → 영조 승하 → 미스터리 회수 → 반전 → 결론 → 무덤 코다 → CTA (회수)
- 중간점(50%) 근처에 가장 큰 정보 반전(가문 인맥)이 놓여 있어 후반 이탈을 막는 구조.

## 5. 도입 해부

- **첫 문장 유형**: 장면(연월+장소 고정) → 2문장 안에 수치(나이)로 전환. 장면형+수치형 혼합.
- **질문 거는 위치**: 12번째 문장에 첫 역설(이상한 점 제시), 28번째 문장에 제목 질문(밤), 30~31번째 문장에 핵심 이분 질문(행운 vs 끝).
- **진입 선언**: 구독 요청 직후, 앞의 역설(아무도 딸을 안 냈다)을 이어받아 자리가 빈 경위로 시간 되감기 선언 → 두 해 전으로 이동.
- **도입 비율**: 0~1:59 = **약 4%** (36문장). 콜드오픈 대사가 30.9%에서 그대로 재등장해 도입 장면을 회수.
- 도입 안에 감정 계약(끝까지 보면 무겁겠지만 남는 것이 있다는 예고)을 명시적으로 걸어 둠.

## 6. 챕터 전환 방식

1. **"기억해 두세요" 표시 후 원거리 회수** (24.6% 표시 → 51% 회수; 41.5% 오빠 표시 → 54%·92% 회수). 앞 정보가 다음 챕터의 열쇠가 되는 퍼즐식 전환.
2. **복선 투척 후 의도적 보류** (10.4% 뒤주 언급 → 뒤에서 하겠다는 보류 → 86%에서 시간 역행으로 회수). 연대기를 깨고 플래시백으로 돌아가는 구조.
3. **자기 정정형 반전** (46.9%): 화자가 앞서 자신이 한 설명(힘없는 집안)을 "절반만 맞는 말"이라 뒤집으며 가문 인맥 챕터로 진입.
4. **대비 재정리 → 왜?** (63%): 앞 챕터들의 숫자(지원 30집 미만 vs 대행렬)를 맞붙여 모순을 만들고, 그 '왜'가 임금의 심리 챕터를 연다.
5. **기록 단절을 문턱으로 사용** (65~66%): 문이 닫히고 사관도 멈췄다 → 공식 기록이 끊긴 자리에 야사·오해 교정 챕터를 끼움. 이후 실록·비석 증거 예고(71%)로 다음 챕터(친잠례·비석)를 당김.

- **말 걸기**: 물음표 문장 57개(약 7%). "아세요?/아십니까?/기억하십니까?"형 확인 질문, "자, ~ 보겠습니다"형 안내. '여러분' 호칭은 적고(4회) 1인칭 화자 개입(저는 ~라고 본다 / 저희도 출처를 못 찾았다 식)이 신뢰 장치.
- **문장 길이**: 평균 약 25자. 장면 묘사는 5~10자 단문 연타(밤이에요/붓을 듭니다 식), 해설은 40자 이상 장문. 단문 연타 → 장문 설명의 리듬 반복.
- **숫자·연도**: 연월일을 매번 명시(1759년 6월 초이틀 등)하되 바로 며칠 만에 같은 체감 단위로 환산. 나이는 집요하게 반복·대비(15/66/25/64/8). 실록 원문 날짜 표기는 풀어 설명(병신년·묘시 → 아침 6시쯤).
- 사료 등급 표시 어휘: 실록/승정원일기/한중록/야사집을 구분해 부르고, 전승은 "~다고 전해집니다"로 일관.

## 8. 클로징

구조: **보조 미스터리 회수(92%) → 예상 밖 반전 사실(94%) → 핵심 질문으로 복귀·"둘 다" 저울 결론(95%) → 화자 개인 소회 한 문장(목화 답과 수미상관) → 코다: 무덤 빈자리 이미지(96~98%) → 댓글 CTA(이분법 두 단어 답 제시) → 1인 제작 고백·감사.**

- 결론을 판정하지 않고 시청자에게 같은 이분 질문을 되돌려 댓글로 받는 순환형.
- 마지막 이미지가 '빈 자리'라서 서사 첫머리(빈 방석·빈 간택장)와 시각적으로 수미상관.

## 9. 가져올 엔진 / 가져오면 안 되는 것

**가져올 엔진 3개**
1. **숫자 하나를 주인공으로**: 나이차를 콜드오픈·가족 산수·할아버지 비교·역대 비교·승하 시 나이로 다섯 번 변주. 숫자가 감정 장치가 됨.
2. **사료 등급 공개를 서스펜스로**: 야사를 먼저 생생히 들려준 뒤 실록에 없음을 밝히고, 이어 기록으로 확인되는 증거(비석·존호)를 예고해 다음 챕터를 당김. 정직함 자체가 훅. 모범 표현: "그런 이야기가 전해집니다"라는 고정 헤지 문형.
3. **표시-보류-회수 3단 복선**: "기억해 두세요"를 명시적으로 걸고 20~75%p 떨어진 곳에서 갚음. 시간 역행 플래시백(86%)으로 연대기 단조로움을 깸.

**가져오면 안 되는 것 3개**
1. **제목이 출처 없는 일화를 약속**: 제목의 밤 일화는 영상 스스로 출처 미상이라 인정(69~70%). 고백으로 막았지만 우리 채널은 지급 못 할 장면을 제목에 걸지 않는다.
2. **추론을 단정으로**: (a) 금혼령 연령(16~20세) 미달 + 상궁 사전방문 + 일주일 진행 → 임금이 처음부터 내정했다(51%)는 정황 추론인데 사실처럼 단언. (b) 정조가 원릉을 옮긴 이유를 정순왕후 때문이라 단정(97%) — 해석의 하나. (c) 정순왕후가 세손 대리청정을 밀었다(94%)는 대목은 학계 해석이 갈리는데 기록 하나로 확정. (d) 정성왕후 무자의 원인을 임금의 소박으로 단정(4.5%).
3. **검증 안 된 일반화·수치**: 왕비 간택 단자가 늘 25~30장이었다는 조선 전체 일반화(14%), 삼간택 탈락자는 시집을 못 갔다는 관습 단정(24%), 친잠례 300년 만(선조 이후 단절이라는 본인 설명과 계산이 안 맞음 — 약 170년, 76%), 경주 김씨 정승 8명·추사도 이 집안(48%, 같은 본관이지 같은 가계라 하기엔 과장), 반차도 화원 명단의 신한평 참여(63%) — 모두 출처 미제시. 또 나이차를 도입에선 50살, 본문에선 51살로 혼용.
