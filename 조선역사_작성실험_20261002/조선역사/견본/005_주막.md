## 2. 이 영상이 잡은 시청 이유 (한 줄)

익숙한 '사극 속 술집'이 사실은 은행·우체국·숙박을 겸한 전국망이었다는 반전을, 25kg 동전을 진 외국인이라는 구체적 미스터리로 열어 끝까지 "그래서 그 동전은?"을 따라가게 만들었다.

## 3. 핵심 질문과 답

- **도입 질문(0:31–0:39, 약 3%)**: 1903년 조선을 걷던 외국인 작가가 왜 25kg이나 되는 동전을 지고 다녔고, 주막 주모는 그 짐을 덜어주겠다며 무슨 제안을 했나.
- **질문 보류 방식**: 질문을 던진 직후 답 대신 주막 전체 서사(기원 → 규모 → 숙박 → 정보망)로 빠진다. 약 31%에서 "또 하나의 기능"으로 은행 역할을 예고만 하고 끊는다.
- **답 1 — 무게의 이유(32–36%)**: 엽전이 작고 구멍 뚫린 동전이라 여행 경비를 환산하면 사람이 질 수 있는 한계 무게가 된다는 설명.
- **답 2 — 주모의 제안(36–38%)**: 돈을 맡기고 증서로 다른 주막에서 쓰고 마지막에 정산한다는 제안 → 화자가 이를 '여행자 수표/신용카드'로 명명.
- **반전 꼬리(41–45%)**: 그런데 작가는 제안을 거절했다 → 시청자에게 "당신이라면?"을 돌려줌.
- 즉 핵심 질문의 답은 **전체의 약 37% 지점**에서 나오고, 이후는 "주막을 움직인 사람 → 주막의 변주 → 몰락 → 마지막 주막"으로 질문이 갈아끼워진다.

## 5. 도입 해부

- **첫 문장 유형**: 장면형(현재형으로 '한 외국인이 걷고 있다'). 곧바로 연도(문서형 신호)와 수치(25kg)가 붙어 장면+수치 혼합.
- **질문 위치**: 10~11번째 문장에서 질문 2개 연속. 그 앞 9문장은 "정체 숨기기 → 무게 → 짐 내용물 반전(옷도 식량도 아님 → 돈)"으로 단계적 정보 공개.
- **진입 선언**: 12번째 문장에서 1인칭 안내 선언 — "오늘 저는 여러분을 조선의 주막으로 안내합니다". 이어서 ① 통념 부정(그냥 술집 아님) ② 규모 수치 2개 ③ 본편에서 다룰 장면 4~5개를 명사구로 예고 ④ 마지막에 주제어(주막)를 문장 끝에 놓아 이름 공개.
- **도입 길이**: 0:00–1:07 = **약 5.8%** (질문까지 3.4%, 선언·예고 2.4%).
- **특징**: 예고 목록에 '하룻밤 사이에 사라졌다'는 결말 떡밥까지 미리 포함 → 끝까지 볼 이유를 하나 더 심음.
- **도입 문장 순서 지문**
  1. 장면(누가, 어디서) → 2. 연도 → 3. 인물 정체 일부 → 4. 이상 징후(무게)
  5. 수치 단독 문장 → 6. 수치 강조 반복 → 7. 내용물 부정 → 8~9. 반전(돈 → 동전)
  10~11. 질문 2연발 → 12. 진입 선언 → 13~14. 통념 부정 + 규모 → 15. 예고 나열 + 주제어 공개

## 6. 챕터 전환 방식

1. **필요의 연쇄(약 12% → 15%)**: "어디 있는지 어떻게 알았을까" → 표지 설명 → "자, 이제 안으로 들어가 보자"는 동행 권유. 공간 이동(밖 → 안)이 곧 챕터 이동.
2. **장점 뒤 단서 달기(약 18%)**: 싸다는 정보를 시청자 반문 형태로 받은 뒤 "싼 데는 이유가 있다"로 꺾어 외국인 기록 챕터를 연다. 긍정 → 부정 전환.
3. **"그런데 말입니다" + 기능 추가 예고(약 27–32%)**: 숙박 이야기를 끝내며 "단순히 밥 먹고 자는 곳이 아니었다"로 범위를 넓히고, 정보망 설명 끝에 "또 하나의 기능"을 이름만 던져 도입 떡밥 회수로 점프.
4. **답 직후 반전 질문(약 41%)**: 감탄의 정점에서 "그래서 그는 받아들였을까"를 던지고 즉시 부정 → 시청자에게 질문을 넘긴 뒤 "이제 사람 이야기 차례"로 인물 챕터 진입.
5. **2단 원인 구조(약 72–75%)**: 몰락을 "처음엔 서서히(철도)" → "이건 시작일 뿐, 진짜 원인은 따로"로 쪼개 한 챕터 안에서 두 번 긴장을 올림. 이후 "사라졌다 → 아니, 거의"의 자기 정정으로 마지막 주막 챕터를 연다(약 85%).

- **시청자에게 말 거는 방식**: 존대 2인칭 '여러분'. 자문자답("이것이 무엇입니까?" 식 짧은 질문 → 한 문장 답)과 상상 유도(숫자를 상상해 보라, 단어가 떠오르지 않느냐), 참여형 되묻기("여러분이라면 믿고 맡기셨겠습니까?") 1회.
- **화자 1인칭 감정 보고**: 챕터마다 1회꼴(실소 → 경악 → 가슴 뜨거움 → 탄식 → 참담함), 뒤로 갈수록 강도가 올라감. 내레이터가 '먼저 느끼는 사람' 역할.
- **문장 길이**: 평균 약 35자. 묘사 구간은 긴 문장, 정보망·몰락 구간은 1~2어절 단문 연타("은행도 없었습니다" 류)로 리듬을 끊음. 체언 종결로 마침표를 찍는 '파편 문장'이 감정 구간 표지.
- **숫자·연도**: 연도는 장면 첫머리에 단독으로 세움(1903, 1894, 1801, 1909, 1916, 2005). 핵심 수치(25kg, 10만 개)는 **같은 숫자를 3~4회 반복**하고 문장 끝에 단독으로 다시 놓아 각인. 10만 개는 결말에서 '불빛' 은유로 재활용.
- **현대어 환산**: 주력 장치. 패키지 상품, 찜질방, 포털+SNS+우체국, 여행자 수표·신용카드, 포차, 포장마차, 편의점·심야식당, 룸살롱 등 8회 이상.

## 8. 클로징 (구조)

1. **실존 장소로 착지(85–91%)**: 지명·물줄기·마지막 주모·사망 연도를 구체적으로 대고, 지금은 복원만 된 빈 공간을 "~도 없다"의 부재 나열로 그림.
2. **통념 제시 → 반박(91–95%)**: 과거를 낙후로 보는 시선을 꺼낸 뒤, 본편 각 챕터의 핵심을 '가치의 이름'(신용, 따뜻함, 용기, 생명력, 지혜)으로 재호명해 나열. 사건 요약이 아니라 가치 목록으로 리캡.
3. **주제 재정의(95–97%)**: 주막 = 한 나라가 살아가던 방식. 신분과 무관하게 '사람'이 되는 곳.
4. **현재로 연결 + 도입 회수(97–100%)**: 오늘 밤 포장마차 앞에 멈추는 한 사람 장면 ↔ 옛 나그네가 용수 표지를 보고 멈추던 순간을 겹침(14% 지점의 용수 떡밥 회수). 마지막은 화자 1인칭으로 "함께 기억하고 싶었다"며 닫음.
- 유형: **정서적 착지형(현재 동일시 + 가치 리캡)**. 구독·좋아요 요청이나 다음 편 예고 없음.

## 9. 가져올 엔진 / 가져오면 안 되는 것

### 가져올 엔진 3개
1. **물리적 수치 미스터리로 여는 도입**: 개념(신용 제도) 대신 몸으로 느끼는 숫자(25kg)와 인물 하나로 열고, 답은 1/3 지점까지 보류. 답이 나오는 순간 현대 개념 이름을 붙여 '깨달음' 보상.
2. **현대 업종 환산 장치**: 낯선 조선 제도마다 오늘 아는 이름 하나를 붙여 이해·친근감을 동시에 확보. 단, '비슷하다'와 '기원/후손이다'를 구분해서 쓸 것.
3. **2단 원인 + 자기 정정 전환**: 몰락을 '불가피한 원인 → 진짜 원인'으로 쪼개고, "사라졌다 → 거의"로 마지막 사례를 끌어내는 리듬. 결말에서 도입부의 작은 소품(용수)을 현재 장면에 겹치는 회수.

### 가져오면 안 되는 것 3개
1. **출처 없는 핵심 수치의 단정**: '전국 10만 개 이상', '자영업의 20~25%'(4–5%, 10–12%, 결말 97%에서 반복)는 근거 제시가 없고 댓글에서도 수천~1만 개 추정으로 반박됨. 영상의 스케일 감각 전체가 이 숫자에 실려 있으니, 쓰려면 출처를 달거나 '추정'으로 낮춰야 함.
2. **야사급 일화를 제도로 일반화**: 세로셰프스키에게 주모가 했다는 제안(36–38%)을 근거 제시 없이 '전국 주막의 신용 결제 네트워크'로 확대하고, 다시 '여행자 수표·신용카드와 다를 바 없다', '근대 금융 원리 구현', '조선 낙후론 반박 증거'(38–41%)로 판정까지 올림. 연도도 1903년 방문인데 '19세기 말'로 서술하는 등 내부 불일치. 거절 이후 작가의 심리('문명 이해의 거부')도 화자의 창작 해석.
3. **극화·단정이 섞인 역사 서술**:
   - 정약용 일화(51–59%): 강진 백성이 모두 문을 닫았다는 대사형 재연, '유일하게 사람 대우'는 극화. 머문 곳(사의재) 자체는 기록이 있으나 주민 반응은 단정할 근거 부족(댓글도 반론).
   - 주모 출신 '기록에 따르면 기생·궁녀가 많았다'(45–48%) — 출처 미제시.
   - 가양주 '하루아침에 금지'(75–81%): 주세법(1909)·주세령(1916) 이후 면허제·단속으로 단계적으로 위축된 과정을 일거의 금지로 압축, 주막 소멸의 결정적 원인으로 단정. 도입의 '하룻밤 사이에 사라짐'과 본문의 '서서히'도 서로 어긋남.
   - 김홍도 → '한 세대 뒤' 신윤복(68%): 두 화가는 거의 동시대. 신윤복 그림을 '룸살롱'으로 환산한 것도 과잉 해석.
   - 찜질방 '직계 후손' 해석(24–28%): 기능 유사를 계보로 바꿔 말함.

## 10. 자막 상태

- **오류 정도: 중** — 문장 구조는 대체로 온전하나 고유명사·고어·한자어가 자주 깨지고, 한 곳은 아랍 문자가 섞여 나옴. 맥락으로 거의 전부 복원 가능.
- 고유명사·용어 오류 예 (자막 표기 → 교정 추정)
  - 바칠라프 세로셰프스키 → 바츠와프 세로셰프스키
  - 김몽도 → 김홍도
  - 사위제 → 사의재(四宜齋)
  - 유홍년 / 유혹년 → 유옥연(삼강주막 마지막 주모, 표기 확인 필요)
  - 옆전 → 엽전
  - 국려 / 국녀, 군궐 → 궁녀, 궁궐
  - 장톨뱅이 → 장돌뱅이
  - 몽로 주점 → 목로주점
  - 신장로 → 신작로
  - 가향주 → 가양주 / (아랍 문자)는 → 빚는
  - 흡길·흡기·흑먼지 → 흙길·흙먼지 / 초과집 → 초가집
  - 집계 후손 → 직계 후손 / 낳구된 → 낙후된 / 규모의 용기 → 주모의 용기
  - 수백일 → 수백 리 / 소단지 → 솥단지 / 진보따리 → 짐보따리
