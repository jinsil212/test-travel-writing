# 조선역사 작성 실험 (서브에이전트 방식)

2026-10-02 시작. 운영 폴더(`Documents/midform-writing`)와 별개인 실험 폴더다. 여기서 바꾼 것을 운영 폴더에 자동 반영하지 않는다.

대본 작업은 `대본쓰기` 스킬을 따른다. 우선순위는 흐름(기승전결·맥락) > 사실 > 말투. 참고하는 문서는 아래뿐이다. 예전 `_대본지침서.md`(200KB)는 쓰지 않는다.

- `조선역사/채널설정.md` — 시청자, 형식, 말투
- `조선역사/금지목록.md` — 20개 이하
- `조선역사/분석지/0NN_*/원문.txt` — **벤치마크 원고 전문. 이 수준이 기준이다.** 자동자막이라 오탈자가 있다. 문장은 가져오지 않는다.
- `조선역사/견본/` — 위 원고의 흐름 해부와 고유명사 교정표
- `조선역사/수정·선택 사례.md` — 사용자가 직접 고르고 고친 기록
- `조선역사/다룬주제.md` — 겹침 확인
- `조선역사/합격대본/` — 사용자가 합격시킨 대본 (생기면 벤치마크 원고와 함께 읽는다)

에이전트: `.claude/agents/` (참고영상분석, 사료조사, 대본작가, 흐름검수, 최종검수, 수정학습). 대본은 대본작가 1명이 처음부터 끝까지 쓴다.
도구: `도구/자막받기.py`, `도구/검사.py`

`_보관/`은 예전 원고·검수·지침 보관용. 읽지 않는다.
`조선역사/분석지/`에서 대본 작성에 쓰는 건 `원문.txt`뿐이다. 예전 `분석지.md`는 견본으로 대체됐다.
