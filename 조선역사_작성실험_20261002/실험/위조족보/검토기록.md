| S1 및 S1-1~7 | 베→옷감은 사용자 표현을 유지. 사헌부·수령·군포·호적·천거를 실제 등장 문맥에서 풀어 줌. ‘부담을 지운’ 중의성과 ‘실제 조상’의 지칭을 수정. 구매자의 항의를 간접 설명한 ‘우리 집안’은 시청자와 공유한다고 말한 화법이 아님. |
| S2 및 S2-1~4 | ‘이름’으로 족보 증거와 고발 신원을 묶은 추상 문장 삭제. ‘진짜라는 사실만으로 … 면제’라는 행동 뒤에 판단 오류를 설명. 사실 없는 가정 대구를 논평으로 만들지 않음. |
| S3 및 S3-1~4 | 조상 연결·군포 납부·옛 장부 대조의 재진술을 전체에서 대조하고 삭제/축소. 최종 선무군관 중복 안내도 삭제. 새 국면은 거래 이유와 행정 대응의 별도 답을 확인한 뒤 추가. |
| S4 및 S4-1~7 | ‘어떤 자리를 찾아 들어갔는지’→‘후손이 끊긴 자리’, ‘왕실이 만든 진짜 족보’→‘선원보략’, ‘그 장부를 찾아 대조’→‘옛 호적’으로 경계 연결. 영조로 돌아가는 곳은 ‘앞서 군포를 줄였던’으로 시점을 명시. |
| S5·S6·S7 | 군포·호적·선원보략 명칭을 유지. 진본 가격을 정가로, 고발자를 유죄 확정으로, 조사 중단을 무죄로 확대하지 않음. 정약용의 가벼운 벌 제안을 심한 처벌로 바꾸지 않음. |
| S8·S9·S10 | 끊긴 후손과 진본 오판을 한 문장으로 압축하지 않음. ‘그 벼슬아치’로 임명장의 원주인 명시. 김종협의 특정 배후·심리는 창작하지 않고 명령의 행동을 서술. |
| S11·S12·S13 | 문서가 진짜인데 왜 속았나를 먼저 받고 왕실 후손 확인 오류로 답함. 시청자 개인에게 교훈을 강요하지 않고 군포 면제의 판단으로 마무리. 채널 다른 전체 원고의 모든 매너리즘을 전수 검사한 것은 아님. |
| S14 | ‘엄하게 처벌하라는 요청’은 F1 조사 지시를 전달할 필요가 있어 유지. 처벌의 자극적 장면은 없음. 영상 제작물 미검사 범위는 위 표 참조. |
| G1·G2·G3 | 사실·비교·문맥 검토를 구별. 자수·추정 시간·해시는 보조 자료. 견본과 실제 진본 오판 문장의 기능으로 문체를 대조. 물음표·어미 비율을 목표로 만들지 않음. |
| G4·G5·G5-1·G5-2 | 마지막 파일 전문을 다시 열어 읽음. 핵심 답을 주는 문장, 삭제한 추상 문장, 유지한 행정 대응, 경계 문단을 실제 구절로 기록. 소리 내어 실제 낭독하거나 오디오로 검사한 것은 아님. |
| G6·G7 | 반복·관계 혼동·주체 반전이 다른 문단에도 있는지 전체 대조 후 수정. 내부 검수에서 문제를 못 찾았다는 것을 품질 보증·사용자 합격으로 바꾸지 않음. |

## 다음 비교에서 기록할 것

사용자가 시험본을 읽고 남기는 실제 수정 전후, 크게 다시 쓰는 문단, 수정에 걸린 시간을 이 편에 기록한다. 확정 선택과 보류를 구별하고, 한 문장만 고친 사례로 전체 품질을 판정하지 않는다. 첫 시험의 오류를 또 한 줄의 금지 규칙으로 운영 지침에 덧붙이기 전에, 이번 입력·검수 과정에서 실제로 걸러졌는지 확인한다.
