# _합격원고 — 1순위 견본

사용자가 **만족해서** 합격시킨 최종 대본만 여기에 둔다. 파일명은 `<편폴더명>.txt`.

- 2026-10-02 현재 **없음.** 「유럽음식짠맛」 최종본은 사용자가 "마음에 안 들었는데 그냥 넘긴 원고"라고 밝혀(2026-10-02) 합격본이 아니다. `참고자료/넘긴원고/`로 옮겼다. v1에서 사용자가 지운 방향(연구 과정·곁가지 삭제, 그림 부사, 말 걸기)은 여전히 참고하되, 그 원고의 수준을 통과선으로 쓰지 않는다.
- 여기에 파일이 하나라도 있으면 원고를 쓰기 전에 **전부 Read로 전문 열람**해야 한다(훅이 검사). 벤치마크 원문보다 우선한다.
- 사용자가 "이건 됐다"고 한 원고가 생기면 그때 넣는다. 그 전까지 `/대본검수` 통과선은 합격본 비율이 아니라 강 0건·약 최소다.
