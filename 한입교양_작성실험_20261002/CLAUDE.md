# 한입교양 작성 실험 폴더

`midform-writing/한입교양`의 복사본으로 **원고 작성 방식 실험용**이다. 원본 폴더는 건드리지 않는다.

## 원고를 쓸 때 (훅이 강제한다)

1. 쓰는 동안 여는 문서는 `한입교양/분석지/_쓰기전에_읽는_것.md`와 견본 전문뿐이다. 견본은 `한입교양/_합격원고/`(사장님이 직접 고친 최종본)가 1순위로 **전부**, `한입교양/분석지/원문/`의 벤치마크가 2순위로 2편 이상(지식팩토리 1 + 같은 유형 1).
2. 견본은 **Read 도구로 전문**을 연다. 요약·발췌·기억으로 대신하지 않는다.
3. 대본을 쓰기 전에 편 폴더에 **`쓰기전_설계.md`**(핵심 질문·문단표·용어표·훅 약속표)를 만든다. 틀은 `_쓰기전에_읽는_것.md` 4장. 없으면 대본 Write/Edit가 차단된다.
4. 공용 `_대본지침서.md`(이 폴더 사본)와 검수 기준서는 쓰는 동안 열지 않는다. 검수 패스에서 사실·수익화·표기만 본다. 내용 기준(S1·S2·S3·S4·S7·S8·S11·P9·H5·B2·G4)은 이미 `/대본검수` 기준표에 사용자 문장 그대로 들어 있다.
5. 초안 뒤 **사장님께 보여주기 전에** ① `python 한입교양/분석지/_계측_원고.py <대본>`으로 합격원고 열과 대조 ② `/대본검수`로 차가운 독자(별도 서브에이전트) 1차 → 문제 행 전부 고침 → 2차 독자 → `판정:` 기록. 대본을 쓴 세션은 판정 없이는 턴을 못 끝낸다(Stop 훅).
6. 사장님이 고친 문장은 규칙으로 만들지 않는다. `_쓰기전에_읽는_것.md` 2장 표(15줄 상한)에 전→후로 넣거나, 합격한 최종본을 `_합격원고/<편>.txt`로 넣는다. 합격본이 표보다 우선이다.

## 기획·제목·썸네일·TTS·출력 형식

채널설정의 사용자 확정 사항(화면 지시 금지, 제목·썸네일은 사용자 선택, 밈·속어 금지, TTS 절차)과 공용 P·T장을 그대로 따른다. 바뀐 건 "쓰는 동안 무엇을 보느냐"와 "보여주기 전에 무엇을 거치느냐"뿐이다.
