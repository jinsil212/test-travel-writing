# 대본검수 — 처음 읽는 사람의 눈으로 (내용 기준)

겉모양 계측(`분석지/_계측_원고.py`)이 못 보는 것을 본다. **문장과 문장이 이어지는가, 처음 듣는 사람이 멈추지 않는가, 훅이 약속한 걸 본문이 주는가, 같은 말을 또 하지 않는가.**

기준은 작업자가 만든 게 아니다. 공용 `_대본지침서.md`에서 사용자가 반려할 때 실제로 쓴 말을 그대로 가져왔다(아래 대조표). 사용자가 "이 기준은 왜 빠졌냐"를 확인할 수 있게 조항 번호를 남긴다.

## 절차 (순서를 바꾸지 않는다)

1. **차가운 독자를 따로 세운다.** 작성 맥락이 없는 쪽이 읽어야 한다. `Agent` 도구로 서브에이전트를 띄우고 **대본 파일 경로 + 아래 "독자 지시문"만** 준다. 작성 규칙·벤치마크·기획 문서는 주지 않는다. 독자가 결과를 `<편 폴더>/검수_v<N>.md`에 쓴다.
2. **문제 행을 전부 고친다.** 같은 파일에 `## 반영` 절을 붙여 행마다 "고친 구절"을 적는다. 안 고친 행은 이유를 적는다.
3. **2차 독자**(새 서브에이전트)에게 고친 대본을 다시 읽힌다. 통과 기준을 만족하면 검수 파일 맨 위에 `판정: 통과 (v<N>, 2차)`. 못 만족하면 한 번 더. 3차까지 안 되면 `판정: 미통과`로 적고 남은 문제를 사용자에게 보여준다.
4. 겉모양 계측 결과도 같이 붙인다. 둘 다 있어야 제출이다.

## 통과 기준 ("80%"의 정의 = 사용자 합격본 수준)

차가운 독자는 사용자가 합격시킨 원고에서도 문제를 잡는다(아래 보정 기록). 그래서 기준은 "0건"이 아니라 **합격본에서 나온 비율 이하**이고, 사용자가 실제로 반려했던 유형만 "강"으로 분류해 0건을 요구한다. 독자는 모든 행에 강/약을 표시한다.

**강 (0건이어야 통과) — 사용자가 실제로 반려한 유형**

| 유형 | 내용 | 근거 |
|---|---|---|
| 지칭 없는 지시어 | 그들·그 ○○·우리가 앞에서 지칭된 바 없음 | S1-3·S1-4·S4-3 |
| 설명 없이 먼저 나온 낯선 용어 | 중2가 멈추는 역사 용어·제도·외국 고유명사가 설명보다 먼저. 뒤에 설명 있어도 강 | S1-1 |
| 번역투 | 한국 사람이 실제로 안 쓰는 동사·목적어 조합 | S1-5 |
| 훅 약속 누락 | 훅이 예고한 것을 본문이 안 줌 | P9·H9 |
| 도입 답 선공개 | 도입에서 흔한 답의 판정·답의 방향까지 말함 | H4-2 |
| 뒤집은 대구·빈 추상어 | 새 사실 0개인 정리 문장 | S2·S2-1 |

**약 (통과선) — 문장 100개당 건수. 합격본이 없는 동안은 아래 값, 합격본이 생기면 그 평균으로 바꾼다**

| 유형 | 통과선 |
|---|---|
| 튐(받을 말 약함·방향 전환·멀리 있는 지시어) | ≤ 3 |
| 멈춤(압축·단위 전환·비유) | ≤ 2 |
| 같은 말(새 정보 없는 재진술) | ≤ 2 |
| 말이 안 됨·말투(비약·모순·교과서체) | ≤ 4 |
| 궁금증이 비는 문단 | 마지막 문단 외 0 |

사용자가 "그냥 넘긴" 원고는 합격본이 아니다(2026-10-02 한입교양 유럽음식짠맛). 그런 원고의 비율을 통과선으로 쓰지 않는다.

## 독자 지시문 (서브에이전트에 이대로 준다. <> 안만 채운다)

```
당신은 이 대본을 처음 읽는 사람이다. 유튜브 나레이션 대본이고 시청자는 <채널 시청자 한 줄>, 화면을 거의 안 보고 귀로 듣는다. 당신은 중학교 2학년 수준의 배경지식으로 읽되 <시청자가 아는 것으로 치는 이름들>은 안다고 친다. 대본을 쓴 사람의 의도나 다른 문서는 보지 말고 오직 이 파일만 읽어라.

대본 파일: <경로>

문장마다 번호를 매기며(마침표 기준, 문단이 바뀌어도 이어서) 처음부터 끝까지 한 번에 읽고, 아래 여섯 가지를 찾는다. 찾은 것은 "실제 구절"을 그대로 인용한다. 추측하지 말고 구절이 있는 것만 적는다. 없는 항목은 "없음". 모든 행에 강/약을 표시한다. 강 = 지칭 없는 지시어, 설명 없이 먼저 나온 낯선 용어, 번역투, 훅 약속 누락, 도입의 답 선공개, 새 사실 없는 정리 문장. 나머지는 약. 맨 끝에 총 문장 수와 항목별 건수를 적는다.

1. 튐: 이 문장이 바로 앞 문장의 무엇을 받는가? 받는 게 없으면 튄 것이다. 새로 나온 사람·장소·시대가 설명 없이 등장해도, "그·이·그때"가 가리키는 말이 두 문장 넘게 떨어져 있어도, 문단 경계에서 방향이 정반대로 바뀌어도 튄 것이다. 문장 사이에 "그래서·그런데·왜냐하면" 중 하나를 넣어 자연스러운지로 판단한다.
2. 멈춤: 중2가 "이게 뭐지?" 하고 멈출 자리. (가) 역사 용어·지명·제도·한자어·외국 고유명사가 설명보다 먼저 나옴 (나) 비유만 있고 무엇을 가리키는지 사실이 없음 (다) 글로는 멋있는데 들으면 무슨 소리인지 모를 압축 문장. 바로 앞이나 같은 문장에 설명이 있으면 멈춤이 아니다.
3. 안 지킨 약속: 첫 문단(훅)에서 보여주겠다고 한 것의 목록을 만들고 각각 본문 몇 번째 문장에서 지급됐는지 적는다. 없으면 누락.
4. 문단표: 문단마다 "이 문단이 하는 일 한 줄", "끝났을 때 새로 이해한 것 한 줄", "다음 문단으로 넘어갈 때 내가 궁금한 것 한 줄". 궁금한 게 없으면 "없음".
5. 같은 말: 같은 사실이나 같은 결론을 다시 말하는 문장. 어휘만 바꾼 것도 포함. 두 문장을 나란히 인용한다.
6. 말이 안 됨·말투: 앞에서 근거가 없었는데 던져진 질문, 앞 문장과 모순, 이유 없이 툭 던진 사실. 그리고 갑자기 뉴스·교과서·논문처럼 들리는 문장, 한국 사람이 실제로 안 쓰는 표현(번역투).

출력(마크다운, 아래 경로에 저장):
<편 폴더>/검수_v<N>.md

# 검수 v<N> — <1차|2차> (차가운 독자)
## 1. 튐
| 문장 번호 | 실제 구절 | 앞 문장에서 받을 말 | 왜 튀는가 | 고치면 좋을 방향 |
## 2. 멈춤
| 문장 번호 | 유형(용어/비유/압축) | 실제 구절 | 설명 있음/없음 | 한 줄 설명 제안 |
## 3. 훅 약속과 지급
| 훅의 약속 | 지급 문장 번호 | 지급 구절 | 상태 |
## 4. 문단표
| 문단 | 하는 일 | 새로 이해한 것 | 넘어갈 때 궁금한 것 |
## 5. 같은 말
| 문장 번호 쌍 | 구절 A | 구절 B | 두 번째에 새로 든 것 |
## 6. 말이 안 됨·말투
| 문장 번호 | 실제 구절 | 유형 |
## 7. 처음 읽은 사람으로서 한 줄
어디서 지루했고 어디서 재밌었는지 솔직하게 한두 줄.

저장한 뒤 채팅 답으로는 1·2·5·6의 건수와 가장 심한 문제 3개만 요약한다.
```

## 하지 않는 것

- 검수자가 대본을 고쳐 쓰지 않는다. 문제와 방향만 적는다. 고치는 건 작성자다.
- 통과 기준표에 없는 취향 지적을 늘리지 않는다.
- 겉모양 계측이 범위 안이라는 이유로 이 검수를 건너뛰지 않는다.
- 사용자가 이미 합격시킨 원고(`_합격원고/`)에 독자가 문제를 많이 잡으면, 원고가 아니라 **기준이 과한 것**이다. 그 항목은 기준표에서 낮춘다(보정 기록을 이 파일 맨 아래에 남긴다).
