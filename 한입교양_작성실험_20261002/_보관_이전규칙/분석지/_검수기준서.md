# 한입교양 검수 기준서 — 초고를 벤치마크형 원고로 다듬기

> **이 문서를 받는 사람:** 초고를 검수하고 수정하는 AI.
> **목적:** 작성자가 쓴 한입교양 초고를, 조회수가 높았던 벤치마크 원고(지식팩토리, 지식 브런치)의 특징에 맞게 **문맥, 흐름, 한국어 표현을 다듬어** 완성도를 높인다.
> **수정 범위:** 초고를 통째로 갈아엎지 않는다. 문맥, 흐름(순서, 연결, 전환), 문장과 표현은 고칠 수 있다. 핵심 주제, 확정 문구, 사실은 바꾸지 않는다(0장).
> **근거 수치:** 같은 폴더의 [_계측_18편.md](_계측_18편.md). 구성 유형은 [_구성유형_기승전결.md](_구성유형_기승전결.md). 벤치마크 원문은 [원문/](원문/).
> 2026-09-19 작성, 2026-09-24 벤치마크 18편으로 갱신. 벤치마크 관찰과 이 채널 사용자 지적(../수정·선택 사례.md)에서 뽑았다. 사용자가 합격시킨 원고는 아직 없으므로, 기준은 합격 원고가 쌓이면 갱신한다.

## 0장. 먼저 지킬 것

### 0-1. 채널 조건

| 항목 | 조건 |
|---|---|
| 채널 | 한입교양 — 밥상에서 시작하는 세계의 ‘왜?’. 음식과 식습관을 중심으로 나라마다 다른 이유를 역사, 과학, 문화로 풀어 준다 |
| 시청자 | 음식과 여행에 관심 있는 일반 한국 성인. 사전 지식 없이 처음 듣고도 따라올 수 있어야 한다 *(사용자 확정 전 작업 기준)* |
| 주체 | **“한국 사람·우리 입·우리 식탁”의 자리에서 본다.** 누구의 경험, 누구의 기준인지 문장 안에 드러나야 한다 |
| 말투 | 존댓말. “~습니다”, “~요”, “~죠”를 섞는다(벤치마크 비율: ~니다 약 50%, ~요 약 40%). “~했다/~이다”로 끝나는 다큐 내레이션 금지 |
| 분량 | 공백 제외 글자 수. 벤치마크 실측 속도 분당 약 300자 기준 **최소 10분 = 3,000자 이상**. 요청서 목표가 있으면 따른다. 수정 후 분량은 초고의 ±10% 안 |
| 화면 | 직접 만든 AI 이미지와 표·그래프. **대본 본문에 화면 지시(`[AI 이미지: …]` 등)를 넣지 않는다** |
| 형식 | 소제목 없이 문단과 빈 줄만. 가운뎃점(·) 쓰지 않음(낭독이 깨진다). 나열은 “A, B, 그리고 C” |

### 0-2. 고치면 안 되는 것 (고정)

1. **제목과 썸네일 문구** — 요청서의 확정 문구. 한 글자도 바꾸지 않는다.
2. **사용자가 확정한 도입부** — 요청서에 “도입 확정”이 있으면 그 문단들은 그대로 둔다. 문제가 보이면 고치지 말고 보고서 ‘확정 구간 의견’에 적는다.
3. **핵심 주제, 핵심 답, 본문 비중** — 초고가 답하는 질문, 그 답, 요청서에 적힌 비중(예: “유럽 쪽 이유 중심, 우리 쪽 이유는 보완”)을 바꾸지 않는다.
4. **사실, 숫자, 연도, 출처** — 바꾸거나 새로 넣지 않는다. 틀려 보이면 고치지 말고 보고서 ‘사실 의견’에 적는다.
5. **초고 아래의 제작 메모, 출처** — 그대로 둔다.

### 0-3. 하면 안 되는 수정

| 금지 | 이유 |
|---|---|
| 새 소재, 새 사례, 새 나라, 새 음식 추가 | 곁가지가 생기고 사실 확인이 안 된 내용이 들어온다 |
| 시청자 경험을 부풀리기(“대부분”, “누구나”, “꼭”) 또는 근거에 없는 대상 덧붙이기 | 사용자 반려 사례(기준 18) |
| 장면을 특정 장소·가게로 좁히기(“로마의 작은 식당”) | 사용자 반려 사례. 장면은 많은 사람이 겪는 일반 상황으로(기준 18) |
| 도입에서 흔한 답의 판정이나 답의 방향 말하기 | 답을 미리 준 느낌. 사용자 반려 사례(기준 3) |
| “~했다” 내레이션, 반말 내레이션 | 채널 말투가 아니다 |
| “충격”, “소름”, “경악” 같은 감정어 | 기대만큼 못 주면 실망을 산다(기준 16) |
| “이유는 세 가지입니다”처럼 번호를 먼저 세우고 채우기 | 한입교양 기본형은 추리형이다(기준 10) |
| 건강 훈계(“줄여야 합니다”)로 마무리 | 주제 밖. 시청자 속을 긁는다 |
| 화면 지시, 소제목, 가운뎃점 넣기 | 0-1 형식 |
| 벤치마크 문장을 옮겨 붙이기 | 구조와 기능만 가져온다. 문장까지 가져오면 표절이고 수익화 심사에 걸린다 |

## 1장. 작업 순서

순서를 바꾸지 않는다. 각 단계의 표는 보고서(6장)에 그대로 넣는다.

1. **초고 전문을 끝까지 읽는다.** 제목, 썸네일, 요청서도 함께 읽는다.
2. **진단 표 세 개를 채운다**(2장): 약속 사슬 표 → 구간 지도 → 계측표.
3. **기준 1~24로 판정한다**(3장). 기준마다 통과 / 수정 필요 / 확정 구간이라 보고만.
4. **고친다.** 우선순위: ① 🔴 반드시 ② 🟡 권장. 한 곳을 고치면 앞뒤 두 문단을 이어서 다시 읽는다.
5. **수정본을 처음부터 다시 읽고**, 진단 표 세 개를 수정본 기준으로 다시 채운다.
6. **보고서를 낸다**(6장): 수정본 전문 + 변경표 + 수정 전후 진단 표.

## 2장. 진단 도구

### 2-1. 약속 사슬 표 (가장 먼저)

시청자는 제목과 썸네일이 던진 질문 하나 때문에 누른다. 그 질문이 도입, 본문, 마무리까지 이어져 답이 나오는지 본다.

| 자리 | 초고의 실제 문장 | 위치(%) | 제목 질문과 같은 이야기인가 |
|---|---|---|---|
| 제목 | | — | — |
| 썸네일 | | — | |
| 첫 문장 | | 0 | |
| 도입 마지막 문장 | | | |
| 핵심 답이 나오는 문장 | | | |
| 썸네일 문구가 풀리는 문장 | | | |
| 마무리에서 처음 장면을 다시 부르는 문장 | | | |

**위치(%) 재는 법:** 낭독문을 공백을 뺀 글자로 센다. 그 문장이 시작하기 전까지의 글자 수 ÷ 전체 글자 수 × 100.

### 2-2. 구간 지도

문단마다 한 줄. 흐름이 한눈에 보인다.

| 문단 | 시작 위치(%) | 첫 구절 | 이 문단이 하는 일 | 표시 |
|---|---|---|---|---|
| 1 | 0 | | 예: 장면 / 모순 / 통념 확인 / 흔한 답 정정 / 증거 이야기 / 원리 / 핵심 답 / 반증 확인 / 한국 쪽 이야기 / 회수 / 댓글 질문 | 전환, 씨앗, 반박, 핵심 답, 회수 자리에 표시 |

### 2-3. 계측표

벤치마크 18편(지식팩토리 6, 지식 브런치 4, 교양만두 5, 지식해적단 3)에서 잰 범위를 옆에 두고 비교한다(근거: [_계측_18편.md](_계측_18편.md)).

| 항목 | 재는 법 | 벤치마크 범위 | 우리 합격선 | 초고 값 |
|---|---|---|---|---|
| 분량 | 공백 제외 글자 수 | 지식팩토리·지식해적단 분당 310~320자, 교양만두 310~370자 | 분당 310자로 계산해 최소 10분 = 3,100자 이상 | |
| 도입 비율 | 도입 마지막 문장 끝 위치(%) | 잘된 지식팩토리 2.9~3.8% / 브런치 6.6~14.1% / 부진 에어컨 12.5% | **7% 이하 권장** | |
| 도입 문장 수 | 첫 문장부터 도입 끝까지 | 잘된 지식팩토리 7~8문장 / 부진 22문장 | **12문장 이하 권장** | |
| 뜻밖의 사실(모순) 위치 | 도입에서 “어? 왜?”가 처음 생기는 문장 번호 | 2~5번째 | **5번째 문장 이내 권장** | |
| 제목 핵심어의 최장 공백 | 제목의 핵심 단어(같은 뜻의 말 포함)가 나오는 위치들 사이 가장 긴 간격(%p) | 추리형·비교형 4.8~26.2%p / 기원형은 31~38%p까지 벌어진다(후반에 다른 음식으로 갈아탐) | 추리형·비교형 **25%p 미만**, 기원형은 갈래마다 원래 음식으로 돌아오는 문장이 있으면 통과 | |
| 첫 전환 위치 | 흐름의 방향이 바뀌는 첫 문장 | 추리형 33~42% / 기원형 25~48% / 비교형 26~34% / 나열형 9~17%(목차 선언) | **20~48%** | |
| 핵심 답 위치 | 2-1의 핵심 답 문장 | **유형마다 다르다.** 추리형 50~81% / 기원형 34~47% / 비교형 69~97% | 요청서에 적힌 유형의 범위 안. 유형이 없으면 45~85% | |
| 마무리 비율 | 마무리 시작부터 끝까지 | 대부분 3~10%(짠 음식만 19.8%) | **12% 이하** | |
| 질문 비율 | 물음표로 끝나는 문장 ÷ 전체 문장 | 지식팩토리 4.9~9.9% / 브런치 1.2% | **3~10%** | |
| 문장 평균 길이 | 공백 제외 글자 ÷ 문장 수 | 21.9~27.4자 | **30자 이하 권장.** 한 문장에 새 정보는 하나 | |
| 어미 | 문장 끝: ~니다 / ~요 / ~죠 / ~다 | 지식팩토리 ~니다 49~51%, ~요 36~42% | **~다(평서) 0개.** ~니다와 ~요·~죠를 섞는다 | |

## 3장. 기준 1~24

**등급:** 🔴 반드시(발견하면 고친다) · 🟡 권장(흐름을 해치지 않는 범위에서 고친다) · ⚪ 보고만(확정 구간이거나 사실 문제라 고치지 않고 적는다)

각 기준은 **본다 → 근거 → 재는 법·합격선 → 고치는 법 → 고친 예** 순서로 적었다. 근거의 인용은 자막을 짧게 옮긴 것이다(원문 오타 교정).

### A. 클릭 이유를 끝까지 책임지는가

#### 기준 1. 핵심 질문이 다섯 자리에 모두 이어진다 🔴
- **본다:** 제목, 썸네일, 첫 문장, 도입 끝, 마무리가 같은 질문을 이야기하는가.
- **근거:** 「안주」 — 제목은 서양에 안주가 없는 이유, 첫 문장은 서양 영화 속 바의 위스키, 마무리는 “안주가 없는 건 서양이 아니었다”로 같은 질문에 답한다.
- **합격선:** 2-1 표의 모든 칸이 같은 질문.
- **고치는 법:** 어긋난 자리의 문장을 제목 질문 쪽으로 돌린다. 제목, 썸네일, 확정 도입은 고정이므로 본문과 마무리 쪽을 고친다.

#### 기준 2. 주체가 문장 안에 있다 🔴
- **본다:** 누구의 경험·입맛·기준인지. “유럽 음식이 짠 이유”처럼 주체가 빠지면 객관적 사실처럼 들리고, 두 집단 비교가 주제처럼 읽힌다.
- **근거(사용자 지적):** 기획 단계에서 “한국 사람이 짜게 느끼는 이유”와 “유럽인과 한국인이 다르다”가 섞여 헷갈린다는 지적을 받았다.
- **재는 법:** 핵심 답 문장, 문단 첫 문장마다 “이 문장의 주어와 기준은 누구인가”를 적는다.
- **고치는 법:** “우리 입에”, “한국 사람에게는”처럼 주체를 넣는다. 비교 수치는 “양 때문은 아니다”를 보여 주는 증거로만 쓰고 주제로 키우지 않는다.

#### 기준 3. 도입은 질문까지만 세운다. 판정과 답의 방향은 본문에서 🔴(도입 확정이면 ⚪)
- **근거(사용자 지적):** 도입에서 “흔한 답 두 가지 → 둘 다 답이 아니다 → 실마리는 우리 밥상”까지 말하자 답을 미리 알려 준 느낌이라는 지적을 받았다. 「사자고기」 도입도 흔한 답을 말하지 않고 “먹어 본 사람들이 있었다”는 단서만 준다.
- **재는 법:** 도입에서 준 것 / 남긴 것을 각각 문장으로 적는다.
- **고치는 법:** 도입의 판정 문장과 답의 방향 문장을 본문 첫 구간으로 옮긴다. 도입 끝은 본문 첫 과정을 판정 없이 가리킨다(예: “먼저 ~인지부터 확인해 보겠습니다”).

#### 기준 4. 핵심 답까지 가는 길에 질문을 놓치지 않는다 🔴
- **근거:** 8편 모두 제목 핵심어의 최장 공백이 27%p 미만이다. 「사자고기」는 탐험가 이야기 뒤 “그런데 쓰러진 건 고기가 아니라 간 때문”으로 질문을 다시 잡는다.
- **재는 법·합격선:** 계측표 ‘제목 핵심어의 최장 공백’ **25%p 미만.**
- **고치는 법:** 공백 구간 중간, 설명 한 단계가 끝나는 문단 끝에 **지금 설명과 핵심 질문을 잇는 한 문장**을 넣는다. 답을 미리 말하지 않는다.

#### 기준 5. 곁가지가 없다 🟡
- **근거:** 부진한 「에어컨」은 사망자 통계와 2003년 참사로 도입과 앞부분을 채웠다(제목 질문인 ‘왜 에어컨이 없나’의 답은 27% 이후).
- **재는 법:** 구간 지도에서 핵심 질문과 이어지지 않는 문단을 찾고 비율을 적는다.
- **고치는 법:** 핵심과 어떻게 이어지는지 한 문장으로 연결할 수 있으면 연결 문장을 넣는다. 이어지지 않으면 줄이되, 통째로 삭제할 때는 보고서에 이유를 적는다.

#### 기준 6. 썸네일 문구의 약속이 풀린다 🔴
- **재는 법:** 썸네일이 묻거나 약속한 말이 본문 몇 %에서 풀리는지 적는다.
- **고치는 법:** 풀리는 문장이 없으면 핵심 답 근처나 마무리에서 썸네일의 말을 받는 문장을 만든다(썸네일 문구 자체는 고정).
- **고친 예(우리 원고):** 썸네일 “유럽 음식엔 두 손 든 이유?” → 80% “그런 입에 … 그대로 닿으니 두 손을 드는 것도 무리가 아닙니다.”

#### 기준 7. 마무리는 처음 장면을 새 뜻으로 거두고, 시청자가 할 일이나 말할 거리를 준다 🔴
- **근거:** 「안주」 도입 2번째 문장의 “소주 앞 안주 접시” → 마무리에서 “소주 옆에 놓인 안주 접시는 우리만의 유별난 습관이 아니다”로 새 뜻을 얻어 돌아온다. 「사자고기」는 참치캔을 딸 때 떠올릴 한 장면으로 닫는다. 두 편 모두 취향이나 경험을 묻는 댓글 질문으로 끝난다.
- **고치는 법:** 도입의 장면 하나를 마무리 첫 부분에서 다시 부르고, 본문을 거친 뒤 달라진 뜻을 한 문장 붙인다. 요약만 되풀이하는 문장은 줄인다. 댓글 질문은 하나만.

### B. 도입과 흐름

#### 기준 8. 뜻밖의 사실(모순)이 다섯 문장 안에 🟡(도입 확정이면 ⚪)
- **근거:** 「사자고기」 4번째 문장에서 “사자고기 파는 곳은 어디에도 없다”, 「안주」 5번째 문장에서 “100년 전 미국 술집은 안주를 공짜로 줬다”.
- **고치는 법:** 모순 문장을 앞으로 당기거나, 그 앞의 배경 문장을 줄인다.

#### 기준 9. 도입은 짧게: 7% 이하, 12문장 이하 🟡(도입 확정이면 ⚪)
- **근거:** 잘된 지식팩토리 두 편은 3~4%, 7~8문장. 부진한 「에어컨」은 12.5%, 22문장.
- **고치는 법:** 질문과 상관없는 배경, 통계, 정의부터 뺀다. 도입의 사실은 모두 질문 하나를 향해야 한다.

#### 기준 10. 흐름이 요청서에 적힌 유형과 맞는다 🟡
- **유형(자세한 근거: [_구성유형_기승전결.md](_구성유형_기승전결.md))**
  - **A 추리형**(제목이 “왜 그럴까”): 흔한 답 깨기 → 연도·장소·인물이 있는 증거 → 진짜 답 한 문장 → 반대 사례로 검증 → 한국 쪽 이야기. 안주(66만), 사자고기(56만).
  - **B 기원형**(“언제부터, 어쩌다”): 그 음식이 없던 조건 → **탄생 장면(사람 한 명, 한 순간)** → 위기나 라이벌 → 확산과 파생 3~5갈래. 교양만두 국밥(380만), 라면(440만), 삼겹살(250만).
  - **C 비교형**(“왜 우리만”): 둘 다 같았던 출발점 → 상대가 달라진 조건 → 우리가 그대로인 조건 → 오늘 남은 차이. 지식해적단 숟가락(172만), 지식 브런치 생선(152만).
- **재는 법:** 구간 지도를 보고 초고가 어느 유형인지 한 줄로 적고, 요청서의 유형과 핵심 답 위치를 대조한다.
- **고치는 법:** 유형을 바꾸지 않는다. 초고가 “첫째, 둘째”로 번호만 이어 붙였으면 번호를 지우고, 앞 갈래에서 생긴 궁금증으로 다음 갈래를 여는 문장을 넣는다. 기원형 후반이 나열로 처지면 **갈래마다 사람과 장면을 붙였는지** 확인한다(교양만두가 지루해지지 않는 이유). 없으면 초고 안의 사실로만 장면을 살리고, 새 사례는 만들지 않는다.

#### 기준 11. 전환은 20~45%에 한 번은 분명히 🟡
- **근거:** 추리형 첫 전환 33~42%(“그런데 미국이 원래 그랬을까요?”).
- **고치는 법:** 전환 문장이 흐리면 기준이 깨지는 문단 첫머리를 “그런데 + 무엇이 달랐는지”로 분명히 한다. 새 내용을 만들어 전환을 만들지 않는다.

#### 기준 12. 시청자 반박을 먼저 말하고 바로 답한다 🟡
- **근거:** 「사자고기」 “사람들이 흔히 대는 이유가 둘 있습니다. 사나워서 못 잡는다 …” → 바로 반박. 원본 댓글에서 가장 많았던 반박(“참치는 먹잖아”)을 본문에서 먼저 다룬다.
- **고치는 법:** 초보자가 품을 반박이 뻔한 자리에 반박 한 문장 + 즉답 한 문장. 한 편에 2~3번이면 충분.

#### 기준 13. 앞에 심은 것은 모두 거둔다 🔴
- **근거:** 「안주」의 “세상에 공짜 점심은 없다”는 앞에서 심은 공짜 점심 이야기를 뒤에서 속담으로 거둔다.
- **재는 법:** 도입과 본문 앞부분의 음식 이름, 장면, 숫자를 목록으로 적고 뒤에서 다시 쓰이는 위치를 짝짓는다.
- **고치는 법:** 짝이 없는 것은 뒤에서 한 문장으로 잇거나 앞에서 뺀다(확정 도입이면 뒤에서 잇는다).

#### 기준 14. 음식 이름, 개념 용어는 정체가 먼저, 이름은 나중 🟡
- **근거:** 「돼지고기」 “선모충” 앞에 “돼지고기의 기생충”을 먼저 말한다.
- **고치는 법:** 낯선 음식·용어가 처음 나오는 문장에서 무엇으로 만든 무엇인지를 먼저 말한다.
- **고친 예(우리 원고):** “관찰레” → “돼지 볼살을 소금에 절여 말린 관찰레”, “페코리노” → “양젖으로 만든 짭짤한 치즈 페코리노”.

#### 기준 15. 숫자는 한국 사람이 아는 것으로 바꿔 준다 🟡
- **근거:** 「사자고기」 “서울만 한 땅에 몇십 마리”, 「에어컨」 “우리나라 전국 초중고를 합친 것과 맞먹는 숫자”, 「안주」 “서태지 데뷔 한 해 전”.
- **고치는 법:** 핵심 숫자 옆에 비교가 없으면 초고 안의 다른 사실로 만들 수 있는 비교만 쓴다. **새 수치를 만들지 않는다**(0-2). 만들 수 없으면 보고서에 제안으로 적는다.

### C. 한입교양 특유

#### 기준 16. 과장하지 않는다 🔴
- **근거:** 「사자고기」는 “죽는 고기가 아니라 먹을 수 있는 고기”라고 먼저 선을 긋고 간다. 우리 초안은 소금세 이야기를 “평생 노를 저어야”로 부풀렸다가 실제 기록(재범 몇 년)으로 고쳤다.
- **고치는 법:** 가능성을 확정처럼, 일부를 전부처럼 쓴 문장을 바로잡는다. 감정어를 넣지 않는다.

#### 기준 17. 한국 쪽 이야기가 한 구간 있고, 비교는 공정하다 🟡
- **근거:** 「안주」 조선 주막, 「사자고기」 경북 돔배기, 「돼지고기」 조선 태종 때 기록. 잘된 세 편 모두 후반에 한국 사례로 한 번 더 뒤집는다.
- **고치는 법:** 한국 쪽 구간이 있으면 그 구간이 제목 질문의 답에 어떻게 이어지는지 연결 문장을 확인한다. 없으면 보고서에 제안으로만 적는다(새 소재 금지). 비교는 같은 조건끼리인지 본다(예: 조사 방법이 다른 수치를 섞지 않는다 — 다르면 “딱 잘라 비교할 수는 없다”는 단서가 문장 안에 있어야 한다).

#### 기준 18. 시청자 경험은 근거 범위 안에서, 일반 상황으로 🔴
- **근거(사용자 지적):** “로마의 작은 식당”은 너무 구체적이라는 지적, 댓글엔 파스타만 있는데 피자와 식전빵까지 덧붙였다는 지적, “꼭 나온다”는 일반화 지적.
- **재는 법:** 도입과 본문의 “많은 분이”, “다들”, “여행 가면” 같은 경험 문장을 모아, 초고 제작 메모의 근거(댓글, 기사)와 대조한다.
- **고치는 법:** 근거보다 넓으면 “적지 않다”, “~하는 사람도 있다”로 좁힌다. 근거에 없는 대상은 뺀다. 특정 장소는 “유럽 여행을 가서”처럼 일반 상황으로 바꾼다.

### D. 문장과 말투

#### 기준 19. 사실 뒤에 뜻 한 줄, 꾸미려고 돌려 말하지 않기 🔴
- **판단 한 줄 근거:** 「사자고기」 숫자 계산 뒤 “소 50마리를 먹여서 소 한 마리보다 적은 고기를 얻는 겁니다”처럼 숫자의 뜻을 바로 붙인다.
- **꾸민 번역투:** 쉽게 말할 수 있는 내용을 돌려 말한 문장. 세 모양:
  - 어울리지 않는 동사: “뽀꼬 살레를 챙겨 가는” → “외워 가는”, “더 먹음직스럽게 굽히게” → “겉이 더 잘 구워지게”
  - 추상적인 말을 물건처럼: “이 차이 뒤에는 ~가 있습니다” → “이렇게 되는 이유는 ~ 때문입니다”
  - 뭔지 안 밝히고 가리키기: “놀라운 숫자가 있습니다” → 숫자와 무엇의 숫자인지를 바로
- **재는 법:** 소리 내어 읽고 ① 한국 사람이 이럴 때 이 동사를 쓰나 ② 이 말이 가리키는 게 뭔지 바로 말할 수 있나 ③ 비유를 빼면 더 쉬운가.

#### 기준 20. 말투는 존댓말만, 같은 어미가 네 번 넘게 이어지지 않게 🔴
- **합격선:** ‘~다’ 평서 어미 0개. ~니다와 ~요·~죠를 섞는다(지식팩토리 비율 약 5 : 4). 반말은 속마음을 짧게 대신 말할 때만.

#### 기준 21. 대상, 행동, 조건, 비교 기준을 같은 문장에 🔴
- **왜:** “4배”만 말하면 무엇의 4배인지 모른다.
- **고친 예(우리 원고):** “파르마 햄은 김치보다 짜다” → “포장 배추김치는 100그램에 나트륨이 평균 570밀리그램 정도입니다. 파르마 햄은 같은 무게에 그 서너 배가 들어 있어요.”(비교 조건 = 같은 무게)

#### 기준 22. 문단 사이에 다리가 있고, 지시어는 받을 말 가까이 🔴
- **왜:** 앞 문단에서 생긴 궁금증을 받아 다음 문단이 시작해야 한다. “그 ○○”가 가리키는 말이 멀면 이름을 다시 부른다.
- **고친 예(우리 원고):** 도입에서 한참 지난 뒤 “그 까르보나라 접시” → “처음에 본 그 까르보나라 접시”. 파트 끝 “매 끼니 빠지지 않는 음식이 하나 더 있어요.” → 다음 문단 “바로 빵입니다.”
- **재는 법:** 문단 사이에 “그래서, 그런데, 왜냐하면, 그러니까” 중 하나가 자연스럽게 들어가는지 본다(실제로 넣으라는 뜻은 아니다).

#### 기준 23. 같은 설명, 같은 질문을 되풀이하지 않는다 🔴
- **고치는 법:** 되풀이하는 문장을 지우고, 다시 부를 필요가 있으면 새 뜻을 붙인다(예: 온도 원리는 한 번 설명하고, 두 번째는 “앞에서 말한 것처럼” + 새 사례만).

#### 기준 24. 한국어로 자연스럽다 🔴
- **보는 것:** 주어와 서술어가 맞는가 / 지시어가 무엇을 받는지 분명한가 / 한 문장에 새 정보가 둘 이상 몰리지 않았는가 / 쉼표로 이어 붙여 늘어지지 않았는가 / 같은 조사·어미가 연달아 반복되지 않는가 / 불필요한 피동·명사형(“~하는 것이다”, “~에 있어서”) / 음식과 양념 사실이 맞는가(예: 떡볶이 양념은 “간장과 설탕”이 아니라 “고추장과 설탕”)

## 4장. 원형 4편 — 초고 옆에 펼쳐 놓고 비교하기

원문 전문은 [원문/](원문/)에 있다. 여기서는 도입의 흐름과 본문 뼈대를 설명한다. 인용은 짧게 줄였다.

### 4-1. 「사자고기」(지식팩토리, 56만) — 흔한 답을 깨는 추리형 기본형 · 도입 8문장, 2.9%

| # | 도입의 흐름 | 하는 일 |
|---|---|---|
| 1~3 | 마트 정육 코너를 떠올리게 하고 소, 돼지, 닭을 늘어놓은 뒤 “전부 풀이나 곡식을 먹는 짐승” | 누구나 아는 장면 |
| 4 | 사자, 호랑이 고기를 파는 곳은 없다 | 뜻밖의 공백 |
| 5 | “왜일까요?” | 질문 |
| 6 | 사나워서, 맛이 없어서라고 생각하지만 답을 아는 사람은 드물다 | 흔한 답을 꺼내기만 함(판정은 본문) |
| 7~8 | 실제로 먹어 본 사람들이 있었고, 그들에게 벌어진 일이 답 | 단서로 진입 |

**본문 뼈대:** 흔한 답 두 개를 논리로 깸 → 탐험가 세 명의 기록(연도, 장소, 인물) → 33% 전환 “쓰러진 건 고기가 아니라 간 때문” → 원리(독이 쌓인다) → 37% 중간 구독 부탁 → 50% 진짜 답 “구할 수 없었다” + 소 50마리 계산 → 57% 반증 “바다 물고기는 먹는다” → 70% 한국 막 경북 돔배기 수은 → 91% 정리 → 98% 댓글 질문 → 참치캔 회수.
**배울 점:** 흔한 답을 먼저 깨고, 반대 사례로 답을 검증하고, 한국 사례로 한 번 더 뒤집는다.
**따라 하지 말 것:** 중간 구독 부탁이 이야기 흐름을 끊는 느낌이 있다. 우리 채널은 넣지 않아도 된다.

### 4-2. 「안주」(지식팩토리, 66만) — 통념을 뒤집는 형 · 도입 8문장, 3.8%

| # | 도입의 흐름 | 하는 일 |
|---|---|---|
| 1~2 | 서양 영화 속 위스키 한 잔 vs 우리의 안주 접시 | 익숙한 대비 |
| 3~4 | “서양은 안주 없이 마신다, 다들 그렇게 알고 계실 겁니다” | 통념 세우기 |
| 5~6 | 그런데 100년 전 미국 술집은 안주를 공짜로 줬고, 없앤 건 법이었다 | 뜻밖의 사실 |
| 7~8 | 무슨 일이 있었는지 질문 → 먼저 우리가 아는 모습부터 확인 | 진입 |

**본문 뼈대:** 유럽 펍 경험 → 영국 펍에 부엌이 없던 이유 → 42% 전환 “그런데 미국이 원래 그랬을까요?” → 공짜 점심 역사 → 58% “세상에 공짜 점심은 없다” → 68% 금주법 → 70% 지금도 남은 바의 땅콩 접시 → 73% 러시아, 중동, 스페인 확장 → 81% 공통점 “독한 술을 마시는 나라엔 안주가 있다” → 83% 조선 주막 → 동아시아인 체질 → 94% 정리, 도입의 “소주 앞 안주 접시”로 회수 → 댓글 질문(어떤 짝을 좋아하나).
**배울 점:** 도입의 통념을 중반에 정면으로 뒤집고, 앞에서 심은 ‘공짜 점심’을 속담으로 거둔다.
**따라 하지 말 것:** 러시아, 중동, 스페인 확장 구간이 사례 나열에 가깝다.

### 4-3. 「생선」(지식 브런치, 152만) — 원인 나열형 · 도입 12문장, 6.6%

**도입:** 바다 나라 이름 나열 → 그런데 식탁엔 바다가 없다 → 아시아는 다르다 → “이 영상의 질문은 이것입니다” + 제목 질문.
**본문 뼈대:** 통계로 확인 → 17% “이유는 여러 개” → 북대서양(위험한 바다) → 지중해(먹을 게 없는 바다) → 갯벌 → 풍요로운 땅 → 비린내 → 종교와 신분 → 93% “다시 정리하자면”.
**배울 점:** 질문을 도입 끝에 그대로 적고, 이유마다 자연·지리 근거를 붙인다. 한국 갯벌 대비가 공감을 만든다(댓글 다수).
**따라 하지 말 것:** “첫 번째, 두 번째” 나열이 이어져 중반 긴장이 약하다. 마무리가 요약 반복이다.

### 4-4. 「에어컨」(지식팩토리, 112회) — 반면교사 · 도입 22문장, 12.5%

**도입:** 폭염 사망자, 영안실, 학교 휴교 통계를 길게 이어 간다.
**배울 점(반대로):** 무거운 뉴스로 시작하고, 제목 질문의 답이 27% 이후에야 “이유가 세 가지”로 나온다. 음식이 아닌 주제라 이 채널 시청자와도 어긋났다.
**가져올 교훈:** 도입은 짧게, 음식이나 식탁 장면으로, 답의 목차 대신 모순으로.

## 6장. 요청서와 보고서 양식

### 6-1. 요청서 (사용자가 채워서 검수 AI에게 준다)

```
[요청서]
대상 원고 파일:
제목(고정):
썸네일 문구(고정):
도입: 확정 / 미확정   (확정이면 고정 구간: 첫 문단 ~ "……" 문단)
핵심 주제 한 문장(주체 포함):
본문 비중: (예: 유럽 쪽 이유 중심, 우리 쪽 이유는 보완)
참고할 원형: 사자고기 / 안주 / 생선 / 기타(       )
분량: 최소 10분(3,000자 이상), 목표(       )
고칠 범위: 문장·표현 / 흐름(순서·연결)까지
특히 봐 줄 것: (예: 흐름 연결, 한국어 표현, 중반 지루함)
```

### 6-2. 보고서 (검수 AI가 돌려준다)

1. **수정본 전문** — 소제목 없이 문단 나눔 유지. 화면 지시 없음. 제작 메모와 출처는 그대로 뒤에.
2. **변경표** — 바꾼 곳마다 한 줄.

| # | 위치(%) | 고치기 전 | 고친 뒤 | 기준 번호 | 이유(한 줄) |
|---|---|---|---|---|---|

3. **진단 표 전후 비교** — 약속 사슬 표, 구간 지도, 계측표를 초고 값 / 수정본 값으로.
4. **기준 1~24 판정표** — 기준마다 통과 / 수정함 / 보고만, 근거가 된 실제 문장.
5. **확정 구간 의견** — 고정이라 고치지 않았지만 기준에 걸린 곳.
6. **사실 의견** — 틀려 보이지만 고치지 않은 숫자와 주장.

**보고서 규칙:** “자연스럽게 다듬음”처럼 뭉뚱그리지 않는다. 모든 변경에는 기준 번호가 있어야 한다. 기준 번호를 댈 수 없는 수정은 하지 않는다.

## 7장. 흔한 실수 — 검수 AI가 하지 말 것

- 벤치마크 문장을 그대로 옮겨 붙이기(구조와 기능만 가져온다).
- 흐름을 고친다며 문단 순서를 크게 바꿔 핵심 답을 도입 가까이 당기기(기준 3, 4 위반 위험).
- 분량을 맞추려고 같은 설명을 다른 말로 한 번 더 쓰기(기준 23).
- 쉬운 말로 바꾼다며 조건이나 비교 기준을 빼기(기준 21).
- “더 재미있게”라며 감정어, 과장, 질문을 늘리기(기준 16, 질문 비율 10% 초과).
- 시청자 경험을 넓혀 쓰기(“다들”, “누구나”)(기준 18).
- 고정 문구를 ‘조금만’ 다듬기(0-2 위반).
- 수정본에 화면 지시나 소제목을 넣기(0-1).
